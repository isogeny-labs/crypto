# Endomorphism-sum image factors for quartic-twist index calculus

Draft experiment design, 23 October 2026. No image-base experiment was
run or scheduled. The command in `card.json` names an unimplemented mode.

## Question and discriminating outcome

The [completed S4 prefix round](../../research/twist_index_calculus_20261020/s4_twist_elimination/REPORT.md)
repairs relation-finder completeness, but leaves full cold cost open.
The current physical base is already saturated by the 24-action's
automorphism images. This card tests a different operation: physical
points `(1-psi)(P)` for original factors P, with log coefficient
`1-lambda_cubic` relative to the same original orbit representative.

An increase in independent rows per original query changes the next
base-shape experiment. An increase in relations alone is insufficient.
Any improvement in completely counted cold cost must survive all
generation, deduplication, solving, matrix, memory and verification costs.
A null result or loss is retained on the same frozen panel.

## Proposed stages, to freeze before execution

1. Use the same seven p37/p73/p97 public synthetic generator/target
   instances, signs, orbit maps and original processed residual prefixes.
   Pin all input hashes. Construct each image by group operations and
   independently verify its claimed scalar coefficient in the group.
   Explicitly retain infinity, kernel, duplicate-abscissa and coincident
   factor cases; do not assume an image lies on either original line.
2. Compare original L2 peels with original L2 plus image-factor peels,
   keeping the other three factors on the original L0 base. Use the
   existing exact S4 coefficient path on each remaining abscissa and the
   repaired F4 solver. New physical factors reuse known coefficients;
   they do not receive new logarithm columns or extra independent rows
   merely for being symmetry images.
3. Construct a separate group-pair oracle only for post-run checking.
   Compare complete signed sets, distinct traces, every row and right
   side, rank progress and verified target/factor logarithms. Preserve
   source and target component labels and distinguish physical-point
   deduplication from matrix-row dependence.
4. After complete counters exist, run cold first/A/A and at least five
   isolated interleaved comparisons, keeping target, resource envelope
   and stop condition fixed. Report strongest same-target twist24 rho
   and the calibrated 0/0.1/1 GAE band. Export the identical polynomial
   systems to msolve/Magma before any fastest-solver statement.

## Prerequisites and cost derivation

The new native mode, independent checker, checkpoint/resume schema and
complete F4/cold-pipeline counters do not exist. The frozen protocol and
implementation commit must be supplied before this card becomes ready.
The original panel contains 46,200 finite signed L2 systems; adding image
factors changes the number of peels and can change residuals to rank, so
that old count is not an estimate for the proposed computation. The
8 GiB/1,200 s envelope is a proposed initial cap, not a predicted runtime.
Core-hour and wall-hour estimates stay null until a bounded pilot supplies
the inputs for an explicit derivation. Funding is zero while this remains
an unscheduled draft; no cairn objective or lease has been posted.

## What done means

An exact input-pinned image/action census, complete independently checked
signed relation sets and matrix recovery, deterministic replay, full cost
or an explicitly scoped incomplete-cost result, and source-linked run
reports with figures and inspected PDFs. Every miss, exceptional factor,
regression, timeout and unpriced phase stays visible. No claim of a new
automorphism order, generic asymptotic improvement or practical crossover
follows merely from this construction.
