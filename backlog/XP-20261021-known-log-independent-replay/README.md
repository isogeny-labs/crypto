# Independently validate arbitrary-target known-log recovery

Status: **blocked**, unfunded, not posted to cairn. The completed local
[study](../../research/ecbench_known_log_targets_20261021/README.md) has 3,610
identical measured replays on its measuring host. Its independent-host and
headline-recomputation obligations remain open; this card is not an active task.

The eight list shards name the exact sealed sessions. On another host class,
build ecbench from the final merged source with the committed lockfile and run
each card command. Do not overwrite sessions or original receipts. Preserve
the first cofactor panel's 144 setup errors; only verified measured executions
are replayed. Each scalar must satisfy the public target and every native
count must reproduce. Totals should reproduce 4,484 recorded executions,
4,340 verified and 3,610 identical measured replays, including controls and
warmups in the record totals.

A separate independent validator must recompute per-curve cold means, paired
target-cluster intervals and the 0/0.1/1 native-cost band from raw records.
It must check both A/A arms and the matched negation-rho reference. The local
author's summarizer is available for comparison but is not an independent
validator. Supply a real verifier command, protocol blob, merged code commit
and replayable checkpoint policy before marking this card ready.

The planning estimate is one core-hour/wall-hour: a local release build took
about ten minutes and all toy-curve panels plus replays finished within the
same order of magnitude; rounding upward allows cross-host overhead. Four GiB
RAM and disk cover the single-thread build/replay working set and an existing
sparse checkout. These are estimates, not measured independent-host costs.
Preserve any resource failure and revise the estimate from its evidence.

Done means real independent replay and validator certificates meeting
[the validation gate](../../docs/VALIDATION_GATE.md), with every scalar and
headline bound to the exact source/target/record set. A mismatch produces a
correction report and blocks admission. Agreement validates the current
modeled-cost result only: native calibration, isolated wall measurements,
strongest external comparators, actual amortization and asymptotic conclusions
remain separate, as recorded in the
[problem](../../problems/known-log-recovery-cost-and-validation.md).
