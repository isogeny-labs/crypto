# Automorphism paper follow-ups

Status: **blocked**. This card preserves proposed work from the DGM paper review;
it is not a launched experiment. No code, fixture or verifier is pinned, and
the commands in [card.json](card.json) name a future harness.

Read the [research report](../../research/automorphism_ideas_20261021/README.md)
and [draft protocol](PROTOCOL.md). DGM-01 is the first bounded correctness
ablation. DGM-02 through DGM-05 have independent map, walk, native-reproduction
or full-literature gates. Split them into pinned child cards before independent
scheduling; this umbrella card does not silently activate every workstream.

The one-hour/one-CPU envelope is a proposed toy correctness cap, not a measured
cost estimate. Funding is zero. No lab task or objective has been published.
Before ready, implement and independently verify the native harness, choose exact
registered fixtures and seeds, define checkpoints, freeze the protocol blob,
pin code, estimate cost and validate with the repository's native backlog tool.
