This draft preserves the complete requested audit as fifteen falsifiable
experiments. The scientific design, controls, model corrections, outcome rules,
atlas mappings, execution order and sources are in the
[campaign plan](../../research/ecdlp_mechanism_falsifiers_20261101/PLAN.md).

funding is zero, and no Cairn task, EKS job, checkpoint or lease was created.

## Before promotion

Split this umbrella into focused cards whose rows share one scientific question,
instrument, control set, measurement class and resource envelope. Each child
must implement a native producer and independent verifier, complete a disjoint
preflight, freeze `PROTOCOL.md` and `experiment.protocol/v1` before data, bind a
merged source/image identity, and route supported x86 work through Iso Lab on
EKS Spot. The interpolation child additionally requires the full
Lange--Winterhof COCOON 2002 theorem text; the paywalled preview is not enough.

A finite failed search records `not_found_within_family_and_budget`, never a
general obstruction. A literal counterexample can refute the literal claim;
proof-kind closure still requires a theorem or checked proof with matching
hypotheses. Results return in focused PRs with raw rows, unified export,
research visual/PDF, independent review, and any affected atlas update.
