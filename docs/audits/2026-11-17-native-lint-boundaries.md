# Native checker interfaces and strict linting

This repair keeps the existing original-protocol source, owner types, wire tags,
limits and failure payloads. Compiler checks still run with warnings denied.
Local validation and annotations do not grant producer completion, measured
execution, training admission or scientific authority.

The host compiles checker interfaces also retained for independent proof/replay
contexts. Declaration-scoped dead-code annotations preserve those interfaces and
the owned residual data they carry. No ignored test, global dead-code allowance,
protocol activation, or removal of a checker is introduced. The natural-plan
schema helper is compiled with its actual test-only callers. Explicit x86 SIMD
names remain available on other architectures with a scoped architecture note.

Repeated source modules intentionally create distinct Rust owner types. A local
Clippy-driver control verified that a declaration-scoped duplicate-module
annotation works. Those declarations retain distinct contexts rather than
sharing types across owner boundaries.

Large errors and enum variants return or retain the admitted owner and payload.
Boxing would add an allocation on a refusal path, including allocation refusal,
and would require a changed charging protocol. The repair documents the
by-value boundary at those functions and enums; it does not introduce a heap
allocation to satisfy a size heuristic.

Visibility is narrowed to the actual owner context. Checkpoint cadence is not
made publicly constructible. Native variable-allocation refusal continues to
return an empty range. The serialized `recorded_unknown` status is retained.

Integration all-target Clippy passes in both default and wide builds, including the enabled maintained example harnesses. Functional example checks pass in both builds. [pcc:unverified]
Frozen source and artifact bindings are checked separately; a passing lint is
not a proof that an optional stage is registered or complete.

The deferred-pair source is also included directly by comparison examples. Its
unit and adapted backends remain public for the sibling comparison; local
unused annotations preserve those entry points and the adapted backend variant.
The maintained native solver adapter checks the 64-bit request boundary in wide
builds instead of truncating masks; the archived source hash remains bound.
