# Weak-curve families

[Browse the catalogue](index.html): 21 family or condition entries and 814 exact synthetic model records. The [family JSON](catalog.json) records hypotheses, recognition, construction, sources and evidence status. The complete 294-class p7 oracle is searchable alongside the models. The [model index](models.json) preserves exact ICV1 identities, model parameters, source bindings, model/class labels and unknown subgroup costs.

[Report and reproduction](../../../research/weak_curve_catalog_20261010/REPORT.md) and [protocol](../../../research/weak_curve_catalog_20261010/PROTOCOL.md) describe the evidence contract. Inventory counts are not empirical family densities. Exact p7 labels, larger-degree geometry controls and unresolved independent large-field sources are separate scopes.

Add a family with its field/subgroup domain, necessary or sufficient predicates, a construction or finite enumeration description, completeness boundary, source and validation status. Add an instance under its existing ICV1/EC1 identity with immutable evidence; assign each property independently.

The [genus 2–8 criteria audit](../../../research/weak_curve_criteria_20261114/REPORT.md)
adds an exact bounded embedding-degree test for MOV/Frey–Rück screening and
cross-checks the current registry's model-bound cover certificates against
selected subgroup orders. Its [command-line checker](../../../research/weak_curve_criteria_20261114/audit.py)
filters by genus, ICV1/EC1 identity, or a supplied field size and subgroup
order. The output distinguishes a pairing divisibility witness, a same-field
cover, a conditional subgroup transfer, and a proposed descent route.

The [complete N=15 generalized GHS profile screen](../../../research/ghs_genus6_7_profile_20261114/REPORT.md)
adds 1,922 genus-6 and 30,721 genus-7 descendable parameter profiles for
one exact binary curve over the `GF(2^5)` tower. An independent field-arithmetic
replay checks every nonzero Hess parameter. These are structural candidates;
the smooth covers and selected-subgroup maps remain construction tasks.

[Conjectures and discovery methodology](../../../research/weak_curve_conjectures_20261012/README.md)
tracks seven open hypotheses, a refuted screening hypothesis, the published-class
backlog and a staged protocol for additional families and 192–252-bit structural
validation. These hypotheses are separate from the existing 21
family-or-condition entries and do not change existing model labels.
