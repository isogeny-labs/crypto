# Plane-curve and genus 2–5 index calculus implementation status

Status: work in progress, `[pcc:unverified]`. This tracks the requested table across `crypto` and `cryptanalysis`. The entries describe code paths, not a claim that they achieve the complexity bounds in the cited papers or beat a matched rho run.

| Requested row | Existing Rust path | Work needed for the requested algorithm |
|:--|:--|:--|
| Smooth plane curves, degree `d` (Diem 2006/2011) | `crypto/src/cryptanalysis/plane_quartic_pic.rs` gives a quartic `Pic^0` group law; `diem_quartic.rs` and `research/quartic-diem-sparse_20261115/src/qds_core.rs` collect quartic line relations. `plane_curve_geometry.rs` supplies bounded degree-`d` homogeneous evaluation, rational tangents, line sections with multiplicities, and fully rational line-divisor differences. A smooth cubic example yields the explicit `2P-2O` line relation. | Generalize the divisor/group representation beyond quartics, extend line-section factoring beyond rational scans, and verify full DLP solves on smooth public fixtures. The geometry primitive does not certify global geometric smoothness; the existing target descent is specific to the quartic study. |
| Genus 2 (GTTD) | `crypto/src/cryptanalysis/hyperelliptic_index_calculus.rs`, `order_free_hyperelliptic_ic/mod.rs`, and `cryptanalysis/suite/src/highgenus/ic.rs` offer generic hyperelliptic IC. The former has an opt-in two-large-prime graph collector and verified-scalar DLP entry point, replayed by `research/hec_two_lp_replay_20261128`. | The exact-source narrow harness passed graph algebra, including repeated places, Jacobian identities, and genus-2 toy DLP recovery; the full root suite still needs a full checkout. Checked `i64` coefficient overflow can discard a cycle; no complete cost comparison. This row is lower priority because its exponent ties rho. |
| Genus 3 non-hyperelliptic (Diem–Thomé / Laine–Lauter) | The quartic `Pic^0` and Diem line-relation paths above, plus `crypto/src/bin/quartic_diem_sparse.rs`. | Consolidate into a reusable end-to-end solver for arbitrary eligible smooth quartics, with independent small-instance replay and a qualified cost comparison. `crypto/src/cryptanalysis/quartic_diem_solver.rs` now exposes a bounded coordinate-input API (q ≤ 131071) that checks the subgroup and verifies the returned scalar; it is still a research solver. |
| Genus 3 hyperelliptic (GTTD; Smith isogeny + Diem) | The generic hyperelliptic IC path above passes genus-3 toy recovery. `crypto/src/cryptanalysis/smith_isogeny.rs` accepts public source Mumford classes, transfers them independently to the existing Picard-class Diem solver, and verifies any scalar again on the source Jacobian. The executable `examples/smith_public_replay.rs` recovered scalar 36 on Smith Example 1 over `F_37` and checked it on the source Jacobian; the Smith construction remains toy-scale. | Run the root test when the build fits. The separate supplied-coordinate quartic solver uses degree-three affine ideals rather than Picard conic-net classes, so that representation bridge and a full cost qualification remain open. |
| Genus 4/5 hyperelliptic (GTTD) | The generic hyperelliptic IC engines handle these genera on supported one-point models; `cryptanalysis/suite/src/highgenus/cantor.rs` supplies group arithmetic. The opt-in two-large-prime collector, now accepting repeated off-base places, passed genus-4/5 combined-relation identity and verified-scalar toy DLP replay over `F_11`. | Test larger public instances and qualify full costs; this is not a measured GTTD improvement. |
| Genus 4/5 non-hyperelliptic (Diem plane model of degree `g+1`) | `cryptanalysis/suite/src/highgenus/kummer.rs` handles a restricted non-hyperelliptic superelliptic family. Draft cryptanalysis PR #2024 exposes degree-five birational charts `f2(x)u³=f1(x)` for standard genus-4/5 trigonal models and maps ordinary affine chart points to canonical Kummer ideals. It also factors completely rational horizontal sections `u=c` and verifies equal divisor classes for two heights in each genus (`F_11` at genus 4, `F_17` at genus 5). `crypto/src/cryptanalysis/plane_curve_geometry.rs` computes general line sections but does not normalize singularities. | Transfer arbitrary line-divisor relations across exceptional fibers and infinity, then build Diem target descent and certify a full DLP. A smooth plane quintic has genus 6 and a smooth sextic has genus 10, so these genus-4/5 plane models are singular. The restricted Kummer chart is not general plane-model arithmetic. |
| Linear algebra modulo `n` (block Wiedemann) | `crypto/src/cryptanalysis/koblitz_sparse_la.rs` and `large_prime_graph/block_wiedemann.rs` provide native block Wiedemann paths; `cryptanalysis/suite/src/highgenus/ic.rs` has dense elimination. `plane_curve_sparse.rs` maps rational plane-line relations and reserved target-descent coefficients into `SparseRow<u64>`. `cado_bwc_io.rs` exports any square row system in the repository's CADO `bwc` matrix/RHS format and verifies a returned solution against every input row. The small planted matrix replay checks the native solve, exact export bytes, and mock CADO solution validation. | Build enough genuine curve and target relations for a full-rank DLP system and certify the resulting scalar on the Jacobian. The suite high-genus path peels singleton columns before dense elimination (cryptanalysis PR #2010). Run external CADO-NFS `bwc` on a curve-derived square system; only format and mock-solution checks have run here. |

The next code milestone is a normalized divisor representation for general plane models and a transfer-compatible input format. Keep every target within the repositories' public benchmark and toy-instance policy.
