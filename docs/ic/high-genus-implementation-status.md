# Plane-curve and genus 2–5 index calculus implementation status

Status: work in progress, `[pcc:unverified]`. This tracks the requested table across `crypto` and `cryptanalysis`. The entries describe code paths, not a claim that they achieve the complexity bounds in the cited papers or beat a matched rho run.

| Requested row | Existing Rust path | Work needed for the requested algorithm |
|:--|:--|:--|
| Smooth plane curves, degree `d` (Diem 2006/2011) | `crypto/src/cryptanalysis/plane_quartic_pic.rs` gives a quartic `Pic^0` group law; `diem_quartic.rs` and `research/quartic-diem-sparse_20261115/src/qds_core.rs` collect quartic line relations. | Generalize the divisor/group representation beyond quartics, implement degree-`d` relation geometry and verify full solves on smooth public fixtures. The existing target descent is specific to the quartic study. |
| Genus 2 (GTTD) | `crypto/src/cryptanalysis/hyperelliptic_index_calculus.rs`, `order_free_hyperelliptic_ic/mod.rs`, and `cryptanalysis/suite/src/highgenus/ic.rs` offer generic hyperelliptic IC. The former now has an opt-in two-large-prime graph collector and verified-scalar DLP entry point, replayed by `research/hec_two_lp_replay_20261128`. | The exact-source narrow harness passed graph algebra, Jacobian identities, and genus-2 toy DLP recovery; the full root suite still needs a full checkout. Unit-coefficient partials only; no complete cost comparison. This row is lower priority because its exponent ties rho. |
| Genus 3 non-hyperelliptic (Diem–Thomé / Laine–Lauter) | The quartic `Pic^0` and Diem line-relation paths above, plus `crypto/src/bin/quartic_diem_sparse.rs`. | Consolidate into a reusable end-to-end solver for arbitrary eligible smooth quartics, with independent small-instance replay and a qualified cost comparison. `crypto/src/cryptanalysis/quartic_diem_solver.rs` now exposes a bounded coordinate-input API (q ≤ 131071) that checks the subgroup and verifies the returned scalar; it is still a research solver. |
| Genus 3 hyperelliptic (GTTD; Smith isogeny + Diem) | The generic hyperelliptic IC path above passes genus-3 toy recovery. `crypto/src/cryptanalysis/smith_isogeny.rs` now accepts public source Mumford classes, transfers them independently to the existing Picard-class Diem solver, and verifies any scalar again on the source Jacobian; the Smith construction remains toy-scale. | Run the new public-source bridge test (the root library check passed, but the root test build exceeded the workspace memory budget). The separate supplied-coordinate quartic solver uses degree-three affine ideals rather than Picard conic-net classes, so that representation bridge and a full cost qualification remain open. |
| Genus 4/5 hyperelliptic (GTTD) | The generic hyperelliptic IC engines handle these genera on supported one-point models; `cryptanalysis/suite/src/highgenus/cantor.rs` supplies group arithmetic. The opt-in two-large-prime collector passed genus-4/5 combined-relation identity and verified-scalar toy DLP replay over `F_11`. | Extend beyond unit off-base coefficients, test larger public instances, and qualify full costs; this is not a measured GTTD improvement. |
| Genus 4/5 non-hyperelliptic (Diem plane model of degree `g+1`) | `cryptanalysis/suite/src/highgenus/kummer.rs` handles a restricted non-hyperelliptic superelliptic family. | Build smooth plane quintic/sextic model arithmetic and Diem relation/descent machinery. The superelliptic engine is not a general plane-model implementation. |
| Linear algebra modulo `n` (block Wiedemann) | `crypto/src/cryptanalysis/koblitz_sparse_la.rs` and `large_prime_graph/block_wiedemann.rs` provide native block Wiedemann paths; `cryptanalysis/suite/src/highgenus/ic.rs` has dense elimination. | Connect curve relation formats to a verified sparse solver. The suite high-genus path now peels singleton columns before dense elimination (cryptanalysis PR #2010). CADO-NFS `bwc` is not wired in. |

The next code milestone is an independently replayed quartic DLP API and a transfer-compatible input format, since the quartic path is the shared destination for the genus 3 non-hyperelliptic row and the Smith transfer row. Keep every target within the repositories' public benchmark and toy-instance policy.
