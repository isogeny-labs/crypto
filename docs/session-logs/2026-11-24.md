### Decisions made (and why)

Treat this as the closure of the lane's "full relation/LA/descent" open item,
not as a new map sweep: the question was whether Algorithm 1 completes with the
paper's map at `|V| = p^(1/m)`, and it does, at every rung to 18 bits.

Keep the two completion rules separate. `incremental-gauss-full-rank-checked`
at 16 bits wants rank 135 and saturated at 134 over 420 rows / 1 000 targets
(286 dependent), although the target was pinned at rank 50 / target 128 and
`incremental-gauss` verifies `k = 60091`. The strict certificate is stronger
than Algorithm 1 step 5 and is the thing that fails there.

No speedup claim: at `m = 2` and `|V| = p^(1/2)` the algorithm needs `2√p`
targets, so it costs `≈ 2√p·T` against rho's `√p`; §3.2 says the win needs
larger `m` or cheaper `T`. Measured `s/ρ` is `2·10^4`–`4·10^7`.

All five recover the same planted scalar and pass the group-law check. `m = 1`
is refused by the oracle (`mode Chain takes m in 2..=6, not 1`) and is
degenerate: `S_2 = x1 − X`, so the paper's `|V| = p` would make the base the
whole curve.

At `m = 5, 6` the F4 exceeded its degree bound on every system
(`budget_exceeded == calls`, `D = 0`) and the exact `|V|^m` grid decided; the
low cost per target there (47 k and 43 k GAE) is enumeration, not Gröbner
work.

Source change: raised the chain cap `2..=5 → 2..=6` in
`pkm_semaev.rs` (`MAX_FREE = 4 = m − 2`), rebuilt with
`~/.cargo/bin/cargo +1.99.1` and `RUSTC=~/.cargo/bin/rustc` because the
Homebrew default is 1.93.1, which the AWS deps reject. New binary
`3c22886c…`; the `m = 5` rerun on it is identical (129 targets, 0.031, 2683).

### Decisions made (and why)

Report the `m = 5, 6` rows as relation-density measurements with an exhaustive
decider, not as algebraic relation search: at a real `|V| = p^{1/m}` that grid
is `p`. Therefore the `m`-axis is blocked by the `S_{m+1}` chain solver at
`m = 5` on a 12-bit field, well before the factor base is the limit.

Killed the 20-bit `m = 2, t = 10` run (still running after 2 h) to free the
machine for this sweep; it is resumable and remains a nice-to-have.

### Open threads (unfinished, pick up next time)

A cheaper `S_6`/`S_7` chain solver is the gate for `m ≥ 5`; without it the
route cannot be measured at `|V| = p^{1/m}`. The 20-bit `t = 10` rung is
