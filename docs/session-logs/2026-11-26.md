### Decisions made (and why)

- Production gets the ADX/mulx kernel only where it measured faster, chosen
  once per scalar multiplication after the CPU check (no per-op check).
- Half-GCD thresholds from true-Euclid baselines and a leaf sweep; separate
  thresholds for xgcd/inverse and plain gcd because classical gcd (no
  cofactors) is much cheaper.
- Sites with recorded op counters, certificate traces, work gates, hash
  pins or separate crates were not routed: changing the algorithm there
  would change recorded accounting or break provenance checks.
- PR #5173 was merged by the owner mid-work; the force-push to restart the
  branch was denied, so main was merged into the existing branch instead and
  a new PR (#5209) opened.
