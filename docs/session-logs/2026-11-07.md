## 2026-11-07 — IC optimization audit and three delegated fixes

### What was done (commands, files, features)

- Audited the index-calculus pipeline (relation collection, linear algebra,
  field and group arithmetic) with three read-only audit agents and a code
  read of `ic_framework/residual.rs`. The work started 2026-10-27; the
  delegated agents were cut off by a model usage limit and resumed today.
- Delegated three fixes to Sonnet agents in sparse worktrees (local commits,
  local L0 sandbox measurements only, nothing on EKS):
  - `claude/ic-gauss-20261027`: `incremental-gauss-echelon`
    (`ic_framework/linalg.rs`), forward elimination only, sparse pivot rows,
    Shoup multiply. 1,200 random systems: same row status, pin row, value
    and rank as `incremental-gauss`. End to end (R-p18 `plan`, `m141`;
    B-hb19 `plan`, 16 targets × 4 rounds): identical trials, relations,
    answers and S; LA `row_ops` 0.59–0.61×. Evidence:
    `research/ic_gauss_echelon_20261027/`.
  - `claude/ic-residual-20261027`: `targets=residual-fused`
    (`ic_framework/residual_fused.rs`), one addition per walk step instead
    of two. Old `residual` walk: 16/16 records byte-identical against the
    main 0e5689117 binary. S at w = 0: fused/old 0.885 (p16), 0.772 (p18),
    0.584 (p36); fused/rho at p36 1.50 (res2 was 2.57). Evidence:
    `research/ic_residual_fused_20261027/`.
  - `claude/ic-arith-20261027`: Barrett multiply for p < 2^32 under
    `CountedFp`, `FastMap` in `fiber.rs`/`large_prime.rs`, opt-in
    `release-lab` profile. Byte-identical (72/72 and 36/36 records), but
    end-to-end wall 0.983× and 0.995× within ~5% noise: no verified speedup.

### Decisions made (and why)

- New variants only (`incremental-gauss-echelon`, `residual-fused`): the
  existing arms must replay byte-identically for sealed evidence.
- The residual-fused table bytes were first counted with a different formula
  than `residual`'s, which made its §5a band look worse at w > 0. Both now
  charge `residual_table_bytes_uncharged` with `residual`'s formula; the
  stored bytes are reported as `residual_table_bytes_stored`.
- The arithmetic branch is not proposed for merge: it adds code for no
  measured gain. The audit's predicted 1.5–3× on the prime group law did not
  hold on this host (hardware division is fast; binary-GCD inversion measured
  2–4× slower).
- LA is priced at 0 GAE in S, so the echelon solver is a component speed-up,
  not a leaderboard row.
