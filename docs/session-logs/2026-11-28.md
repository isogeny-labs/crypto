### Decisions made (and why)

- Keep the compact artifact numeric and require the complete strict packing source separately. Eight summary fields can replay the final arithmetic, but cannot authenticate endpoint arrays, label traces, or the source class cap by themselves.
- Derive the projection from a successful native summary rather than accepting caller-supplied projection values in the node verifier. This narrows the remaining boundary to equality with the formal natural-number record and execution semantics.
- Use arbitrary-precision integers in the projection checker so the interface is not limited by the live `usize` allocation ceiling.
