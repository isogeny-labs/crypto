- `subgroup_index_b0.py` (p = 23, 37, 53): for b = 0 curves the subgroup generated by the trace image has index 2 in exactly the (curve, line) cases where N(g) is a square in F_p, and index 1 otherwise; generic curves are index 1 in all 4,400 cases.
- `descent_coset_test.py`: on ordinary curves with a rational 2-torsion point (r, 0) and lines V = r + F_p·g, the 2-isogeny descent class delta(P) = x(P) − r mod squares is constant on the trace image and equals the square class of N(g); index 2 exactly when N(g) is a square. 400/480, 720/720 and 1040/1040 split by class at p = 23, 37, 53; no mixed case.

### Decisions made
- Mechanism: delta is a homomorphism E(F_p) → F_p*/squares, and delta(Tr Q) = N(x(Q) − r) = t²·N(g) on such a line, a constant. Derived after the b = 0 finding; the tests above confirm it on toy fields only.
