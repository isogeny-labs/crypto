### Decisions made (and why)

- Corrected my own earlier estimate before building. A shared product/remainder tree over D is Õ(|D|) per node but carries log²|D| factors that exceed log p without FFT multiplication. The measured bottleneck was per-child F4 and allocation (about 26 µs wall vs about 5 µs counted per child at |D|=4096), so the algorithm removes the child F4 instead.
- Set equality (not sequence) is the guarantee when a child needs more than one substitution, because F4's variable choice is not reproduced. Exact sequence holds for one-level univariate children.
- Raw JSONL gzipped (5.9 KB) and the figure sized so its 150-dpi PNG is under 64 KiB (62 KB), so neither is store-bound. `artifacts.py plan` shows 0 files moving. The previous record's store migration remains blocked on credentials.
- Corrected two wrong derived ranges in the README prose before commit (m=2 vs Frobenius is 10–14×, m=3 vs Frobenius is 4.7–7.3×) and the fallback share (1.5–6%).
