### What was done (commands, files, features)

- Five changes were made, each on its own `ic-cache2/*` branch, merged into `aburan28/confident-sagan-cudszh`.
  1. **Factor-base log store for `ic.koblitz_descent`/`_v2`** (`src/cryptanalysis/koblitz_log_store.rs`, moved from `src/bin/ic/log_store.rs`; `ecbench/koblitz_descent.rs`, `methods.rs`, `runner.rs`, `record.rs`, `audit.rs`).
     - Opt-in with `log_store=<dir|env>`.
     - On a hit, every column is re-verified in a charged phase, and collection and linear algebra are skipped.
     - A hit record nulls `cost.s`/`total_gae`, sets `s_store`/`total_gae_store` and `cost_basis: "amortized"`, and is skipped by `ecbench amortize`.
     - Without the option, records are unchanged.
  2. **Method-aware `is_reusable_phase`** (`ecbench/work.rs`). This is an accounting correction, not an improvement.
     - `koblitz_descent` factor_base, oracle_setup, relations, linear_algebra and descent_setup now count as reusable.
     - `prime_orbit_relations_v1` relations now count as reusable.
     - S is unchanged. No pinned record changed.
  3. **`petit_quisquater` `PqLookup`.** The x-index, subspace set and V-basis are built once per run in all five drivers. The four public functions are now wrappers.
  4. **F4 trace replay** (`pq_f4_f2.rs`, solver option `trace=1`, default off). The verification is one charged F4 pass on the interreduced replay basis, with fallback to the plain path. Measured on 32 S_3 descents over F_2^13:
     - 31 replays, all of which fell back.
     - 382,248 word XORs against 133,813 plain (×2.86). This is a net loss.
  5. **Sparse LA attempt schedules** (`ic_framework/linalg.rs`, `name:schedule=fixed|geometric|predicted`, default fixed).
     - `predicted` keeps overshoot at or below `margin` but costs 1.9–5× the row_ops of `fixed`, because the filter's deficit bound is almost always 0.
     - `geometric` cuts row_ops by 10–55% but breaks the ~3% overshoot rule.
