### Decisions made (and why)

- Only bit-identical changes go into `Point::scalar_mul` (contract: equal to
  the `BigUint` ladder for every odd modulus); wNAF and the binary-GCD inverse
  go into `scalar_mul_vartime`, whose contract is "equal over a prime".
- Tuned kernel chosen on end-to-end `k·P`, not the isolated kernel loop: run 2
  showed the loop-favoured SOS/sqr choices at N ≤ 3 regressed `k·P` 1–3%.
- Karatsuba kept as a measured kernel, not used.
- Raw JSONL gzipped into Git (35–41 KiB each): artifact-store push refused
  (HeadObject 403 for this session's AWS identity).
- Measured locally, not on Iso Lab EKS: a component microbenchmark of a code
  change; recorded with isolation "local container" in the record.
