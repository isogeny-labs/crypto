# Koblitz crater versus level-1 neighbours

Browsing copy of the counts-only study in [`research/volcano_koblitz_layers_20261018/`](../../research/volcano_koblitz_layers_20261018/). It compares generic rho on Koblitz crater and level-1 curves for n = 19, 23, 37, 41, 61. All `rho.negation` ratios' intervals contain 1. One of ten `rho.plain` intervals excludes 1 (n = 41: 1.152 [1.021, 1.304]); this does not support the earlier ±8% claim, which the report retracts. The intervals remain too wide to rule out differences around 10–20%. No isogeny maps or transfer-attack costs were measured. Isolation L0; deterministic operation counts, no wall-time claim.
