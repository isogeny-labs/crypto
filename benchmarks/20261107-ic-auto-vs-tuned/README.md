# ic size=auto vs the tuned prime baseline (2026-11-07)

Equal at 20 bits. At 24 and 28 bits the auto base is cheaper at w = 0 (0.914, 0.885) but costlier at w = 1 (1.153, 1.107), so the order flips inside the band and this is not an improvement. The baseline is unchanged.
