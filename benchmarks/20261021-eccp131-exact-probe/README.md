This directory contains browseable copies of the [2026-10-21 run report](../../research/eccp131_bsgs_ic_20261020/reports/run-20261021T1534Z/REPORT.md), its inspected PDF, and both SVG/PNG graphs. The graphs are copied from that same plotting source.

The exact stage matrix reported five L0 descriptive whole-CLI medians per arm: 624.70 ms at B256; 835.47 and 720.66 ms in identical B512 A/A arms; 1,051.25 ms at B1024. All 20 bounded runs had zero natural relations and rank zero. A separate native `ecbench` 20-bit control had 24 verified records and full replay of all 18 measured records; its lower-bound IC/rho `S` ratio was 9.4076 [7.2188, 12.9316] across six pairs. The two runs use different curves and IC code paths and have no cross-curve ratio.

This diagnostic is **not an admitted `benchmarks/README.md` row**. The validation gate requires an independent replay certificate, an independent headline recomputation, and a matched rho reference for a row. The exact ECCp-131 stage run has no matched whole-solution rho reference or independent candidate replay, while the 20-bit control's replay was on the producer host class. Adding a row now would misstate that evidence and fail the gate.
