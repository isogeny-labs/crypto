# Catalog generator replay protocol

This is a local software control for generating the existing searchable catalog. It does not measure an elliptic-curve algorithm or supply a rho comparison.

Freeze the protocol and both source hashes in a code commit. Open all four benchmark records from that same clean commit, then execute the declared baseline/candidate/candidate/baseline order before closing any record. Each arm checks the complete document against the committed display and an independently normalized semantic digest. Only the generator's documented volatile citation counters are excluded from that digest. Materialized local inputs remain authoritative.

The baseline loads the original generator from the immutable commit named in `protocol.json`; both variants run against the same current workload commit. Timing covers the generator main function, including build, render and document comparison. Python/module import and the independent digest are outside that interval. Host execution is unisolated, so the observations describe this local software workload.

Each arm writes a raw JSON receipt and a separate `bench.record/v1` entry. The existing benchmark-record CI uploads tracked raw inputs to S3 and checks custody before merge. Retain unsuccessful arms with their actual status. Interpret any timing comparison within this component and workload.
