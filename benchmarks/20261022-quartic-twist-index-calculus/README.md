# Quartic twist index-calculus visual record

This directory copies the [source study's results PDF](../../research/twist_index_calculus_20261020/QUARTIC_TWIST24_REPORT.pdf), the [mixed-polynomial results PDF](../../research/twist_index_calculus_20261020/MIXED_POLYNOMIAL_REPORT.pdf), 65 run-report PDFs and their graphs as SVG and 150-dpi PNG. The source [reports](../../research/twist_index_calculus_20261020/QUARTIC_TWIST24_REPORT.md), [mixed-polynomial report](../../research/twist_index_calculus_20261020/MIXED_POLYNOMIAL_REPORT.md), [run index](../../research/twist_index_calculus_20261020/MIXED_POLYNOMIAL_RUNS.md), raw records, native audits and frozen protocol remain in `research/twist_index_calculus_20261020/`. The original 36 runs cover the structural and exact-oracle work. The new 29 reports preserve the five-pattern S5/S4/S3 pilot, failed generic k=2 solver, two final-source A/A runs per pattern, four S5 degree retries, and the full restricted-pattern one-target polynomial controls with their A/A copies.

The studies compare counted field multiplications and group operations on a shared-host L0 panel. The dense exact-oracle p=37 one-target path uses 119,740,945 versus 4,048,104,018 counted `Fp M` (33.807× lower), combining dense relation retention and a public known-log anchor. The combined tagged/dense producer uses **89,828,606 `Fp M` and 848,000 group operations** on the same base, target and first residual, compared with the full-table dense producer's 119,740,945 and 1,204,356 (1.333×/1.420× lower in separate count units). On the separate 48-point mixed-line **polynomial** path, the k=1-only one-target run recovers 271 at rank four in eight residuals with independently audited complete signed sets: **116,050,118 `Fp M` and 3,936 group operations** versus same-process twist24 rho's 348,941 and 2,745 in separate units. The adaptive k=1-only path uses 3.928× fewer counted `Fp M` than the k=1,2,3 path on this target, but is still far above rho's counted field work. The initial native S5 k=0/4 arms remain incomplete after degree-30/31 retries. No same-input external-tool comparison exists, and native hash/allocator CPU, memory and calibrated GAE are missing. The study has no admitted polynomial one-target `S` or 0/0.1/1 GAE band. This visual record is **not** a validated benchmark row under [`docs/VALIDATION_GATE.md`](../../docs/VALIDATION_GATE.md). It is intentionally absent from `benchmarks/README.md` and the priced IC-versus-rho leaderboard tables until that gate is met; the counted component results appear outside those tables.
