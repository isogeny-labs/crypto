# Quartic twist index-calculus visual record

This directory copies the [source study's results PDF](../../research/twist_index_calculus_20261020/QUARTIC_TWIST24_REPORT.pdf), 36 run-report PDFs and their graphs as SVG and 150-dpi PNG. The source [report](../../research/twist_index_calculus_20261020/QUARTIC_TWIST24_REPORT.md), raw records, native audits and frozen protocol remain in `research/twist_index_calculus_20261020/`. The runs cover three two-query native S5 pilots, an exhaustive two-dimensional invariant-space census, p=13 and p=37 full-2D exact-oracle IC solves, a twist-quotient pair-table oracle, three action-tagged pair-index variants on two curves, a full 53-residual pair-index replay, dense same-residual anchored solves on both curves, and a combined tagged/dense p=37 solve with a final-source rerun; all have registered A/A controls. The final-source rerun matches the first combined run in every non-timing JSON field.

The studies compare counted field multiplications, group operations, requested allocator bytes and modular row operations on a shared-host L0 panel. The dense exact-oracle p=37 one-target path uses 119,740,945 versus 4,048,104,018 counted `Fp M` (33.807× lower), combining dense relation retention and a public known-log anchor. The combined tagged/dense producer uses **89,828,606 `Fp M` and 848,000 group operations** on the same base, target and first residual, compared with the full-table dense producer's 119,740,945 and 1,204,356 (1.333×/1.420× lower in separate count units). The S5 results have no same-input external-tool comparison (msolve and Magma were unavailable), and no external implementation of the same action-tagged pair-index computation was compared. The study has no admitted polynomial one-target `S` or 0/0.1/1 GAE band. This visual record is **not** a validated benchmark row under [`docs/VALIDATION_GATE.md`](../../docs/VALIDATION_GATE.md). It is intentionally absent from `benchmarks/README.md` and the priced IC-versus-rho leaderboard tables until that gate is met; the counted component results appear outside those tables.
