# Quartic twist index-calculus visual record

This directory copies the [source study's results PDF](../../research/twist_index_calculus_20261020/QUARTIC_TWIST24_REPORT.pdf), the [mixed-polynomial results PDF](../../research/twist_index_calculus_20261020/MIXED_POLYNOMIAL_REPORT.pdf), the [larger-curve scaling PDF](../../research/twist_index_calculus_20261020/K1_SCALING_REPORT.pdf), the [ideal thinning survey](../../research/twist_index_calculus_20261020/K1_ORBIT_THINNING.pdf), the [native thinning report](../../research/twist_index_calculus_20261020/K1_THIN_NATIVE_REPORT.pdf), the [peeled-orbit reuse report](../../research/twist_index_calculus_20261020/K1_PEELED_ORBIT_REUSE.pdf), **132 run-report PDFs** and their graphs as SVG and 150-dpi PNG. The source [reports](../../research/twist_index_calculus_20261020/QUARTIC_TWIST24_REPORT.md), [mixed-polynomial report](../../research/twist_index_calculus_20261020/MIXED_POLYNOMIAL_REPORT.md), [scaling report](../../research/twist_index_calculus_20261020/K1_SCALING_REPORT.md), [polynomial run index](../../research/twist_index_calculus_20261020/K1_SCALE_RUNS.md), [census run index](../../research/twist_index_calculus_20261020/K1_CENSUS_RUNS.md), [native thinning run index](../../research/twist_index_calculus_20261020/K1_THIN_NATIVE_RUNS.md), raw records, native audits and frozen protocol remain in `research/twist_index_calculus_20261020/`. The original 65 reports cover the structural, exact-oracle and p=37 polynomial work. The next 25 preserve the p=37 generalized-source control, six p=73/p=97 first/A/A polynomial pairs, and six first/A/A complete-stream occupancy pairs. The further 42 preserve every first/A/A native thinning arm. [K1_VISUALS.json](K1_VISUALS.json) records SHA-256 equality for all 216 newly copied files.

The studies compare counted field multiplications and group operations on a shared-host L0 panel. The dense exact-oracle p=37 one-target path uses 119,740,945 versus 4,048,104,018 counted `Fp M` (33.807× lower), combining dense relation retention and a public known-log anchor. The combined tagged/dense producer uses **89,828,606 `Fp M` and 848,000 group operations** on the same base, target and first residual, compared with the full-table dense producer's 119,740,945 and 1,204,356 (1.333×/1.420× lower in separate count units). On the separate 48-point mixed-line **polynomial** path, the k=1-only p=37 one-target run recovers 271 at rank four in eight residuals with independently audited complete signed sets: **116,050,118 `Fp M` and 3,936 group operations** versus same-process twist24 rho's 348,941 and 2,745 in separate units. The p=73/p=97 polynomial extensions recover all six one-target scalars, with one partial p=73 signed-set audit, and use 1,788–17,249 times matched rho's counted `Fp M`. A complete-stream independent group census records 167 signed k=1 relations in 359 p=73 residuals and 79 in 1,497 p=97 residuals; a scalar-keyed BSGS audit matches all 1,856 per-query signed-set digests. The 21-case native orbit-thinning grid compares every frozen prefix choice, preserving four partial p=73 seed-one relation sets; its full-base and subset costs are charged in the counted path. A separate exact symmetry-reuse test finds only two same-residual orbit collisions among 142,248 finite S4 peels and 788 more within-stream cache opportunities. The initial native S5 k=0/4 arms remain incomplete after degree-30/31 retries. No same-input external-tool comparison exists, and native hash/allocator CPU, memory and calibrated GAE are missing. The study has no admitted polynomial one-target `S` or 0/0.1/1 GAE band. This visual record is **not** a validated benchmark row under [`docs/VALIDATION_GATE.md`](../../docs/VALIDATION_GATE.md). It is intentionally absent from `benchmarks/README.md` and the priced IC-versus-rho leaderboard tables until that gate is met; the counted component results appear outside those tables.
