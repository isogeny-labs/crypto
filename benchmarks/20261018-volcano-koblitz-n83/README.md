# Koblitz n = 83, ℓ = 6473 structure and construction cost

Browsing copy of [`research/volcano_koblitz_n83_20261018/`](../../research/volcano_koblitz_n83_20261018/). Native CRT construction used 9,864 primes and took 8,590 seconds on three threads; the resulting Φ₆₄₇₃ construction yielded 6,474 distinct level-1 j-invariants, matching the expected count. All 48 sampled neighbours had exactly one twist of order N; none of eight random-j controls passed. This is a volcano-structure/build study, not an ECbench or rho comparison: no n = 83 solver timing and no isogeny maps were produced.
