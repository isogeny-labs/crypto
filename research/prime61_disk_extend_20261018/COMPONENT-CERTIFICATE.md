# Exact size of the selected-prime subgroup

The additive certificate establishes that the eight selected prime-form
classes generate a subgroup H of **545,296,208** proper ideal classes.
It does not certify that H is the whole class group. Under the standard
ordinary maximal-order CM class action, this is also the size of the
selected-prime curve component, rather than a count of enumerated curves.
The frozen preceding [genus report](CLASS-COVERAGE.md) and 512 checkpoint
remain unchanged.

## Witnesses and argument

The discriminant is D=-6649310858224389603. Write p=34081013 and
n=2p=68162026; p is checked prime. Let A=(7,5,237475387793728201) and
G=A²=(49,-9,33925055399104029), with multiplication in Cl(D).
The old exact-order certificate for A is replayed and G has exact order p:
G differs from the principal reduced form and G^p is principal.

Let the ordered involution basis be

1. T0 = (3,3,554109238185365801), the degree-3 class;
2. T1 = A^p = (10426821,10426821,159430654291);
3. T2 = C11^p = (113,113,14710864730584961);
4. T3 = C61^p = (97,97,17137399119135049).

Every T_i squares to the principal form. All 16 subset products have
distinct canonical reduced forms, so they generate C2^4. The odd cyclic
subgroup generated by G intersects this exponent-two subgroup trivially.
Because proper ideal classes form an abelian group,
H0=<G,T0,T1,T2,T3> has order p*16=545296208.
Every basis element belongs to H by its definition. Conversely these
explicit relations put all eight selected classes inside H0; mask bit i
selects T_i:

| ---: | ---: | ---: |
| 3 | 0 | 1 |

Thus H=H0. Every relation is checked by exact reduced-form composition;
no whole-class-number oracle, GRH assumption or genus theorem is needed
for this subgroup-order argument. Choosing inverse prime orientations
leaves the generated subgroup unchanged.

## Coordinates and limits of formalization

Equivalently H is C68162026 × C2^3, with cyclic generator A and the three
involutions T0, T2, T3. This supplies potential unique coordinates
(a,b), 0<=a<68162026, 0<=b<8, for every class in this component.
[ComponentCoordinates.lean](proof/ComponentCoordinates.lean) proves that
the finite mixed-radix encoding a+68162026*b has inverse quotient/remainder
and that the coordinate count is 545296208. The project has fourteen
explicitly authored theorems; the repository gate audits sixteen, including
two generated equation lemmas, with zero extra trusted axioms.

**Formalization is partial.** Lean proves the finite coordinate bijection,
not its interpretation as ideal classes or elliptic curves. Exact PARI
arithmetic, reduced-form/class-group correspondence, the elementary group
product argument and the CM action remain outside this Lean project. The
[component proof map](component-proof-map.json) records this split. The
separate IDC certificate concerns only form discriminants.

The entire class number is still uncertified: the previous value
545296208 remains conditional. A rigorous whole-class upper bound at this
value would imply H=Cl(D). Until then, the request for every horizontal
class remains open. Even the selected component has not been exhausted:
the experiment has enumerated only a prefix. The fundamental-discriminant
result still excludes vertical base-field edges in this fixed class.

An index-free streaming backend could exploit these coordinates, using a
degree-7 cycle and three involution routes (degrees 3,113,97). It has **not
been implemented or tested**. The existing experiment still uses SQLite
BFS with a growing disk index. Before any replacement, validate orientation,
all coordinate transitions and transported targets on complete small
classes, add degree-97/113 map controls, then freeze a full-run storage and
compute protocol. Neither these coordinates nor the small Drive archives
establish sufficient quota or runtime for the requested full experiment.

## Reproduce

With PARI 2.15.2 available as gp, from the repository root:

```sh
timeout 300 gp -q -f -s 256M research/prime61_disk_extend_20261018/class_relations.gp
timeout 300 gp -q -f -s 256M research/prime61_disk_extend_20261018/verify_relations.gp
bash tools/lean/proof-gate.sh --out /new/component-proof-receipts \
  research/prime61_disk_extend_20261018/proof
```

Lean requires the pinned 4.34.1 toolchain. Native package hashes, exact
commands, exits and outputs are in `results/pari-environment.json` and
`results/class-relations*`; use new output paths when replaying evidence.
