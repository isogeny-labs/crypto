# Selected-prime coverage: finite diagnostic and conditional conclusion

The selected ideal classes span all 16 genus-character patterns. This is a
finite, checked result. It does **not** certify the full class number or
complete the requested traversal. The native record deliberately leaves
`full_class_generation_certified` and `full_class_number_certified` false.

## Exact inputs and finite checks

The fundamental discriminant from the preceding study is
`D=-6649310858224389603`, with prime-discriminant factorization
`(-3)*97*113*(-35831)*(-5643470711)`. The native
[genus_span.rs](genus_span.rs) rechecks the prime factors and the exact
product, constructs primitive positive forms `(ell,b,c)` with
`b^2-4*ell*c=D`, and chooses a represented norm coprime to D. For ell=3
it uses `c=554109238185365801`; otherwise it uses the represented norm
ell. The relevant genus-character values are `(n/p)` for the five positive
prime factors p, equivalently the Kronecker values of their prime
discriminants on n. This equivalence uses quadratic reciprocity.

The [native record](results/genus-span.json) contains every form, norm,

These controls do not constitute a formal proof of Euler's criterion.

## Mathematical bridge and stronger bound

Let `Cl(D)` be the proper ideal class group of this maximal imaginary
quadratic order, and H its subgroup generated by the eight selected prime
ideal classes. Either orientation gives the same subgroup, since the two
orientations are inverse classes. Standard Gauss genus theory identifies
the genus-character map with `Cl(D)/Cl(D)^2`; for five prime-discriminant
factors this quotient has size 16. The computed character images show
that H surjects onto it. Lagrange's theorem gives `16 | |H|`.

The form for ell=7 is exactly
`(7,5,237475387793728201)`. The earlier
[exact-order certificate](../prime61_isogeny_20261016/results/class-order-certificate.txt)
proves that this class has order `68162026=2*34081013`, so
`68162026 | |H|`. This is the exact power certificate, independent of the
old GRH-conditional whole-class-number computations.

Consequently,

```
lcm(16,68162026) = 545296208 divides |H|.
```

Thus **|H| is at least 545,296,208** under the stated standard class-group
interpretation of the checked forms and the cited prior certificate. The
ordinary maximal-order CM class action transfers this lower bound to the
selected-prime curve component. This is a mathematical derivation, not a
count of enumerated vertices, an independent whole-class certificate, or
an empirical full-class memory measurement.

If `|Cl(D)|=545296208`, then `H=Cl(D)`: the subgroup has at least that
many elements and is contained in a group of exactly that size. The
previous whole-class-number value remains GRH-conditional after its BNF
certification timeout. Accordingly **full generation is conditional on
certifying that class number**; it is not promoted as unconditionally
established here. A rigorous upper bound `|Cl(D)| <= 545296208` would
suffice together with this lower bound. If the actual class number is
larger, additional work must establish whether H contains the remaining
classes.

## What Lean proves, and what it does not

[GenusSpan.lean](proof/GenusSpan.lean), pinned to Lean 4.34.1 with no
external dependencies, checks eleven theorems. These include the exact
factor product and discriminants, the ramified represented norm's
coprimality, coverage of all even five-bit patterns by subsets of the
specified masks, exclusion of odd patterns, the count 16, the LCM
arithmetic, and the two abstract natural-number implications used above.
The exact integer polynomial residual identity is also proved.

The repository axiom gate passes all eleven, with zero extra trusted
axioms. Transitive dependencies are only the standard `propext` and
`Quot.sound` where recorded; there is no `sorry`, custom axiom or
`native_decide`. `lean4checker` is unavailable. An initial Lean 4.24
build compiled the actual theorems, but the repository audit script uses
the newer String.ofList API; its failure is retained and the proof was
rebuilt and audited under the repository's recent 4.34.1 pin.

**Formalization is partial.** The Euler/reciprocity link from norms to
these masks, primality, the ideal-class interpretation and genus
homomorphism theorem, the prior class-power certificate and the CM class
action are not formalized by this file. The natural-number implications
explicitly assume their divisibility premises; they are not a Lean proof
that the actual H satisfies those premises. See the
[proof map](proof-map.json) for the precise split. This preserves the
mathematical argument while keeping the missing bridges visible.

The polynomial certificate
[`IDC1h5d70c781a75cea1c`](results/discriminants.identity.json) records
`sum_i (b_i^2-4*a_i*c_i-D)*x_i=0` over F_(2^61-1), with a pointer to the
checked universal integer Lean proof. Native issue/check uses 32 derived
and 32 extra domain-separated points. This certificate concerns the
discriminant coefficient identities; it certifies neither genus theory
nor full class coverage.

## Reproduction

Build/run `genus_span.rs` against the pinned worker's native library and
serde_json dependencies; its two native tests check square sets and
independent span algorithms. The build/run commands and logs are retained.
Then, with Lean 4.34.1 on PATH:

```sh
cd research/prime61_disk_extend_20261018/proof
lake build GenusSpan
cd ../../..
bash tools/lean/proof-gate.sh --out /new/proof-receipts \
  research/prime61_disk_extend_20261018/proof
```

No factor-base result, speedup, class-number upper bound or completed
enumeration is inferred from the finite quotient calculation.
