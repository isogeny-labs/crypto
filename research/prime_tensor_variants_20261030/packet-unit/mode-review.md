group in this fixed packet has one row, and every source has two

## Why the correct split enumeration is valid here

After pinning X,Y, each row factor consists of its local affine
constant plus two crossing terms. A crossing mode is indexed by
(source column,target row group). Since each target group has one
row in this packet, selecting one of the three terms per row
enumerates ordinary coefficients of the product exactly.

Source values are multiplied once for every selected mode occurrence.
If two distinct target modes share a source column, both occurrences
are present; evaluating them on a Boolean pin gives the correct
power of X_y. The code does not conflate their coefficient exponents.

The weight is the number of selected crossing terms. Every omitted
term has at least p such factors and is divisible by3^p, because
crossing coefficients are checked divisible by3 and all remaining
coefficients/source values are integers. Thus truncation to weight<p
preserves the pinned product modulo3^p for these fixed inputs. This
argument uses the actual verified coefficients; it does not depend
on an unimplemented3-adic Hermite theorem.

## Precisely what the bad unsplit operation tests

The intentionally wrong routine has one exponent beta_y per source
column. It requires that same exponent at both target-group row
coefficients crossed by that source, while evaluating the source
linear form at beta_y only once. For each affine row it explicitly
computes the coefficient of that forced subvector: degree0 gives
the local constant, degree1 the selected crossing coefficient, and
higher degree gives zero.

This implements the addendum's declared invalid coefficient product.
It duplicates a source exponent across target coefficient extractions
instead of allowing independent target exponents whose contributions
are combined correctly. A genuine polynomial with a globally shared
variable, expanded/evaluated before factorization, would be valid;
the unit makes no contrary claim. Final reporting should retain
the qualifier “forced common target exponent” rather than interpret
the word “unsplit” as refuting all shared-variable methods.

The explicit pin X=Y=(1,0,0) gives

    W00*(1-W10)*(1-W20).

Modulo27 the term containing both crossing entries W00,W10 vanishes.
The retained split term W00*(1-W20) is9 modulo27. Forcing the one
source-column exponent into both target rows instead gives0 in
the bad routine, as checked by the actual source calculations.

## Limits

- The three p values are fixed local moduli, not recursive child
  precisions p_t derived from a3-adic analogue of D.5.
- This packet has one row per target group and singleton source
  columns. It does not test general multirow coefficient extraction,
  higher tile moments, arbitrary tensors or groupwise bit summation.
- The unit checks a concrete failure of one incorrect mode
  factorization and a concrete corrected local identity. It does
  not prove the complete18M/D mode budget, valuation accounting,
  child-network reduction, recursive complexity or a contraction
  algorithm.
- Retained pass records were inspected rather than independently
  regenerated by this reviewer. Separate replay receipts should
  carry any executed reproducibility claim.
