## Construction and proof obligations

For an actual finite trace-kernel residual(z,y), Tr(z)=0 and

    t=y+zH(z),   t²+zt=1.

For u in V, Tr(u)=0, so every S3 solution is exactly

    v=t+zH(u²)+epsilon*z,    epsilon in F2.

Project this expression modulo W=span(VV). Precompute binary masks for
z -> L_j(zH(x_i²)) and z -> L_j(z), leaving d+1 coefficient bits. Incremental
row elimination can stop on contradiction. Full rank forces a unique vector;
reconstruct v and check its COMPLETE W remainder before accepting consistency.
Deficient systems use the previous solver with original kernel/model order.
All original signs, monic roots, S3 checks and original-group replay remain.
Projection setup is charged, lazy after the first residual. The evaluated
integral-translation certificate covers its polynomial expansion only; small
complete-field checks and full case parity check the implementation, not a
formal arbitrary-field solver proof.

The candidate also avoids redundant membership arithmetic: the first actual
ordinate at an x is fully admitted; an identical/opposite ordinate can reuse
that admission after coordinate-width checks, while all supplied indices and
signs remain. No arbitrary point bypasses curve/subgroup admission.

Symbolic trace q is materialized only when requested and shared by clones.
Numeric membership does not need this polynomial. An explicit eager method
reconstructs the same polynomial and is exercised by the factorial context
arms. Existing symbolic model outputs and small-model equivalence must pass.
