# H116 generating-set characteristic-certificate protocol

Protocol `H116-GENERATOR-CHARPOLY-001` is frozen before generator search. The
parent eight-cell panel already established and independently replayed every
all-point positive check; this follow-up measures a new proof-carrying
compression interface rather than treating those identities as prospective.
[pcc:unverified]

## Certificate

The new Lean theorem states that an additive endomorphism which is zero on a
set whose additive-subgroup closure is top is globally zero. Applied to
`pi^2-[t]pi+[p]`, a finite point group therefore needs characteristic checks
only on certified generators. The trace is fixed in Lean by
`t=p+1-Nat.card E(F_p)`. [pcc:unverified]

For each parent cell, points are ordered with infinity first and affine points
by their polynomial-basis x and y indices. The producer computes every point
order, chooses the first maximum-order point `P`, and uses it alone if cyclic.
Otherwise it chooses the first `Q` for which all `iP+jQ` fill the group. Failure
to find such a `Q` is retained. [pcc:unverified]

## Checks and controls

The selected set must contain one or two nonidentity points, generate the full
enumerated group, and satisfy the characteristic equation on every generator.
Wrong trace and wrong norm must each fail on at least one generator. Removing
the sole generator, or the second generator of a two-point certificate, must
leave a proper subgroup. [pcc:unverified]

The already known missing-inverse degeneracy is reported but is not reused as
an acceptance control. A separate Python implementation will recompute point
orders, canonical selection, closure and equation values. Source hashes must
be sealed before execution. [pcc:unverified]

The output records generator encodings and orders, closure sizes, checks,
control counts and the ratio between all-point and generator evaluations.
Elapsed time is diagnostic only. This finite compression result cannot prove
the equation over the algebraic closure or identify the retained rational map;
it is not an ECDLP or asymptotic claim. [pcc:unverified]
