# Signed collector offline replay

From this directory:

```sh
cargo test --locked --offline -- --test-threads=1
cargo run --locked --offline -- fixtures/5.header.json fixtures/5.jsonl
```

Use the repository resource and execution rules. These are fixed software checks and offline replay, not a scientific launch command. `check.sh` uses one job, 3 GiB virtual memory and 180 seconds, preserves stdout/stderr, and verifies source identities. It requires exclusive ownership of the named private build cache.

Library API: `replay_jsonl(bytes, expected_header, Limits)` validates the saved stream and returns per-edge prefix information. Supply the expected header from a separately pinned manifest. An input's own first row cannot establish provenance. `parse_expected_header` enforces unique JSON keys. CLI input defaults: 8 MB stream, 64 KiB header, 16384 events, 2048 nodes, 20 million cumulative prefix cells. No timing metric is returned.

Read REPORT.md for exact checked and unchecked properties. `fixtures/` contains the six actual captured streams and CLI outputs, and `prefixes.csv` exposes all 364 edge prefixes. The expected headers in the fixture are generated by a second source invocation, not authenticated external custody.

Hydrate stored raw logs and the three larger streams from repository root with `python3 tools/artifacts/artifacts.py pull research/pencil_lifecycle_20261030/integration/followup-continuation-v2/signed-replay`. The directory manifests bind exact hashes and lengths. Raw bytes remain locally available after publication; committed pointers preserve their remote identity.
