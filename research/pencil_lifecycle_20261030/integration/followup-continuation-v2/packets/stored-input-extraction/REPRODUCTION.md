# Archive and rendering

Hydrate official artifact entries before running sha256sum -c manifest.sha256 in this packet directory. Original producer sources and failed/successful attempt records are byte-preserved; .lean files are archived as .lean.txt and .olean caches are omitted. For an independently assigned replay, restore names in a new private directory and adapt absolute dependency paths while preserving exact bound bytes. The producer check.sh is provenance, not an automatic execution instruction. Scientific execution is not authorized by this packet.

Render with python3 render-report.py using rsvg-convert and pdflatex, then inspect report.pdf. REPORT.md, editable flow.svg and render source stay together. status.json is the original producer record; its repository_modified=false describes the private producer phase, not this publication archive. Manifest generation includes raw hydrated artifact bytes and pointer metadata after official-store handling.
