# Retained native session exporter: implementation and cache diagnosis

The source implements a postrun exporter through the existing FreshOwnerPins custody check, SessionResourceJournal::close_fresh_enclosing_evidence, and the native diagnostic_file_adapter::check_file typed-session validator. It snapshots bounded native records and retains independently supplied controller receipt digest and owner pins. Self-asserted JSON flags do not authenticate controller custody. Worker allocation, active-worker time and exact kernel exit remain null; scientific admission and mathematical row acceptance remain false.

The intended source controls cover complete synthetic record joins, mismatched expected identities, mutated native files, owner lifecycle errors, changed PID start identity against the supplied digest, self-asserted authentication, prelaunch records, and symlink rejection. These controls have not run. Compilation failed before tests, so the source remains unverified and requires successful software validation and a non-author source review.
