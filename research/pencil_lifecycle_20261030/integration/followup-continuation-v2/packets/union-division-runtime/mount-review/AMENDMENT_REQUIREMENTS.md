Invoke the parser as the final diff predicate; handle every parse/type/error as a failed qualification, retain raw bytes and failure, and preserve exact-ID cleanup. 5. Bind and independently test the actual callsite: valid parse plus valid prerequisites may reach case success; valid parse with invalid identity/mounts, wrong/nonzero transport, missing/truncated output, or parser failure must not. Current source has no such adapter: it still requires empty diff.

7. Keep 300 seconds total, 30 seconds cleanup reserve and 20 seconds per active case if a new run is admitted. No budget, deadline, runtime authorization or admission is supplied by this parser review. Obtain the required prospective review and current execution authorization before any qualification rerun.
8. Report only exact accepted diff entries. Keep writer_attribution=null and no_writes_claim=false. Docker diff alone neither identifies the writer nor audits writes within bind mounts/tmpfs or transient/overwritten activity. Pre-exec pids observations remain bounded to after container startup and before tested exec; they are not proof of earlier or continuous enforcement.
