# Private-runtime lifecycle interface

No draft here is admitted. Actual operator approval is external to JSON; a root operator launches exact reviewed source with exact admitted input/review joins. Root-owned `/var/tmp/pencil-private-<owner>` is created exclusively once. Existing state is never reused as a fresh attempt. No new signing-key infrastructure or permission expansion is required.

Assembly and qualification use separate service owners and separate admission records. Both run the same source in phase-specific mode. Assembly has 600 total seconds with60 reserved; qualification has 300 with30 reserved. RuntimeMaxSec is at most590/290 seconds, clipping to UTC expiry; TimeoutStopSec5 plus remaining margin fits within the respective ceiling. Each unit has2 CPU quota, 2 GiB RAM, zero swap and256 tasks. Systemd's actual cgroup controller values are checked before storage/bootstrap. Root code uses a process leaf and a separate delegated payload descendant; dockerd uses cgroupfs and its managed private containerd is identified across all daemon threads. This is a prospective containment mechanism for the reviewed trusted worker; root privileges are not a security sandbox against hostile root code.

Assembly creates one4GiB ext4 backing file inside its service. The mount is namespace-private and0700; Docker socket/data/exec/config are private. The exact saved base archive is copied into bounded storage, hashed, loaded once, and checked for exact layers/platform/emptyOnBuild. Context is copied into private storage with exact bytes and modes, then built once using the pinned COPY-only recipe. Metadata readiness alone may retry within30seconds; load/build cannot retry. Runtime image identity, owner/source labels, platform/configuration and base-layer prefix are checked.

Before exit, the worker stops its daemon, requires no remaining managed/payload descendants, unmounts and hashes its disk. `RemainAfterExit=yes` retains the successful exited unit long enough to record native invocation and exit properties before explicit stop. Launcher then requires empty cgroup, unchanged disk metadata and no loop attachment. Only then does it record `assembled_stopped`; any uncertain launch, process, mount, image, hash or stop state remains `unresolved` and retains files. No recursive cleanup or automatic retry exists.

Qualification authenticates its own reviewed admission, takes a nonblocking exclusive lock on the exact predecessor disk, checks predecessor receipt hash/owner/path, stopped cgroup, custody and full disk hash, and mounts the same filesystem inside a new service. Its RWallowlist includes only its state plus the exact predecessor file. It starts a fresh private socket/exec-root daemon, verifies retained daemon ID and image, then snapshots the four exact qualifier files (supervise.py, head_contract.py, private_contract.py, gate.c) and binding. The callback runs from those root-owned snapshots with inherited INVOCATION_ID and exact `--private-endpoint` receipt/hash.

Endpoint schema `software.private-runtime-endpoint/v1`, mode qualification, supplies owner, socket_path/uid/gid/mode/device/inode, daemon_id/pid/start_ticks, service_unit/invocation_id/service_cgroup, cgroup_parent, supervisor_pid, source_binding_sha256, image_id,input_manifest_sha256,assembly_receipt_sha256 and expires_at. Expiry is clipped to the current phase work deadline. Source/fixture/assembly hash fields join the separately admitted qualifier binding. That callback must verify endpoint/process/cgroup ancestry and its held-release gate before payload execution. A stopped assembly endpoint is never advertised as live; final receipts explicitly say endpoint_live=false.

Read-only `--reconcile` remains available after expiry but cannot launch new work. It requires preserved native successful-unit snapshot, current stopped-or-collected unit, empty cgroup, unchanged disk custody and absent loop attachments. The dispatcher must reconcile any uncertainty before admitting a later phase. Actual boot/load/build/mount/cgroup/gate behavior still requires prospective runtime qualification; mocked controls do not establish it.
