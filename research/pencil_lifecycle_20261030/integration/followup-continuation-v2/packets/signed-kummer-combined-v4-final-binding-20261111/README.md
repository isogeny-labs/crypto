# Combined signed/Kummer v4 final-binding template

This is a non-executable template for one prospective v4 invocation. It binds
the unchanged source inputs, published offline locks, fresh cache snapshot,
campaign authorization, and prior terminal evidence. The v4 source revision,
independent review, post-pivot ledger, live lease, source publication, release,
and execution command remain null until the currently serialized pivot attempt
is terminal and the coordinator reviews the exact current state.

`admission-template.json` remains `released: false`. No worker time is reserved
and no invocation is authorized by this directory.

`packaging-supersession-custody.json` preserves exact copies of the two metadata
files hashed by the immutable v4 source manifest and separately binds the
canonical additive `report.pdf` publication metadata. The semantic source
manifest remains unchanged; the publication metadata is not silently treated
as part of that earlier freeze.
