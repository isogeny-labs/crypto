\section*{Negative controls and provenance}
Five independently altered copies of saved inputs were processed. All returned native exit 1, \texttt{reconciliation\_pass=false}, and explicit discrepancy records:
\begin{itemize}
\item Omit a required observed identity: missing-field error.
\item Set required observed identity to null: type and equality error.
\item Change expected-index workload: index versus archive mismatch.
\item Change archive workload: manifest hash and identity mismatch.
\item Remove pre-execution manifest: provenance failure.
\end{itemize}
Original inputs were preserved. Controls only alter copied JSON records; they do not simulate a collection process. Individual receipts, altered-input hashes and outputs are retained under \texttt{controls/}; \texttt{controls/summary.json} records all five outcomes.

\textbf{Implementation basis.} Repository \texttt{AGENTS.md} requires native research/accounting implementation. The historical \texttt{retained-duplicate-executed/run.py} combines producer execution with analysis; its entrypoint was not run. The new Rust reader preserves the existing analysis contract and adds the archive-hash namespace, archived-case joins and explicit unselected partitions.

Input lineage:
\begin{itemize}
\item \texttt{archive.jsonl}: physical input rows and retained case witnesses.
\item \texttt{input-index.jsonl}: selected expected disposition identities.
\item \texttt{run.stdout}: historical native output records.
\item \texttt{analysis.json}: historical once-per-row totals used for comparison.
\item \texttt{receipt.json}: historical producer exit, not a new execution receipt.
\item \texttt{src/pruned.rs}, \texttt{src/duplicate.rs}, \texttt{src/graph.rs}: source boundaries for setup, disposition and graph accounting.
\end{itemize}
Exact absolute paths and SHA256 hashes are embedded in \texttt{reconciliation.json}. The final Rust build and read-only run exited zero. V1 evidence remains separately preserved; v2 checks the additional identities and manifest chain.

\textbf{V2 provenance scope.} Required observed and index target identities and indexed case labels are compared to archive values. Receipt-to-manifest SHA256 and manifest-to-archive/index SHA256 plus byte lengths are verified. Missing bindings fail closed. This checks recorded consistency, not receipt authenticity, output execution authentication or all manifest inputs.
\textbf{Review boundary.} The checker reconciles saved identities and accounting metadata. It does not replay scalar certificates, prove mathematical invariants, certify timing isolation, or replace a full experiment review. Root review of the checker remains separate.
