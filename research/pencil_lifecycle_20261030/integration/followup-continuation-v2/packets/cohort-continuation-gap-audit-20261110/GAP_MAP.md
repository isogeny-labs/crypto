# Full-1,260 scientific-cohort continuation: source gap map

Date: 2026-11-10. Repository revision inspected: `36a0004f7857e06f5e3a8357819986ad1a88621d`.

This is a source-only audit. It ran no target, solver, test, compiler, materializer, or cloud job. The shared research KB was unavailable in this runtime and no repository wrapper was present, so the audit used the retained primary protocols, source maps, source files, and prior-review packets named below. No new mathematical, performance, or absence claim is made. The records remain PCC-unverified unless a separately signed verdict says otherwise.

## Fixed denominator and matched controls

The continuation has one admissible scientific denominator:

- 7 exact-order size levels x 3 models x 60 targets = **1,260 targets**;
- pencil, matched source-negation rho, and identical rho A/A control;
- 5 measured streams plus 1 warmup per target and arm = **22,680 execution slots**, of which 18,900 are measured and 3,780 are warmups;
- **6,300 measured pencil/rho pairs** and 6,300 rho_AA/rho control pairs;
- all 36 cells from S/M = {0, 0.5, 1}, I/M = {1, 10, 100, 1000}, and native-event GAE = {0, 0.1, 1};
- method-only, calibration-only, and method-plus-calibration costs, with allocation, serialization, wall/CPU/RSS, controller, retry, storage, and infrastructure observations retained in their own units.

The prepared-plan validation already records exactly 1,260 targets and 22,680 slots with zero solver executions ([prepared_native_plans/result.json](../../../../../pencil_large_prime_20261029/prepared_native_plans/result.json), lines 2-19). The current aggregate source hard-codes the seven plan hashes, rejects a gate scope on the full route, requires the three exact arms and methods, rejects duplicate workload IDs, and requires five measured plus one warmup three-arm round per workload ([aggregate.rs](../../../../../pencil_large_prime_20261029/native_price/src/aggregate.rs), lines 134-184 and 287-420). Missing or ineligible pairs null the full affected ratio instead of shrinking the denominator (lines 111-120; [native_price/README.md](../../../../../pencil_large_prime_20261029/native_price/README.md), lines 126-136).

The 543 historical solved workload keys, one cap-only key, and 716 absent keys belong to earlier pencil variants. The retained audit explicitly forbids adding those rows to later C1 records as if they formed the current cohort ([goal-coverage-audit/matrix.json](../goal-coverage-audit/matrix.json), lines 27-32; [four-followup status](../four-followup-status-20261109/status-map.json), lines 121-124). The older 717-open-target N3 handoff is therefore not a completion route for the current `ic.three_leads_genus2_pencil_symbolic_v2` instrument. The current continuation must preserve the complete 1,260-target enrollment; no smaller survivor, open-only, or historical-union scope is substituted.

## What is already implemented

1. **Exact target/control enrollment.** The seven prepared specifications bind the frozen archive SHA-256 `550f7178e30b60db62931a752b0c179beeef7ea99a96cf94486ff8aee631d339`; each size has three models and 60 targets, with pencil, rho, and rho_AA arms. The native plan receipt records 1,260 targets, 22,680 slots, matched first seeds, and identical rho/rho_AA methods.
2. **Fail-closed full-cohort aggregation.** The Rust aggregator validates plan bytes, execution identities, workload uniqueness, exact arm identity, records, missing slots, per-stream sums, and ratio-of-sums. It does not average ratios or select survivors.
3. **Finite price mapping.** The analyzer implements the 36-cell exact-fraction grid, separates calibration, and lists unconverted resource units. The importer retains missing observations rather than filling zero. A source-bound nine-category independent review is required before prices become non-null ([native_price/README.md](../../../../../pencil_large_prime_20261029/native_price/README.md), lines 28-84).
4. **Pencil relation capture and offline replay components.** The donor solver can emit a bounded target-local header, candidate/relation events, admissions, pending constraints, and a terminal record. The offline consumer validates an independently supplied header and recomputes generated and incorporated prefix ranks separately ([target-stream README](../../target-stream/README.md), lines 3-24; [target-stream/src/lib.rs](../../target-stream/src/lib.rs), lines 90-127 and 204-260).
5. **Matched answer checks.** The root pencil adapter independently recomputes `kP` after a returned scalar; the parent ecbench verifies again. The rho arm uses the same public target and seed through the same study adapter.

These components are useful building blocks. They do not yet form one source-identical, retained, full-cohort production path.

## Execution and evidence gates after the code gates

These are not substitutes for I1-I7:

1. Freeze and publish the exact source, binary, plans, full-1,260 protocol, 36-cell mapper, controls, seeds, launch command, resource limits, retry/deadline ledger, and exporter/stream identities. Old expired deadlines and old binary receipts are history, not admission for the renewed campaign.
2. Run the separate prescribed gate with all three arms and all 18 slots; retain every outcome and independently replay all 15 measured arm executions. A cap, invalid answer, missing row, or failed replay remains a recorded gate result and stops automatic extension under the frozen rule.
3. Run all **1,260 targets** under the selected final method, not only the 717 old open IDs. Retain 22,680 primary slots, every failed/capped/missing result, same-process rho and rho_AA, and fresh-process replay under the frozen replay policy.
4. Recompute every one of the 6,300 measured pair rows in all 36 cells. Publish ratios only for a scope whose complete denominator is admitted; otherwise preserve partial sums as diagnostic and the ratio as null.
5. Publish standardized target rows, cost-grid rows, attempt/resource rows, replay and validator records, SVG/PNG graphs, a neutral PDF, checksum manifest, artifact-store pointers, and a data dictionary. Historical variant rows remain separately identified by method and source record.
