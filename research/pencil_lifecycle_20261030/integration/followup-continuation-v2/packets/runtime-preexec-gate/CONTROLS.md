Independent source review precedes every compile or native control. Compiler must be the existing qualified static musl toolchain; pin source/compiler/spec/header/binary receipts. Static-library unused symbol presence alone is not proof of a call; review the linked call path and gate source.

Before live container use, bound fixed parser controls in a separate test translation unit without changing production source: well-formed Q1/Q2/Q3 case + valid nonce accepted; every other case and malformed/overlong nonce rejected; mountinfo with exact read-only cgroup2 root/mountpoint accepted; writable/wrong-fstype/wrong-root/duplicate-target/missing-target variants rejected. Refactor only under separate reviewed source change if test visibility requires it; do not silently compile a modified gate as production.
