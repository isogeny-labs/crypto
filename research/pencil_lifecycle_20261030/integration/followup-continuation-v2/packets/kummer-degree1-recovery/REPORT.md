## Construction
The existing forward projection maps a degree1 divisor with affine coordinate x to the classical homogeneous vector(0:1:x:x²), then applies the invertible C1 theta-coordinate transform. The old inverse conversion normalizes by its first coordinate, so it rejects this chart. The candidate factors out the homogeneous inverse and, only after generic conversion fails, checks the boundary. A nonzero vector with q0=0,q1!=0 must satisfy q1*q3=q2²; then x=q2/q1. Evaluate the curve polynomial and obtain at most two y values with the existing counted square-root routine. Validate each divisor, project it back, add the signed anchor, and require its projected sum to match the supplied neighbour. Accept exactly one distinct matching divisor; reject zero or multiple matches.
For identity(0:0:0:1), require the neighbour to project to the signed anchor. Zero vectors, malformed boundary chart, nonsquare ordinate, singular coordinate map, no match and ambiguous match have explicit statuses. The code assumes the existing valid curve/model, canonical coordinates, nonzero prime modulus and valid signed anchor. It does not prove those caller preconditions.

## Why sign selection is justified
Assuming faithful quotient coordinates, two opposite non2-torsion points R and -R can both match a signed-anchor neighbour only if2G=0: equality up to sign gives either2R=0 or2G=0. The algorithm checks uniqueness rather than silently relying on the anchor condition. Tests using torsion anchors reject as ambiguous. With y=0 the candidates coincide and are deduplicated. These are algebraic arguments about the quotient; no new universal Lean proof is claimed.

The expected divisor is only an assertion input. Recovery itself uses the signed anchor, quotient point, quotient neighbour, curve and model. It does not use a planted scalar, expected divisor or group-label reconstruction. Fixtures use torsion T to force repaired arithmetic; signed recovery uses the original non2-torsion G, not T.
