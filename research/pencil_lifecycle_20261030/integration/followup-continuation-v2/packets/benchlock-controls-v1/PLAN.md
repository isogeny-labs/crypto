# Prospective fixed helper review — no execution

This packet implements six controls from ../pencil-benchlock-proposal-20261031-v1/TEST-PLAN.md. Runtime order C1,C2,C3,C4,C6,C5 is intentional: all forks occur before the helper creates a thread. One single-threaded-at-fork executable invocation; no fork inside Cargo's parallel test process. Compile the standalone helper with the existing pinned rustc and matching libc rlib (exact paths and hashes must be frozen by the admitting runner before invocation). No dependency download or installation. Proposed compile bound120s+5s, one invocation; proposed run bound60s+5s, one invocation, helper alarm15s. No retries. Preserve compiler output, native stdout/stderr and exit receipts including failure.

benchlock.rs is byte-extracted from the proposed primitive using bindings.json boundaries. It is not independently reimplemented. The crate path signals::interrupted is a local None stub: all acquire calls use wait=false and therefore return before that path on contention. The helper does not validate wait=true or signal handling. Compile command after binding: timeout -k 5s 120s "$PINNED_RUSTC" --edition=2021 helper.rs --extern libc="$PINNED_LIBC_RLIB" -o helper. Run command after admitting compiled binary hash: timeout -k 5s 60s ./helper UNIQUE_ABSENT_OUTPUT_DIRECTORY. These are proposals, not commands executed here.

C1 contends while owner live then succeeds after drop. C2 retains close-only raw descriptor semantics and records exact EAGAIN/EWOULDBLOCK with CLOEXEC confirmed. C3 requires owner Drop to release while child is held behind a pipe. C4 invokes exactly the inherited guard's Drop body then libc close; parent must remain locked. C6 returns intentional error with child retained; parent must be released. C5 moves ownership to a joined thread and then reacquires. Six PASS lines plus ALL_SIX_CONTROLS_PASS and exit0 are required; every probe records errno and acquisition outcome. Failures remain failures.

Child paths use only stack state, Option pattern matching, reviewed Drop::drop (getpid/flock), libc close/read/write/alarm/_exit. Full Rust guard destruction is deliberately not invoked: its String field could invoke allocator deallocation after fork. C4 therefore checks the destructor body plus the File close syscall, not complete Rust field destruction. _exit prevents automatic stack destruction. Signal interruption of a child pipe syscall causes explicit nonzero exit; no retry or formatting in child. Parent RAII terminates/reaps a remaining child on ordinary unwind; child and parent alarms bound abnormal paths. Parent process exit by alarm cannot execute RAII; the child's own alarm bounds its lifetime. A successful finish records waitpid and exit status. Fork/pipe creation failure terminates the check; already-open file descriptors close at process exit. This small diagnostic is Linux/Unix specific.

Only internal-field access in this included standalone module is used to retain descriptors; production BenchLock still exposes no raw descriptor. It does not add Clone. The current-source public call inventory remains the original proposal's report. This helper is neither proof of the original failed interleaving nor a benchmark.
