## Next construction: a bounded event bridge, then offline replay

Implement a new optional native observer receiving target-local ordered `RelationEvent`s; preserve a no-observer path and the existing arithmetic/order. Do not edit frozen archival packets. A fresh source proposal should define:

- Immutable header: schema, source revision/hash, curve/model identity, subgroup modulus/order evidence, source/transfer G,Q identities, workload and run/attempt IDs, algorithm/seed, node-order/partition policy and row-convention enum. A stream belongs to ONE target/attempt and cannot be appended across it.
- Event sequence: monotonic ordinal, actual walk/candidate identity (pencil walk_index/lambda, signed trial/candidate index), eligibility/disposition, raw geometric signs and labels, dedup canonical key/sign and first-event reference where relevant, sparse input row, column-map version, exact Admission/returned scalar/terminal state. - Emit call-boundary observations around actual `GraphSolver::relation` and `SignedGraph::edge`; expose the composed sparse row using a single shared assembly result, not a second independently implemented sign reconstruction. Include duplicate/identity/rejected/capped/stop dispositions at their enclosing callsites. - Preserve existing terminal semantics: after a return no additional events may mutate the solver. On a cap retain pending row and mark it unincorporated. An output failure must be explicit; no silently truncated prefix. Enforce a byte/event ceiling without silently changing the algorithm, and record observer failure separately from mathematical inconsistency.
