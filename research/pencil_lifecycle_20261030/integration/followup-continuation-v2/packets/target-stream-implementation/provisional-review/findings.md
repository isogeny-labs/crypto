# Adversarial contract findings

Prospective plan precedes patch reads. Review scope is software/source contract; no build or native invocation was performed by this reviewer.

F1 — Completion custody. Initial Trace wrote terminal bytes before flush and poisoned complete() on flush failure. The serialized prefix could nevertheless contain a syntactically valid terminal. Producer added a concrete CLI path that writes create_new .partial, requires solve Ok and trace.complete(), synchronizes the file, then hard-links without overwriting the final name. Consumer renamed completion syntactically_complete and reports producer custody unverified. Source-level resolution: complete JSON alone is not proof of successful publication; library callers retain responsibility to check Result and trace.complete. Directory crash-durability and external tampering are not certified.

F2 — Phase accounting. Initial API comment implied all trace overhead appeared in measured phases. Header, candidate, relation and terminal serialization are outside measured() closures; Header precedes begin_online. Producer corrected documentation and publication metadata to diagnostic phase-excluded tracing. Total envelope can include work absent from phase sums. Failure returns do not contain complete failed-attempt cost accounting. No timing equivalence claim is accepted.

F3 — Boundedness. Serializer enforces event and cumulative serialized-byte limits and poisons capture after failure. This bounds output and its serialization buffer, not all preexisting solver or newly cloned event materialization. Header clones node map and vectors before serialization. Producer explicitly documented this distinction. Consumer CLI bounds both input files to16MiB; reusable decode requires caller byte bounds before allocation, while ReplayLimits bounds event/column/term/prefix-work counts. These are explicit diagnostic resource controls, not a whole-process memory proof.

F4 — Admission semantics. Exact shared native submitted row is moved into the optional event after insertion. Event carries actual Admission, pending small-coordinate row, residual rank and candidate scalar. Collector cap can occur after graph mutation; residual basis remains unchanged and pending row unincorporated. Consumer replays the same Collector to verify outcomes and computes separate generated-producer-attested input versus successfully admitted input prefix spaces. Neither space is mislabeled as the retained residual constraint matrix. No cap rollback is inferred.

F5 — Source signs and identity. Native point terms retain order, duplicates and zero labels, with y=0 omitted, y<=p/2 sign+1 and upper-half sign r-1; target coefficient b and RHS -a are preserved. Consumer reconstructs this exact sparse vector independently from captured candidate points before admission replay; zero-equation adapter negates only RHS. Separate expected header equality binds source metadata, actual curve/target/generator, seeds, column map and partition. Caller-supplied source strings are asserted metadata, not authenticated provenance. Consumer explicitly does not verify geometry or source group scalar.

F6 — Errors and terminal state. Candidate events precede insertion and Relation follows it; sink failure after insertion has mutated local solver but aborts the operation and leaves capture incomplete. Pending candidate without adjacent relation and missing terminal are rejected offline. A scalar candidate is distinct from terminal source_verified. Counters cross-check captured relation/admission counts, and lambda exhaustion is checked separately from early stop. Post-terminal records, stale maps and header replacement are rejected. Trace reuse errors poison complete; no continued same-instance trace is accepted.

F7 — Observer resource state. ObservedSystem::begin_envelope resets an atomic peak and returns a Boundary snapshot; finish_envelope only reads. No active lease or flag is leaked on early trace return; next begin resets the peak. OnlineGuard performs end_online after begin_online, and PriceGuard is RAII. Failure cost detail is absent, not complete. No-observer branch avoids event clones/serialization and preserves original assembled row and measured operations by inspection; fixed-test execution evidence belongs to producer, not this review.

F8 — Real caller. --trace-cohort BITS P OUT_JSONL IDENTITY_JSON MAX_RECORDS MAX_BYTES invokes the actual solve_one_with_trace and requires exactly one selected cohort target via PENCIL_MAX_TARGETS=1. It checks workload_id against the selected frozen row and keeps source key metadata separate. This review inspected but did not invoke the path. It establishes an implemented entrypoint, not an observed natural stream or full cohort result.
