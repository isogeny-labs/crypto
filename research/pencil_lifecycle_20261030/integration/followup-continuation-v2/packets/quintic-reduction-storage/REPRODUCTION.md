# Reproduction

Restore archived .lean.txt files as .lean in a fresh directory. check.sh and dependencies.txt identify the source-host paths to adapt; before.sha256 files bind helper sources, caches, toolchain and native source. replay.sh freshly checks the six modules named in check.rs, followed by the false control. inventory.txt lists the fourteen audited declarations. Compiled caches and the checker binary are omitted. This is a source-and-receipt archive, not a self-contained toolchain distribution.
