# Generic scalar-image control

Frozen before inspecting any native polynomial image-collector outcomes.
The previously frozen six- and nine-arm experiments remain unchanged.

Add the physical factors `[2]P` for original L0 factors. Their logarithm
coefficient is 2, so they require only the original L0 log columns, just
as the active phi(L0) arm does. Construct each point by group doubling,
verify its scalar coefficient, retain any sign/abscissa collisions and
check actual factor-base orbit closure. Keep the same original three-L0
S4 unknowns and use the doubled points as fourth-factor peels.

Run this control on all 21 existing frozen instances, the same original
residual streams, the same rank/cap criterion, and the same F4 settings.
Use complete independently checked reference sets and first/A/A. A
separate process shard gets the same 8 GiB/1,200 s cap. Record all costs
and omissions with the same boundary as the nine-arm study.

This tests attribution. Appending known scalar images can enlarge a
physical factor base without adding unknown logarithms on curves that
do not have the cubic automorphism. If doubling gives comparable rank
and relation-work changes, that part of the mechanism cannot be
attributed solely to the special twist/cubic action. If phi performs
differently on the frozen streams, examine the precise geometry,
coefficients, collisions and row dependence before inferring a general
advantage. The uniform first-moment prediction is the same for the two
disjoint injective image bases of equal size.

This is an additional control, not a change to the encoded nine-arm
shard mapping or a replacement for its negative and censored cases.
No image-base speed or novelty claim is admitted before this control
and the declared cost and external-solver checks are complete.
