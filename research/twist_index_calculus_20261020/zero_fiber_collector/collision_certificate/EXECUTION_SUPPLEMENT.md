# Fixed diagnostic decision rule

2026-10-25, before the first production certificate search. This supplements
the [protocol](PROTOCOL.md) without changing its workload, search limits,
controls or the original complete-cost objective.

1. **Safety and coverage:** require all 42 case-arms' complete canonical
   systems, all 84 registered first/repeat executions, 42 independent
   first-run audits and 42 deterministic parity checks. Each certified
   system must pass exact coefficient expansion and the retained complete
   physical/root reference. Keep all failures, timeouts and partial prefixes.
   A failure or missing case is not a gain or an exhausted mathematical lead.
2. **Cost diagnostic:** for each case-arm retain the calculation
   `M = search_muls + certificate_check_muls + old_F4_row_muls_on_uncertified_systems`.
   Compare M with the old row-reduction multiplication count for that same
   complete case-arm. Both integers and their definitions remain visible;
   counts from different targets or curves are not an amortized solve price.
   A strict reduction is evidence only in this partial multiplication model.
   Equal or larger M is recorded as such, including every failed degree.
3. **Twist attribution:** compare phi with doubling under the same D/k caps,
   canonical quotient and safety checks, with one row for each prime and
   presentation. Distinguish differing certificate frequency, minimal found
   degree/power and charged arithmetic. No copied orbit is counted as an
   independent relation. Static removal of empty physical sets preserves
   their reference rows; it is not new target recovery or a new matrix-rank
   measurement.
4. **Next action:** if verified cases reduce M, instrument and integrate the
   candidate into a full charged pipeline after the live producer is
   reconciled. If they do not, report the cost loss, identify which failed
   degrees dominate and test a cheaper certificate or shared reduction
   strategy as a separately frozen follow-up. This leaves full cost unknown;
   no bounded unsuccessful search proves impossibility.

Full end-to-end price and speedup fields remain null in this diagnostic.
No polynomial-construction cost or unmetered work is silently zeroed.
The original single-target, strongest baseline/rho, GAE sensitivity,
independent replay, external-tool and proof-bridge obligations remain open.
These are diagnostic decisions, not a redefinition of the user's goal.
