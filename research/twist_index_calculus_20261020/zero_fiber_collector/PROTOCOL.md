# Five-factor zero-fiber polynomial collection and charged target descent

Prospective continuation, 2026-10-24. This protocol is written after the
completed 21-case scalar census and independent public-point replay, before
implementing or running this polynomial collector. Neither the protocol nor
the earlier rank difference establishes an IC improvement. The broader
twist-symmetry and complete-price objective remains open.

## Question and controls

Can the fixed zero residual let us quotient image/ordinary peel pairs by
the existing cheap action, then obtain enough independent factor-log rows
to lower the complete one-target IC cost? Compare phi=1-psi and generic
doubling under exactly the same action quotient. The quotient itself is
available to both; a difference between them must come from rank trajectory,
solving cost or another separately measured phase.

Use every original p=37,73,97,157,229,241,337 case and all seeds 0,1,2.
These are seven curves in three presentations, all with the public synthetic
target scalar 271, not 21 independently sampled secrets. The fixed model
is a quartic extension twist; selecting different twists is not tested here.
Retain p337, where doubling's five-factor rank exceeds phi's, as well as
p37/p157, where phi's rank is larger. Do not restrict to the positive cases.

The source line is the same invariant L0 used in the completed parent
study. Each relation contains four distinct ordinary abscissae and one
disjoint image abscissa. Both signs are included. Do not introduce extra
independent image-log columns or count transported rows as independent.

## Candidate inputs and construction

The candidate receives only the existing 13-key public input, its expected
SHA-256, an explicit arm and a fresh output path. It must not read known
factor logs, recovered target scalars, previous physical sets, reference hit
counts, BSGS tables or a verifier's output. Reference files enter only the
post-run verifier after candidate output has been saved.

Reconstruct and charge the candidate's factor lifts, chosen image map,
subgroup and eigenvalue checks, action/sign tables, exact S4 coefficient
derivation and matrix allocation. Reuse the native cold-build algorithm
instead of accepting an uncharged precomputed point base. Preserve the
existing supplied public sign encoding and disclose the same input boundary.

Enumerate all signed pairs (ordinary point, image point). The proposed
24 actions are sign times transported Frobenius^j times psi^k, with
0<=j<4 and 0<=k<3. Check actual point images, closure, signs, nonzero and
distinct subgroup actions, and bijectivity on both allowed factor sets.
Choose one deterministic pair representative per orbit. Verify the full
pair partition, orbit sizes and coverage before solving. A conditional
orbit argument is not a substitute for these fixture checks.

For each representative pair A,B, set R=-A-B and solve the existing exact
S4 restriction for three remaining ordinary factors. Decode every field
root, split the cubic, check allowed distinct ordinary IDs and both signs,
and verify the actual five-point sum. Apply every checked action to each
accepted tuple and deduplicate physical signed tuples and projective rows.
The pair's ordinary ID need not be the smallest ID in the relation:
imposing that non-invariant condition would require a new completeness
argument. Retain infinity and exceptional-map outcomes explicitly rather
than dropping a branch. Disjoint signed factor sets should exclude an
infinity pair residual, but check that precondition executably.

The proposed pair-orbit count is 4*L0^2/24 when the checked action is free.
This is a pre-run operation-count hypothesis, not an observed count or a
24-fold wall-time gain. It also holds for the matched doubling control.

## Phase 1: complete sets and independent rank

Execute all 42 case-arm collectors to completion or their unchanged
watchdog, even when their matrices attain full factor-log rank earlier.
This phase verifies the complete enumerator; its full enumeration is not
silently substituted for an optimally stopped complete-cost pipeline.
Preserve every attempted S4 system, native root verdict, root/decode
failure, accepted physical tuple, zero/projective row and rank increment.
An undetermined system or watchdog stop makes completeness unverified,
never a zero-yield observation.

Post-run Rust verification must compare the entire physical set and its
canonical serialization against the completed, independently point-keyed
five-factor replay from `../joint_image_elimination/`. Reconstruct folded
rows independently, check zero target coefficients, compare factor-log
rank and verify all recovered factor points when full rank is reached.
The earlier oracle/replay runs are reused as immutable evidence; do not
repeat BSGS or their complete enumerations to manufacture new receipts.
Input/hash corruption, omitted tuple, altered sign and incomplete-system
controls must fail. Test quotient coverage separately from polynomial-root
completeness. Sharing the native field/curve kernel remains explicit.

## Phase 2: complete one-target pipeline

After Phase 1 passes, use the same canonical pair order and stop zero
precomputation immediately when every factor-log column is determined;
otherwise exhaust the declared pair set. Carry all independent zero rows
into the anchored matrix, then collect nonzero target relations on the
original frozen public query trace until full target/factor rank or its
original cap. Keep every failed decomposition in the cost. Verify the
recovered target and all allowed factor points. Never infer target recovery
from zero-only equations.

Compare the complete candidate with matched plain phi and doubling
pipelines and the strongest existing verified invariant-base IC baseline
on the same case. Freeze the baseline selection and executable hashes
before the comparison; retain every per-case loss. Old admitted timings
from another host cannot supply a new paired elapsed comparison. Reusing
the completed parent records for deterministic source parity and operation
counts is separate from conducting a newly admitted matched price trial.

Charge public point lifts, setup, map evaluation, action canonicalization,
all successful and failed polynomial work, root extraction and decoding,
group verification, hashes/trees/allocator work, sparse/dense matrix work,
back substitution and target verification. Report cold and genuinely
amortized costs separately. Keep peak memory, allocation work and phase
boundaries; process startup, input decoding and output serialization must
be identified. A reduction in S4 calls alone is a stage result.

Require first/A/A parity, meaningful positive and negative controls,
matched strongest rho and the 0/0.1/1 GAE band before a promoted full-price
claim. Use the fastest available external tool on identical inputs with
checked outputs before a fastest-solver claim. The shared migrated host
currently admits correctness/counter diagnostics only; it cannot supply
new admitted timing evidence. Missing admission or calibrated costs stay
open, without changing the scientific question or calling a rank gain a
complete-cost gain.
