# Distinct fourth factor and the named S5 regression

Frozen before executing this round's algebra/export suite. This supplements
the v1 protocol without changing its physical signed-set acceptance rule.

For pure L0 the fourth source abscissa u belongs to the same physical base
as the three ordinary roots. Saturating only their cubic discriminant does
not exclude u repeating one of them. The primary geometric pure-L0 system
therefore saturates

    Delta(e1,e2,e3) * (u^3-e1*u^2+e2*u-e3).

The mixed phi and doubling images are already disjoint from ordinary L0,
so their guard is just Delta. Equality of a source parameter u with an
ordinary root is allowed for an image: its physical image factor is
different. A cubic-only geometric pure-L0 input is retained explicitly as
an under-saturation diagnostic, not the strongest baseline.

The finite-domain pure input already requires the full monic quartic to
divide the squarefree factor-base domain polynomial, which excludes all
four repeated roots. No extra reciprocal variable is needed there.

Additionally include query 2 of p=37, seed=0, in all three arms. This is the
named historical pure-L0 S5 regression in the open problem. It is added
to the fixed ordinal and first-positive controls with ordinary deduplication.
Selection uses the historical failure, not any new solver result or time.
Complete-root comparisons must keep the distinction between the newly
constructed systems and the exact historical system until coefficient
equality has been established.
