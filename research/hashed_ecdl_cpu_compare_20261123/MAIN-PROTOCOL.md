# Prospective main public-target comparison

Run **360 calls on 12 fixed public targets**: parent a, current candidate b,
same-parent A/A c; one warmup plus nine fresh-process observations per arm/target.
All six original curves, both seeds, m8/batch64, target construction, row/trial/
column caps and unchanged scale workers are retained. The only worker source
change is the exact stored-numerator versus reverse-pass library file. No
preflight, historical or synthetic-canary observation enters the main data.

Counted recovery, certificate/counter equality and explicit verification controls
are primary. Each call must pass the worker's internal checks/corrupted-scalar
assertion and external full Native replay. Every complete certificate must also
pass the separate OpenSSL public-target/scalar check and both intended negative
controls. This point audit does not independently prove primality, Hasse order,
all relations or execution provenance. [pcc:unverified]

The frozen V2 analyzer reports per-target/arm complete, enclosing-driver and
oracle seconds as medians/full ranges, with parent/candidate ratios and A/A
observations. These L0 summaries do not decide ranked timing, confidence,
equivalence, total-operation S, peak RSS, exponent or a global solver ranking.
Build paths, executable layout, ASLR and unblinded analysis remain disclosed.

Measured rounds use three Latin rotation blocks, reversing the middle block.
Every arm appears in each position three times per target. Warmup round 0 keeps
the original preflight order. Native argv remains u; raw replicate 0/warmup false
stay unchanged. Canonical instance IDs include case and seed; collector round
identifies the actual replicate. Two seeds are two distinct targets.

The supervisor stays outside guarded phase process groups. It always **attempts**
a separate finalization after the driver becomes terminal, preserving driver
exit status. Finalization can itself be refused by the resource guard or hit its
deadline; such an analysis gap remains explicit. Configuration reconstruction,
when needed, supplies only the frozen config and creates no run or cell record.

Enforced phases: 1500s driver, 120s finalization, 120s point audit, with 10s kill
grace each. Their 1770s nominal phase budget leaves a planning allowance within
1800s for supervision/hash I/O; 1800s is not a hard overall watchdog. Workers
have 120s and external Native replay 60s. One main attempt, zero retries; stop
the driver at the first cell failure and retain all unattempted cells. A main
supervisor marker prevents re-executing the same attempt.

The 4 GiB virtual-address limit applies to the worker wrapper/timeout/taskset/
worker only. Driver, external verifier and point auditor do not have that ulimit.
The sampled whole-cgroup guard remains 15,032,385,536 bytes, including retained
unrelated research. Worker/Native-replay affinity is CPU 4. No builds/tests run
during the main panel. A pre-call CPU/kernel/cgroup/affinity/runtime-library
receipt, exact source/config/protocol, all qualifiers and all launcher/guard/
finalizer bytes are pinned in the main execution manifest.

The real 36-call preflight completed in a 103-second whole-second wall span;
using 104s × 10 × 1.25 gives a **1300s planning estimate**, not a guarantee.
The preflight source/records stay unchanged. Review 11 retains its original
interruption/custody/order gaps. V2 source/control repairs, source-pinned clean
reproduction and separate qualifiers are prospective remedies. All four clean
reproduction binaries match earlier V2 copies byte-for-byte. Ten V2 controls
pass; the empty point-audit test harness is not counted as a test. [pcc:unverified]

unattempted, with failed driver/finalizer and skipped point audit. A group-TERM

some become zombies. It does not exercise the RAM threshold or stress the virtual
limit. V2 analysis of valid copied preflight records is byte-identical. A clearly
labeled synthetic fixture copies the 36 warmups into 360 metadata cells solely
to exercise nine-value summaries; it produces no new solver or timing samples.
These controls are separate from main observations. [pcc:unverified]
