# Adaptive PKM solver-cost continuation

Frozen 2026-11-23 before the first F4 call. This follows the 56-candidate relation-yield screen in merged PRs #5041 and #5061. The prior screen measured no confirmed gain; this stage tests whether low-degree isogeny membership helps the algebraic solver against a same-size interval.

Primary source: Petit–Kosters–Messeng, *Algebraic approaches for the ECDLP over prime fields*, §§3.1–3.4. Repository prior work: `docs/ic/SWEEPER.md` `prime-algebraic`; `research/isogeny_vs_mu_factor_base_20261102/`; `docs/ic/factor-base-encyclopedia/README.md` A13. KB `source:81a446d8a0f88023cfe934a2fcb608bb` found the existing F4 space, and `source:8c240c74031ac4ef0c31a0bc562fd876` points to the published yield-conservation proposition. At fixed base size, total multiset relations are conserved; only their distribution and extraction cost can improve.

Development qualification: run the existing local `ic sweep run --space prime-algebraic` binary on rungs 10,11,12,13, generic prime family, target-log2r 24, one trial, one repeat, one rho context run, one worker, 30-second per-trial timeout and 2048 MiB RSS limit. Save the append-only store and the binary hash. Inspect errors, timeouts, exact candidate identity, baseline, measured F4 work and source provenance before extending. This one-trial call cannot certify a speedup.

Continuation gate: use the same store, instance family, rungs, target identity policy, units, timeout and resource envelope as trial count rises. Preserve failed/censored trials. A candidate only advances after it beats the baseline on complete same-target cost with setup charged, a verified scalar, independent replay and a matched optimized rho comparison. A F4 subtotal or planted-system solve alone cannot satisfy the gate. Do not promote online reuse as a single-target result. Cap local development at 120 seconds wall per call and 2048 MiB RSS; do not launch paid compute without an explicit budget. A later call must have a separate dated protocol amendment specifying trial count and expected information gain.
