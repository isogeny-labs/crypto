# Runpod execution package

The user explicitly selected Runpod for the native trace/pullback lead.
`PROTOCOL.json` freezes the growing public-target panel, fresh labelled pools,
four charged attempts, misses, lazy auxiliary construction, witness recovery,
five measured rounds and a USD1 total attempt ceiling. Root and complete
translation controls are separate panels. No existing pod is reused or stopped.

All scientific computation and timing is native C++/Rust/PARI. Shell scripts
only build, invoke fixed commands and retain outputs. The checkpoint workflow's
Python is administrative AWS credential presigning, with no crypto algorithm,
timing or result calculation. Credential material is encrypted to the committed
public recipient certificate; the private key stays outside this repository.

`incidence_lazy.cpp` retains the original native norm/GCD, root and witness code
but obtains a checked datum only inside its existing nonlinear-root branch.
`pair_control_callable.cpp` makes the frozen historical C++ pair control callable;
it renames main, adds its implicit successful return explicitly, and suppresses
clock reads in check mode. Original pinned files remain byte-preserved.

The bounded PARI constructor searches at most128 curves with both orders
1024-smooth and a rational two-isogeny kernel. It charges point counting,
factorization, group generators and correction of PARI's second generator
to the required invariant-factor order. Native datum validation follows.
The isogeny arm separately constructs and validates the codomain datum.
Neither construction is a new polynomial-time theorem. A failed construction
is retained as an execution failure, not a free miss or usable relation.

Requires C++17, FLINT/GMP/MPFR, nlohmann-json headers, PARI/GP, and the Rust
toolchain/dependencies for the existing rho adapter. Build/check commands:

```sh
make -C research/trace_incidence_20261116/runpod
bash research/trace_incidence_20261116/runpod/check.sh
```

Local development receipt `development-checks.jsonl` records22 no-timer calls
through an immutable qualifier. Separate hashes are in `development-*`.
These are unsigned development assertions. [pcc:unverified]

Before launching, require the standard source-bound S3 checkpoint receipt with
gate_exit0, exact source/protocol/closure hashes and live Runpod credit/price
admission. One CPU pod, no automatic retries,1800seconds maximum from creation;
an external supervisor must collect and terminate it at completion/deadline.
The remote pod never receives the Runpod account key or S3 signing credential.

Raw output retains every planned/attempted round, miss, failure and timeout,
parent/child memory high-water marks, native binary/pre/post manifests, package
versions, CPU/cgroup metadata, fresh public generation and original-curve checks.
The final archive is hash-checked and uploaded to the approved bucket using a
short-lived credential scoped to one immutable per-workflow-run object name.

Shared hosting, ordinary CPU affinity and A/A rows do not establish L2. The
canonical sibling protocol source is encrypted/unreadable in this runtime;
canonical-schema validation is therefore explicitly unavailable. This package
collects descriptive evidence without fastest-tool, asymptotic, signed PCC,
leaderboard or security-tier promotion. Rho configuration and instrumentation
limits are recorded explicitly; censored IC targets remain labelled censored.
The original binary-field goal remains outside this
prime-field implementation's domain.

Sources checked (KB unavailable): the supplied paper and existing derivation,
frozen `historical/repo_controls` source assessment, repository Runpod receipts
and loss record, [Runpod REST pods](https://docs.runpod.io/api-reference/pods/POST/pods),
and [PARI ellgroup](https://pari.math.u-bordeaux.fr/dochtml/html-stable/Elliptic_curves.html#ellgroup).
PARI explicitly warns that its second generator need not have order d2; the
charged elllog correction and native validation address that dependency.
