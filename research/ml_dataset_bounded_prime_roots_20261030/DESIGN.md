## What existing solve actually guarantees

For nonzero f, it computes X^p mod f, monic g=gcd(f,X^p-X), then recursively splits g using gcd(h,(X+delta)^((p-1)/2)-1). Accepted splits strictly reduce positive degree; linear leaves produce roots. Finish verification recomputes g and requires product(X-r)=g with strictly ordered roots. Thus acknowledged Complete certifies ALL DISTINCT Fp roots, not merely found examples. It neither factors every nonlinear irreducible part of f nor preserves multiplicities. Repeated and nonmonic inputs are supported by monic gcd normalization. A nonzero constant has no roots; zero polynomial has the separate AllFieldElements status, never an enumerated field-sized list. Failed/capped legacy runs expose no final roots.

Current bounds are degree<=8, field_work<=1,000,000, events<=100,000 and split attempts<=100,000. They do not bound retained heap layouts or original wall deadline. Every acknowledged RootEvent is retained, many events contain cloned vectors, sink errors own arbitrary Strings, validation repeats primality, and StdRng::gen_range may internally reject samples. The existing dataset callback serializes before its byte check and retains reports/intermediates outside native counters. Calling this legacy API under an outer timeout does not close these gaps.

## Reusable kernel and concrete storage discipline

Port existing control flow and identities; do not call legacy Vec-returning helpers underneath the new API. Use one fixed `Poly17 { len:u8, coeffs:[u64;17] }` scratch representation. Input/factors and gcd results have at most9 coefficients; products of degree<8 residues need at most15, with17 leaving a conservative explicit degree16 bound. Check every logical length before indexing. Long division decreases degree, modular power has<=61 exponent iterations, inversion<=61 bits, Euclid<=9 degree-decreasing divisions. Keep polynomial operations iterative, with fixed local scratch and no heap.

Use an iterative factor stack of eight degree<=8 polynomials; total degrees of pending factors plus emitted roots never exceed8. Roots capacity8. Cap every push; a violation is an internal-invariant failure, never reallocation. Pending h must remain represented on refusal (or expose unresolved accounting explicitly unavailable); no empty-queue completion inferred after popping h and failing a split.

Events use inline coefficient snapshots and fixed root arrays. Stream each event by borrowed reference; do not retain a native Vec of all events or use HashMaps. Report retains only fixed terminal/checkpoint state and at most one fixed unacknowledged event. Copying old events into vectors to reuse the old report is forbidden in this bounded path. Adapter owns durable stream retention and separately budgets serialization, manifests and selected snapshots.

Freeze actual `size_of` sums after types exist: reserve fixed workspace + report + one pending event + scratch-frame allowance BEFORE input copies, arithmetic or first observer. Proposed hard fixed allowance16KiB, with compile-time/test assertion that explicitly enumerated objects and maximum simultaneous nonrecursive helper frames fit it; if they do not, reduce layout or amend before execution rather than silently increase. This is a modeled native storage reservation, not OS-stack/RSS enforcement. Reject one byte less before observer. Caller-owned inputs and observer-owned allocations are outside native storage but must remain within adapter run accounting. No native heap allocation is needed.

All arithmetic operations are precharged individually (including inversion, normalization, final root checking); use checked counters. In addition, precharge modeled coefficient scans/copies/conversions at32 units per visited coefficient, field operations32 units each, and fixed event handling256 units before observer. Charge every explicit RNG step and stack/branch action before execution. These tariffs bound named logical operations, not machine instructions. Fixed arrays have at most17 entries so each scan/copy is a small bounded chunk; check deadline before/after it. Charge initialization of actual inline arrays in entry admission. No bulk uncharged vector clone, formatting, sorting or serde.

Replace `gen_range` only in the new API with an explicitly specified fixed-cost seeded word stream followed by word modulo p, charging each word. Record exact RNG/version and delta. This is reproducible deterministic trial scheduling with biased shifts, NOT a deterministic polynomial-time factoring guarantee or uniform random claim. Alternatively implement a capped rejection sampler, charging every rejection and exposing exhaustion. Do not inherit an unbounded sampling loop. Split exhaustion is always censored. No loop over 0..p or fallback whole-field scan; no hidden retry with reset budgets.

Observer failure is sticky: attempt counted, operation work remains charged, acknowledgement only on Ok, original deadline checked after Ok. After any error/deadline no subsequent callback, including synthetic Finish. Check deadline at entry, before every operation/event/attempt and after observer. Terminal callback returning Ok after deadline returns Deadline, no finite completeness claim. Preexisting expired deadline causes zero callbacks. Observer runtime cannot be preempted by this API; supervisor remains necessary.

## Certificates, replay and residual-system obligations

A bounded stream needs an independent streaming replay API rather than unrestricted legacy verify over retained vectors. Reuse its independent canonical u128 arithmetic identities, but fixed state tracks the nested power/gcd/inverse/split structure and bounded pending polynomial factors. The producer and checker must not share solve/control flow. Final check independently computes X^p mod f and monic gcd and compares product(X-r); checker itself gets original remaining work/bytes/deadline, including its finite arithmetic, and reports replay-incomplete on refusal. Do not claim hardware/full-operation-trajectory proof from these identities. Existing verifier has explicitly weaker trajectory semantics; preserve that label.

Bind every call to residual-node id, selected variable, canonical univariate coefficients, field identity, parent assignment, seed/schedule, original context and admitted budget. The root certificate is restricted evidence. Final candidate roots require evaluation against ALL original multivariate equations and original group/domain rules; root completeness alone is not PDP completeness.

The required nonlinear residual visitor remains real work: after substitutions, derive genuine univariates of degree<=8, branch over all certified roots, substitute into retained residual equations, and continue bounded depth<=28. Use one node/work/storage/event ledger; budget residual copies and signed-domain extraction separately. If a polynomial is zero, it imposes no restriction; do not expand all Fp values. Select another equation, or only enumerate an explicitly finite leaf domain when semantically justified. If only coupled nonlinear auxiliary equations remain, preserve them and report UnsupportedResidual/Censored until an actual bounded elimination/branching path is implemented. Higher-degree univariates require explicit unsupported/censored status, not truncation. No roots of a genuine necessary nonzero univariate prune that branch; global negative requires exhausting every justified branch. Exceptional-infinity group tuples remain outside affine-root exhaustion and require the separate signed-group checks.

## Frozen implementation refinement

The native stream is a new versioned algebraic-boundary certificate, not a legacy field-operation transcript: Begin, LinearPart(xp,g), Split(h,delta,d,q,accepted), LinearRoot(h,r), Finish. Each event owns only inline fixed arrays. A replay state consumes these in order, tracks the pending factor stack and independently recomputes power/gcd/division/root/product identities. Producer operation counters are reported metadata, not independently verified trajectory counts. The replay implementation does not invoke producer polynomial routines or solve; it uses separate left-to-right modular powering and Euclidean arithmetic. Shared types/resource gate are permitted; shared algebraic producer kernels are not.

No native heap allocation or retained transcript is permitted. A fixed 16KiB modeled storage admission covers 64 Poly17 scratch equivalents plus explicit report/event/replay state size checks; actual source contains nonrecursive bounded call stacks. Fixed refusal/result metadata exists even when storage admission fails; the reservation covers admitted arithmetic workspace and event publication, not unavoidable caller-return ABI storage. This is not measured stack/RSS. Every scalar operation costs32 modeled units; every bounded17-coefficient operation/copy envelope costs544; event publication costs256; entry costs4096. Field operations have a separate cap. Whole fixed-array copies use precharged envelopes; checked resource counters and deadline checks precede operations. Checker gets separate remaining limits/deadline and never reuses historical wall time as its execution deadline.

Fixed split schedule is explicitly versioned SplitMix64, one charged word reduced modulo p per attempt. It is biased and makes no uniform sampling or guaranteed completion claim. All splits remain independently checked. Trial exhaustion is censored. Native report final roots are cleared on censorship; pending factor count remains diagnostic only, not resumability evidence. Invoked means actual admitted scalar arithmetic; a zero polynomial may complete AllFieldElements without invocation.
