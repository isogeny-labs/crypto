# Frozen 6,137-vertex measurement overlay

The exported HTML contains every vertex and recorded directed kernel map in
the three additional selected-degree classes: 24,823 vertices, 51 strata,
69,300 maps. Only 6,137 vertices have audited survey measurements in this
frozen overlay. Completeness does not extend to original A/C/D/E, other prime
degrees or infinitely many compositions.

Native graph/hash/population checks, Node interactions, real Chromium desktop,
floor inspector and mobile-width checks pass. All three screenshots were
visually inspected. Exact field elements remain decimal strings. Download the
HTML from the publication's Drive receipt and open it locally; Drive preview
does not execute it. An unmeasured vertex remains part of the graph.
