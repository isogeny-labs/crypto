# Campaign protocol

The canonical machine-readable protocol is [`protocol.json`](protocol.json),
generated by [`build_protocol.py`](build_protocol.py).  It is intentionally in
`draft` state: no fresh data have been collected, and the trusted EKS image
digest cannot be bound until an authenticated GitHub/AWS route publishes the
pinned source.

The scientific design is fixed now:

- cold, one-target E2E scope;
- four prime sizes and four Koblitz sizes, plus one matched solver-backend cell;
- eight public targets per cell, one warmup, six measured rounds;
- accounting-v2 rho reference and an identical rho A/A control in every spec;
- pricing weights 0, 0.1 and 1 GAE per native operation;
- L2 required for wall time, replay-all, retained failures and timeouts;
- scaling language only after all four sizes in a domain complete;
- no cross-ranking of unlike native solver counters.

Before execution, the trusted executor must add the immutable ECR digest and
the corresponding static `ecbench` SHA-256, validate every request, freeze the
canonical protocol, and commit that freeze before the first warmup.  This is an
identity amendment, not permission to change the workloads, algorithms,
budgets, metrics, or decision rules.
