# Campaign protocol

The canonical machine-readable protocol is [`protocol.json`](protocol.json),
generated by [`build_protocol.py`](build_protocol.py). It is intentionally in
`draft` state: no fresh data have been collected. Trusted publication run
`41241104247` bound the exact static binary and EKS image. The finite
implementation roster and 92-spec queue-safe shard list are now explicit and
plan-valid, and the analysis driver is hash-bound in `protocol.json`.
Exact-image runtime preflight, checkpoint upload and prospective freeze are
still open.

The non-negotiable comparison rules are fixed:

- cold, one-target E2E scope;
- separate prime, random-binary, Koblitz, j=0, j=1728, generator-orbit,
  extension-field, transfer, and solver-backend domains;
- eight prospectively selected targets per comparison cell in two four-target
  queue shards, one warmup and six measured rounds;
- strongest applicable accounting-correct rho reference and an identical rho
  A/A control in every frontier shard;
- pricing weights 0, 0.1 and 1 GAE per native operation;
- L2 required for wall time, replay-all, retained failures and timeouts, and
  no measurement retries;
- scaling language only after all four sizes in a domain complete;
- no cross-ranking of unlike native solver counters.

[`IMPLEMENTATIONS.md`](IMPLEMENTATIONS.md) closes the named implementation
space. [`SHARDS.md`](SHARDS.md) defines the 92 candidate/reference/A-A shards,
their fixed reference rules and their 2,400-second aggregate child-timeout
budget inside each 3,600-second job. The exact binary accepted all 92 specs,
covering all 13 `current_primary` top-level methods and all 11 nested solver
backends. The original nine broad specs remain planning history and are not
queue submissions.

The F_((2^m)^4) torsion fixtures are a disclosed exception to the public-target
rule: their public hash-to-subgroup constructor exhausted its fixed attempt
bound during preflight, so those eight specs use planted known-answer targets
with the scalar hidden from solvers. They form a separate implementation panel,
not public-target frontier evidence.

Before execution, the trusted executor must record exact-image runtime
preflight, preserve the hash-bound analysis driver, freeze these exact spec IDs
and the protocol, merge that preregistration to `main`, and pass
`scripts/checkpoint.sh gate` before the first warmup. The immutable identities
already published may not be changed after data are seen.
