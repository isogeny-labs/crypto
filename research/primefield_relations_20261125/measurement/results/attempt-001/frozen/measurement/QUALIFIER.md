# M31 shared-selector counted measurement qualifier

This measures a fixed public archived-fixture construction and replay, using
the ordinary prime-field M31 curve and public target of the parent study.
It does not execute a new relation search. Discovery yield and time to a newly
found useful relation remain unmeasured. [pcc:unverified]

The primary observations are typed native Rust operation counts, output
identities, admission counts, and representation payload bytes. The two
membership arms receive identical ordered inputs and must return identical
answers. Do not sum field multiplications, comparisons, inversions, and group
calls into a single uncalibrated cost. Multiplication counts include the
underlying multiplication work of exponentiation; inversion/square-root calls
are overlapping diagnostic counters, not extra additive work.

No wall-time comparison, instruction-count result, GAE conversion, strongest
implementation claim, rho ratio, or new ECDLP speed claim is admitted.
Command duration in provenance is execution metadata only. [pcc:unverified]

Full-source public-tag coverage must use all 4,608 reconstructed columns.
The original three-column roster is a separate historical acceptance control.
Selector roots, curve abscissae, signed lifts, and admitted original columns
are separate counts. The archived target and selected row are known-answer
fixture data, not a blinded new-target experiment.

Before any measured call, publish the exact source, protocol, seed manifest,
and commands. Copy this qualifier and measured sources into a fresh attempt
directory, record hashes, and refuse overwriting earlier attempts. Keep build,
pre-call, and post-call manifests distinct; preserve failures and capped runs.

Resource envelope: one native process, one logical CPU, at most 60 seconds per
measured invocation, two complete measured invocations (initial and exact replay),
plus one complete fixture invocation in the six-test correctness suite, and a
512 MiB virtual-memory cap for execution. The suite also has a 60-second cap.
Compilation is separate. No
cloud job, paid resource, parameter sweep, or new random cohort is authorized.

Standing remains unsigned producer measurement until a separately signed
admission says otherwise. This fixture does not satisfy the exhaustive
coordinate-input gate for new PCC claims, so no new ledger IDs are minted.
[pcc:unverified]
