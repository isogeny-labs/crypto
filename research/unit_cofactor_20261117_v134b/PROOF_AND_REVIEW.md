# Exact unit-cofactor compiler

Scope: binary-selector Boolean circuits with a separately certified universal identity c(theta+v)=c(theta)+1. C133 provides that identity for the frozen actual chart. The compiler accepts a certificate as a precondition,not an unverified sample-derived guess.

Choose p with v_p=1. Let x embed n-1free bits with x_p=0,h=c(x),theta=x+v*h. Then c(theta)=h+h=0. Conversely any theta with c(theta)=0 has x=theta+v*theta_p,pivot0,and c(x)=theta_p;the reconstruction returns theta. This is a bijection between n-1free selectors and the zero-correction slice. Every other output and every recovered root is evaluated at theta. The old affine chart map is applied to theta,never directly to the n-1free assignment;this retains the same original73norm bits and3quotient bits.

The compiler first clones the cofactor cone under x. It then seeds a second clone with reconstructed input wires and c=0. Substituting c=0 in downstream gates is valid by the certified universal identity on all reconstructed inputs. Each remaining gate is copied in topological order with the same operation and mapped arguments. Induction proves all outputs equal their original values at theta. Recovery-only wires are retained by pruning but excluded from zero assertions. The final raw-product verifier remains asserted. Repeated roots are preserved because the output tuples retain all five words and their repetitions.

The full accepted original-selector/root tuple set under the transformed circuit is exactly the old accepted set restricted to c=0. When c is already among the old zero assertions,that is the complete old accepted set,not a relaxation.
