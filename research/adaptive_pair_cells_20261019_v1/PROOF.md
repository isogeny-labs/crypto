# Adaptive empty pair cells (binary characteristic only)

Hypothesis: replace arbitrary cell directions by the nullspace determined by an empty point's exact dual certificate. This changes the previous fixed-grid direction assumption; it does not rerun an unchanged hard timeout.

Let K=GF(2^n), D be a d-dimensional binary subspace, p in D, and q_i=e_i^2+p e_i. For fixed s, the original binary pair equation is exactly sum x_i(q_i^2+s q_i)=1+s^2 p^2, with y=x+p in D. An empty point admits a binary functional lambda with lambda(q_i^2+s0 q_i)=0 for all i and lambda(1+s0^2 p^2)=1. Define V by lambda(v q_i)=0 for all i and lambda(v^2 p^2)=0. Both are linear constraints over GF(2). For every v in V, the same lambda annihilates the columns at s0+v and evaluates its RHS to1. Thus every point of s0+V has exactly zero ordered source pairs. This is a universal linear-algebra certificate, not a sampled estimate.

For p nonzero, x->x^2+p x on D has kernel {0,p}, so span(q_i) has dimension d-1. The V constraints have rank at most d (d-1 multiplication forms plus one square form); dim V>=n-d. For p0, the square RHS form vanishes and span(q_i) has dimension d, giving the same bound n-d. The implementation asserts a slightly weaker p0 bound, but reports the actual RREF dimension. For n83,d18 the proved lower bound is65 for every successful certificate. Repeated and zero sources are not removed; no division occurs.

The native worker reconstructs the direction nullspace, replays every original column and every direction identity, and serializes each wide cell's full basis, center, pair sum and lambda. Independent small multiplication uses raw polynomial convolution and a literal unfactored S3. Across GF8,GF16,GF32,GF128, it exhaustively checks every member of each constructed cell against every ordered source pair of that fixed sum. Field irreducibility is checked. Wide certificate validation uses the same exact universal identities; it does not enumerate2^65 points.

Work: one n-row source-span elimination per seed, d*n field products to form the direction equations, and binary RREF of at most d+1 equations in n variables. Storage polynomial in n,d plus output bases. The finite calibration grid is six p values and three centers. Setup, oracles, construction, replay and final serialization occur inside the worker boundary (65s guard,90s parent deadline,4GiB,one CPU). A late output exits3, giving no accepted exact result.

Training was exploratory and already inspected before registration. Registered replication is a correctness/profile confirmation on those exposed inputs, not a fresh holdout or performance comparison. Native algorithms remain C++; Python is metadata/exec only.

Scope: each output cell is empty only for its declared fixed p and first S3 pair. Overlaps must be accounted for; neither adding cell volumes nor a union bound proves coverage of the full2^101 (p,s) grid. Other chain links and the full original339-coordinate root set remain unresolved. No odd-characteristic transfer, hard solve, novel-priority, comparative speed, or release claim follows. Additive duality is classical. The next experiment must quantify unions/residuals and full controller overhead rather than enumerate all pair sums blindly.
