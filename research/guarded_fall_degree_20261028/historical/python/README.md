# Historical source snapshot

These files preserve the sources that produced the earlier proof traces and
finite checks before this repository was selected. They are retained unchanged
for provenance. They are not a supported execution path and are not invoked by
the native checker, research extension, build, or CI.

The active native replacement is `../../native/`. The generic binary-field
implementation is `../../extensions/char2_compute/native/`. Historical input
parameters and certificates are preserved separately; no legacy timing is
presented as a native benchmark or a performance improvement.
