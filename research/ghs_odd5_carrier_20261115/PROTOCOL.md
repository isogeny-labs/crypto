Enumerate **all** `3^11=177147` coefficient masks in base-three digit order for monic `f=x^11+sum_(i=0)^10 c_i x^i` over F3. This is the rational-Weierstrass-point odd-degree model slice; it is not all genus-five curves. Use the lexicographically first monic irreducible degree-m polynomial over F3 with coefficients in base-three integer order for m=1..5, namely masks `[0,1,7,5,7]` and moduli `x`, `x²+1`, `x³+2x+1`, `x⁴+x+2`, `x⁵+2x+1`. For the surviving masks, require f squarefree, then compute N5 and set `t=(244−N5)/5` only when integral. Retain rows with `|t|≤31` and `3∤t`; record every stage count and every retained polynomial and all five point counts. The sparse zeta criterion `N_1..N_4=3^m+1, N_5=244−5t` implies `L_Y(T)=1−tT^5+3^5 T^10` by Newton identities and the Weil functional equation. An ordinary elliptic E/F243 with trace t would have `L_(Res E)(T)=1−tT^5+3^5T^10`, giving an isogeny-class match by Tate, but no explicit map follows from the count. [pcc:unverified]
