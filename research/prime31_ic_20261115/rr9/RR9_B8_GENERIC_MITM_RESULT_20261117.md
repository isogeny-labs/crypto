## Mathematical equivalence (generic baseline, NOT novel)
Let `S_i^±` denote the two public rational points at each of the eight B8 x values, `L={Σ_{i=0}^3 ε_i P_i}`, `T={Σ_{i=4}^7 ε_i P_i}`, each with at most 16 points. Then for every public group point `R`:
```
R is a signed eight-leaf sum iff there exists l in L with (R-l) in T.
```
Precomputing `T` as a hash table and scanning `L` exactly decides signed-support membership and returns the sign mask, which is replayed with the **original group law**. This is generic meet-in-the-middle, not index calculus. The RR9 chart comparator from merged [#4556](https://github.com/isogeny-labs/crypto/pull/4556) enumerates **all 256 signs** and solves 4×3 barycentric linear systems; its nonexceptional *normalized-chart* predicate is compared on the same three frozen fixtures, not asserted equivalent on all 256 residuals because RR9 chart exclusions can apply.
