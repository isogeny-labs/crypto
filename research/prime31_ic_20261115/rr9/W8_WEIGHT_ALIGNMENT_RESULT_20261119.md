## Audited mismatch and consequence

The complete original Prime31 four-window generic-4+4 grading control, with rank **31** and **1,024/1,024** verified unknown public logs, used
`w_odd = [1,3,5,7,11,13,17,19]` in PR #4728. The current 14-variable transformed-slot public-Q Semaev F3 candidate from PR #4812 uses
`w_pow2 = [1,2,4,8,16,32,64,128]`.

**These are different relation languages.** Their relation hit rates, rank, chosen witnesses, field-operation counts, and full-solver times need not agree. Prior F3 correctness for powers-of-two cannot use the old odd-weight 1,024-log experiment as its own measured end-to-end evidence. This is an evaluation correction, not a refutation of either approach.

The exact primitive for either arm is
`R=sum_(i=0)^7 epsilon_i [w_i] P_(j_i)` with `epsilon_i in {+1,-1}`, `j_i` restricted to each eight-point window. A training relation `[a]G=R` yields the linear equation `a=sum epsilon_i w_i log_G(P_(j_i)) mod n`. Only a *working public-only nongeneric extractor for the same w_i* may replace the control's explicit 4+4 group-sum table without changing the measured relation language.

## A second methodological correction: planted SAT is size-biased

For any fixed weighted eight-slot words, write `N(q)` for the number of ordered signed representations of group point `q`, `W=16^8`, and `n=2147446831`. Then

```
P_uniform(Q=q) = 1/n;
P_planted(Q=q) = N(q)/W;
E_uniform[N(Q)] = W/n = 2.00003428909;
E_planted[N(Q)] = (sum_q N(q)^2)/W
                 = E_uniform[N] + Var_uniform(N)/E_uniform[N].
```

This identity is *exact*, not a distributional heuristic. Because `Var(N) >= 0`, a target generated by constructing a witness is systematically biased toward more representations. All planted-positive S3 tests necessarily hit, so they cannot estimate the uniform public-residual miss probability or correctly weight the cost of UNSAT F4 searches.

For intuition only, if uniform natural-target multiplicities happened to obey an independent Poisson model with `lambda=W/n`, the predicted miss fraction would be `e^-lambda ≈ 0.13533`, whereas the expected number of witnesses under planted sampling would be `lambda+1 ≈ 3.00003`. **No Poisson fit is claimed; real curve/factor-base correlations must be measured.** This matters for the frozen 46-positive /18-negative public-only extractor corpus: the natural public-Q cohort and all negative searches must be separately reported and costed.

### Relation language and extrapolation

This validates the previously missing **powers2-to-B31 assembly bridge**: with original source and same 31-coordinate factor base, weighted powers2 B8 relations across four windows can generate full rank and recover 1,024 public logarithms using the *generic 4+4 oracle*. It does **not** show a 14-variable F3 extractor can recover unknown signs/indices in reasonable time; the successful solver here is still generic-equivalent group-table enumeration.

The observed 1,151 calls impose an additional **necessary-only** extraction budget against the separately recorded historical ~170.113ms/1024 shared-BSGS control. Even granting *zero* cost for all non-extractor work, a candidate replacement must average **strictly less than 147.80 microseconds per attempted natural residual** to beat that historical numeric control. Actual allowed cost is lower after setup, linear algebra, failed F4 searches, and verification. That BSGS result was not measured on this exact CI runner, so **no matched BSGS/rho comparison is claimed**. The current powers2 generic oracle itself costs 8.741 seconds, **51.38x** the historical 170.113ms BSGS figure numerically across different runs, and is not a competitiveness result.
