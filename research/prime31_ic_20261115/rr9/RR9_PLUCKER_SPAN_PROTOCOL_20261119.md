# Frozen protocol: Prime31 RR9 exterior-four span and bilinear-rank gate

Date: 2026-11-19 UTC. PR #4779. Status: prospective and frozen before the
producer, checker, or study rows are run. Every research statement and future
reading in this document is `[pcc:unverified]`.

## Question and boundary

The public-target RR9 exterior-four predicate from parent PR #4776 contracts
two 70-coordinate Pluecker vectors. This experiment asks whether the vectors
generated by each four-slot half lie in proper linear subspaces and, more
precisely, whether the complementary-minor pairing restricted to those two
spans has rank below 70. It tests lossless **fixed linear** compression of this
specific bilinear predicate. It does not test nonlinear indexing, F4, XL, SAT,
orthogonal-vector search, relation yield, scalar recovery, or a complete ECDLP
solver.

The source parent is commit
`71859709335f1178bf7ffba043bdc989bddf6ac9` from PR #4776. Reuse the original
`prime31-algebraic-ic` arithmetic pinned there at
`1df714645aa683cf975bc76fcacb9842cb4780fd`: `p=2147483647`,
`E: y^2=x^3+847514846x+2087444724`, prime group order `2147446831`, cofactor
one, and `G=(625037715,2100627251)`. Reuse weights
`(1,3,5,7,11,13,17,19)` and the canonical first-x base construction. This is
the same fixed Prime31 instance as the parent component, not a growing-prime
or weak-curve experiment.

## Exact invariant

For public residual `R=(r,s)` and signed slot leaf `Q=(x,y)`, use the parent
row

```text
T_R(Q) = ((x-r)x^0,...,(x-r)x^3,(y+s)x^0,...,(y+s)x^3) in F_p^8.
```

For each ordered four-word in slots 0--3, enumerate the 70 ordered `4x4`
column minors of its four rows to obtain `l in wedge^4(F_p^8)`. Do the same
for slots 4--7 to obtain `r`. Let `J` be the signed complement permutation
from generalized Laplace expansion, so the parent predicate is `l^T J r=0`.

Compute, exactly over `F_p`:

- `L = span{l}` and `Rspan = span{r}`;
- `rank_L` and `rank_R` by deterministic streaming elimination;
- `pairing_rank = rank(B_L J B_R^T)`, where `B_L` and `B_R` are exact bases;
- selected source words, pivot columns, and nonzero determinant certificates.

`pairing_rank` is the minimum dimension of a factorization through linear
messages for this restricted bilinear form. Separate span ranks alone are
diagnostics; the decision uses the restricted pairing rank.

## Frozen source cases

The signed support size per slot is `2B`.

| ID | B | canonical base x values | public residual |
|---|---:|---|---|
| N4 | 4 | first four valid x values; parent expects `0,1,2,3` | `G` |
| P4 | 4 | same as N4 | exact sum of signed label zero in all eight slots |
| N8 | 8 | first eight valid x values | `G` |
| P8 | 8 | same as N8 | exact sum of signed label zero in all eight slots |

The planted targets are semantic controls only. Their hidden words are not
inputs to rank construction. Each half contains `(2B)^4` vectors: 4,096 for
`B=4` and 65,536 for `B=8`. No left-right pair scan is permitted.

## Controls and independent replay

1. Producer unit tests compare generalized Laplace contraction with a direct
   `8x8` determinant on deterministic matrices.
2. A deterministic support-matched random-vector null must reach rank 70 for
   both sides and pairing rank 70.
3. A synthetic seven-coordinate positive control must report span and pairing
   rank seven; one-coordinate mutations must be detected.
4. A fresh-process A/A producer run must be byte-identical after removal of no
   fields: the producer emits no clocks or host-dependent values.
5. A separately implemented Rust checker reconstructs the named Prime31
   leaves, evaluates `4x4` minors by permutation expansion rather than the
   producer's elimination routine, verifies every selected source vector,
   verifies the claimed basis and pairing minors, and rejects mutations of a
   target, word, coordinate, pivot, determinant, or rank `[pcc:unverified]`.

If any reported rank is below 70, the checker must additionally enumerate the
entire affected half independently and verify the upper bound. A nonzero
`70x70` certificate suffices for a full-rank lower bound because the ambient
space has dimension 70.

## Decision rule

- `KILL_FIXED_LINEAR_COMPRESSION`: N8 and P8 both have
  `rank_L=rank_R=pairing_rank=70`, all controls and replay pass. This closes
  only fixed linear compression of the registered 70-term exterior-four
  message.
- `ADVANCE_LINEAR_COMPRESSION`: N8 and P8 both have `pairing_rank<=35`, the
  same deficiency is independently replayed, and both controls pass. Build the
  exact compressed evaluator and test the frozen 46-positive/18-negative B8
  public-target panel before any solver promotion.
- `WEAK_OR_INCONCLUSIVE`: any B8 pairing rank from 36 through 69, disagreement
  between N8 and P8, censoring, source mismatch, or failed control. Preserve
  the rows and identify the first missing certificate or scaling test; do not
  label this a solver advance.

SAT/F4/XL is not authorized by this gate alone. A full-rank result leaves the
separate public-only unknown-index lane in PR #4692 open but supplies no linear
compression mechanism for it. Only `ADVANCE_LINEAR_COMPRESSION` authorizes a
compressed-message follow-up; that follow-up still must charge positive
witness search, failures, rank, linear algebra, and final scalar recovery.
