## Exact group-theoretic reference

On the existing cofactor-one `p=2147483647`, `n=2147446831) curve, let `A={±P_1,...,±P_31}` be the fixed signed factor base. The eight-leaf reachability set is **exactly** `8A=4A+4A`: split any signed eight-word into two signed four-words, and concatenate any two four-words in the other direction. This equality includes repeated coordinates, cancellation and the identity. Consequently a complete 4A hash followed by exhaustive `Q-U` probes proves **both** membership (with a concrete eight-point witness) and nonmembership (by exhausting all U). It is a **generic meet-in-the-middle oracle**, not selected-root S9, not a factor-base-log solver, and not a non-generic ECDLP attack.

The number of signed four-token multisets is `C(65,4)=677,040`, while cancellation-normal net vectors are counted by `[z^0]+[z^2]+[z^4]` of `((1+z)/(1-z))^31` = **618,885**. Distinct group points may be fewer. This audit found **exactly 618,885 group points** for **both** factor bases, so these particular four-leaf signature-to-group maps are injective. This fact is *not* eight-leaf injectivity: the eight-leaf count 5,654,193,417 exceeds group order, so collisions necessarily exist there.

## Consequences for the actual algorithmic goal

1. **Protect correctness before speed.** The existing full-case Rust oracle must compile, return the exact two-panel hit/miss pattern, independently reconstruct all returned eight-point witnesses and report zero nonmembership false positives. The previous B4/B8 S9 example failed due to a real `E0499` nested mutable borrow, fixed at [15733881](https://github.com/isogeny-labs/crypto/commit/15733881eef897a1a144008c0653f689eb239aa5). Exact-head CI is still required; the separate big-integer calculation proves no native execution.
2. **Build an actual algebraic extractor on the matched base.** `M8_RATIONAL_QUOTIENT_BRIDGE_20261116.md` represents this special base by H degree31 and pair-support K degree961. Compose the existing Rust #4228/#4349 certified selected-root/actual-root machinery with the target-conditioned S5 constraint; recover f and signs from public Q *without constructing or querying 4A*. The 24-Q Dickson panel is now a fixed truth table containing 22 feasible and 2 infeasible natural targets; add blinded planted, cancellation, repeated-root and infinity controls. No first-x31 evidence is a substitute for the matching Dickson factor-base test.
3. **Completeness is a separate burden.** Even a perfect eight-leaf oracle for Dickson31 will have legitimate natural misses. A complete ECDLP algorithm must generate additional labelled public target transforms `R=[a]G+[b]Q`, search until enough verified independent relations have been accumulated, solve for base and target logs, and charge all misses, matrix work and final scalar replay. No unknown target k is passed to the solver. A fixed-cap exhaustion is not silently counted as success.
4. **Compare to the true frontier only after a complete algebraic solve.** Frozen producer-only 48-Q reference: published APS-style Rust cold 109.734280 ms versus unfolded-rho64 99.473873 ms; the bootstrap interval crosses parity. The separate tuned Wiener–Zuccherato `rho.negation` and fastest external PKM/APS/CAS controls are not measured on this exact panel. Do not claim a win on rho from a generic eight-sum oracle or promote a leaderboard row without matched costs and independent signed PCC.
