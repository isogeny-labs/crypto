## Exact algebra and reference boundary

For E:y²+xy=x³+ax²+b with b!=0, use actual original field/basis and
S3(x,y,z)=(x+y)²z²+xyz+(xy)²+b.
The source `binary_semaev_s3_in_x3` returns A=(x+y)²,B=xy,C=(xy)²+b. For the two pairs (x1,x2) and(x3,xR), the existing S4 computes
(A1*C2+A2*C1)²+(A1*B2+A2*B1)*(B1*C2+B2*C1).
This is the characteristic-two4x4 Sylvester determinant. The generic characteristic-two S3 and resultant recurrence are given in Semaev2015 §2, equations2 and characteristic-two display: https://arxiv.org/pdf/1504.01175 . These statements support construction, not the paper's heuristic complexity claims.

Kosters–Yeo Proposition2.1 states the summation-polynomial condition over the algebraic closure, not automatically the chosen rational signed factor base: https://arxiv.org/html/1503.08001 . Accordingly do not trust the donor's loose phrase “y_i in F_(2^m) (possibly in a quadratic extension)” as a rational-domain equivalence. All candidate and negative PDP labels require the separate original signed-group replay. The IACR2014/806 PDF fetch was403; it was not used as a verified source.

Independent replay must reconstruct A/B/C from original x values and actual b, evaluate the Sylvester determinant via its24permutations (signs coincide in characteristic2), and compare every truth-table value and all ANF evaluations. Do not use binary_semaev_s4 itself as its sole verifier. This determinant check is an implementation-independent arithmetic algorithm but shares field primitives; retain independent small-field polynomial arithmetic controls as a second boundary. Zero/degree-drop quadratics, repeated x, x0, target collisions, and infinity pair sums are mandatory tests. Fixed-degree resultant degeneracies are handled as candidate algebra; group replay decides exact domain membership/completion.

## Full free-intermediate chain is still a separate integration

A genuine m3 free-intermediate system is S3(x1,x2,u)=0,S3(u,x3,xR)=0 with u represented by n field bits. Finite selectors with K x codes need3*ceil(log2K)+n variables and2n coordinate equations. For K2,n61 this is64variables/122equations; it cannot enter current3variable/61equation bounded_matrix. For general m the finite-selector shape is m*ceil(log2K)+(m-2)*n and(m-1)*n equations. Existing `build_decomposition_system` instead uses m*ell+(m-2)*n subspace variables and checks MAX_VARS; those are different domains.

Before that route: introduce generalized pre-materialization monomial/row/byte admission and original cumulative native accounting around existing matrix_f4_f2/matrix_f5_f2; preserve full-width masks and refuse shapes beyond compiled capacity. Add intermediate-identity branches or independent complete signed-domain coverage; an all-affine chain misses decompositions with an identity intermediate. `binary_semaev_chain_sat.rs` already documents and implements that branching boundary and is the source reference, not an interchangeable F4 result. No n-independent degree or complexity assumption is used.
