# Next operation: compile the existing interpolation kernel

Question: can an exact, guarded elimination of the section-coefficient block
reduce solving work on unknown original member coordinates? This is an open
algorithmic proposal, not a new geometric theorem or exponent claim.
The existing torus-section-operator already evaluates a six-dimensional
section basis and computes a kernel for a SUPPLIED tuple, including aliases,
repeated-point jets and both target-pole charts. Reimplementing that predicate
or reconstructing coefficients after guessing all six points is no discovery
algorithm. [pcc:unverified]

## Exact proposed interface

Keep the original public Spec/R/Q and member/index/sign/range guards. First
resolve the raw-R versus image-Q sector distinction in FIDELITY.md; charge
any sector enumeration/filter and prove completeness for the declared task.
[pcc:unverified]
The existing operator's admitted finite non-two-torsion charts are narrower
than a universal elliptic point domain. Unsupported charts must remain
explicit or acquire separate exact branches, never count as negative roots.

Compile its six evaluation/jet rows with UNKNOWN point coordinates. On the
regular finite target chart its existing basis is
1,x,y,x^2,xy,(y+s)/(x-r). Preserve its P=R local section, P=-R removable value,
and Hasse jets for equal points with distinct raw IDs. A naive row that
vanishes automatically at -R must not replace the local jet constraint.
Retain the original normalized coefficient chart and every original equation.

Choose five coefficient columns and a nonzero5x5 row minor, introduce the
minor inverse with an explicit guard, reconstruct those coefficients, and
substitute into the remaining row and norm/characteristic interfaces. Cover
every selected pivot alternative; keep the original linear equations as an
exact fallback on unresolved/rank-deficient strata. Never assume rank5 or
normalize a coefficient without its guard. Fraction-free determinants or
Schur complements are classical operations, not novel algorithms.

## Acceptance before interpreting cost

1. Extension/projection both ways, checked against the original circuit and
   numeric section predicate on admitted charts. Include +/-R, aliases,
   multiplicities, zero minors and rank-deficient synthetic systems. Keep all
   original guards; no supplied unknowns in a root-discovery query.
2. Record degrees, fill, operations, live memory and original lifting/setup
   costs for each branch. Fewer coefficient variables or a fixed6x6 kernel
   does not bound elimination degree or the remaining point/index search.
3. State the route-specific sufficient full-cost/yield inequality using the
   unchanged criteria and actual growing family. A complete exponent claim
   still requires useful target yield, independent relation rank, private
   selection, kernel/recovery and memory/indexing/setup costs.

Do not enumerate all triples, increase the unchanged generic caps, treat
quotient rank6 as solution-ideal dimension, or transfer an AG-code worst-case
hardness theorem to fixed-six average-case decomposition. No campaign/paid
worker or implementation of this proposal is scheduled by the PR checker.
