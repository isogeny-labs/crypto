The native query performs no explicit q-element ratio enumeration. It handles
only adjacent original cosets j2=j1+1 within1..K; it does not search all
original pairs or the six-member problem. The two original raw parameter
columns remain distinct even when their physical images alias. The original
target circuit, numeric decoder and independent native signed-row/group
replay all run on returned roots. No numerical scalar enters query.
[pcc:PCC-20261124-0a02aa]

As shipped, the supplied-old-list admission is linear in L, and exhaustive
search also visits every old column. Merely lifting the finite list cap
retains that loop family. This cannot meet the preceding optimistic closure
model's sub-square-root-in-L query target. That is an algorithm/model-specific
cost observation, not a lower bound for every data structure or method.
The optimistic ell^(1/3) closure scale itself has not been achieved.
[pcc:unverified]

Pre-admitted persistent old-column structures may move repeated validation
into setup or incremental insertion; charge that work cold to the same DLP.

an upper-bound estimate for this implementation cannot disprove a different
implementation. No fastest-tool comparison, normalized GAE, timing, peak RSS,
full allocator, private-target sampling or full-base recovery is reported.
