{\Large\bf Pair-yield obstruction: return to joint six-member discovery}\par
24 November 2026 \hfill Scoped follow-up to anchored-ratio-v1

\textbf{A correctness component is not a useful relation generator.}
The new anchored Rust interface returns original checked/indexed pair roots
on selected fixtures. For fresh uniform tagged points, the original base's
size already rules out competitive pair collection in the stated model,
even with a free complete pair oracle.

Let $B=Kq$ be the declared number of original raw labels and $S$ its admitted
signed image set. Then $|S|\le2B$, so
\[
 |S+S|\le |S|^2\le(2B)^2.
\]
Distinctness, old-column and adjacent-ratio restrictions only reduce that
image. Include one additional target to account for the identity draw that
can directly reveal the scalar. For the original parameters,
\[
 \bigl(2(213156431\cdot20633)\bigr)^2+1<2^{87},\qquad
 \ell=2^{252}+27742317777372353535851937790883648493\ge2^{252}.
\]
Thus a fresh uniform raw tagged point hits an original pair target or the
identity with probability less than $2^{-165}$. By a union bound, at most
$2^{164}$ draws have success probability less than $1/2$ for a method whose
only recovery path is these pair rows or identity draws. Failed queries are
included. Known-consistent fixtures are not draws from this distribution.

\textbf{Exact formal scope.} The two concrete natural-number inequalities
above are kernel-checked endpoints with no axioms. The focused maintained
gate passes two named theorems, no failures and no trusted-native proofs.
The finite-base/native-map and uniform-sampler bridges remain written
hypotheses; the probability/model conclusion is not a full Lean theorem
about this Rust implementation. The count is classical, not a novelty claim.

\textbf{What is rejected.} Fresh-target \emph{two-member} relation collection
over this fixed original base is closed as the next exponent lead in that
model. This does not reject nonuniform query strategies, a larger/different
base, additional large-prime columns, extra logarithm transport or six-member
relations. It is not a general ECDLP lower bound.

\textbf{Next plan.} Resume joint six-member extraction without enumerating
triples or silently reducing it to rare original pair queries. In the
previous conditional common-base model, full attempt cost $B^\gamma$, useful
six-sum probability of order $B^6/\ell$, $B$ useful rows and sparse linear
algebra $B^2$ give
\[
 \ell B^{\gamma-5}+B^2,\qquad
 \text{optimized exponent }\frac{2}{7-\gamma}.
\]
The optimized-family target is $\gamma<3$ under those assumptions. Keeping
$B\sim\ell^{1/6}$ instead gives relation exponent $(\gamma+1)/6$ and requires
$\gamma<2$ at that model point. Neither useful yield nor either solver-cost
bound is established. Setup, failures, indexing, selection, kernels, memory
and checked scalar recovery remain charged. The pair interface is a retained
component, not a surrogate for the missing joint selector.
