{\Large\bf Anchored ratio queries with original indexed witnesses}\par
Curve25519 research component \hfill 24 November 2026

\textbf{Implemented.} Public target $T$, supplied old physical columns,
original context and finite limits enter the Rust query. No scalar, private
target tag, numeric label, planted tuple or root list enters it. For each
old column it tries both signs $P$, forms $T-P$, enumerates original inverse
fibres, tests the implicit ratio condition $r^q=h^q$, and returns checked
original two-member target-circuit witnesses on adjacent cosets
$j_2=j_1+1$. Numeric $(j,t)$ indexing is a separate replay phase.

\textbf{Recorded correctness.} One source-qualified fixed native call
completed four groups, zero failed, with 42 raw records. The toy declared
base has 24 raw labels, 44 signed admitted leaves and six physical columns.
All 208 direct-reference pair witnesses across all 12 nonzero image targets
equal the complete ALL outputs. FIRST returns a member of the matching set.
The reference shares field/group/raw-map primitives and bypasses inverse
and coset-search algorithms; it is not independent signed validation.

Original actual parameters remain $p=2^{255}-19$, $A=486662$,
$a=60824497$, $q=213156431$, $K=20633$. Five selected queries produce four
roots, each with 339 original witness values and original numeric-index /
signed-row / group replay. No $q=1$ substitute or full actual-base enumeration.
The no-root RFC-generator case exhausts only one supplied old column.

{\Large\bf Closing a row is different from obtaining a useful kernel}

The known-consistent actual root has a new complementary column with one
supplied old column. Supplying its second column changes the closure flag.
That second column is chosen fixture data; no unknown relation collection
or actual informative kernel has been established by that comparison.

\textbf{Separate synthetic row controls.} Toy columns and tags are chosen
for validator $Q=[5]G$. Group tags are replayed \emph{before} exact rank.
Native elimination checks invertible row operations and complete left-kernel
products. Every recovered scalar is checked by $[x]G=Q$.

\textbf{Refusals and provenance.} Ten admission/cap cases reject, as do all

identity-sum fixture; its source and failure are retained. Validator sign
selection was corrected before qualification. Clippy diagnostics and the
one inadvertently repeated pre-repair check are preserved too.

Three final release tests, formatting, strict all-target Clippy and build
pass. Source118 is the previous111 plus seven new crate inputs, in six

\textbf{Exponent-relevant next step.} Query performs no explicit $q$-element
ratio scan, but the old-column list still has linear admission and exhaustive
selection. Merely raising its cap keeps that loop family and cannot meet
the preceding prospective closure-query target. This is a statement about
this implementation and model, not every data structure or index-calculus
method. A no-root result on one old column is not full-base absence.

The missing primitive is a structured intersection with $T-S$ that yields
two-old-column rows and nonzero target-tag kernels without a free $L^2$ sum
table or an $L$-sized scan. Review primary 3SUM-indexing tradeoffs and the
actual old-set structure before choosing an approach. Persistent validated
old sets, cached encodings, and deducing $j_2=j_1+1$ can reduce repeated work,
but do not themselves move the selection exponent. Charge construction,
updates, useful yield, memory, numeric indexing and final scalar replay to
one cold DLP. No such campaign is scheduled here.
