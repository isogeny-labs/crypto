# Section-search v1: analytic recurrence and identity controls

User requirement: find exponent-moving Curve25519 index-calculus mechanisms,
preserving the original useful-row, private-tag, cold-cost and recovery
criteria. This round derives an implicit section-membership/restriction
interface and a bound against uniform coefficient seeds. It does not implement
or admit a coefficient solver, solver campaign, paid run or full-base search.

The classical six-section predicate and its native v1 source remain frozen.
The new derivation moves to pre-eightfold points, transports the public target
through the complete rational [8]-fibre, and uses a sextic norm. All returned
rows would still require the original raw-index/sign/nonidentity/distinctness
and public-target checks. No chart refusal is a target absence certificate.

Prospective native controls use the maintained identity_certificate.rs and
SHA256 source unchanged, with a small new Rust issuer. Two declared identities:
(1) the degree3 geometric trace factor with its explicit residual combination;
(2) the degree5 cleared norm evaluation at the target abscissa. Each receives
32 fixed issuer points, 32 further domain-separated points, and a plus-one
false-identity refusal. Seeds are 202611170845+i and 202611170846+i for i=0,1.
These evaluated records use the module's declared 2^61-1 field, not the
Curve25519 field or a formal universal proof. No independent/signed standing
or Schwartz--Zippel randomness interpretation is inferred from fixed streams.

Build/fmt/strict Clippy and focused existing native module tests are development
qualification. Before the final issuer call, commit and pin source, copy the
binary outside target/, write distinct BUILD/PRECALL/POSTCALL manifests and
refuse overwriting PRECALL. Retain initial failures and sources. No code edits
after qualification without a new version. Raw JSON and stdout use separate
paths. A complete output means only those declared identity controls passed.

The analytic query bound is in terms of actual polynomial multiplication M(n),
including scalar work and setup. No implementation, native query timing,
complexity fit or full attack exponent follows from the identity issuer.
Uniform sampling is rejected only under its explicitly stated coefficient
distribution, finite divisor model and counting assumptions.

Formalization is partial: reuse existing Mathlib unit cancellation for the
sixth-power rescaling endpoint. The geometric norm/divisor equivalence,
finite-field support criterion, quotient-algebra algorithm, counting injection
and cost theorem remain written obligations. The assembly endpoint is not
substituted for them. Full proof-map and pinned dependencies accompany it.
