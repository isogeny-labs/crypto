# Replace the cubic loop before pursuing scaling

The bounded reference now accepts public targets and returns original
roots or exact finite exhaustion under its documented contracts. Its
representative families address distinct-index correctness; they do not
remove explicit triple generation.

For retained raw cardinality n, the uncapped six-member loop enumerates
8*C(n,3) signed triples before a query. Lifting its caps without replacing
this loop retains cubic setup. Under the prior n~ell^(1/6) model that setup
alone reaches exponent1/2, before query/row/kernel/recovery work. The loop
family therefore cannot supply a strict exponent advantage at that model
point, even if one target query became free. This rejects that extension,
not all index calculus, all meet-in-the-middle variants or every solver.

The next discriminating solver implementation should operate directly on
the existing quadratic relation ideal and receive public inputs only. Freeze
its hypothesis, domain, method, limits and pass/falsification/censoring rules
before running. A structure-specific compressed operator or elimination
method must explain how it avoids enumerating all triples, preserve both
Fp2 coordinates/range/distinctness/point equations, and lift every reported
root back to the unchanged original system. A compressed table built after
all triples have been generated does not satisfy that condition.

Separate actual root-discovery work from root checking, public-base setup,
index/sign recovery, selection, matrix/kernel and scalar replay. Charge
failures and reusable setup to the one-target cold interval. Require useful
target yield and a growing family; finite fixture success is not a gamma
estimate. Timeout/OOM/resource refusal remains censored, not disproof.

Continue applying the unchanged criteria:

Any experiment still requires the existing runner/admission/budget process.
This plan schedules no solver campaign or paid job. The private-tag and
one-retained-row contract, full family/phase/memory gates and unsigned
standing remain unchanged.
