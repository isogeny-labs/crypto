## A reduction that avoids scanning the ratio family

Let R be a predeclared family of allowed norm-one ratios. Given a fresh
public target T and one supplied old signed physical column P, form U=T-P.
Refuse identity U or handle it as an explicit anchor case. Enumerate the
original inverse encodings of P and U, at most32 each, including all8 raw
cofactor fibres. Each pair(z,w) yields sigma=z and ratio r=w/z for the
relative template(1,r). Test r in R, raw/index guards and [8]sum=T.
At most1024 candidate pairs per signed P, or2048 for its two signs, cover
all admitted two-member decompositions using that physical column. Raw
distinctness and original base guards must be replayed, not inferred from
norm membership. This is a written reduction, not new native qualification.
[pcc:unverified]

If R={r:r^q=omega} in the norm-one group, a candidate ratio's membership can
be checked by binary powering; it does not require enumerating |R| elements.
The exact cardinality, rational roots, coset/label range and index extraction
still require the original parameter hypotheses and checks. No q1 replacement
is allowed in a claimed original-parameter successor. A direct implementation
can reuse the frozen Family.encodings semantics in a NEW versioned crate or
study; do not change its prior qualified source. [pcc:unverified]

This reduction changes where the search lies: choosing the OLD column P.
It is not a constant-cost decomposition algorithm for a common useful base.
If every accepted row attaches one new column to one old column, repeated
singleton peeling leaves no useful kernel. Returning many encodings of the
same row does not repair that. [pcc:unverified]

## Target the second old column, not the first overlap

For L known physical columns, a closure row must hit a signed sum of two of
them (plus explicit doubled-column cases). There are at most2L² such public
targets before ratio/range guards. A fresh uniform target therefore has
closure probability at most2L²/(ell-1), independent of the ratio test's speed.
The coefficient test remains exact field algebra: graph cycles can be
nondependencies, and dependencies can have zero target coefficient.
The current owner LargePrimeGraph laws and original tagged replay apply.
[pcc:unverified]

An optimistic L~t closure model suggests t~ell^(1/3) queries. Scanning all L
old columns per query costs order t², giving ell^(2/3) in that model, before
other phases. With actual tight per-query work Theta(L^beta), its optimistic
phase is ell^((1+beta)/3); beating1/2 would need beta<1/2. These are conditional
research gates, not an attained rate, a generic lower bound or a guarantee
that the first closure gives a useful dependency. Setup, family admission,
growth/acceptance and complete cold recovery costs cannot be omitted.
[pcc:unverified]

   returning one original witness in sub-square-root-in-L total query work

   explicit L² sum table, or an O(L) scan cannot satisfy that prospective gate.
4. Reject only the admitted algorithm/model after its stated gate fails. Do
   not extend the finite-incidence result to every coordinate, isogeny,
   nonuniform query, extra logarithm transport or index-calculus method.
