# Prospective discrimination protocol; no run launched

This protocol is a proposal under the existing goal, not an experiment,
implemented solver, admitted performance result or scheduled paid job.
Use Rust for field/group/polynomial/rank work. Native source/fixture/version
qualification and execution admission must precede the corresponding new run.
The existing CI-only checker does not execute this protocol. [pcc:unverified]

## A. Algebra and two-leaf public interface

1. Implement the four degree<=8 numerators from DERIVATION.md with explicit
   canonical/norm/denominator guards. Retain an unchanged numeric rational
   S3 comparator and direct Montgomery group replay. Qualify a maintained
   identity-format record plus exact coefficient or formal instance checks.
2. The query accepts public curve/spec,h,template alpha1/alpha2,R/Q and fixed
   limits ONLY. No planted sigma, candidate multiplier list, root list, raw
   target scalar, known section or auxiliary assignment enters the query.
   Labels of alpha_i are public template constants, not planted target data.
3. Extract every Fp root of each nonzero branch polynomial; include sigma=-1
   separately. Split cap/unsupported/degenerate polynomial/malformed input
   are errors or incomplete results, never absence certificates. Identify the
   finite chart/target sectors actually supported. Repeated roots are retained
   without multiplying the apparent number of bases or useful rows.
4. Every root lifts to raw rational points, signs, exact R, eightfold Q and
   shifted raw-label replay. Do not pass shifted points to the unmodified
   original map circuit and call it a valid replay. A shifted wrapper needs
   explicit extension/projection and all original guards.

## B. Fixed correctness controls before a larger backend

Freeze once: toy p101/A95 with existing h(17,12),a17,q3,k8 and templates
h/h². Compare all102 torus multipliers, including the infinity chart, and
all supported finite raw target points with an independent direct group
enumeration. Retain every target with no accepted lift as well as successes.
Exact expected counts are not invented in advance. Alias/opposite-sign,
double/inverse, malformed/norm/denominator/zero-polynomial and cap controls
must be separately classified. Exhaustion applies only to the declared finite
domain and completed factorization/lifting. [pcc:unverified]

Original actual p/A/a/q/K remain unchanged; templates h/h² have original
relative labels(1,0)/(2,0). Use public Montgomery u9 point and its negative
as declared target controls, plus one known-consistent raw target constructed
for validation. That known multiplier stays outside the query API. Native
qualifier and raw logs must reveal whether all fixed arms completed. This is
a small correctness protocol, not a uniform-target cohort, benchmark or
full actual-base enumeration. No q1 substitution. [pcc:unverified]

Source publication before immutable qualification/final fixed call; exact
source/archive/compiled hashes, retained executable pre/post, copied immutable
qualifier, write-once BUILD/PRECALL/POSTCALL, real successful transport/collision
checks. Each bounded call must bind actual caps before execution; proposed
local correctness ceiling600seconds/2GiB only where current instructions admit
it. Preserve failed attempts and complete raw. No unapproved backend/paid work.
[pcc:unverified]

## C. Shared-base recovery is the decisive second gate

Before six-leaf scaling, freeze a method for sharing bases/columns or transporting
logs. On a declared toy group, receive only public G,Q, obtain checked rows,
canonicalize raw/cofactor aliases and compute M,a,b. Retain rank(M),rank([M|b]),
an exact left-kernel recovery witness when present, and held-out scalar check.
Keep private-column rows, repeated rows and base relabels as negative controls.
This stage is UNIMPLEMENTED and cannot be replaced by displaying a short
target decomposition on a fresh base. [pcc:unverified]

Only after that gate prices its full cold work/yield/index/memory cost should
a six-leaf resultant/root backend or a scaling campaign be proposed. A failure
of one overlap mechanism closes that mechanism/domain, not all adaptive bases.
The old conditional energy orthogonality audit is separate proof work.
