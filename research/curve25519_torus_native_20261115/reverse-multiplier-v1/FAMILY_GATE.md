# Shared-base and target-tag gate

The multiplier fibre may cheaply return a decomposition into an adapted base.
The acceptance object is useful, independent relations on shared geometric
columns with complete base-selection cost. This gate precedes any exponent
interpretation. It does not disprove all adaptive-base algorithms.
[pcc:unverified]

## Parameter-base equivalence

Let H_q=<h^a>. Multiplication by any delta in H_q permutes t within each
coset label j, so sigma and sigma*delta define the same raw parameter set.
Conversely, a stabilizer of nonempty S lies in<h>, since S is contained
there. In <h>/H_q it must preserve J={1,...,K} in Z/aZ. The cyclic boundary
J\(J+1) is the singleton{1}, for0<K<a-1; preserving J preserves that boundary,
forcing the shift to be0. Thus the PARAMETER-set stabilizer is exactly H_q,
under the stated exact-order/bounds hypotheses. This written argument still
needs its own formal/native qualification. [pcc:unverified]

There are (p+1)/q possible parameter-base classes, not one. Normalizing
sigma modulo H_q needs an exact class key and a charged index transport.
The existing BSGS raw index adapter is not a free scalar-DLP oracle. A t
relabel within one class gives the same actual parameter/point, and no new
independent row merely from its names changing. Extra accidental point/cofactor
aliases must be canonicalized and counted separately from this set stabilizer.
[pcc:unverified]

## Exact linear recovery criterion

For public G,Q=xG in the prime group, let all collected rows be checked
against actual geometric prime-group +/-columns. Remove known-log columns
into their known scalar tags; normalize equal/opposite images consistently,
while retaining raw provenance. Write the resulting equations

    M*z = a + b*x   over F_ell.

A left-kernel vector v with v^T*M=0 and v^T*b!=0 gives
x=-(v^T*a)/(v^T*b). Its existence is equivalent to

    rank([M | b]) > rank(M).

This is a written application of ordinary finite-dimensional linear algebra,
not a new theorem or a tested recovery instance here. It is the necessary
and sufficient criterion for recovering x from THESE LINEAR EQUATIONS ALONE,
with their stated known information. Additional side information or nonlinear
methods would be separate data/algorithms, not silently excluded.
[pcc:unverified]

If each row introduces a column absent from every other row, those private
columns force full row rank and zero left kernel. Rows on different parameter
bases cannot be assumed disjoint or shared: compare their actual points and
charge generation/canonicalization. Repeated/relabelled copies do not add
rank. No blanket claim that rows must exceed every named raw column is made.
The target point itself, if encountered, must enter its known target tag,
not masquerade as an independent unknown logarithm. [pcc:unverified]

## What could make this route useful

A candidate must supply a construction producing enough genuinely shared
columns or transporting logarithms between adapted bases, with the tags and
rank condition above. The original elliptic encoding is not a torus-group
homomorphism, so torus multiplication alone is no transport proof. Freeze any
proposed overlap/template mechanism and its complete costs before testing it.
Do not assume a birthday collision of base classes is a recovery certificate.
[pcc:unverified]

For comparison with the old six-sum cost target ONLY, suppose one common
base of B normalized classes has useful yield of order B^6/ell and public
decomposition cost B^gamma. B independent useful rows would then cost
ell*B^(gamma-5), and sparse algebra B². Balancing gives2/(7-gamma); gamma<3
is the familiar sufficient phase threshold, conditional on every other
phase/family/rank/recovery bound. The adapted-base fibre has established
NEITHER that common-base yield NOR that gamma. Its constant-degree equation
cannot be inserted as gamma0 in this calculation. Original criteria govern
compiler/parameter search/indexing/lifting/rejections/memory/kernel/recovery.
[pcc:unverified]
