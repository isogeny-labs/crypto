$C:y^2=x^5+x+2$ and the reduced divisor with

\noindent The direct author output has $Z=W=0$ and is not a valid weighted
divisor. Two normalization denominators would be zero. The author's public
dispatcher checks the inverse condition first and therefore does not reach
that subroutine on this input. The public paths have zero undefined inverses
for this fixture. This is a subroutine edge, not a public-law discrepancy.

\noindent\textbf{Reproduction.} The standardized row is \texttt{ROWS.csv};
\texttt{run.py} compiles the pinned Rust source plus a temporary test module.
The initial intentionally failed assertion and corrected passing rerun are
retained as raw logs. \texttt{check.py} pins the complete author and Rust source
SHA-256 hashes, checks dispatch order, and evaluates the author expressions.
The exact command and source URL are in \texttt{README.md}.

\noindent\textbf{Boundary.} This checks one $\mathbf F_{17}$ input. The
author Magma source was evaluated, not executed in Magma. It establishes no
universal formula parity, Picard-group theorem, or new cost measurement.
