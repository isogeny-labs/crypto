\section*{Checked statement}
Let $a$ be a rational simple root of the quintic and $R$ the structure-sheaf stalk of the actual weighted-Proj curve at that branch. The previously checked local geometry makes $R$ a DVR, with $\operatorname{ord}(y)=1$ and $y^2=(x-a)q$ for a unit $q$. The new theorem proves that if $N=(x-a)t$ and $B$ is a unit in $R$, then
\[
\operatorname{ord}(N-By)=1.
\]
The proof transports the generic branch zero-order lemma into this actual projective stalk. The underlying DVR criterion is discussed in the \href{https://stacks.math.columbia.edu/tag/00PD}{Stacks Project, Lemma 10.119.7}.

A second checked theorem composes the separate norm-factor transport with this result. If a polynomial norm identity holds at a rational support root and $B$ is a unit in this stalk, then the evaluated polynomial numerator satisfies $\operatorname{ord}(n(x)-By)=1$. A checked corollary replaces the unit premise with the source-style scalar guard $b\ne0$: its image $B$ is a unit. The norm polynomial and its link to the compiled runtime numerator remain explicit inputs.

The source-style specialization uses the checked common 2+2 coefficient formulas. Under valid Mumford input congruences, a normalized quintic head, nonzero determinant, a rational simple branch, and a root of the norm support product, it proves the same local order for the proof-side polynomial numerator. Equality of the supplied quintic with the actual curve equation and compiled runtime semantics are still separate obligations.

The actual-quintic specialization proves the weighted-Proj quintic evaluates to the affine branch polynomial and has the required normalized head. A further checked corollary derives the simple-root condition from separability of that quintic. Valid input congruences, nonzero determinant, rational branch root, and norm-support root remain explicit.
