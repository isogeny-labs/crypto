# Finite-branch stalk on the actual weighted-Proj curve

This is a conditional formal geometry packet, not a new target experiment or cost comparison. The [diagram](finite-branch-stalk.svg), [gate table](finite-branch-stalk.csv), [Lean source](WeightedFiniteBranchStalk.lean), [axiom log](finite-branch-proj-lean.log), and [PDF](FINITE_BRANCH_STALK.pdf) preserve the exact statement and limits.

For any field `K`, coefficients `a3,a2,a1,a0`, and rational root `a` of the affine quintic, `WeightedFiniteBranchStalk.finiteBranchProjPoint` places the branch point in the actual weighted `Proj` through its `Z` basic-open chart. `finiteBranchProjStalkIso` identifies the structure-sheaf stalk there with `Localization.AtPrime (branchIdeal ...)`. This transports the *ring model* used by the checked simple-branch order-one theorem to the actual projective curve. The new isomorphism itself needs only the root hypothesis; the earlier DVR and zero-order results additionally require a simple root and, for the order-one conclusion, `N=(x-a)t` and unit `B`.

The proof composes the existing [affine basic-open chart isomorphism](WeightedProjSchemeChart.lean) with the [affine branch-stalk localization](Common22BranchStalk.lean), using Mathlib's open-immersion stalk-isomorphism theorem. [Stacks Project, Section 26.3](https://stacks.math.columbia.edu/tag/01HD) states the corresponding open-subspace stalk identification. The checked isomorphism does not construct a global divisor, prove the principal-divisor/Pic⁰ equation, or connect the compiled Rust law to all branch hypotheses. It changes no frozen target, cost, or rho row.
