# Whole weighted-Proj curve: checked integrality under separability

The pinned Lean theorem `WeightedProjIsIntegral.whole_curve_integral` establishes `IsIntegral (Proj (degreeSubmodule a3 a2 a1 a0))` for any field `K` and coefficients `a3 a2 a1 a0 : K` when `WeightedProjSmoothPoints.quintic a3 a2 a1 a0` is separable. This is a theorem about the **actual weighted-Proj scheme** used by the common 2+2 proof line. It has no characteristic restriction beyond the stated separability hypothesis.

The same file checks two intermediate transports: `x_basic_open_integral` needs only `Field K`; `z_basic_open_integral` additionally needs the quintic separable. It obtains each basic-open scheme's integrality from the corresponding affine coordinate-ring domain and the checked scheme isomorphism. The whole-curve theorem uses `WeightedProjCover.two_basic_opens_cover` and the checked `WeightedProjOverlapNonempty.actual_x_z_overlap_nonempty` to glue preirreducibility. It builds a two-open `Scheme.OpenCover`, glues reducedness, and applies pinned Mathlib's `isIntegral_of_irreducibleSpace_of_isReduced`.
