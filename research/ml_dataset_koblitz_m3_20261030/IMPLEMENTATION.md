# Native implementation handoff

2026-10-30. Design frozen in5a56535dba0 before implementation. Only parent module declaration plus new bounded child module changed; no legacy call path redirected. Seven authored tests are unrun. No builds, tests, draws, cloud or adapter changes performed here. Scoped rustfmt only.

The public API is koblitz_groebner::bounded_s4::build, with Limits/Reserved/Output/Failure/Stop/Event/Stage. Failure is allocation-free. A caller-certified irreducible modulus is required; canonicality alone is checked, not irreducibility. Fixed metadata admission precedes callbacks, and every callback error immediately unwinds without another callback. No returned equations on any stop. Callback-owned memory and process allocator bookkeeping are excluded. The final Complete event describes construction only, never solving.

All native Vec buffers use try_reserve_exact and checked Layout before fill. Bounded coefficient operations retain FieldSum and exactly the old table multiplication/XOR semantics, but use fallible local variants because old helpers allocate infallibly. No FieldSum::of, SymElement::mul, legacy S4 wrapper, hash map, or multiply fallback is called. In-place sort_unstable needs no secondary heap buffer; support remains in existing canonical monomial order. Each operation checks deadlines before admission, before allocations and within bounded loops. Sort is a finite <=65536-entry noninterruptible native chunk; no hard preemption promise. External supervision remains required.

Internal arithmetic operands derive from admitted n<=61, support<=256, domain<=64, V<=18. Thus individual tariff computations are bounded far below usize/u64 overflow on supported targets; cumulative additions and raw pair multiplication explicitly use checked arithmetic. The input low_terms length is capped before scans. FieldSum masks/coefficients are constructed internally from canonical inputs, never deserialized or accepted as public data. This prevents alternate high-mask sort paths. Products use a single B*n row table; no arbitrary block-size parameter. Bytes are cumulative nonrefunded reservations and include all created buffers, not actual live peak or RSS. Setup native multiplication has inline one-limb operands and at most one excess-bit fold; the1MiB allowance includes temporary setup storage.

Coordinate work is admitted BEFORE the popcount sizing scan, then bytes before allocation. Selector reservations include value table, terms, transform and sorting. No clone of full symbolic values. Construction preserves the original17-product/8-square DAG and constants; the setup uses powers ofz and exact differential test to old table.

Authored controls: required K2 nonconstant equations at n23/31/47/53/61 with all eight assignments against separate Horner scalar eval_f3 and general resultant (targets0,domain0,37); exact power table equality; K1/2/3/4/5/64 selector modulo padding; K3/4 full sparse result or explicit modeled budget refusal; exact/one-less work/bytes; begin metadata boundary; sticky observer; expired deadline; invalid b/modulus/coordinates/domain/limits; checked cumulative overflow and raw pair refusal before field access. Sparse deterministic existing modulus selection used by tests, no retries or resampling. Tests are not execution evidence.

The native API correctly omits a/twist because the polynomial is independent of a. Parent agrees both actual-twist group/domain positive/negative/exceptional-prefix controls remain mandatory at adapter layer. Neither artificial duplicate twist labels nor native polynomial equality substitutes for them. Actual native Boolean F4/F5 invocation/nontrivial reduction, bounded solver gates, persistence/replay/feature compatibility and signed-domain extraction are pending separate integration.
