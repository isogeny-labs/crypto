\section*{Observed source and protocol facts}
\begin{enumerate}
\item Grading version 3 compares \texttt{time.solve\_wall\_ns} with the unchanged 1,000,000 ns floor. The protocol primary cold field is \texttt{time.method\_call\_wall\_ns}.
\item The protocol prose says the cold endpoint is the immediate method return before the profiling dump. The selected method-call field actually stops after nested instrumentation closes and \texttt{methods::complete} returns.
\item Every one of the 720 rho/rho\_AA method-call intervals is also below 1 ms. Changing only the classifier field would therefore admit none of those rows.
\item The instrument contract permits \texttt{rho\_solve} and \texttt{recovery\_check} for a generic method. The canonical exporter checks every arm for exactly the five index-calculus target phase names.
\end{enumerate}
