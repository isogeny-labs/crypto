\section*{Algebraic interface}
An input row is $\sum a_iX_i+\sum b_jS_j=0$ over a prime field. At most two
large-variable terms survive canonicalization; the $S_j$ remain symbolic.
The forest stores $X_i=s_iX_{\mathrm{parent}(i)}+u_i(S)$ and uses union by size.
Root substitution leaves zero, one or two free roots. Zero emits a constraint,
one anchors a root, and two join components by an invertible pivot.
An unbalanced signed cycle anchors its root; it does not immediately yield
an additional relation involving only small variables.
\section*{Recorded development checks}

row reduction after every prefix: 40 prefixes, 128 deterministic streams and
five prime fields (2, 3, 5, 7 and 101), totaling 25,600 checks.
Additional cases cover signed cycles, duplicate terms, rejected inputs,
composites and a prime near the 64-bit limit. The test log is retained.
The four Lean declarations cover pivot equivalence, substitution, balanced
cycles and unbalanced cycles. Their direct compiler result and axiom report
are retained separately. They do not formalize the full forest invariant or
prove correspondence with Rust.
The retained residual basis is now also compared with the independent reference
at all 25,600 prefixes. Fourteen default library tests pass. Explicit working and retained
coefficient caps leave the basis unchanged on rejection; callers must stop or
retain that rejected row. Original residual diagnostics count failed attempts; the separate semantic
and allocation observations described below extend their coverage. These are
coefficient limits, not process-memory guarantees or a complete cost model.
The composed adapter binds both stages to one field and fixed column
partition, rejects three-large-variable rows explicitly, and retains an
unincorporated constraint on terminal cap. Its row space is also checked
at all 25,600 prefixes. The optional producer now connects this adapter to
the existing geometric checks and matched control. Producer tests check
signed coefficient parity, rejection of constant-only inconsistencies and
phase attribution of symbolic events. Setup is a separate recorded phase.
Semantic arithmetic counts include inversion multiplications and distinguish
primality powers from inversions. Direct pivot lookup replaces full basis

\section*{Online timing integration}
These are implementation observations for public synthetic mathematical
instances, not performance measurements. The root harness uses the existing
exclusive phase clock. Target-blind curve, base and empty-solver setup precede
target validation. Query/control owns the intervals between named stages;
the five exported phase times must sum exactly to the online window.
A regression checks this partition and setup exclusion. Additional independent
adapter verification remains outside online and is charged in cold group counts.
The matched reference opens at target transfer or the first nonzero target
multiple. The original interface retains a no-op hook. A regression checks one
hook invocation and unchanged answers, operation counts and phase counts in
plain, negation and transferred modes. The root zero-coefficient and replay-digest regressions have passed within
the full-library run. That run recorded 5,146 passes, seven failures and
123 ignored tests. Six failures required omitted tracked fixtures; the other
reported a test-lock conflict. After materialization, all eight selected tests
passed in a serial recheck of the same compiled binary. Both logs are retained.
The root adapter hashes the deterministic ledger into four exact SHA-256
words for replay. Clock and allocation observations are explicitly excluded;
these digest words are identifiers, not charged operation counts. Full native
pricing and root allocator observations remain unavailable. Instrumentation
overhead is included in clocks. The standalone CLI does not create a phase
session and therefore does not export these online times. No qualified host
measurement, new cohort outcome or revised ratio is reported here.

for each clock. This tolerance is not a confidence interval. Ratios remain
unqualified pending protocol, isolation and independent evidence review.
No new cohort costs or security conclusions follow from this packet.

\section*{Sources and limitations}
The graph construction follows the mathematical distinction between full
relations and cycles leaving a large prime in Gaudry, Theriault and Thome,
\href{https://cacr.uwaterloo.ca/techreports/2004/corr2004-29.pdf}{double large prime
variation}, sections 2.3 and 3.1 (2005 version). Its genus-at-least-three
complexity result is not asserted for this genus-2 pencil stream. Existing
repository graph and large-prime eliminators informed the implementation.
The editable graph is \texttt{reduction.svg}; the machine-readable check
table is \texttt{checks.csv}. All results are development checks; no runtime,
memory improvement or full-cohort completion is inferred from them.
