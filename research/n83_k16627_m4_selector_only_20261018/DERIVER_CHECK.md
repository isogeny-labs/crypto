# Partial-choice capped-outcome derivation controls

The [capped-outcome filter](derive-capped-outcome.jq) was checked before any degree-83 arm on two **synthetic metadata fixtures**. Each fixture has 8 ordered phase records, 100 progress samples, a root `Fixpoint`, SAT entry, a modeled exit 124 without OOM, a hard 4 GiB/zero-swap envelope and monotone completed work counters. The selector-only fixture marks four selectors pinned and 28 phase wires free; the phase-only fixture marks the reverse. Both accepted outcomes are `UNKNOWN_wall_cap` in [selector-only/outcome.json](deriver-fixtures/selector-only/outcome.json) and [phase-only/outcome.json](deriver-fixtures/phase-only/outcome.json). Their source string `fixture`, 1,700-second sample times and counter values are synthetic and are not N83 solver observations.

Changing the last selector-only sample's completed XOR row scans from 990 to zero makes the filter exit 5 with an empty success file; [the stderr](deriver-fixtures/selector-only/nonmonotone-stderr.log) and [exit receipt](deriver-fixtures/selector-only/nonmonotone-exit.txt) are retained. Presenting the phase-only stream as a selector-only arm also exits 5 and writes no success record; [that stderr](deriver-fixtures/phase-only/wrong-arm-stderr.log) and [exit receipt](deriver-fixtures/phase-only/wrong-arm-exit.txt) are retained. These controls test fail-closed mode and counter checks, not the worker or its scientific result. Each actual capped arm still requires its own source and input identity, container state, phase/progress streams, missing-worker-receipt check and raw-file hashes.

For a real capped arm, run from the study directory with `jq -n --arg arm selector-only|phase-only --arg source FULL_SOURCE_COMMIT --slurpfile state ARM/container-state.json --slurpfile host ARM/host-config.json --slurpfile phases ARM/worker.json.phases.jsonl --slurpfile progress ARM/worker.json.progress.jsonl --rawfile start ARM/start.utc --rawfile end ARM/end.utc --rawfile peak ARM/peak.bytes -f derive-capped-outcome.jq`. The shell must separately require that `ARM/worker.json` does not exist. A SAT return follows the separate checked-relation path, not this capped filter.
