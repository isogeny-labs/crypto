## Frozen arms and order

Compile one native binary with three named commands that share model construction, source attestation, input files, seven x pins, checked returned selector/phase wire API, solver configuration and optional observer. The difference is only which of the four selector and 28 phase-zero units are added. The selector-only arm adds exactly four selector units; its receipt must record phase wires as allocated but **not pinned**. The full-choice arm adds four selector and 28 phase-zero units and repeats the accepted positive control under this same binary. The phase-only arm adds exactly 28 phase-zero units and records the selectors as allocated but **not pinned**.

Run **A1 full choice, B selector only, A2 full choice**, sequentially on the same host, each from a fresh output directory. Do not stop B early because A completes quickly. Require both A arms to pass the original-field, group, rank and separate native relation replay checks before interpreting B. If B reaches its 1,800-second cap, execute one preregistered **C phase only** arm from the same binary after A2: pin the 28 known phase-zero bits but no selectors. C discriminates a selector-choice search bottleneck from a phase-choice bottleneck; its own cap remains censored. If B returns a checked SAT relation, omit C and proceed to a separately frozen natural-query protocol. If A fails, retain the failure and stop before B. Do not convert these single L0 controls into a speedup ratio.

Before degree-83 execution, a small native chained-field fixture must show direct and observed SAT model equality with full-choice, selector-only and phase-only pins, original-field S3 and group-lift validity, and contradictory UNSAT behavior. The existing 20 AB/BA paired observer-overhead fixture remains historical; this branch does not retime it unless the observer changes. Any new observer field or solver policy needs its own small control before the degree-83 arms.
