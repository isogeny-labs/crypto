## Correction and controls

The reader previously accepted `[0,0]` as a degree-one field polynomial
because it checked only the list length. A native CLI reproduction imported
that row and emitted JSONL. The corrected reader requires a nonzero last
coefficient in the constant-first list, matching Magma's `Coefficients`
representation. It rejects zero polynomials, negative-zero spellings and
noncanonical high-degree padding. It preserves arbitrary-precision
coefficient strings and accepts legitimate nonzero leading coefficients.
This does not prove irreducibility or validate the number field's geometry.

Four native tests pass, including all 654 pinned example rows and the new
adversarial degree controls. Release Clippy with `-D warnings` and rustfmt
pass. A malformed-row CLI run exits 2 with no stdout; the whole input is
still validated before emission. The original example, Magma sources,
license and compressed catalog are unchanged. Magma is unavailable and
no upstream search was executed.
The [validation receipt](review-20261019-validation.json) binds the repaired
reader source hash and both single-row and mixed valid/invalid CLI controls.
The one-page PDF and the candidate-count figure were rendered and inspected.
