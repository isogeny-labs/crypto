Use `q=32`, `K=F2[z]/(f)` with f the first irreducible trinomial `X^35+X^j+1` for `1<=j<=17`; if none exists, take the first irreducible pentanomial `X^35+X^i+X^j+X^k+1` in lexicographic `1<=i<j<k<35` order. Choose the least polynomial-basis mask `a∈F32` with absolute trace one and set c=1. Let `V1=ker(σ³+σ+1)` and `V2=ker(σ³+σ²+1)`, σ(x)=x^32. Enumerate the nonzero kernel elements in increasing mask order, form `b=(1+v)^2` so the Artin–Schreier coefficient has base component one, remove duplicate b, and retain only b of full absolute F2 degree 35. Order by arm then b mask; screen the first 128 exact coefficients. (This differs from the q16 screen's unsquared parameter convention; it uses the published equation's `b=β²` directly.)

For each coefficient compute `#E(K)` for `E:y²+xy=x³+a x²+b`, factor it, and record trace, largest prime r, cofactor h, arm, and exact mask. Select the **first** row with `r>=2^30`, `h<=8`, and `r∤#E0(F32)`, where `E0:y²+xy=x³+a x²+1`; stop with no selected candidate if none qualifies. Do not claim novelty from selection. A candidate must have an explicit nonzero order-r map, complete projected relation solve and descent, and a same-target rho total below the full GHS total to be called vulnerable.
