# Import and evidence notes

## Status

This directory is an exploratory research import. It is not admitted to the
repository's canonical benchmark table and has no `VALIDATION.json`. All timing,
correctness, and algorithm-selection statements remain repository-unverified
`[pcc:unverified]`. In particular, this import does not establish an end-to-end
ECDLP improvement, a fastest-tool result, or an independently reproduced
performance result.

No `identity.certificate/v1` is included. Summation-polynomial and automorphism
identities are retained as imported formulas and local self-test evidence, not
as independently certified algebraic results `[pcc:unverified]`.

The repository validation gate requires an independent replay certificate, an
independent recomputation from raw data, and a matched strongest-rho comparison
before a new canonical benchmark row may be added. Those obligations remain
open, so the evidence stays under `research/`.

## Evidence boundary and open work

The recorded measurements isolate root extraction, coefficient construction,
target membership, or reducer paths. They exclude point lifting,
relation-system construction, sparse linear algebra, and full ECDLP cost. The
following remain open before any broader performance conclusion:

1. independent campaign replay on repository-controlled hardware;
2. independent recomputation of summary values from the stored raw records;
3. matched strongest generic-factorization, rho, or external-tool controls in
   the same process and cost unit;
4. confidence intervals and multi-host sensitivity analysis;
5. end-to-end accounting for lifting, relation collection, and linear algebra;
6. application-specific crossover calibration for target-set size and field.

The existing reports retain neutral and negative findings: fixed reduction was
neutral for `p=1009`, explicit SIMD was investigated but not implemented, and
the tested automorphism-orbit evaluator regressed beyond tiny degrees. Those
controls are part of the imported evidence rather than discarded attempts.
