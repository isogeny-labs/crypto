# Fixed development checks and raw artifacts

The Hermite lemma unit is independent native GMP arithmetic. Its prospective
protocol, first and corrected source, both complete record sets, failed
control-coverage review and correction remain under lemma-unit/. No scientific
timing or asymptotic claim follows. Its original files.sha256 is a frozen
full-package manifest and verifies after retrieving any stored raw tables.

Large raw TSV tables are eligible for the repository's normal artifact-store
migration. records.sha256 binds all seven final tables. The wrapper
check_hermite.sh regenerates every final row and checks those hashes, so
reproduction does not require downloading the large reference tables.
Pull the .artifacts.json payloads using the maintained artifact tool for
direct row inspection. Original small manifests and all source remain in Git.

The outer source-manifest.sha256 excludes payloads eligible for migration and
PNG duplicates and managed artifact-pointer/ignore metadata. Their frozen content hashes remain in the unit manifests
and managed artifact manifests. The native replay, rather than file presence,
checks the complete final tables.

The Rust test result is a separate existing-crate correctness suite. Toolchain,
source snapshot and exact command are recorded separately; no compiled binary,
downloaded toolchain or credential is committed. A passing bounded suite does
not certify arbitrary recursive instances or its asymptotic cost.
