## What is common, and what requires different kernels

An exact finite-domain decomposition can share orchestration, canonical tuples,
branch accounting and certificate interfaces across fields. Its arithmetic and
support kernels require field-specific proofs. In binary K, r²+hr for h!=0 is
h²(u²+u), r=hu: the AS image has absolute trace zero and a two-element kernel.
Restricted coefficient spaces have their measured trace-functional rank0or1;
degenerate constants and even-extension AS solving must remain explicit.

For odd prime fields, ordinary squaring is not additive and there is no
nontrivial proper Fp-subspace. Interval/composed-map domain kernels need their
own exact support/lift semantics. For odd extensions, p-th Frobenius is
Fp-linear, but k² still is not when p is odd. Generic odd Hermite charts keep
their true quadratics and0/1/2-root fibers. Ordinary binary and Koblitz curves
may share scalar-field kernels, but curve coefficients/targets and exceptional
source coverage remain distinct admitted inputs.

The current87-coordinate binary ordering first solves e2=C2+r²+hr in W2,
then uses v3=e3 in W3 and w=h^-1(v3+C3+zr²+kr), s=w+zr. Original(r,s)
recovers(r,e3), so this is an exact affine coordinate bijection when h!=0,
not a newly discovered constraint. The remaining e4/e5 rows must still be
enforced. AS image inversion is classical linearized-map machinery; eliminating
the invertible h block is elementary block substitution/Schur elimination.
Reordering constraints can reduce paid implementation work, but it preserves
the existing73-bit actual relaxation. It neither prunes supported quintics nor
establishes generalized-rootfinding novelty. The strongest166-coordinate
implementation, not only the slower104-coordinate version, is the comparator.

G(2)=2t-1 is nonzero. Its residual cubic is

A hand derivation avoids a blind parameter search. Tangent lines at A and B,
and the line through A,T, can be written

    l1=Y+X,
    l2=Y-tX+2,
    l3=Y-(1+t)X+1-t.

## A precise boundary beyond the refuted constant-functional class

The existing odd-zero residual witnesses refute constant linear functionals
sum_j a_j R_j=1 on specified cells. They do not refute parameter-dependent
multipliers. A concrete next certificate family is

    sum_j (a_j+sum_{i in J} b_ij x_i) R_j(x)=1

in the Boolean coordinate ring x_i²=x_i, with fixed J={0,1,2,3} of the SAME
73 global parameters and no new independent local assignments. The previous
odd witness need not remain a witness for the augmented features (R,x_i R),
because multiplier values vary per sample. This is classical polynomial
