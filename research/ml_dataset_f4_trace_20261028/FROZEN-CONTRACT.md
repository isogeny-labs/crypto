The attached APPROVED-DESIGN.md describes the bounded unit. These explicit refinements take precedence:

- Admit q <= 8 and D <= 4 only, with at most 64 input polynomials, canonical unique descending degrevlex Boolean terms, masks within q variables, each polynomial n_vars equal to q, and **every input degree <= D**. Reject degree overflow and malformed inputs before native work; do not skip/truncate a generator. Zero polynomial degree is zero by convention. This ensures the full column universe is at most 163.
- Preserve current direct matrix-call semantics: all-variable multipliers, no criterion, full readback, no recursion/cache. Trace the actual shared native candidate and suffix routines, not a second scalar simulation. Resolved unsupported layouts are rejected before work. Existing untraced wrappers remain behaviorally equivalent.
- One caller-owned fallible JSONL sink. Cumulative input/candidate/row/event/serialized-byte/workspace budgets and an absolute caller deadline plus cancellation function. No unbounded whole-trace buffer and no internal S3 access. Every record is acknowledged before the next arithmetic block; sticky sink failure preserves the prior acknowledged sequence/hash and prevents completion.
- Canonical first-profile wire masks are JSON unsigned integer bytes 0..255 (no string/radix aliases), coefficients implicit F2 ones. This supersedes the broader draft hex-mask representation for this separately named suffix profile. Ring degree, variable order and quotient multiplication remain explicit. JSON bytes use fixed Rust schema field order; the separate consumer rejects duplicate/unknown fields and noncanonical numeric aliases.
- Header/input records bind exact ordered original polynomial data and supplied source/binary/config/call identifiers. Events enumerate every candidate including zero products, columns, packed input rows, actual pivot/row swap/XOR and terminal output. Packed words use fixed 16-digit lowercase hexadecimal strings to avoid JSON precision loss. Row slots and versions are explicit; the hash chain binds order but is not arithmetic proof.
- The producer always reports input_encoding_checked=false, matrix_rank_independently_verified=false, execution_stream_complete=false, total_operation_count_verified=false, unsat_verified=false, groebner_basis_complete=false and fall-degree fields unknown. A completed native rank is an observation only. Root owns a separate checker after schema handoff.
- No adapter/solvers.rs, curves.rs, consumer, cloud worker or other-owner edit; no Cargo before root grants the slot. USD200 total cap and all original cloud/recovery requirements stay unchanged.
