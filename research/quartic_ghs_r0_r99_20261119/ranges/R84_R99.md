The native screen checks registry structure and the source contracts needed by
these lanes. It deliberately does not build or execute the full ECBench binary:
the checkout has no `target/release/ecbench`, and a static scan is not a fresh
solver run or a measurement `[pcc:unverified]`.

The final native screen compiled with `rustc --edition 2021 -D warnings` and
accepted 16/16 ordered lanes. It found 111 static optimization-policy macro
invocations, 21 `Box::new` entries in the `solver_registry` function, nine
PDP3 engine strings, and four PKM tower engine strings. These are source
declaration counts, not executed backend counts `[pcc:unverified]`. Repeating
the same fragment was rejected as duplicate R84, and `--expect-all` correctly
rejected this one fragment as missing R00-R83. Exact commands, failures, exit
statuses, hashes, and output are retained in `../receipts/r84_99.txt`.
After all six range fragments appeared, the same binary ran with
`--expect-all` and accepted exactly 100 globally unique, contiguous lanes with
spans R00-R16, R17-R33, R34-R50, R51-R66, R67-R83, and R84-R99
`[pcc:unverified]`.

## Lane registry

### R84 — freeze the live ECBench inventory

- Use `ecbench optimize inventory --json` at the execution revision.
- Run `ecbench optimize audit --require-all` on development specifications.
- Require exact equality with the live method registry and coverage of every
  registered system solver, PDP3 engine, and PKM tower engine.
- The deterministic falsifier is any missing or stale policy or nested entry.
- Current status: the native fail-closed mechanism exists and its defining
  source markers are screened; an inventory executable was not available.

### R85 — integrate GHS strong rho as a versioned method

- Add restricted-family applicability, canonical ICV1 identity, counted and
  counter-free implementations, explicit authority, and exclusive phase
  windows.
- Refuse non-GHS curves and false/missing authority at plan, run, analysis, and
  replay boundaries.
- Preserve planted-scalar, trajectory, collision, and phase-count parity.
- Current status: specified; no ECBench adapter or spec is added by this range.

### R86 — freeze matched GHS IC and rho controls

- The exact same curve, subgroup, target, target seed, cache policy, and unit
  feed optimized strong rho, plain/negation rho diagnostics, and IC arms
  `B0,S,L0,L1,L,D,DL1,DL`.
- Preserve the eleven-size grid, seeds 1-3, repetitions, deadlines, and failed
  attempts in the parent specification.
- Current status: blocked by execution admission and R85.

### R87 — F4 and Faugere-Lachartre F4

- Compare identical exported systems and query streams.
- Count symbolic preprocessing, matrix build/packing, reducer/free-column
  selection, elimination, extraction, and witness verification.
- Treat elimination word XORs as a component unit until full construction is
  symmetrically priced.
- Current status: solver implementations exist; the requested matched campaign
  is not run.

### R88 — signature F5

- Freeze `matrix-f5` and `sig-f5` configurations in method identities.
- Require the same systems and independently equal solution sets as F4.
- A reduction in rows or XORs remains solver-local unless cold pipeline cost
  moves on untouched holdouts.
- Current status: registered engines screened; no fresh run.

### R89 — F6 and F6-IC

- Cover `f6-ic`, `f6-ic-pair`, and PKM `f6`.
- Charge geometric support closure, residual group arithmetic, sign lifts, and
  witness replay; retain every native solver counter.
- Never map node-budget exhaustion to UNSAT.
- Current status: registered nested engines screened; no fresh run.

### R90 — SAT-CDCL and sound WD-SAT controls

- Pin CNF versus native-XOR encoding, branching, restart, conflict, learned
  clause, seed, and budget settings.
- Independently check every SAT model.
- WD-SAT must first reproduce the exhaustive solution set on a frozen small
  corpus and return UNKNOWN, not UNSAT, whenever completeness is absent.
- Current status: SAT-CDCL is registered. WD-SAT is blocked on the soundness
  gate; prior retained evidence found a false UNSAT.

### R91 — FES, Gray-code, and guess-and-determine

### R92 — root-finding engines

## Composition rule

R84 can run before implementation. R85 is the integration dependency for the
matched GHS panel. R87-R93 may be developed independently on valid cells, but
their measured deltas are never added. R94-R98 compose the selected candidate
under one frozen revision. R99 runs last and only for admitted evidence.

This dependency order limits mutation of the common baseline; it does not
cancel the parallel discovery and deterministic-screen work requested for all
sixteen lanes.
