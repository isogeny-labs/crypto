# Exact rebracketing of a binary two-factor block

Contract: all ordered triples (x,y,z) with x,y in the low-d polynomial-basis prefix D and z in K=GF(2^n), satisfying S3(a,x,z)=S3(z,y,b)=0 for fixed finite a,b and ordinary binary curve Y^2+XY=X^3+A X^2+B, B!=0. This is an ORIGINAL intermediate-coordinate contract; not just a resultant or rational-point relation.

Algorithm: (i) explicitly solve the z=0 bridge; (ii) for every finite w in K with S3(a,b,w)=0, use the exact symmetric prefix pair solver on S3(x,y,w)=0, then solve the original S3(a,x,z) overK and retain every z satisfying the second original equation; (iii) when a=b, explicitly enumerate the x=y infinity branch and restore all original z. Union/deduplicate. Pair-fiber,source and diagonal caps return unresolved with exact count null; no incomplete branch yields exact emptiness.

Soundness follows from original equation checks after restoration, except the direct zero bridge which is checked independently by the worker. Completeness needs more than associativity of resultants because w could leaveK or be infinity. The curve has exactly one nonzero geometric two-torsion point T, abscissa0. For any finite abscissa inK, Frobenius sends either lift P to P or -P; the two types coincide onT. For a zero-sum relation among three lifts, if one is a nontwo-torsion point, all other nontwo-torsion points have the same Frobenius sign: applying Frobenius and subtracting a proposed common sign relation would force2P=O for a remaining single point. This argument also handles a two-torsion endpoint, which is both signs.

If z!=0, the shared intermediate lift is nontwo-torsion. Therefore both original triples share one Frobenius sign. Align signs of the shared lift and combine the two group relations. The endpoint sum P_a +/-P_b equals an appropriately signed source sum, and its abscissa w lies inK unless the sum isO. For finite sum, the two S3 equations inw vanish, so the exact pair solver finds(x,y), and original reconstruction includes the originalz. If the sum isO, then a=b and x=y, precisely the explicit infinity branch. No assumption about rational lifts is made: the common sign may be negative, retaining the twist/nonrational branch.

If z=0, S3(a,x,0)=(ax)^2+B and S3(0,y,b)=(yb)^2+B. For a,bnonzero there is exactly one possible pair x=sqrt(B)/a,y=sqrt(B)/b; retain it iff both lie inD. If either endpoint is0 there is no such pair becauseB!=0. These mixed-Frobenius-sign bridges may have no finiteK rebracketing witness, so they cannot be dropped. For a=b=0 the finitew polynomial is constantB and has no roots; the infinity branch still recovers every x=y!=0 original solution. Repeated sources are explicit tuples, not deleted divisor multiplicities.

The finite-w block uses at most2endpoint roots, each an exact F2linear coefficient-fiber solve in d+min(2d-1,n)bits followed by constrained quadratic support. At n83,d18 this is53bits versus83equations perw, with explicit high-nullity caps. No generic rank or unique-fiber assumption is made. Above caps the result is unresolved. A non-diagonal complete block can avoid scanning all2^d source values; the strong comparator scans onlyx (notD^2), solveszoverK,then solvesyprefix. Actual-source choices and all endpoint discovery remain outer work: the original five-source chain still has many unfixed coordinates.
