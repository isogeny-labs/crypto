# New comparison plan: half-GCD and certified rational towers

This is a new experiment, not a rerun or amendment of the completed polynomial panel. The instrument and native analyzer are native/next_compare.rs. It compares five arms: classical-Euclid Karatsuba/Newton, recursive half-GCD, its identical A/A repeat, batched lookup, and the same lookup under an unused half-GCD setting. All share exact targets and stage limits, with rotating/reversed arm order. Fixture seed0x686763642d7631 XOR m, root seed0x48470000+input index. Each of two target populations has3 retained targets; two warmups are excluded. A/A tests deterministic counts, not clock noise.

Primary metric: field multiplications over descriptor/certification, necessary base lifting and query, freshly executed for each arm. The two arithmetic candidates do not build an unused point table for finite targets; lookup does build its required point table and hash set. Construction and query counters are also reported separately. Same fixed Newt-on construction backend for every arm; query backend is the treatment. Hashing, memory allocation and sorting have no field-operation price; clocks are diagnostics belowL2. No elapsed-time, external-fastest or complete DLP claim.

Six configurations: coset/word62 m8192,16384; coset/P224 m2048; rational/word62 m2048; rational/P224 m128,512. Rational fixtures are Möbius conjugates of squaring, with full sibling-fiber certification, representative3. They test general rational evaluation; they are not a claim about the cost or applicability of auxiliary-isogeny search. A normalized genuine Vélu map is separately covered by correctness tests.

A separate preflight executes two inputs per configuration, all five arms (60 calls), excluded from primary data. The frozen native forecast computes fixed fixture cost +8*max(two observed complete input costs), including all arms/draw/verifier, per size class. This is a diagnostic point projection, not a confidence interval or guarantee. Primary N is fixed before calibration. Missing/failed calibration classes have no runtime forecast. Primary data start only after a separately frozen main protocol incorporates the calibration receipt.

Main planned flow:6 configurations*5 arms*(2 warmups+6 retained)=240 calls. The preflight900s and main3600s envelopes are separate. Each construction and query context has30s,4e9 multiplications and65536 root split attempts. Configuration process cap300s preflight/600s main; memory8GiB virtual; isolated CPU4. No adaptive retry, no incomplete row counted as a win. Fatal fixture/verification errors are retained with missing planned calls reported. A set mismatch or positive-control miss invalidates its input. All remaining arm outcomes are retained.

Raw records checkpoint naturally per input (one verifier plus five arms) with a separate fixture file per configuration. The driver refuses existing output directories. Raw files remain in Git within ordinary artifact limits; no byte is omitted or rewritten to fit. Local immutable executables are SHA-pinned and ignored, while exact buildable Rust sources/lockfile, compiler/build receipts and protocols are published before calls. Local binary cache availability is not a remote archive claim. No S3 operation or cloud spending is authorized.

All successful query rows undergo a separate-process wide scalar completeness replay. The frozen native summary retains raw values and observed ranges, separates representations/fields/sizes/populations/identity, excludes warmups, and pairs only matching completed inputs. Report all failures, paired total/query count ratios, A/A and unaffected control ratios. No exponent fit or significance claim; n3 per population is descriptive only. Every producer observation remains unverified pending independent signed standing.
