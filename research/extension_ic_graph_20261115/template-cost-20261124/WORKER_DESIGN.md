# Matched public-residual worker design

Build a Rust-only worker before freezing its binary and execution protocol.
This document authorizes source/data qualification, not an unregistered
timing call. Continue the same lane and local backend.

Extract exactly the first two already exposed residuals from the retained
Run51 raw packet and H1 reference file. Verify their existing whole-file
hashes. Save public curve, residual divisors and original-system digests in
a strict public fixture. Keep expected roots in a separate validator file.
No saved basis, scalar or root enters the solver interface. Data extraction
performs no F4, template application or scientific solve.

All three arms use the same six-coordinate root stage and original Nagao
materializer: plain F4, traced F4 with its existing shape/fallback checks,
and degree-7 H2 with explicit traced fallback. Each interval builds a fresh
curve/context/factor base (seed13), clears algorithm trace caches and
includes both residuals, roots, materialization, original divisor checks
and cleanup. Root RNG starts at389 per residual. Baselines stop at staircase64;
the candidate obtains its full development basis afresh on residual0,
compiles H2, uses that basis for residual0, then applies H2 on residual1.
All learning, compilation, attempted checks and fallback remain charged.

Compile counted checker support, use one Rayon thread, disable the partial
native bitop hook collector uniformly during timing, retain the existing
F4/root/materializer field counts and separate template/checker counts.
No complete native total, end-to-end IC or fastest-tool claim follows.

After source-only controller controls, freeze source/binary/input hashes,
one common warm-up, two traced A/A intervals and five fixed interleaved
three-arm rounds. Stop the panel if correctness or the prespecified A/A
gate fails. Preserve all attempted samples, errors and remaining not-run
positions. Use native isolation, 8GiB virtual memory and a finite watchdog;
never rerun the same frozen panel to obtain a quieter or favorable result.

Sources: prior H2 packet and NEXT_COST_STUDY, qualification documents in
this directory, jv_cover root/F4 APIs and jv_nagao_unit materializer. KB MCP
is absent; the previously checked wrapper has no executable. This is a
composition of existing techniques, with no novelty claim.
