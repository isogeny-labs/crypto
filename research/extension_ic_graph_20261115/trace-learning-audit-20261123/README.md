## Missing learning work

The pinned engine learns contributors with an uncounted dense Gauss-Jordan.
Read-only matrix progress/run logs bound that matrix by pair rows R, full
columns C and rank k<=min(R,C). The per-step bounds include:

- R*C*k row multiplications, including pivot-row normalization;
- (R-1)*(C+1)*k field additions, including p-fnegation;
- k inverse calls, or19*k Fermat multiplications at p1009;
- (R-1)*k*ceil(R/64) contributor-bitset word ORs.

Empty matrices contribute zero. Checked u128arithmetic refuses overflow.
Separate units are retained; inverse-call and expanded-multiplication columns
are alternatives, never charged twice. Allocation/copies/scans/bookkeeping
remain outside these bounds. No complete F4or pipeline price is asserted.
