# Candidate input separation before the first dual run

Frozen 2026-11-15 UTC after [PROTOCOL_V1.md](PROTOCOL_V1.md), before any dual identity or solve execution. The V1 protocol required the candidate to use only destination columns, yet the prior factor-base JSON also contains source witnesses for checking. This amendment makes the information boundary executable and auditable.

The native `freeze-dual-input` command reads the frozen full base (`f4e0b303e37173c0a764e717dffe571facf0c39e492869712e0d11090d46b73f`), removes `base_witness_source`, changes the schema to `isogeny_dual_projected_public/v1`, and records the full-file SHA-256. Freeze the output hash and bytes before the first dual child. Pass **only** this stripped file to the two dual candidate arms. All eight control arms continue to receive the original full base. The independent checker receives both files and the answer file, confirms the parent hash and absence of witnesses in the candidate input, and checks each transported source column against the original source witness.

This changes neither destination columns nor targets, trial streams, caps, relation algorithm, row solve, arm count, or cost unit. The candidate still charges its dual-kernel search, destination enumeration, map evaluations, scalar multiplications, and forward checks inside each cold child. A failed freeze, parent-hash mismatch, missing independent witness check, or nonidentical projected base stops the panel. The generated stripped-file hash will be recorded in the first run manifest; it is not asserted here before generation.

The 10-arm schedule extends V2's rotated ordering deterministically: in each `(round, base_index, position)` cell, start at offset `(round + base_index + position) mod 10` in the fixed order `chi-dual, direct-dual, chi-inverse, chi-full, direct-inverse, direct-full, destination-direct, source-bsgs, rho-negation, rho-negation-aa`, wrapping modulo 10. This only schedules execution; the target and trial RNG seeds remain exactly V2's. The versioned run plan and SHA-256 are frozen before children start.
