# Linear remainders in lifted group checks

For monic U=X²+sX+t, the conjugate of aX+b is b-as-aX. Its product with aX+b modulo U is the scalar b(b-as)+a²t. A nonzero norm gives the inverse by one scalar inversion. If a=0 invert the scalar directly; a zero norm indicates noninvertibility. Use the existing Cantor fallback on shared support.

For a higher-degree Euclidean inversion, let previous and current remainders be F and aX+b with Bezout coefficients B and C on the original input modulo U. Set r=-b/a, and divide F synthetically by X-r to obtain Q and F(r). Then (B-CQ/a) times the input is congruent to F(r) modulo U. Use this coefficient divided by F(r) when nonzero. A zero remainder evaluation certifies shared support.
