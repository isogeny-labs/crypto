## Question

Which elliptic curves over `F_{q^n}` admit an `F_q`-rational maximal isotropic
subgroup `Λ ⊂ W[ℓ]` with `Λ ∩ E^{σ^i}[ℓ] = 0` for every `i` (a **Tian
kernel**)? Tian assumes such a `Λ` and gives one example (`q = 523`, `ℓ = 3`,
`#E(F_{q^3})` prime); the paper states no existence condition, no dependence
on `q mod ℓ`, on the trace or on the `ℓ`-torsion Galois structure, and no
proportion of affected curves. Covering attacks never reach prime-order curves
over `F_{q^3}` (they need rational 2-torsion: Diem 2003, Momose–Chao 2009,
Tian–Li–Wang–Yu 2018; Theorem 3 of round one), so the isogeny association is
the only Weil-restriction route to prime-order curves over cubic extensions,
and the set it reaches has never been written down. This round writes it
down exactly for small `ℓ`.

## Setting and notation

- `E/F_{q^n}`, `t = q^n + 1 − #E(F_{q^n})`, `φ = π_{q^n}|E[ℓ] ∈ GL_2(F_ℓ)`,
  `det φ = q^n mod ℓ`, `tr φ = t mod ℓ`. `[φ]` is its conjugacy class: scalar
  `λI`, Jordan `J(λ)`, split `diag(λ, μ)` (`λ ≠ μ`), or nonsplit (irreducible
  `T^2 − tT + q^n`).
- `W[ℓ] = V = V_0 ⊕ … ⊕ V_{n−1}`, `V_i = E^{σ^i}[ℓ] ≅ F_ℓ^2` identified with
  `E[ℓ]` through `π_q^i`. The `F_q`-Frobenius acts by
  `π(v_0, …, v_{n−1}) = (φ v_{n−1}, v_0, …, v_{n−2})`, so `π^n = φ` on every
  factor. The `ℓ`-Weil pairing of the Weil-restricted principal polarisation
  is `ω_V = ⊕_i q̄^i ω` with `ω` the standard symplectic form on `F_ℓ^2` and
  `q̄ = q mod ℓ` (the Frobenius raises `μ_ℓ` to the `q`-th power); `π` then
  satisfies `ω_V(πv, πw) = q̄ ω_V(v, w)`, as it must.
- A **kernel** is an `F_ℓ[π]`-submodule `Λ ⊂ V` of dimension `n` with
  `ω_V|Λ = 0`. A **Tian kernel** is a kernel with `Λ ∩ V_0 = 0` (then
  `Λ ∩ V_i = 0` for all `i` by `π`-stability). Its **type** is
  `(d_01, graph)` with `d_01 = dim Λ ∩ (V_0 ⊕ V_1)` and `graph = true` iff the
  projection `Λ → V_0` is bijective (then `Λ = {(v, ψv, …)}` for one
  `ψ ∈ GL_2(F_ℓ)`).

Everything about the existence of a Tian kernel depends only on
`(n, ℓ, q̄, [φ])`: this is the whole content of Part G. Part H attaches the
census to actual curves over toy fields by computing `[φ]` for every curve.

## Part G: kernel census over the Frobenius classes (exact, finite)

For every `(n, ℓ)` in the frozen range, every `q̄ ∈ (Z/ℓ)^×`, and every
conjugacy class `[φ]` with `det φ = q̄^n`: enumerate every `F_ℓ[π]`-submodule
of `V` of dimension `n` (as sums of cyclic submodules, closed under addition
with the dimension bound; the sum of the cyclic submodules generated by a
basis of `Λ` is `Λ`, so the closure is complete), keep the isotropic ones,
and record `#kernels`, `#Tian kernels`, and the type multiset. Output
`kernels.csv` with one row per `(n, ℓ, q̄, class, tr, det)`.

Frozen range: `n = 2: ℓ ∈ {2,3,5,7}`; `n = 3: ℓ ∈ {2,3,5,7}`;
`n = 4: ℓ ∈ {2,3,5}`. Budget: 60 minutes wall for all of Part G on this host
(4 cores); a `(n, ℓ)` cell that does not finish is recorded as not run.

Predictions frozen before the run:

- **P1 (graph kernels).** For `n = 3` and odd `ℓ`, a graph-type Tian kernel
  `{(v, ψv, ψ^2 v)}` is isotropic iff `1 + d + d^2 ≡ 0 (mod ℓ)` for
  `d = det ψ`, and `π`-stable iff `φ = ψ^{−3}`. So graph kernels exist only
  when `ord_ℓ(q̄) = 3` (hence `ℓ ≡ 1 mod 3`) and `φ` has a cube root of
  determinant a primitive cube root of unity. The census must find no graph
  kernel at `n = 3` when `ord_ℓ(q̄) ≠ 3` (in particular none at `ℓ = 3, 5`).
- **P2 (Tian's example).** Tian's curve has `q = 523 ≡ 1 (mod 3)`, `ℓ = 3`,
  `#E` prime. So at `(n, ℓ, q̄) = (3, 3, 1)` some class `[φ]` with
  `det φ = 1` and `tr φ ≢ 1 + det φ` (no eigenvalue 1, since `ℓ ∤ #E`)
  has a Tian kernel. If none has, Part G is wrong.
- **P3 (covers, `ℓ = 2`).** Genus-3 covers of `E/F_{q^3}` over `F_q` need
  three rational points of order 2 (Diem; Momose–Chao). So at
  `(n, ℓ) = (3, 2)` Tian kernels exist only for `φ = I`. The same statement
  at `n = 2` would mean Scholten's genus-2 association needs full 2-torsion,
  which Scholten's "odd order and `j ∉ F_q`" case contradicts; so P3 is
  stated for `n = 3` only and the `n = 2` row is reported as found.
- **P4 (prime order, density).** For odd `ℓ` and `n = 3`, the set of classes
  `[φ]` with no eigenvalue 1 (the only ones a prime-order curve can have) and
  a Tian kernel is non-empty for every `q̄`, and in Part H the fraction of
  prime-order curves with a Tian kernel for some `ℓ ∈ {3, 5, 7}` stays
  bounded away from 0 as `q` grows (a dense, not a hidden, regime).

## Part H: every curve over `F_{q^3}`, `q ∈ {3, 5, 7, 11, 13}`

For every `F_{q^3}`-isomorphism class of elliptic curves (every
`j ∈ F_{q^3}` with its twists: two for `j ≠ 0, 1728`; the four quartic twists
at `j = 1728` and the six sextic twists at `j = 0` for `p ≥ 5`; for `p = 3`
the classes with `j = 0` are enumerated as orbits of `(a_4, a_6) ↦
(a_4/u^4, (r^3 + a_4 r + a_6)/u^6)` on `y^2 = x^3 + a_4 x + a_6`, `a_4 ≠ 0`,
and `j ≠ 0` uses `y^2 = x^3 + x^2 − 1/j` and its twist):

1. `#E(F_{q^3})` by point counting, `t`, and whether `#E` is prime, has
   cofactor 2, or other.
2. For every `ℓ ∈ {2, 3, 5, 7}` with `ℓ ≠ p`: the class `[φ]` from
   `(t mod ℓ, q^3 mod ℓ)` and the orbit pattern of `φ` on
   `(E[ℓ] ∖ 0)/±1`, read off the distinct-degree factorisation of the
   `ℓ`-division polynomial `ψ_ℓ` over `F_{q^3}` (`ψ_ℓ` in the `b`-invariant
   form of the general Weierstrass equation; degree `(ℓ^2 − 1)/2`). The four
   class types have different patterns for a given `(tr, det)` (scalar: all
   orbits of size 1; Jordan: one fixed point and orbits of size `ℓ`; split:
   two fixed points and orbits of size `ord(λ/μ)`; nonsplit: no fixed point);
   the tool asserts that exactly one class matches.
3. Join with Part G: `tian(ℓ) = 1` iff `(3, ℓ, q mod ℓ, [φ])` has a Tian
   kernel.

Outputs: `curves.csv` (one row per class: `q, j, twist, t, numE, order_class,
pattern_ℓ, class_ℓ, tian_ℓ` for each `ℓ`), `summary.csv` (per `q`: classes,
prime-order classes, cofactor-2 classes, with a Tian kernel at `ℓ`, for some
odd `ℓ`, prime-order with a kernel, full rational 2-torsion, kernel at
`ℓ = 2`), `by_class.csv` (per `(q, ℓ, q̄, class)`: curves, prime-order
curves, kernel flag), `checks.txt`.

Budget: 30 minutes wall for Part H at all five `q`.

## Checks

1. Part G, `n = 3`, `ℓ = 2`: every Tian kernel has `φ = I` (P3).
2. Part G: no graph kernel unless `ord_ℓ(q̄) = 3` and the cube-root
   condition holds (P1); every graph kernel found satisfies it.
3. Part G: at `(3, 3, 1)` a Tian kernel exists for a class without
   eigenvalue 1 (P2).
4. Part G: the kernel count is invariant under the choice of class
   representative (the tool runs two representatives of every split and
   nonsplit class and asserts equal counts).
5. Part H: `#E ≡ q^3 + 1 − t`; `|t| ≤ 2 q^{3/2}`; the number of classes equals
   the known count `2q^3 + O(1)` (exact: `2(q^3 − 2) + 4 + 6` for `p ≥ 5`).
6. Part H: `ψ_ℓ` has degree `(ℓ^2 − 1)/2` and is squarefree; the number of
   `F_{q^3}`-rational roots of the cubic equals the number of rational
   2-torsion points; `t mod ℓ` and `q^3 mod ℓ` agree with the class found.
7. Part H: the class with `ℓ = 2` is `I` exactly when the cubic splits
   completely; every curve with a Tian kernel at `ℓ = 2` has full rational
   2-torsion (P3 instantiated).
8. Part H: a prime-order curve never has eigenvalue 1 at any `ℓ`
   (`ℓ ∤ #E`), and never has a kernel at `ℓ = 2`.
9. Part H: the fraction of prime-order curves with a Tian kernel for some
   odd `ℓ ≤ 7` is reported at every `q` with the per-`ℓ` breakdown (P4).

## Decision rules (frozen)

- A `(q̄, [φ])` cell with a Tian kernel and no eigenvalue 1 is a class of
  **prime-order curves over `F_{q^3}` reached by an `F_q`-rational
  `(ℓ,ℓ,ℓ)`-isogeny to a genus-3 Jacobian (a plane quartic by round one's
  Theorem 3 and Tian–Li–Wang–Yu 2018)**: these curves are *affected* in the
  sense of this search (the DLP transfers to a group where Diem–Thomé's
  index calculus costs `Õ(q)` against `q^{3/2}` for rho and `Õ(q^{4/3})` for
  Gaudry's decomposition), **provided** the isogeny is computed (Tian's
  algorithm, `Õ(ℓ^3)`) and the quotient is geometrically indecomposable as
  a polarised variety, which `Λ ∩ V_i = 0` is Tian's stated condition for.
  This round establishes the kernel existence exactly and takes the two
  provisos from Tian [T]; it does not compute an isogeny.
- The characterisation is by `(q mod ℓ, t mod ℓ, φ-type)`: a
  polynomial-time test (factor `ψ_ℓ`), so the regime is *not hideable*; the
  margin framework of round one gives `a < 0` whenever the affected fraction
  is a constant.
- Negative results (cells with no kernel, `ℓ = 2` rows, the `n = 4` rows
  whose Jacobian question is open) are reported as found.

## What this round does not do (stated now)

- No isogeny is computed and no DLP is solved; the transfer's constants are
  not measured. `Õ(q)`, `q^{3/2}`, `q^{4/3}` are exponents.
- `n = 4`: a Tian kernel gives a ppav of dimension 4, which need not be a
  Jacobian (Schottky); the census counts kernels and leaves the Jacobian
  question open.
- Characteristic 2 base fields are not in Part H (the field tables of the
  tool are odd-characteristic); Part G is characteristic-free.
- `ℓ = p` is excluded (the `p`-torsion has rank ≤ 1).

## Amendment 1 (before any run; commit follows the freeze commit)

Two errors found while writing the tool, before any run was started:

1. **P1 and the "graph" type.** A Tian kernel has dimension `n`, and `V_0`
   has dimension 2, so for `n = 3` no kernel can be a graph over one factor
   and P1 as first written is void. Corrected statements: for **`n = 2`**
   every Tian kernel is a graph `Λ = {(v, ψv)}` (the projection to `V_0` is
   injective because `Λ ∩ V_1 = 0`, hence bijective), and it is isotropic iff
   `1 + q̄ det ψ ≡ 0 (mod ℓ)` and `π`-stable iff `φ = ψ^{−2}`; so **at
   `n = 2` a Tian kernel exists iff `φ^{−1}` has a square root `ψ` with
   `det ψ ≡ −q̄^{−1}`**, and the tool extracts `ψ` from every `n = 2` Tian
   kernel and asserts both conditions (this replaces check 2). For `n = 3`
   and `n = 4` the type recorded is `d_01 = dim Λ ∩ (V_0 ⊕ V_1)`; no
   prediction is made about it. P2–P4 are unchanged.
2. **Check 5, the class count.** The number of `F_{q^3}`-isomorphism classes
   for `p ≥ 5` is `2(q^3 − 2) + gcd(4, q^3 − 1) + gcd(6, q^3 − 1)`, not
   `2(q^3 − 2) + 10`; for `p = 3` it is `2(q^3 − 1)` for `j ≠ 0` plus the
   number of orbits computed for `j = 0`.

Also made explicit: for `ℓ = 2` the polynomial whose roots are the
`x`-coordinates of `E[2] ∖ 0` is the cubic `x^3 + a_2 x^2 + a_4 x + a_6`, not
`ψ_2 = 2y`; the class types at `ℓ = 2` are `I` (cubic splits), Jordan (one
rational root) and nonsplit (irreducible cubic), and no split class exists
over `F_2`.
