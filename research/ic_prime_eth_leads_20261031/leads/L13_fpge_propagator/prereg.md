# L13 pre-registration (written before any timing run)

Question: does a CaDiCaL ExternalPropagator doing F_p Gaussian elimination over the slope/t words (plus an ablation with univariate-quadratic root rule) lower the work-charged exponent of m=3 prime-field point-decomposition SAT?

## Decision rule (copied verbatim from SYNTHESIS.md section 7)
"Decision rule (proposed, pre-register before running): charge propagator work, not only conflicts, and cluster CIs by curve (at least 10 curves). Close the lane for good if the work-charged slope per window bit at m = 3 has a lower CI bound >= 1.0 over b = 9..12, or if b >= 12 stays censored. Extend to b = 15..24 only if the upper CI bound is < 1.0. A slope < 0.5 (ladder bar) with the soundness gate green is the only outcome that would reopen exponent claims, and it needs an independent reproduction first. Note L04's offset is 2*log2(cap) - 1; the engine must show it beats that offset with propagator work charged, otherwise it is enumeration relabelled."

## Definitions
- Instance family: m=3, bits-s3 style encoding (x1<x2<x3 lex, all in small-x window [0,2^s), y-witness liftability for x1,x2,x3,t, S3(x1,x2,t)=0, S3(t,x3,xR)=0, t!=x3), p random n=b bit prime, random short Weierstrass curve; same semantics as the sweep's bits-s3 (own emitter, not the Rust one, because the propagator needs word-level variable maps).
- Diagonal: s = b/3, b = 6, 9, 12 (15 only if the rule says extend). Window bit = bit of s (per x). Slope e = d log2(work)/d s (that is "per window bit"; enumeration is e = m-1 = 2, the ladder bar is e < 1/2). Slope per b is e/3 and is reported too; the thresholds 1.0 / 0.5 are applied to e (per s) as in L05/L11.
- Metric: log2 of work (primary: work-charged, unit PE below), per instance, mean within curve, then OLS slope of curve-mean vs s per curve; CI = t-interval over per-curve slopes (cluster = curve, >= 10 curves), also curve-bootstrap.
- Work unit PE (propagation-equivalent): PE = CaDiCaL propagations + propagator ops, where one propagator op = one F_p add/mul (1 op), a modular inverse or sqrt = 3n ops, GE row operation of k columns = k ops. Conversion 1 op = 1 propagation (generous to nothing: a propagation is ~tens of ns, an F_p op ~ns plus bookkeeping; sensitivity columns at 0.1x and 10x are reported). Also reported: conflicts alone, CPU seconds (descriptive, host load 50+).
- Kissat has no propagator: work = its propagations (stat), conflicts also reported. Plain CaDiCaL with no propagator connected and a no-op propagator (observed vars frozen, never propagates) are both run as controls.
- Censoring: per-run conflict cap; censored runs counted at their work at the cap (lower bound on slope). Censored fractions reported per cell; if b=12 censored in > 50% of runs in an arm, that arm's b=12 slope is labelled lower-bound and the rule's "b >= 12 stays censored" clause applies.
- Instances per cell: >= 10 curves (seeds), per curve 6 planted (SAT) + 6 uniform targets (mostly UNSAT), identical targets across arms (paired). b=6 cell may lack planted targets when fewer than 3 lifting abscissae; curves are resampled until >= 3 lifting abscissae exist (documented selection).
- Arms: kissat (default, --conflicts cap), cadical_plain (library, no propagator), cadical_noop, cadical_ge (GE over linearised monomial system), cadical_geq (GE + univariate quadratic root rule; L04-like, labelled ablation).
- Soundness gate (before timing; any failure stops the run): (G1) planted solution never conflicts: assign the planted bits in order, propagator must never emit a clause falsified by the planted model nor a reason clause violated by it; (G2) every clause the propagator emits (reason and conflict) is checked against the CNF: for small instances every emitted clause is verified implied by exhaustive model counting restricted to the word-level semantics, and every clause is checked true under every model of the CNF found by enumeration (b=6); (G3) oracle agreement: SAT/UNSAT answer of every arm equals the exhaustive oracle on all b=6 instances (and b=9 s=3 subset), models verified by exact group arithmetic; (G4) known-UNSAT instances conflict (answer UNSAT in every arm); (G5) cb_check_found_model re-evaluates all polynomial constraints on the full model and aborts on mismatch (tests propagator polynomials against CNF semantics).
- Confound ledger: cadical_noop vs cadical_plain isolates the cost of observing/freezing variables; geq vs ge isolates root rule. Same CNF, same targets, same cap, same cadical seed (seed 1) in all CaDiCaL arms. One seed only per instance (variance is across curves).
- Budget: <= 20 CPU-h, nice, <= 4 concurrent solvers.
- Not claimed: anything about asymptotics beyond b=12 (or 15); a slope < 0.5 would need independent reproduction.
