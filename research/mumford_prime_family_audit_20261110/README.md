# Unbounded prime orders in the checked arithmetic family

Lean proves that the growing F3 reduced-pair family has arbitrarily large
**prime** orders. For every bound B there is a parameter t such that
g=12t+2 and n=24t+5 both exceed B and n is prime. The actual arithmetic
group has cardinality n, its actual pair (X,1) has order n, every member
is generated by it, and every group sum has the previously checked
normalized Cantor certificate. [pcc:unverified]

Every family member is smooth, with fraction 1. The full finite universe
of valid reduced pairs has strictly smaller smoothness fraction, witnessed
by the same explicit nonsplit pair. Lean proves such prime-order
disparities beyond every order bound and directly negates universal
equality for this prime-order arithmetic family. [pcc:unverified]

## Existing theorem, actual parameter extraction

The proof imports the pinned Mathlib
[`PrimesInAP.lean`](https://github.com/leanprover-community/mathlib4/blob/56a005855ea17e0b0958f73ec801ae140b0a1679/Mathlib/NumberTheory/LSeries/PrimesInAP.lean)
proof of Dirichlet's theorem, by Michael Stoll. Its
`Nat.forall_exists_prime_gt_and_modEq` theorem applies because 5 and 24
are coprime. It supplies a prime p>24B+5 with p≡5 mod 24.
Lean then uses the actual division/remainder identity to set t=p/24,
proving t>B and 24t+5=p. No assumed Dirichlet or prime-infinitude premise
is added. The imported analytic proof's transitive axioms are checked by
the same gate. [pcc:unverified]

The existing uniform arithmetic certificate applies to that actual
parameter. This combines the proved prime order with the earlier actual
polynomial outputs, group law, generator, finite universe, nonsplit
witness and unequal fractions. It does not replace any arithmetic with
an assumed cyclic-group interpretation. Issued parent formal sources
remain unchanged. [pcc:unverified]
