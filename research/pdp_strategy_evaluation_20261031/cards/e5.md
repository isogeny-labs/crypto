### LEAD-15 — Diem-Thome plane-quartic line harvest on the cubic-GHS m=2 cover
Verdict: PROMOTE, with four revisions below. It is the only lead in this cluster that moves an exponent on a family the repository can already build.

Novelty: the atlas has no known-result entry for Diem's plane-quartic theorem (KR-IC-a4dd54 is the hyperelliptic Õ(q^(2-2/g)) bound only); this dossier is not in the atlas. The Smith lead mislabels the same exponent (Appendix C). Literature: Diem JTNB 2012 Thm 1 proves Õ(q) for non-hyperelliptic genus 3 (expected time, q large), which corrects the census README's "heuristic" sentence. Diem-Thome give the practical variant (heuristic, Assumption 12).

Evidence check: the 13 repository paths in LEAD-15 exist (its verify file). Primary sources agree on Thm 1, Thm 3 (q^2/24 split lines), Prop 4 (1/6 per point, fails only for O(1) points), DT numbers (86 mults per PP relation, 87,803 rows, 352 non-zeros per row). Four corrections:
(a) "about 48q additions" for the provable algorithm is low. Diem's stage 0 takes ceil(log q * q^(1/2)) points, stage 1 takes ceil(sqrt(180) q^(1/2)), and each relation costs up to 24 q^(1/2) tries (Prop 11 proof), so at least 322 q additions. Conclusion unchanged (provable variant is not competitive).
(b) "rho about 10^5x more work" is against relation collection only (DT p. 16). DT Table 2 (8 h + 1 day + 1 day on 8 CPUs, about 224 CPU-h) against their 370,000 CPU-h rho estimate is about 1.6e3 end to end.
(c) w = 12 non-zeros per row is the weakest assumption. DT measured 352 at q = 2^31, and their graphs at 2^19-2^24 have mean tree depth 17-21 and mean component depth 35-43 (Table 1).
(d) The baseline is stale. "1.30 / 2.60e8 at 2^15" is item 7. Round 4 (`research/ic_improve4_20261015/01-genus3-relations`) has incumbent slope 1.408 (2^16-2^22), 9.967e10 at 2^22, and C1+C2 at 0.715x. Derived: about 1.1e8 at 2^15. Its matched-rho gap was not measured there.

Prediction (derived; LEAD-15's cost model, my w-sensitivity): total at q = 2^15 = 7.3M + 0.53M*w. For w = 12 / 40 / 100: 13.6M / 28M / 60M. Against the Item-7 rho model (1.61e8): 0.085 / 0.18 / 0.37. Against the round-4 hyperelliptic incumbent: 0.12 / 0.26 / 0.55. At 2^22 (derived): 1.7e9 / 3.6e9 / 7.6e9, i.e. 9-40x below the hyperelliptic C1+C2 (7.1e10) and 30-140x below rho. Class if it holds: advance (exponent), on instances with both covers; otherwise a new row. Rho scales as c^(-1/2) in the cofactor c, so cofactor 4 is the best case and c = 60 moves the crossover to about 2^10.5.

Decisive experiment (revised Part C): Rust builder for prime q in {257, 2053, 32771, 2^22}, 6 curves per size, only instances with prime l and cofactor 4 that carry both an m=2 and an m=3 cover (24/62 at q=5, 49/157 at q=7 in the census), so the baseline is same-instance. Run the full DT harvest and report PP and FP yield per pair, giant fraction, the rank and nullity of the recombined system mod l, and the measured row weight w after cycle selection and SGE. The harvest at 2^22 is 1.7e7 pairs (seconds). Frozen kills: K1 PP per pair < 0.20; K2 usable cycles < N+2; K3 nullity != 1; K4 projected total at 2^15 (measured w) above 0.6x the matched hyperelliptic incumbent. Cost: builder 2-3 person-days, run under 1 CPU-hour and 1 GB; Parts B and D as in LEAD-15.

Exploratory toy, not a claim (`.../eval/e5/toy/lpart.rs`, std-only, derived F_q-structure with N(y0) = N(x-a)N(x-b)): 115 random Type-1 curves y^2 = (x-a)(x-a^q)(x-b)(x-b^q) over F_{q^3}, q in {11..103}, prime l >= q^1.5. The q+1 points of C(F_q) give 5791 distinct nonzero l-components against 5784 expected for uniform draws (control 5872 for one extra draw each); seven instances have cofactor exactly 4. So the toy "FB points are 4-primary" observation is not structural for q >= 11. This tests only generation of the l-part, not nullity.

Risks and contradictions: (1) family gap (Appendix B): needs E/F_{q^3} with 4 | #E, never prime order, absent from Tables A-C. (2) In the nested tower F_{p^6} / F_{p^2} / F_p (Table D family), Joux-Vitse's own Table 1 gives decomposition p^(5/3) and sieving p^(12/7) against Diem's p^2, so the quartic route is the better exponent only for q with no subfield (q prime). (3) Memory Õ(q). (4) Chebotarev error constants at q = 257 are vacuous (genus of the S_3 closure is about 10); only the measured pair yield counts. (5) Ranking needs the section 5a band.

Confidence: medium. Literature high; GHS-specific yield, nullity and w unmeasured.

### LEAD-TRF-odd-char-descent-smith-quartic — Smith isogeny from the genus-3 hyperelliptic descent to a plane quartic
Verdict: REVISE (no obstruction found, but dominated by LEAD-15 and mis-stated in the atlas; do not run first).

Novelty: Smith's construction is not new here (`src/cryptanalysis/smith_prop24.rs` and four Smith studies). The atlas lead is an error-bearing restatement. The title and `discriminates` say "Diem's q^{4/3} attack ... instead of rho's q^{3/2}". That is wrong. Smith's intro (arXiv:0806.2995) says genus-3 hyperelliptic DLP is already Õ(q^{4/3}) (Gaudry-Thome-Theriault-Diem) and the quartic is Õ(q) (Diem). Diem's Math. Comp. theorem (arXiv:math/0606607) gives q^{2-2/g} = q^{4/3} for any genus-3 curve. The repository measured that hyperelliptic branch on this very family (1.30 in item 7, 1.36-1.43 over 2^16-2^22 in rounds 2-4). The value of Smith is therefore q^{4/3} to q, the same gain as LEAD-15, not q^{3/2} to q^{4/3}.

Evidence check:
- `problems/ghs-to-smith-pipeline-characteristic-mismatch.md`: present. It says no characteristic obstruction remains in odd characteristic. It also says Props 2 and 4 are "not implemented", which contradicts `smith-kernel-isogeny-class-walk.md` (native Props 2/4 done 2026-10-14, 18.638% on 10^6 curves against Smith's 18.574%).
- `odd_char_descent_genus3_20261014/REPORT.md`: present; genus 3 only for (m,r) in {(2,6),(3,5)}; cycle types (3,3,1,1) give #S(H) = 3 (verified).
- `ghs_cubic_quartic_ic_20261012/README.md`: present; S = 6.5e5 to 3.8e7 correct.
- `plane-quartic-jacobian-class-arithmetic-missing.md`: present, resolved for toys.
- `odd-isogeny-quartic-transfer-execution.md` and `cubic-extension-transfer-admission.md`: not present locally (not verifiable).
- IDEA-20261018-670088: not verifiable (autoresearcher checkout stale).

What blocks it: the stated blocker is stale. Props 2/4 exist. The elliptic-walk W3a module exists (29 tests pass), but its Q1 pass-rate measurement on the Joux-Vitse family has no results in the repository (only a validation recovery; "no larger-prime campaign launched"). Genuinely missing: the explicit map psi on divisor classes (W3b), canonical quartic class arithmetic (W1; no `plane_quartic_pic.rs`), and the pass rate on this family (codimension-large, three bielliptic involutions, so Smith's 18.57% need not apply).

Prediction: if Smith's two coins held on this family, P(some subgroup passes) = 1-(3/4)^3 = 0.58 for #S = 3; derived, unmeasured. Supply is the real limit. In the census at q = 5, 7 the plane quartic comes directly (m=2) for 42/62 and 115/157 of the self-covered curves with 4 | #E, and a 2-isogeny reaches a genus-3 cover for 104/104 and 286/286. Smith adds supply only for the hyperelliptic-only 32% and 27%, at most 58% of those. The hyperelliptic family also has density 1/q (Joux-Vitse: Theta(q^2) of q^3, walk about q steps), while the m=2 family is about half of the full-2-torsion curves.

Decisive experiment: run W3a Q1 only (protocol frozen, module exists): exhaustive p in {7,...,23}, measure pass(H) and pass(E). Kill: pass(E) below 10% on hyperelliptic-only curves means closing the lead as supply-dominated. Hours, no new code beyond the existing example. Defer W3b until LEAD-15 Part C passes.

Risks: closure in characteristic 2 is stated as "Smith excludes char 2" but Diem's plane-quartic IC does hold in char 2 (DT ran C_{3,4} over F_{2^31}); the closure holds because char-2 genus-3 GHS covers are hyperelliptic (per KR-IC-791cb7, not re-verified) and Smith's (Z/2)^3 kernel is unavailable.

Confidence: high on the exponent error (primary quotes); medium on dominance (counts are from q = 5, 7, 11 only).

Sources: Smith arXiv:0806.2995 intro; Diem arXiv:math/0606607; Diem JTNB 2012; Joux-Vitse sec. 4.1; repository census and problem files above.

### LEAD-TRF-odd-prime-ghs-cover-floor — genus floors of odd-characteristic GHS covers at prime degree n (n=7 plan)
Verdict: CLOSE as an improvement lead (named obstruction below). The Lean lemmas and census may continue only as formalization hygiene.

Obstruction (scope, not a theorem): (i) for a cover with g = n, Diem's q^{2-2/g} equals Gaudry's cover-free Õ(q^{2-2/n}) (Diem Compositio 2011 intro; Tian intro: "optimal if g = n"), so a floor result cannot change the exponent of any E/F_{q^n}. A lower exponent would need a degree-d plane model with a completely split line (Diem JTNB Thm 2: 2-2/(d-2)); existence for the genus-7 cover is unverified. (ii) The n=7 floor is already known: Momose-Chao slide 20 ("2^n-1: exist" gives (d,n) = (7,3)), Iijima-Momose-Chao 2015 (abstract: complete classification for d = 2,3,5,7), and the repository's own table (`odd_char_descent_genus3_20261014/REPORT.md`: min genus 7 at n = 7, Theorems 1-3, exact counts for n <= 8). Check: (m,r) = (3,7) gives g = 1+2(7-4) = 7, the seven translates of a difference-set complement spanning the [7,3] simplex code. (iii) No leaderboard row lives there (all rows are F_p or F_{2^m}).

Novelty: new vs atlas only in the Lean statements and the "isogeny-class reach" claim; duplicates `LEAD-TRF-small-genus-cover-general` (closed, same Riemann-Hurwitz argument) and the n <= 14 table. Not in the 19-lead study.

Evidence check: all five evidence paths are in crypto-autoresearcher (ledger, problems), absent locally: not verifiable. Neighbouring `odd_char_descent` REPORT is present and matches (n=7 -> 7).

Prediction: no effect on S for any benchmark row. Exponent arithmetic if it were used: g=7 gives q^{12/7} = q^1.714 against rho q^3.5 on E(F_{q^7}), but Momose-Chao slide 21 (conjectured, "?") puts the weak set at Theta(q^{4}) of q^7 curves, i.e. density about q^-3, so a class walk of about q^3 steps dominates (about q^3 against rho q^3.5). Group size is q^7 (q = 7 gives 2^19.7), where asymptotics do not apply.

Decisive experiment: none worth IC compute. If kept as math: the approved plan is a finite census; kill is a counterexample to the Theorem 1-3 floors.

Risks: odd q only; `last_reviewed` 2026-10-30 postdates my local ledger; the Lean/census claim "n7 floor" would be a relabelling of a known classification.

Confidence: medium (IMC full text unreachable, density claim from slides only).

Sources: Momose-Chao ECC 2007 slides 20-22; Iijima-Momose-Chao ePrint 2015/805 abstract; Diem Compositio 147 (2011); Tian arXiv:2012.07173; repository REPORT above.
