## 0. Summary [pcc:unverified]

1. **The d + 1 is the degree at which a binomial must first be multiplied by a variable.** An elementary
   lemma (TH-1) shows that 1 ∉ I_curve + K·(y_1^d − 1) + … + K·(y_m^d − 1) for every target, m = 2, 3 and both
   forms. Every certificate of inconsistency therefore uses u·(y_i^d − 1) with deg u ≥ 1, so F4 must run a step of
   degree ≥ d + 1. The bound is "trivial" (it is not about hardness), but it is form-independent and rigorous.
2. **The recorded value is the first fall degree, in every prime-d cell, in both forms.** Computed from top-form
   syzygies with no free parameter: sym D_ff = d + 1; plain D_ff = d + 2 (m = 2) and max(d, 4) + 8 (m = 3).
   Adding the input-degree floor 2^{m−1} of S~, the rule matches 28 of 28 recorded prime cells. That includes the 7
   cells where SD ≠ d + 1 (exponent-study README §3). This is post-hoc, but it has no free parameter.
3. **Chains break first-fall-degree heuristics.** At composite d, D_ff = e_min + 1 while SD = e_max + c. In the
   30 composite cells, c = (m − 1) + ⌈(m − 1)(s + m − 2)/4⌉, where s = Σ_{j ≠ j_max}(e_j − 1). This fits 20/20 at
   m = 2, 10/10 at m = 3 and the single m = 4 cell. The rule is fitted, so TH-2 preregisters a new test.
4. **SD does not set the cost; the residual density does.** At m = 3, T/max_cols is about 4–5e3 at prime d and
   5e4 to 7e6 at composite d. The naive Macaulay count C(n + SD, n) ranks flat and chain in the *wrong* order at
   d = 27 (TH-5).
5. **Semaev 2015's d_F4 ≤ 4 concerns Boolean Weil-descent systems over F_{2^n}; nothing transfers either way** (TH-3).

## What this changes for the real curve [pcc:unverified]

- The W5 §1 statement "SD ≥ 65,148 on every μ_d base with d ∤ 12" rests on the chain law at composite d. Only
  the flat presentation has a rigorous bound: TH-1 (i) gives SD ≥ d + 1 at any d. A chain has only SD ≥ e_max
  (TH-2), plus ⌈s/4⌉ (m = 2) if the s-law holds; s ≥ 1 for every composite d with e_max = 65147.
- The flat presentation removes the smooth-p − 1 requirement but not the dependence on d. No divisor of p − 1
  lies in the useful 2^64 to 2^85 window (W5 README §1), so the route stays closed.
