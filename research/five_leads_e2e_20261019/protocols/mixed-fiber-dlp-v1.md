# Mixed-fiber relation DLP: frozen before execution

This is an end-to-end small-field test of the mixed-fiber factor-base choice
with an explicitly charged complete pair-table relation oracle. It does not
test the proposed F4/msolve implementation. The algebraic-solver part of the
original lead remains open even if this DLP run succeeds.

For `(p,d)=(97,8),(193,12),(257,16)`, scan `a,b=1..20` in lexicographic
order. Keep the first three nonsingular `y^2=x^3+ax+b` with an exhaustively
counted group whose largest prime factor `r>=23` occurs only once, and with
at least three multiplicative cosets of order `d` having the same lift-count
shape and positive rational points. Selection depends only on public curve
data. Pick the first nonzero `h`-projected point (`h=#E/r`) as generator.
This replaces the earlier pair-table census curves, some of which have only
four distinct nonzero prime-order targets. Publish every selected curve and
all 20 exact-order target points/scalars; scalars are harness checks only.

For each curve, target index 0..19 is generated by the seeded unique-scalar
rule in `native/mixed_fiber_dlp.rs`. Keep the same curve, target, seed, cap
and pair-table solver for homogeneous, mixed, and matched random coset arms.
Generate source negation rho once per target with the same cap, and charge
source verification to rho and each candidate. No solver receives the
planted scalar. Preserve failures and cap exhaustions without replacement.

Each candidate builds its fibers, lifts all points, projects them to the
prime subgroup, builds the complete first/second summand pair table, and
searches `R=aP+bQ` targets. Every triple relation yields a row whose unknowns
are projected factor-base logs and the desired target log. Scalar elimination
extracts the target coefficient only when all preceding columns eliminate;
the answer is checked by recomputing `kP`. Charge all field M/S/I, source
group operations, relation trials, root/lift work, table insertions/lookups,
scalar row work, random draws and memory. Report per-size and pooled cold
cost ratios to source negation rho across S/M={0,0.5,1}, I/M={1,10,100,1000}
and native charges {0,0.1,1}; retain losses and all zero-relation attempts.
