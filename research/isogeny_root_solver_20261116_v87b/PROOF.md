# Matching complete finite S3 root solvers on an explicit rational domain
Input is a proved odd-prime curve with odd group order,finite source domain D represented by every rational point over each listed x (closed under negation),finite target Q and a certified rational3kernel. The odd order excludes rational2torsion. Every ground-field finite S3 chain anchored at the rational target then has rational point lifts throughout (C74 torsion-cut proof); align signs along the chain. Thus every original ordered source/auxiliary x-root is produced by rational source points summing to Q,with all prefix sums before the target finite. Global negation covers target -Q as well. Conversely every retained point tuple satisfies the original equations. Deduplicate identical x/intermediate tuples without removing distinct orderings,repeats or auxiliary values.

Reference: store every ordered first point pair by sum; enumerate the remaining one or three point tails and match Q-tail. Drop an original first-pair infinity because that original finite intermediate is forbidden. Final validation checks every original prefix and target. This covers the complete finite original polynomial root set under the stated field/domain/odd-order certificates.

Auxiliary: map source points and target through the certified3isogeny,store every original fiber,run the same sum join on image points,then expand every fiber and filter original point sums/prefixes. Do not drop auxiliary infinity: its preimage can be a nonzero rational kernel point that is a valid original intermediate. An image target infinity must remain valid. Domain and target remain exactly those of the declared original instance; auxiliary domains are internal images. Every original point tuple maps to an enumerated image tuple and is restored,so completeness follows,not just residual membership.
