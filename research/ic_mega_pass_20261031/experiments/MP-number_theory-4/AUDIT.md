## Defects / caveats not (fully) stated in README
1. Planted control is mis-sized, not merely "underpowered". Planted shift of Fhat(j0) ~ 2*nf*(2/pi), nf=0.05*hits, so expected lam_j0 ~ 0.5,1.0,2.0,4.1,8.1 for k=14,16,18,20,22 vs null floor 3.2-4.2. At k<=18 the planted signal is below the noise floor by construction (a miss says nothing about the detector); k=20 is marginal (4.1 vs 4.15); only k=22 is above. Fixed fractional dose => SNR ~ sqrt(N mu) grows with p. Protocol rule "planted must exceed 3x null or run invalid": best is 2.08x (k=22) => formally invalid at every k, README only says k<=20 and notes k=22 <3x in passing. No control at all for the theta-sweep arm.
2. Pre-registered comparison null (NULL-2 iid) is mismatched: REAL F is symmetric (F[k]=F[N-k]), so Fhat is real and max over N/2 real values ~ sqrt(2) x max of complex Rayleigh values. Expected ~1.4x artifact; observed REAL/NULL-1 ~1.3 and REAL/NULL-1sym ~1.03. So the 1.5x SUPPORTS line is effectively ~1.1x after correction, and 3x REFUTES line is far too loose to catch anything but gross bias (needs Fhat > ~12 sqrt(N mu)). Strictly the SUPPORTS rule FAILED (REAL 1.53 at k=14; k=18 passes by 0.001: 1.4991; held-out 1.64) -- README mentions only 1.64.
3. NULL-2 = max of 16 unclimbed masks vs REAL/NULL-1 = best of 40 climbed (k<=18): selection-count mismatch inflates REAL/NULL-2 slightly. REAL and NULL-1 climbers use different rng states (not matched candidate sequences) in main run.
4. Search is essentially random sampling: 16-40 evaluations over p^(d+1) coefficient space, restart every 8 evals. "No structured degree<=6 filter" (README Verdict) is unsupported; the data say only "none found by a tiny random search"; structure that a good f would expose is not excluded. README's "leans toward no structure" is the strongest defensible wording and only as a prior, not evidence.
5. Theta sweep: the random-A,B arm is vacuous by construction (sums of random indices are ~uniform, mass ratio ~1 regardless of structure; theta=0.25 has e~4 hits). Adversarial arm: selection bias, identical on NULL-1 (15=15, 187/185, 2015/2055, 24274/24266). Interval arm: s^2 pairs count over-counts multiplicity (~2s distinct sums), z-scores invalid (e.g. -35.6 / -17.9). So no arm is informative; REAL and NULL-1 arms use different A,B draws. Single curve, single f (d=2 climbed).
6. Brief section 2 lists "DL character-sum pseudorandomness" and "coordinate-statistic bias hunts" as closed/exhausted; README does not position against these or state a section-0 rule-5 certificate/classification (relabelling/accounting at best).
