# MP-symmetry-4: outcome SUPPORTS the null-consistency prediction ("no structure at toy n"). Class: relabelling.
Files: PROTOCOL.md (pre-registered, plus one budget amendment), run.py, agg.py, raw_output.txt, RESULTS.json (the aggregate is under "aggregate").
- Identity: x lifts iff Tr(x)+Tr(beta/x)=Tr(a). 0 mismatches over all of F* for 45 curves (n=7,11,13,17,19). The DFS counter matches brute force at n=7, l=2 (9/9 curves).
- n=11, exact counts over 9 curves, obs/hypergeometric null: l=2 0.9999 (z=-0.05); l=3 0.996 (z=-7.3); l=4 0.9227 (z=-35, per curve 0.89-0.95). This reproduces the programme's 0.921x census. It is a DEFICIT, not an excess.
- Orbit-preserving shuffle (pairs {x,beta/x} permuted), l=4, curves 0-2: obs 14025/38392/14686 vs shuffles [14443,15255]/[40372,43384]/[15080,14900]. The shuffled sets also sit below the hypergeometric null, so part of the deficit comes from the pairing and density, not from field structure.
- n=13: exact l=2 1.0000 (9 curves); exact l=3 0.9991 (2 curves); SIS l=3 0.975+-0.011; SIS l=4 0.966+-0.032. No excess. The l=4 ratio does not grow from n=11 to n=13 (0.92 to 0.97).
- Positive control: a planted 4-dim subspace raised the l=4 count 15285 -> 17529 (>= +1, detected).
- SIS check against exact at n=11, l=4: 13190+-1987 vs 14025; 37655+-4873 vs 38392; 17352+-2618 vs 14686. Consistent within 1-1.1 se.
- sigma check: Tr(beta*sigma_V)=Tr(a) held for 4,119,277/4,119,277 all-lift V (n=11, l=2,3). sigma_V=0 in 1692 cases (4.1e-4, about 2^-11.3, matching 2^-n). beta/V a subspace: 0 of 4,119,277.
- l*(n), budgeted randomized DFS, given as true / shuffled / formula: n=7 3/3-4/3; n=11 4/4-5/4-5; n=13 5/5/5; n=17 5/5/6; n=19 5/5/6. The true sets never exceed the shuffled null. At n=17 and 19 both arms fall short of the formula value by the same amount (a search-budget limit).
Verdict: the falsifier conditions (ratio >=1.5 that grows with n, l* >= null+2, beta/V-closed families) did not occur. The data are consistent with Z behaving like a random union of {x,beta/x} orbits, with a small deficit at l=4. This is NOT a closure of lever 7. It is a census at toy n, and l <= 5 here, far from the l ~ n/2 that n=131 would need. Sum-freedom results give only the single bit sigma_V != 0.
Caveats: runtime was 1333 s (~22 min), slightly over the 20-min budget. The shuffle arm has only 2 samples per curve on 3 curves. SIS at n=13 has a 3% standard error. The l* search is a heuristic lower bound (node budget 2e4, 64-branch cap). Novelty is unverified: no literature search was run in this pass.
