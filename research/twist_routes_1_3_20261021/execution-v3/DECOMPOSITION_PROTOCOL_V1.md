# Cold decomposition-worker interval, version 1

This separate diagnostic prices work excluded from the basis-only probes.
It is not the complete E27 IC pipeline or the original 1,920-attempt replay.
Freeze native source, task plan and binaries before running it.

First use all ten original curves, B=8, arities 2 and 3, original public target
label 0: 20 configurations, ten target pairs. For each run direct A/A, direct,
the eight-branch helper and first-pair invariants including the diagonal.
All branches share one worker and one budget. These are already observed
training cases; no final E28 label is opened. Retain every requested attempt.

The worker receives public curve parameters, target point, B and arity only.
It reads no expected tuple list, old basis or target logarithm. Reconstruct
the first B nonzero-y abscissae, construct all candidate equations, run the
existing generic native F4/substitution solver, recover invariant pair roots,
lift signs and verify sums on the source, enumerate the missing infinity-prefix
chart for m=3, and deduplicate the same canonical first-pair tuples.
The generic solver enumerates roots in Fp; this is a real algorithm whose
field-size overhead is charged, not a census used to generate the answer.

Each worker has 15,000 ms cooperative shared budget, 18-second hard timeout,
one-second kill grace, one thread, 4 GiB address space and 32 MiB/file bound.
The 80-process timeout envelope is under 30 minutes; cap the complete run at
1,800 seconds and 1 GiB raw output. Checkpoint every cell. Preserve incomplete,
failed, unstarted and mismatched outputs. One solver worker runs at a time;
no time is admitted from this L0 host and no paid resource is allocated.

Callgrind Ir includes startup, parsing, finite-base/equation construction,
all F4/substitution work, root/sign lifting, exception enumeration,
deduplication, source verification and serialization. It excludes the parent,
OS/kernel, independent certification, relation-matrix work and full DLP
recovery. Keep this interval separate from the earlier basis-only interval.
No subtraction of the two different worker measurements is admitted.

Outside the worker, require complete solver verdicts and exact full projected
tuple equality to the frozen E26 census. Reopen input/expected/output hashes.
Generate independent PARI signed-point replay and deliberately wrong-sign
controls for every retained witness. Require that replay's marker, captured
exit, clean-error/hash gate and an independent Rust instruction/aggregate audit.
Direct A/A spread must be <=5 percent per configuration before paired costs
are interpreted. Report all failures, missing pairs and ten target pairs.

Stock msolve is the earlier applicable basis reference, but this native generic
root worker has no newly measured external full-root reference. Do not claim
fastest implementation, novelty, calibrated IC speedup or complete E27 cost.
If root overhead dominates, freeze a separate algorithmic optimization and
rerun baseline/candidate on identical tasks; keep the original run unchanged.
