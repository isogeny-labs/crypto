# Frozen protocol: n=83 adaptive image-router gate

Frozen: 2026-11-18, before the new native router audit or its pair counts were
run.

## Question

Does the already implemented norm/projector furnish a new compact
growing-degree or adaptive relation router for the transported order-`r`
elliptic image in the genus-three Jacobian?

The candidate tested here is deliberately narrow.  For the degree-three cover

```text
phi : C -> E,       e = phi^* phi_*,       p = [3^(-1) mod r] e,
```

the **projector-only router** maps an arbitrary Jacobian class `D` to `p(D)`
and then attempts to collect or factor relations in the transported elliptic
image.  This protocol does not classify a future router that supplies an
additional, non-generic source-label or Prym-cancellation oracle.

## Pinned objects

- `E/GF(2^83): y^2 + xy = x^3 + 1`;
- `C/GF(2^83): v^2 + u^2 v = u^7 + u`;
- `phi(u,v) = (u^3, uv + 1)`, of degree three;
- target prime `r = 2417851639230796216685689`;
- pinned order-`r` point coordinates from the preceding projector audit;
- exhaustive implementation control: the `GF(8)`, `a=1`, `b=3` cover, whose
  Jacobian has 486 represented classes and whose elliptic target has six
  points.

## Prior evidence (known before freeze)

- The arbitrary Mumford-class pushforward is implemented with closed-point
  residue-field norms and exhaustively cross-checked on all 486 `GF(8)`
  classes.
- `phi_* phi^* = [3]`, `e^2 = [3]e`, and the normalized order-`r` projector
  are already checked.
- The `GF(8)` norm has six fibers of size 81; this is an implementation fixture,
  not an asymptotic model.
- Degree-one/degree-two rational fibers on the odd-degree fields project to
  already known labels `P` and `[2]P`.
- Fixed bounded-degree projected branches and ordinary full-Jacobian genus-3
  index calculus were screened in the preceding studies.  A compact
  growing-degree/adaptive router was left unclassified.

## Algebraic predictions

Assuming the certified homomorphisms and `gcd(3,r)=1`:

1. For every `K` in `ker(phi_*)`, `p(D+K)=p(D)`.  Hence a projector-only
   router is constant on norm fibers and cannot retain a Prym/kernel label.
2. Every exact Jacobian relation pushes to an elliptic relation.  The converse
   only implies that the Jacobian sum lies in `ker(phi_*)`; it need not be
   zero.
3. On the transported order-`r` image, `phi^*` is injective because
   `phi_* phi^*=[3]` and `3` is invertible modulo `r`.  Therefore relations
   among image-closed elements are exactly elliptic relations among their
   labels, not an additional source of independent rank.
4. A reduced genus-three Mumford class has support degree at most three.
   Consequently, a genuinely growing-degree router must use non-reduced
   effective divisors/Riemann--Roch data or another representation; merely
   changing the factorization of reduced classes is not growing degree.

## Native audit

The deterministic Rust audit will:

1. reconstruct the 486 `GF(8)` Jacobian classes from the independently checked
   presentation generated by classes `A` and `B`;
2. push every class to the six-point elliptic target and record every norm
   fiber size;
3. enumerate every ordered pair `(D1,D2)` and separately count
   `phi_*(D1)+phi_*(D2)=0` and `D1+D2=0`;
4. verify that every exact pair is projected-zero, while projected-zero pairs
   have the kernel ambiguity predicted by the fiber size;
5. replay the pinned n=83 pullback/pushforward and normalized-projector checks;
6. emit a deterministic JSON certificate with the exact populations and no
   wall-clock fields.

The exhaustive fixture is a correctness and ambiguity control.  It does not
estimate the n=83 relation probability.

## Acceptance and rejection rules

- **Reject the projector-only router as a new relation mechanism** if the
  coset-collapse identities hold, all six norm fibers have size 81, and the
  projected-zero pair population exceeds the exact-zero population by the
  predicted kernel multiplicity.
- **Keep the candidate open** if any certified homomorphism or n=83 projector
  identity fails, if projection retains a class-specific invariant not
  determined by the norm label, or if the projected relation lifts uniquely
  despite a nontrivial kernel.
- Regardless of the outcome, do **not** generalize the result to every
  growing-degree/adaptive calculus.  A surviving broader proposal must name
  the additional label/descent or Prym-cancellation oracle and cost it through
  individual logarithms in the actual order `r`.
- No timing, throughput, security-level, or speedup claim is admitted by this
  protocol.  EKS measurement is therefore out of scope.

## Controls

- positive: exact inverse pairs in `J(C)(GF(8))` must project to inverse
  elliptic labels;
- negative: a nonzero kernel class paired with the identity has projected sum
  zero but nonzero Jacobian sum;
- cardinality: 486 distinct ambient classes, six target labels, 81 classes per
  label;
- n=83: the pinned order-`r` point, general norm, and normalized projector;
- representation: reduced Mumford support degree is explicitly capped at
  genus three.
