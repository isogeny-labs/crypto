# Cost-unit clarification
C82 PROOF.md calls map operations bit-XOR steps. Each recorded map_xors increment is one XOR of an n-bit field-element representation, not one individual bit operation. The O(n^2 log n) preparation estimate counts n-bit word-vector XOR operations; a conservative bit-operation bound is O(n^3 log n). The O(n log n) per-coefficient application estimate has the same unit distinction. The measured18397map XOR steps are therefore additional multi-bit work, excluded from the field multiplication/square sum. Frozen proof/source bytes are preserved; this clarification changes no output contract or recorded measurement.
