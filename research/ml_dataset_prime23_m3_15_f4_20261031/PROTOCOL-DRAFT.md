Status: **design only**. No prime cell has been launched under this draft. This is not a frozen `experiment.protocol/v1` record, and `plan.draft.json` deliberately has `protocol_sha256: null`, so it cannot authorize `dataset generate`. The proposed source pin is merged main commit `9e8fba70a8c63aff65d3562ba1d5d29ccb5edab1`; the release binary SHA-256, frozen protocol hash, priced resource envelope, S3 prefix and worker identity remain to be bound. ## Population and mathematical scope

The fixed natural block is 26 cells: prime family, n=23, every arity m=3,…,15, one curve seed, one generator/key index, and both `twist=false` and `twist=true`. Use `f4` only, factor-base size 8, degree bound 3, and `work_limit=20,000`. The seed `2026103106` matches the completed Koblitz n23 block's nominal seed but selects a distinct prime family and disjoint run/protocol IDs. The generator and nonzero scalar are sampled by the native generator, independent of the chosen method; no witness is planted or selected for a favorable outcome. The same curve/generator/key is reused across arities within each twist, so the 26 rows are a matched arity panel, **not** 26 independent public-key samples. The pair of quadratic-twist positions is required and no failed curve construction is resampled.

The native prime curve constructor starts at `2^n−1` and decrements odd candidates to the first prime. Independent trial division gives the **candidate** n23 modulus 8,388,593; 8,388,607 is composite (47 × 178,481). Bind the exact modulus only after a native preflight/readback confirms it at the pinned binary. Source-level inspection confirms the relevant native F4 chain's `p < 2^32` gate at n23. The m3–15 adapter constructs an affine S3 chain, with m leaves, m−2 auxiliary variables and m−1 S3 equations; infinity partial-sum branches are outside this encoding. A verified lifted group sum is a PDP witness. Exhaustion of a bounded or degree-truncated encoding is not an impossibility proof, and neither observed degree nor a degree-3 stop proves first- or last-fall degree. ECDLP scalar labels require independent recovery and generator-target replay.

The separate completed Koblitz n23 `enumerate` block has 26 retained rows (4 verified method outcomes and 22 timeouts) and S3 custody records. It is a distinct family/solver block, not a baseline speed comparison or a source of prime outcomes. Keep its controller and host ownership separate. Treat this prime block as one component of the larger requested corpus; do not imply that 26 cells satisfy the full generator/key/curve-size portfolio.

## Claims, controls and analysis

Class all campaign claims as `exact_computation`: (1) all 26 fixed indices have at most one native attempt and every status is retained; (2) each constructed curve, twist, order and factor base passes native replay; (3) each F4 input, bounded trace and returned lifted witness passes the central verifier; (4) each restricted archive and pointer has content-addressed S3 fresh-GET hash/byte readback; (5) any scalar label has independent recovery/replay evidence. The numerator for each property is exact; failed, timed-out, unsupported, interrupted and unattempted cells stay in the denominator. Do not make a comparative runtime, solver advantage, fall-degree or model-efficacy claim from this block.

No A/A or statistical power test is needed for these exact counts. A fixed known-positive F4 chain fixture and a recomputed-hash tampered-witness negative verifier fixture should pass the **same verification path** before admission, outside the 26 natural rows; they check detection/rejection rather than estimate natural success probability. If later comparing methods or twist effects, freeze a new controlled factorial protocol with independent curve/key draws, interleaved arms, A/A and a declared effect threshold. The natural block's positive count can be zero without turning the verifier positive control into a natural sample.

The primary metrics are per-cell Boolean and integer counts: attempted, sealed, native-verified, F4 input retained, native backend invoked, trace complete/censored, group-lift candidate/addition counts, verified PDP witness, independently recovered scalar, strict export, durable S3 archive/pointer and fresh readback. Retain native F4 call, pair, row, field-operation and stop counters with their exact source fields and units; retain zero/missing counters distinctly. Record whole-worker wall time, CPU/RSS/I/O and host contention as operational diagnostics only. PMU retired instructions are eligible only with event ID, enabled/running time, process/thread scope and readback; otherwise store null plus reason, never a solver stage counter under that name. A degree trace is an observation, not an exact fall-degree label.

Use the plan's deterministic mixed-radix order, m3 untwisted/twisted through m15 untwisted/twisted; no arm ordering inference follows. Freeze the one seed, source, binary, toolchain, flags, threads (`RAYON_NUM_THREADS=1`), CPU/NUMA/SMT and co-tenant record, filesystem, memory and timeout limits before execution. Keep n23 base/twist/keys in one ML split component; use strict causal predecision features and keep private witness, future trace and supervised labels restricted. Later ML holdouts must be by whole field-size or stronger algebraic transfer components, not by row.

## Proposed finite execution and custody

Build one `cargo build --locked --release --bin crypto` artifact from the exact source pin after the binary controller and host admission clear; hash it and check `crypto dataset capabilities`. Validate/freeze `experiment.protocol/v1` with the repository checker, then replace the plan's null `protocol_sha256` with the frozen file's actual SHA-256. Native preflight must read back the generated public modulus, both twist models and curve/order certificates before any measured cell. Build, preflight and positive/negative controls are outside the fixed 26-row denominator.

Run 26 one-case shards with `dataset generate --max-cases 1`, each index once. Proposed bounds match the completed n23 block for operational comparability: 30 seconds per case, 90 seconds for the outer generate command, 2,048 MiB memory, 64 MiB worker trace, 20,000 requested work units and one worker at a time. The prime chain further caps emitted events and group-lift additions at `min(work_limit,100,000)`, pair batch width at `min(work_limit,256)`, and each native F4 visitor at five seconds; **`work_limit` does not cap all native work or native matrix allocation**. The outer process/memory caps therefore remain authoritative. If a larger degree bound or work cap is later needed, make a new protocol version/arm before affected data, retaining this block unchanged.

Admit a finite cumulative monetary/resource/S3 envelope before launching. Each attempted shard gets a unique one-attempt marker; infra-only retry requires reconciliation of the original worker, checkpoint and S3 pointer before any resubmission. Write a local sealed manifest, run `dataset verify`, `report` and strict `export`, then content-address and publish the restricted archive and pointer with conditional write, fresh GET and digest/byte equality. Record failed puts/gets and unresolved custody as charged failures. Preserve independent restore/replay samples and every per-case stdout/stderr/exit/timeout/host-receipt hash. Spot/preemption resumes may preserve counted work but invalidate the continuous wall-time comparison. The prime job must wait until the Koblitz controller is terminal and the host is free of heavy Rust compiles or benchmark owners; no prime trial is authorized by this draft.

The frozen analysis should emit exactly 26 rows, counts by m/twist/status/termination, artifact inventories, native counter availability, verified PDP/scalar labels, an explicit attempt/censor/failure flow, and S3 custody/replay status. It should never drop a row due timeout or missing trace. A report may describe counted outcomes at their exact scope; training claims require a separate held-out, preregistered evaluation.
