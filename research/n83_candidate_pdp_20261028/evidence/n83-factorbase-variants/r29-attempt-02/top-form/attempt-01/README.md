# spike29 top-form outputs

`certificates/summary.json` indexes 48 original highest-homogeneous-form quotient certificates. Each row has an individual JSON certificate. `replay-summary.json` records fresh replay verification for all rows. `producer.log` and `replay.log` preserve command resource summaries.

The 48 cases cover binary, Koblitz, and prime families, m=2..9, with natural and planted targets. These are graded top-form dreg bounds/intervals, not affine solving degrees or LFD results.
