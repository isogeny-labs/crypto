# Exact build validation v1

This directory contains the offline Rust build log, compiler versions, build receipt, validation index, SHA-256 manifest, and exact `pdp` and `top` binaries. The source/project inputs and launch protocol are in the parent attempt capsule. All nine files were read back from the S3 validation prefix and compared byte-for-byte. See `../BUILD-VALIDATION-ADDENDUM.json` for the protocol binding and URIs.
