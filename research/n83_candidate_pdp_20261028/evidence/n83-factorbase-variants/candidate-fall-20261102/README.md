# Candidate first-fall panel, attempts 01–02

This directory records execution of the existing frozen `N83-FACTOR-BASE-PDP-FFD-LFD-20261031-V2` procedure on the 144 already-generated PDP systems for `spike35`, `spike36`, and `spike37`. Each candidate uses the same fixed 2^27 x-coordinate domain across m=2..9. The cohort contains all three curve families and both natural and planted targets.

The preflight verifies every `inputs.json` and `system.sing` against the attempt-08 dataset index and the source SHA recorded in each PDP row. It also pins the V2 protocol freeze digest and the release `fall` binary digest. The first runner stopped after producing the `spike35/koblitz-m2-planted` certificate because its replay helper missed a required argument. That certificate was read back from S3 byte-for-byte and passed a fresh recovery replay; the missing producer exit/stdout fields are explicitly recorded as unavailable. The corrected continuation preflight covers only the other 143 systems and uses a new S3 namespace. Each first-fall invocation has a 60 second timeout and 8 GiB address-space cap. Attempt and replay records upload to S3 before the next case starts.

This run records standard first-fall certificates only. It does not complete the V2 panel's separate degree-two closure work, and no LFD, affine degree of regularity, solving degree, or factor-base ranking is inferred. The exact scientific definitions and assumptions are documented in [the frozen V2 protocol](../../../protocol-pdp-factorbase-v2.json), [the original fall design](../../../../n83_ic_degree_sweep_20261027/fall/DESIGN.md), and the primary sources listed there: [Kosters–Yeo](https://arxiv.org/html/1503.08001) and [Caminata–Gorla](https://arxiv.org/html/2112.05579).

## File structure

See [FILE_LAYOUT.json](FILE_LAYOUT.json) for the machine-readable layout. `run_first_fall.py` and its script binding preserve the original attempt and error. `attempt-01/runner-error.json` and the per-case recovery record retain the partial attempt. `attempt-02/run_remaining.py`, its preflight, source index and script binding cover only the remaining 143 untouched cases. `analyze_run.py` independently recomputes counts and certificate hashes after production. Each per-case `attempt.json` preserves the exact command, output, input identity, outcome, and fresh replay. The aggregate summary and independent validation are derived from those case records.

The immutable source `system.sing` files remain in the attempt-08 content-addressed dataset at the hashes recorded in the attempt source indexes; they are not copied into the result bundle. The original certificate is under `s3://setec-astronomy-artifacts/runs/n83-ffd-lfd-factorbase-panel-20261102/v2/spike35/first-fall-attempt-01/certificates/`; the continuation writes to the separate `.../v2/attempt-02/` prefix. The combined `combined-144/combined-summary.json` contains all 144 rows, preserving attempt provenance. `combined-144/S3-CUSTODY.json` records the S3 audit and archive readback. The attempt-02 prefix contained 143 attempt records and 143 certificates; all 286 were downloaded and compared byte-for-byte. The complete archive, including the per-case `inputs.json` records but excluding source-system payloads, is at `s3://setec-astronomy-artifacts/runs/n83-ffd-lfd-factorbase-panel-20261102/v2/combined-144/panel-complete.tar.gz`. Its SHA-256, byte size, and fresh-readback match are in `combined-144/S3-CUSTODY-complete.json`.
