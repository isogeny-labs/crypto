# Prime m3–9 terminal certificate metadata

JSON files are byte-identical native copies. Factor paths in certificates refer
to each case under the raw archive results/ tree,not this metadata directory.
Hydrate prime-terminal-archives/runs.tar.gz and extract into a fresh directory.
Check its manifest,run instrument replay ROOT ROOT/results,and check manifest
again. PRIME_TERMINAL_FORMAT.json defines every sparse byte and exact circuit.
Upper FFD certificates do not establish exact FFD or strict LFD. All prior
lower-bound datasets remain separate;this stage records no new LFD bound.
