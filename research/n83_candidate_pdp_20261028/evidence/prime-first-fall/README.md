# Native prime first-fall metadata

These JSON certificates and summary are byte-identical copies of raw results.
Their factor-file paths are relative to each case in the raw archive's `results/`
tree. The `.poly` factors live in the content-addressed raw archive, not this
metadata directory. Hydrate and extract it using `prime-first-fall-archives/README.md`.
`raw-manifest.sha256` inventories that entire raw tree; it does not describe this
metadata directory. See PRIME_FIRST_FALL_FORMAT.json for exact reconstruction.
Producer checks plus fresh/S3 replay remain distinct from independent review.
