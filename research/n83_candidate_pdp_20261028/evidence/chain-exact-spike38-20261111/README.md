# spike38 chain-exact original-top Dreg run

This directory records a fixed 28-case exact-computation panel: Koblitz and binary families, m=3..9, natural and planted targets, all using the existing r=38 selector basis. The frozen case list binds each input.json and system.sing SHA-256, factor-base manifest SHA-256, and prior S3 object URI. No new point set, target, cloud job, or S3 upload is part of this run.

## File layout

- `protocol.json`: exact frozen `experiment.protocol/v1` copy.
- `inputs.manifest.json`: machine-readable 28-case input/S3/hash map.
- `CHAIN_EXACT_DESIGN.md`: written proof and theorem scope bound by the certificates.
- `LAUNCH_COMMAND.txt`: bounded producer and separate fresh-process replay commands.
- `certificates/controls.json`: explicit small structural positive/negative controls.
- `certificates/global.json`: finite-field, selector-window, and embedding certificates.
- `certificates/<case>.json`: source/top-form and exact-degree certificate for each case.
- `certificates/summary.json`: per-case exact result and failure status.
- `export.json`: experiment.export/v1 index with raw-file hashes and CONSORT flow.
- `replay.json`: fresh-process replay result.
- `manifest.sha256`: byte manifest for retained run files.

The only scientific metric is exact degree of regularity of the homogeneous ideal generated by original individual highest forms, including Boolean squares. This is not FFD, LFD, affine solving degree, or a base ranking. The design and export explicitly retain those boundaries.
