# Koblitz n23 m4 F6 and BSGS local controller

`campaign.py` executes the separately frozen four-cell protocol in `../ml_dataset_koblitz_m4_f6_bsgs_20261031/`. The native mixed-radix shards are 0 F6 untwisted, 1 BSGS untwisted, 2 F6 twisted, and 3 BSGS twisted. `check` is read-only admission: it verifies the pinned native binary, runner, store tool, frozen protocol and plan hashes, clean source identity from native preflight, four-cell plan axes, XFS filesystem and the configured checkpoint file. It reports whether the current 4 GiB new-attempt free-space floor is met; a low-space `check` is a diagnostic record, while `run` refuses a new attempt. It neither creates the output root nor contacts S3.

`run --max-new-cells N` requires N in 1..4. It uses a nonblocking campaign lock, writes an atomic per-shard attempt marker before starting the runner, and never launches a shard again after its marker exists. An interrupted marked shard can only be finalized from retained native artifacts. A 4 GiB XFS free-space check precedes each new attempt. Native generation is fixed to one cell per shard, 30 seconds per cell, 2 GiB memory, 64 MiB trace and a 90-second supervised outer cap. The controller separately retains native verification, report, and strict public/restricted export status for every attempted shard, including timeout or failure. It attempts restricted archive and content-addressed S3 custody even when a solver or stage does not succeed; completion of custody requires fresh archive and pointer GETs with exact byte/hash checks. A per-cell Git-ready receipt is written under this directory's `checkpoints/` after S3 readback. The owner must commit/checkpoint those receipts after execution waves.

An F6 row may retain a hash-verified geometric pair domain and a separately replayed positive PDP witness. It is not a general Gröbner F6 result, and a negative F6 outcome is not independently certified exhaustive by this controller. Only a BSGS row with native independently recovered scalar verification receives an ECDLP solve label. No clock comparison, whole-worker instruction count or first/last fall-degree claim follows from the controller.
