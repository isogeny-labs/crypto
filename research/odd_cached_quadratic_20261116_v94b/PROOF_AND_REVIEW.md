# Odd cached quadratic backend

Hypothesis: for finite explicit source domain D, cache square classes and normalized roots of f(x)=x^3+Ax+B once, then recover all third roots of S3 for each ordered (x,y). Reduce O(|D|^2) square-root calls to O(|D|), and batch inversions. This tests a genuinely different prime/odd-extension backend, not binary linearization. The source domain is finite and explicit, not an implicit huge interval solver.

For odd characteristic, the S3 coefficients in z are a=(x-y)^2, b=-2((x+y)(xy+A)+2B), c=(xy-A)^2-4B(x+y), with discriminant b^2-4ac=16f(x)f(y). For x!=y a!=0. Choose one nonsquare delta. Represent nonzero f(x)=delta^epsilon_x r_x^2 with epsilon in{0,1}; store zeros separately. Mixed nonzero classes give no roots, equal classes give discriminant root 4r_xr_y or 4delta*r_xr_y, and a zero gives discriminant zero. Ordinary quadratic formula supplies every finite z, deduplicating the repeated root. This includes pairs on the twist and nonrational original curve lifts. For x=y, b=-4f(x); if nonzero the linear formula gives the unique z. If f(x)=0, c=(3x^2+A)^2 is nonzero on a smooth curve, so no finite roots. These identities remain valid in characteristic three; smooth short models there require A!=0.

General finite-field Tonelli-Shanks uses exact q and field multiplication. The nonsquare search is bounded and reports unresolved on failure; field moduli must be irreducible as in frozen controls. Batch inversion uses prefix products and a reverse pass, proving each returned element inverses its nonzero input. No zero denominator is inverted. Unbounded domains are rejected and all explicit original roots are serialized. Complexity O(|D|) field square roots/classifications plus O(|D|^2) arithmetic/output and O(|D|^2) storage; output can itself be quadratic. This is a standard discriminant/caching optimization, no novelty claim. Compare direct quadratic recovery, not Gröbner, for this component experiment.
