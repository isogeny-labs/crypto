# Smooth p+1 four-summand study

The [refinement report](REFINEMENT_RESULT.md) ([PDF](REFINEMENT_RESULT.pdf))
describes the earlier Dickson cutoff, fixed-query controls and native F8191
recovery. Its results have producer-local, unverified standing.

The [production integration report](PRODUCTION_RESULT.md) ([PDF](PRODUCTION_RESULT.pdf))
adds the exact-source cofactor adapter, retains thirteen full-base resource
refusals, and records a separate planted positive integration test. No matched
cost conclusion is established. [pcc:unverified]

The [cofactor output report](COFACTOR_OUTPUT_RESULT.md)
([PDF](COFACTOR_OUTPUT_RESULT.pdf)) preserves two partial-RUR failures and adds
a conservative acceptance guard plus fixed parameter forms. Eight degree-16
full-set controls complete; five degree-32 controls time out. Nine Refined
regressions pass on their narrower chart. [pcc:unverified]

The [oriented-chain report](ORIENTED_RESULT.md) ([PDF](ORIENTED_RESULT.pdf))
composes the existing oriented-pair S3 identity into a bounded four-leaf
interface. All 26 full-base dense/tower calls reach the native matrix limit;
separate semantic and planted controls pass locally. [pcc:unverified]

The [cold-accounting report](COLD_ACCOUNTING_RESULT.md)
([PDF](COLD_ACCOUNTING_RESULT.pdf)) binds the actual production relation
consumer to fresh-process recovery. All three F127 arms recover with reconciled
intervals; five cofactor target-in-base refusals remain retained. This is local
software qualification, without a timing ratio. [pcc:unverified]

The [common-lookup report](BASE_LOOKUP_RESULT.md)
([PDF](BASE_LOOKUP_RESULT.pdf)) applies the same signed-base lookup to every
arm. All three F127 arms recover with four four-leaf calls each; the original
policy retains all five cofactor refusals and matches its recorded history.
This is a recovery-policy coverage result, with no cost ratio. [pcc:unverified]

The [full-output report](FULL_OUTPUT_RESULT.md)
([PDF](FULL_OUTPUT_RESULT.pdf)) consumes every returned relation until recovery,
charging each replay and rank update. All twelve policy/arm controls recover;
with shared lookup, Direct/cofactor each use one four-leaf call plus two
singleton rows, while Refined uses four calls plus three singleton rows.
Both earlier first-row histories remain unchanged. [pcc:unverified]

The [larger-control report](LARGER_FULL_OUTPUT_RESULT.md)
([PDF](LARGER_FULL_OUTPUT_RESULT.pdf)) adds F8191 degree-16/32 endpoints and
separate whole-answer replay. Direct recovers the degree-32 fixture after eight
calls; the other five endpoints remain incomplete. Across retained/new inputs,
145 complete sets and 98 consumed rows pass local replay, while 33 incomplete
queries retain missing outputs. The checker shares reference/consumer source.
[pcc:unverified]

The latest [full-cutoff report](FULL_CUTOFF_RESULT.md)
([PDF](FULL_CUTOFF_RESULT.pdf)) extends the catalog to every feasible fine-image
multiset. Three public fixture audits check complete tuple coverage and every
admissible signed RR5 witness. At degree 32 the catalog has 119 systems;
1,104 of 16,008 checked bindings have effective Jacobian rank two. These are
finite point/equation checks; solver integration and total branch costs are
next. [pcc:unverified]
