## Exact implementation contract

`full-cutoff` enumerates all capacity-bounded multisets in the qualified
catalog's sorted order. Each chart uses the existing `System::at_cutoff`
equations, retaining repeated images, at depth d−3. All charts are required.
The method uses the full distinct-abscissa, target-disjoint extraction scope,
matching Direct.reference and the cofactor comparator. The original regular
Refined method, frozen protocols and prior results are unchanged.

For each chart append the same uniquely determined coordinate used by the
cofactor adapter: A=t0+j*a1+j²*a0, in the fixed order j=0,...,15. Pass `-c 0`
to disable automatic variable-order/random-form repair. Advance only on the
specific exit-zero/empty-output genericity refusal or an eliminant-degree/
reported-quotient-dimension mismatch. Other failures stop the whole query.
The degree guard stays conservative for nonradical ideals; it is not a signed
completeness certificate. All returned signed sets must additionally match
the exhaustive reference on the fixed controls. [pcc:unverified]

Every chart prefix, attempted form, solver result/reason and completed-chart
row set is recorded. Exact inputs are prefix + comma/newline + recorded linear
equation + newline. Prefixes and raw RUR strings share a cumulative 262,144-byte
capture allowance, charged by their escaped JSON byte length. If a required
capture does not fit, record its byte count and omission and stop the query
as incomplete. No result requiring an omitted capture is accepted.
The system construction cap is 20,000 terms before the linear form.

One absolute three-second deadline covers catalog generation, every chart,
all form attempts, construction, solver setup/elimination, extraction,
membership/sign replay, union checks and receipt construction. No branch or
form gets a fresh budget. A completed prefix, even with useful rows, is not
an answer when a later chart fails. Duplicate/cross-chart rows also fail.
The process logs a mismatched complete set and then exits nonzero.

The legacy fixed-panel harness constructs the base and exhaustive reference
outside the per-query deadline and emits final JSON afterward. This qualification
does not price those intervals or recover a scalar. The new method is exposed
only for fixed panels at the three qualified fixture/depth inputs; recovery
and accounting interfaces explicitly await the next integration step.
