# Production cofactor adapter: fixed development qualification

Frozen before the first adapter panel, 2026-11-24. This extends PR #5142;
all earlier protocols and failed calls remain unchanged.

## Scope and source

The optional `production-controls` Cargo feature links the existing
`prime31_four_summand::extractor::extract_cofactor` entry point, its original
curve arithmetic dependency, and its exact-source production F4 closure.
The adapter supplies only the public curve, ordered unsigned base, target,
and limits. Neither the reference pair dictionary nor a known target scalar
enters this call. The existing reference is used after the call as a checker.

The production entry point enforces the monic identity \(U W=h\), where
\(h=\prod_{x\in\mathcal F}(X-x)\), with a unique monic cofactor. This is
the existing quotient-product representation, not a new construction.
See [the original addendum](../prime31_four_summand_20261122/QUOTIENT_PRODUCT_ADDENDUM.md)
and [the extractor](../prime31_four_summand_20261122/native/extractor.rs).
The wrapper changes neither its equations nor its F4 or root-finding algorithm.
Its source inventory is generated by the existing closure build script.

The cofactor scope is the full four-distinct-x, target-disjoint RR5 chart.
It can contain rows with colliding Dickson intermediate images. The Refined
arm searches only the separated-image subset. Preserve the full production
set, and also record its `matched_regular_rows` projection for comparison;
do not credit the candidate with the wider baseline's coverage. A target in
the production base remains explicitly unsupported by that API.

## Fixed limits and acceptance

- Three seconds per enclosing query, including conversion, production call,
  signed replay and output assembly. The existing production API takes a
  whole-second cooperative limit after input validation. Its inner allowance
  is three seconds; the outer deadline starts earlier and controls acceptance.
  A noninterruptible phase may overrun, in which case the query is undetermined.
- Production degree cap 10; 20,000 construction terms; 4,096 assignments;
  20,000 pairs; 8,192 symbolic monomials; 2,000,000 matrix-workspace entries.
  The allocation caps are the existing B677 gate's limits, not a claim of
  equal physical memory to msolve. Keep a separate 2 GiB process address-space
  ceiling, one worker, and a 60-second outer process timeout per panel.
- Accept only native `Complete` or `Empty`, no executed forbidden domain
  evaluations, four distinct valid signed leaves, and independent group replay
  in the existing Dickson harness. Reject incomplete output even if it contains
  a valid partial row. Any exact-set disagreement fails the process.
- Use the existing four F127 depth-four targets, four F8191 depth-four targets,
  and five F8191 depth-five targets, including its existing planted positive.
  Run the cofactor mode alone to avoid repeating unchanged candidate panels.
  Compare full sets to the direct reference; compare regular projections to
  the retained Refined records. No new target search, cap increase, or retry
  is part of this protocol.
- First run the adapter's mutation/partial-output/zero-budget tests and the
  existing production library and public-example tests. Freeze the executable,
  source revision, build inventory and command before the panel calls.

This is local source and correctness qualification under AGENTS.md §9a.
It is not a cold-cost experiment. Native arithmetic counters do not price
allocation, process launch, all setup or linear algebra. No EKS job is
submitted and no speedup or novelty conclusion follows from completion.
