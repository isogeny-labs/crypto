# Full native replay protocol

The contract is the frozen historical source and its exact finite domains.
No workload, prime, field basis, point enumeration, relation family, random seed,
budget (100,000 relation/descent attempts), or acceptance condition is reduced.
This continues the prior declared native-parity step; it introduces no benchmark.

1. Verify the historical archive checksum; extract it without executing Python.
2. Compile snapshotted C++ sources with C++17, O2, warnings and warnings-as-errors.
3. Recompute the full census, S3/S4, extension-group, scalar, mixed-relation,
   associativity, subfield, trace-zero, pairing and relation-collection paths.
4. Expand the three symbolic identities exactly over the integer polynomial ring.
   Match original MT19937 integer draws, new relation matrices and attempt counts.
5. Compare every historical mathematical output field recursively. Exclude only
   `elapsed_seconds`, `total_seconds`, `total_verification_seconds`, root source hash,
   and SymPy version. Provenance exclusions do not become admitted timings.
6. Independently verify every emitted IC certificate with the separate tuple-based
   auditor; verify all 81 logs, 3,219 bilinearity checks and both point-count examples.
7. Convert the subfield tower into its explicit simple polynomial basis. Check
   bijectivity, multiplication/addition by a field basis, point equations, and the
   source group's full pairwise map before assigning the target EC1 representation.
8. Reject a false newly collected relation, a removed log certificate, and a false
   historical census counter. Preserve the expected failure logs.
9. Reuse native Rust ICV1 and IDC1 backends for metadata. Preserve all prior registry
   rows; compare regenerated catalog/certificate bytes and require zero missing
   registry rows/aliases. Issue three identities, independently rederive 16 extra
   points in addition to the 32 sealed points, and reject a false identity.
10. Build the pinned Lean project, print each theorem's axioms, and run the
    repository proof gate. Keep universal geometric bridges explicitly open.

Raw sources, commands, input/output digests, UTC boundaries and exit codes remain
beside each native run. The protocol claims finite correctness only. No primitive
cost, solver speedup, cross-method ratio, or extrapolated security result is promoted.
The original archive did not retain each exhaustive relation set separately; new
per-model set digests support future replay but cannot retroactively hash an
unrecorded historical set. The original full output and all its predicates are replayed.
