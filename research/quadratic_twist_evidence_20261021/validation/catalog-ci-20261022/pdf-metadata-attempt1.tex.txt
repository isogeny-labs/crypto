{\Large\bfseries Quadratic-twist registry: cover catalog refresh}\\[5pt]
2026-10-22 \quad --- \quad bounded correctness and metadata consistency
\end{center}

The native quadratic-twist study added 1,921 exact models and 27 selected EC1
representations. This follow-up updates the existing native cover catalog and
its assessment for all 4,493 registry models. It corrects CI integration failures;
it supplies no new transfer algorithm or solver claim. The input registry is
unchanged from commit \texttt{4711f1c73887}.

The exact graph binds 538 declared fields, 4,491 Jacobian contexts, 4,493 maps,
and 1,004 selected EC1 representations (140 binary and 864 odd-characteristic).
Missing generators remain unknown. One assessment profile covers every map and
every EC1/curve/map triple; classification is not blanket arithmetic support.

\textbf{Evidence.} The native Rust checker recomputes equations, smoothness and
field checks within its stated boundary, and exact HC1/CV1/ICV1/EC1 links.
The standalone test retains every per-model assertion and now visits all 4,493
models. The separate assessment verifier checks every formula, exact membership,
typed context, and source digest. Commands, failed reproductions, source hashes,
and replay outputs are retained in the adjacent validation record. The complete
434-field native twist replay already passed CI, with the independent IC audit,
corruption controls, metadata replay, and receipt upload.

\textbf{Boundaries.} Odd base-prime validity remains the checker's explicit
primality-screen assumption. Cover geometry is not an induced Jacobian map,
exact subgroup-order proof, or efficient DLP transfer. Catalog-wide arbitrary
norms, independent all-element map oracles, odd balanced-Jacobian maps, and
proper-subfield descent remain open. The 27 added EC1 records do not promote
the full odd profile to arithmetic or transfer support.

The exact fixed-GF(8) arbitrary-class fixture remains outside this catalog.
The old packaged artifact was replayed on 592 bundled rows; its historical
746/1,354 allowlist comparison is not an expanded-catalog artifact replay.
No performance, general GHS, or general ECDLP hardness conclusion follows.
The twist-to-Frobenius-negation proof and shared Conductor access remain open.

\textbf{Provenance and reproduction.} The prior dated assessment report, its
graphs and PDF, frozen twist results, and historical receipts remain intact.
Run \texttt{cargo run --release --locked --bin curve\_cover\_check -- --check},
the standalone constructor tests, the deterministic assessment check, and its
independent verifier. The source-linked README and validation record give exact
commands. Canonical IC/rho cost graphs are unchanged: no cost comparison was run.
