# Restricted whole-pass learned pivot selector

**Completed bounded experiment; original item 9 remains partial.** Native exhaustive empirical-risk fitting on n5/n9 selected the constant `min-weight` policy. It offers no benefit over directly fixing that same policy; prefix extraction and inference add cost. This is a retrospective shape split, because historical heldout outcomes were already present in the earlier visible study summary.

Read [report](reports/REPORT.md), [PDF](reports/report.pdf), [graph](reports/policy-counts.svg), [protocol](protocol.json), [native summary](summary.json), and [status](status.json). Sources are [selector.cpp](src/selector.cpp), [summarize.cpp](src/summarize.cpp), and [run.sh](run.sh). The selector compiles against the unchanged earlier [native reducer source](../bounded_memory/src/disk_macaulay.cpp); frozen source and binary digests are in `runs/frozen-v1/`.

Training reads input-only N, D and first-64-row term-count sum/maximum. Two constant models and all one-level stumps over training thresholds are evaluated. Both training shapes favor min-weight under the declared conventional proxy, so a constant is the simplest empirical-risk minimizer. All four choices were frozen using only model and input prefixes before heldout outcomes were opened. There is no calibration set: two independent training shapes cannot support credible uncertainty calibration.

All six fresh reductions succeeded: both policies at n5/n9/n15. The four small controls passed independent exact mutual dense RREF. Fresh n15 chosen-policy counts match the archived min-weight vector, with rank 20,490 from 20,670 rows. Its independent row-space correctness remains uncertified. n17 has input-only inference and archived outcome evaluation, with no fresh replay in this bounded experiment. A same-counter replay does not establish independent correctness.

The proxy adds sparse term visits and journal I/O words. The report also preserves their separate units. It is not a complete machine cost: dense verification, hashing, parsing, decompression, trace writing, row allocation and bookkeeping are not fully instruction-priced. Historical label-acquisition work is charged rather than treated as free, while the fresh audit/control costs remain separately recorded. Elapsed times in resource receipts are shared-host diagnostics only, not speed results.

Replay from a fresh clone/worktree: `bash research/ideas_execution_20261018/learned_pivot/run.sh` from the crypto root. It refuses to overwrite `runs/frozen-v1`; for another trial, make a separately named copy of the script/run path. Exact compilation options are retained there. They can be restored in a separate directory using `gzip -dc`. No prior evidence was modified.
