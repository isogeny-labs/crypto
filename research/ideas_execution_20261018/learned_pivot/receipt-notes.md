# Receipt boundaries

The protocol, selector source, runner, original native reducer source and probe source were hashed before compilation and new training. Uncompressed matrix digests were written before training and agree with the preexisting frozen study. The historical evidence streams were already immutable study artifacts; `external-evidence.sha256` is an additional post-run dependency receipt, not a claim that these particular receipt bytes existed before fitting. Training checks the exact trace-weight total against every input training result. Summarizer source/binary and report rendering are separate post-run analysis steps.

The 512 MiB address-space limit is enforced by the recorded native wait4 wrapper on all model fitting, inference and reduction executions. Compilation and the small summarizer/rendering processes were not run through that wrapper. All execution algorithms are native, serial processes; Python only renders stored native results. Conductor was unavailable (exit127), retained in conductor-attempt.txt. No earlier evidence or source file was changed.

The counted proxy includes the reducer counters exactly as emitted. On small controls their journal reads include final verification basis loads, while dense RREF arithmetic is unpriced. The proxy is therefore neither a pure reduction-only instruction count nor a complete cost. Trace records contain weights and decisions, not an independently checkable row-operation provenance certificate. Historical input/journal reconstruction costs and original failed-trial effort are not erased; they remain in the earlier study, with fresh trial resources separate here.

Post-run review added fail-closed assertions that the frozen model and every chosen policy are constant min-weight, and made gain subtraction signed. The resulting summary is byte-identical to summary-before-assertions.json. The earlier summarizer source is retained as src/summarize-before-assertions.cpp; analysis-source-before-assertions.sha256 is its historical original-path receipt. Final analysis-source.sha256 and analysis-binary.sha256 bind the current files. Independent spot review reproduced the arithmetic and all 16 decompressed archive digests. Aggregate disk/time targets were respected operationally, without runner-level aggregate enforcement.
