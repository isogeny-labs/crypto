# L05 deviations from PROTOCOL.md / SPEC.md

No threshold, arm, seed rule, prime, instance size, count rule or decision rule was changed. PROTOCOL.md and SPEC.md are unmodified (frozen.sha256 verified).

1. **Command wrapper.** PROTOCOL section 10 was executed through `drive_common.sh` (a `logrun` function that runs the command and appends rc and the output sha256 to `raw/COMMANDS.log`) and `drive_relphase.sh` (the section-10 loops, same order and same arguments, each command wrapped by `logrun`). The unit tests and the five gates were run with the same loop text from the shell, in the order the task required (unit tests, then gates, then relation phase). Reason: the task asked for a log of every command with exit code and output hashes.
2. **Verdict precedence in `analyze.py` (SPEC 10.5 item 6 is silent on ordering).** (a) G7 is treated as one of the gates in the "all gates pass" premise of the H1 kill rule, so a G7 failure gives inconclusive, not killed. (b) The kill and refuted tests are evaluated on the available cells before the missing-cell test. (c) A failure record in any raw file makes H1 report "failure record present: examine". None of these branches triggered in this run (no failure record, no missing cell, G7 passed everywhere), so the choices did not affect the reported verdicts.
3. **`delta_fraction`.** SPEC 7.8 defines `has_delta = (dcoef2 != 0)`. Implemented as a per-arm constant (1.0 for E_0, E_1a, E_g, 0.0 for E_low, null for O arms). Not used by any decision.
4. **Gate runs with `pencils_exhausted`.** At g = 3, p in {37, 53}, several gate arm runs (E_low, E_1a on most curves, E_0 on curve 3 at p = 37, O on curve 3 at p = 37) reached the 10000-pencil stop of SPEC 7.6 before `N_target` (status `pencils_exhausted`). SPEC 9 defines a curve pass by the verification counters only, so these gate curves pass; the relation counts are in RESULTS.md. No instance size was changed.
5. **Un-logged development runs.** Before the logged commands, ad-hoc development runs (a quick fixture check, the unit tests during development, and one timing run of `run.py relphase --g 3 --p 65537 --class root --curve-index 1 --seed 1 --arm E_low` to a scratch file outside the lead directory, which was deleted) were made. Their outputs are not in raw/ and not used.
6. **Extra files.** `drive_common.sh`, `drive_relphase.sh`, `plot.py`, `plot.svg`, `l05/ctx.py` (curve-context builder, not listed in SPEC 1) were added inside the lead directory.
