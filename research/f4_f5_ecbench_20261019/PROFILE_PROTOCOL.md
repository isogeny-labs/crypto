# Auxiliary complete-root instruction profiles

Before profile execution, freeze the a78 benchmark executable and current
candidate executable hashes, local CPU/compiler and Valgrind version.
Use the original n23 planted seed230 complete-root fixtures for F4/F5.
Five interleaved rounds compare baseline, prepared-only and quadratic-tail,
with all previously qualified GF2 switches enabled. Every root set must
equal the independent original-system audit and agree between variants.

Callgrind client requests bracket the same complete-root API calls as the
native harness. Collect merged-thread Ir with simulated AVX2, one worker,
no hardware cycles/IPC or local wall claim. Per-cell timeout300seconds,
whole auxiliary batch1500seconds. A failure stops the batch and all
partial/failed cells remain. Missing five-pair cells are incomplete, not
qualified. This count experiment neither replaces nor reprices the
dedicated native timing or ecbench full-recovery runs.
