# Disjoint arity-four APS label check

This bounded correctness check compares fixed weights [1,2,4,8] and [1,1,1,2] with existing APS coordinates, validation, Split4 and recovery. Its target is preservation of the nonzero-denominator invariant on genuine one-per-slot relations. Source anchor is tracking head 3e353639a6b0677f06a5a565d27bc1a60767da32. This development check collects no timings and registers no benchmark.

- Use existing public fixtures from the APS test suite. The group orders are prime and the fixture generator and target are nonidentity subgroup points. Use (p,a,b,r,G,d)=(101,59,6,107,(78,4),37) and (211,166,158,227,(155,121),73). The harness constructs public Q from the disclosed d and checks it with separate affine arithmetic. Sampling and recovery receive only G,Q.
- Use slot sizes [2,2,2,2] and [3,3,3,3] on each fixture. For each slot size use the four fixed seeds 20261115 through 20261118, for 16 paired cells and 32 main arms. Each seed supplies one ordered StdRng stream of 100 independent scalar draws using the same gen_range(0..r) as production. An arm consumes its own prefix. Infinity and globally duplicate abscissae consume their draws as in production. Record each consumed draw including slot, scalar, outcome, and canonical coordinates. Verify each arm against the same stream by draw index. Scopes differ when rejection changes the slot reached at a draw index, so the comparison does not assume equal accepted coordinates.
- Construct labels at draw time as uG+wQ. Normalize canonical sign together with both label coefficients. Count slot setup as four shift calls in both arms. Assert that the baseline reproduces the existing sampler layout, consumed draw count, and accepted labels. The planted target scalar never enters this validity check or either algorithm.
- Enumerate one point per slot and all eight sign choices modulo global sign with separate affine arithmetic. Count exact coordinate roots, informative incidents, and zero-denominator incidents. Verify every informative incident by inversion modulo r and multiplication of G on the reference curve. Compare complete Split4 coordinate roots to the exact group set, require each reported root to lie in that set, and use the existing APS recovery API on those reported coordinates. Limit each algebra call to degree 24 and two cooperative seconds, plus 120 seconds total process time and 1 GiB of virtual memory. A cap hit remains an incomplete row and cannot support a completeness claim. A separate exact-root feed verifies recovery even when a budget is hit.
- Audit the bridge's centered-coefficient valuation rule against exhaustive signed denominators on every unrestricted four-subset. Keep this mixed-slot audit separate from fixed-slot solver inputs. Check modular wrap for [1,2,2,2] mod 7. Reject a corrupted label and refuse to advance incomplete samples. On the first fixture and seed, test both laws with explicit draw caps 0, 7, and 8. Counts on mixed-slot tuples cannot justify changing production's deterministic law.
- Acceptance is matching baseline sampler output, every label agreeing with independent group operations, exact nonzero denominators on all generated disjoint tuples, and agreement between independent group checks and complete algebra/recovery results. Preserve every attempt and retain byte-comparable evidence.tsv with draw traces and result rows. The compact schedule is a development candidate with no measured speedup, scalable success, or production-default claim.

The sampler and recovery contract lives in src/cryptanalysis/aps_single_relation.rs. The valuation rule lives in tools/aps-partition-bridge/src/valuation.rs. The earlier report in research/aps_four_leads_20261117 uses a different deterministic stream and unrestricted four-subsets.
