The discovery question is whether a compact x-only left support can trade memory against lookup and setup costs when both sides are reused. The four left-support arms are full oriented point hash, x-only hash, sorted packed x-only, and packed x-only partitioned by high bits. All use the same rational lifts, batched inversion arithmetic, right-pair preparation, and public residual panel. Production PairTable already has high-bit x buckets and a globally sorted x arm; this diagnostic focuses on count-only support and four disjoint slots.
