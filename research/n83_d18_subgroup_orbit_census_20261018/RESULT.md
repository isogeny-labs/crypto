# Direct subgroup-x dimension-18 N83 orbit census

The [frozen protocol](PROTOCOL.md) enumerated all 262,144 field words whose polynomial-basis x coordinates have only bits 0–17 set on public curve `icv1-f2m83-tm6151469093347-debefd74`. A lift exists for 130,724 x values. Direct multiplication by the 81-bit prime subgroup order retained 32,710 x values; these form **32,643 distinct full-length signed-Frobenius orbit classes**. Every retained class had x-orbit length 83. The frozen size threshold was 16,627 classes, so the direct-subgroup source **passes the size premise** by 16,016 classes. The deterministic first 16,627 classes have a *derived* closure count of 2,760,082 points; that point object has not been exported or replayed yet.

The [complete run report](reports/run-20261019T0141Z/RUN_REPORT.md) preserves two executions of the same committed native binary. The first emitted the full result but the macOS `/usr/bin/time -l` wrapper exited 1 after a sandbox-denied `sysctl kern.clockrate`; that is a wrapper infrastructure failure, not a failed census. The direct second invocation exited 0. Its complete orbit-class CSV and selected-representative CSV are byte-identical to the first attempt. Seventeen selected representatives were cross-checked with the library's general curve, subgroup and Frobenius arithmetic. Both executions share the same algorithm and host; this is repeatability, not independent implementation replay.
