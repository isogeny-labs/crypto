# Frozen N83 m=5 paired-orbit natural-relation screening gate

**Freeze point:** before the opt-in m=5 worker or any m=5 arm is implemented or run. This is a source-qualification and natural-relation screening gate, not a selection of minimum total index-calculus runtime. It is independent of the completed m=4 `natural-v1` binary and receipts; no prior capped arm is reclassified.

## Reason for this gate

The two exact 16,627-column signed-Frobenius bases each contain 2,760,082 labeled points in the primary subgroup of order 2,417,851,639,230,796,216,685,689. Their unordered point-multiset support counts are `C(2,760,085,4) = 2,418,118,845,293,427,158,134,785` and `C(2,760,086,5) = 1,334,843,194,246,110,838,237,521,238,302`. Dividing by the subgroup order gives about 1.00011 for m=4 and 552,078.21 for m=5. This is only a uniform-target support heuristic: symmetries, correlations, collisions, solver access and rank can invalidate a yield prediction. The m=4 searches were capped, so their results cannot establish absence of relations. The m=5 model needs an empirical access test before any yield claim.

## Worker and functional gates

Implement a new opt-in m=5 command without changing the legacy m=4 command's receipt schema or meaning. Parameterize public fixture selection without exposing known-answer scalars. Reuse the exact checked imports, chained-S3 orbit-domain builder, SAT backend, full original-field group lift, signed-Frobenius label verification and wide rank insertion for both bases. The model uses five summands, affine identity mask zero, complete orbit domains, one returned model, at most 300,000 variables and 8,000,000 domain clauses. A model is a relation only after original-curve five-point sum, signed-orbit row replay, independent process replay, rank increment and changed-target/changed-row rejection. A SAT x-model that does not group-lift is recorded as invalid, not yield. Identity-mask-zero search covers only that pattern, so a capped or UNSAT result cannot refute the other identity patterns.

Before natural search, fresh preflights must import both bases, validate both public points, and construct the exact m=5 model without solving. They must report actual variable, clause and XOR-row counts, build wall, process CPU and cgroup peak. Then construct one positive control per base from the first five distinct signed-orbit representatives, check each affine partial sum and exact group equation, pin its five selectors/phases and nine x blocks, and require a model that independently replays to rank increment one. If any preflight, resource or positive-control gate fails, stop the dependent natural arm and retain the failure. This control is not a natural-yield sample.

For natural arms, use one source- and binary-attested x86_64 host and pinned container image, one pinned CPU, hard 4 GiB cgroup, zero swap, no network, read-only source/binary/inputs, fresh writable output, no concurrent compiler or other research job. Spot is the authorized cloud market for this gate; do not silently substitute On-Demand. Use a 600-second internal deadline from process start and an independent 610-second outer cap per arm, 100,000 conflicts, and one model. Fsync source/binary/base/target/model/root receipts before `solve()`, and ten-second observational progress samples through search. Mirror each arm's raw sidecars off-host before the next arm and retain AWS interruption events. If Spot terminates early, classify missing work as infrastructure-censored; a cross-host continuation is a new panel, not completion of the same-host sequence.

Run the exact four-arm order U0, D0, D1, U1 after controls pass. Here `0` and `1` denote public fixture indices, not repeated independent SAT seeds. The first two arms are a same-point U/D pair on fixture 0; the last two reverse order on fixture 1. Stop only for a failed prerequisite, resource breach or infrastructure interruption; a search cap does not terminate later arms. If any arm returns a checked relation, independently replay its original-field group equation, signed labels, dense row and rank, and reject changed point and row. Preserve all cap/no-model/invalid attempts, UTC intervals, OOM and memory data, exact hashes and an immutable SHA-256 raw manifest.
