# Paired N83 natural-query implementation

The frozen [protocol](PROTOCOL.md) is implemented by the opt-in `primary-paired-orbit` and `primary-paired-replay` example commands. Both U and D require their exact compressed objects, point-set digests, original export and import evidence, and the same SHA-256-pinned public fixture. The worker constructs the same m=4 signed-Frobenius orbit model, limits and solver for both arms. The positive control pins the first four representative choices and seven x blocks; the natural command fixes only the public target x. Each search writes fsynced phase and ten-second progress sidecars, and returned relations require separate group/rank replay and negative controls. The runner applies the 4 GiB/zero-swap/one-CPU scope and 1,800-second outer cap.

Validation before any paired arm: the touched release example passed 21 tests (`paired-example-tests-rerun.log`); `cargo test --release --lib --locked` passed 4,395 tests with 118 ignored (`paired-lib-tests.log`); the N83 Python suite passed 63 tests (`paired-n83-python-rerun2.log`); and the boundary Python suite passed 52 tests (`paired-boundary-python.log`). `sh -n` accepted the Spot runner and `git diff --check` passed. The first example-test attempt failed with `ENOSPC` because Rust used the nearly full `/Volumes/SSD990/llm/tmp` (`paired-example-tests.log`). The first two N83 Python attempts used that volume, then a directory inside the frozen checkout; supervisor fixtures require an outside-checkout path. Those failed logs are retained (`paired-n83-python.log`, `paired-n83-python-rerun.log`), and the final passing run used `/Volumes/SSD990-2/.codex/n83-paired-temp-20261019`.

The source, binary, input package, host identity, per-arm receipts, replay and raw-file hash manifest must still be frozen and retained before a candidate qualification can be interpreted. This implementation and its passing local tests alone do not establish natural relation yield or a total-runtime ranking. `candidate_id`, `selected_best_total_runtime`, and complete index-calculus runtime remain null.
