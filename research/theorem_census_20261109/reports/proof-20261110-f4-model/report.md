# The original F4 model has a saturation boundary

Lean proves that every run of the repository's original `F4Run` model
stays in the ideal generated by its inputs. It directly disproves the
unrestricted claim that every saturation member can appear in such an
ordinary run. The original model files are imported byte for byte.
[pcc:unverified]

For $I=(xy,x^2-x,y^2-y)$ and saturation by $x$, both $y$ and $x-1$ have
power-1 saturation witnesses. Every generator vanishes at $(0,1)$ but
$y$ does not. Therefore $y\notin I$, and no ordinary model run from
these generators can contain the registered saturated rows.
The generic proof holds over every field; a separate literal F101
certificate also interprets printed coefficient 100 as -1.
[pcc:unverified]
