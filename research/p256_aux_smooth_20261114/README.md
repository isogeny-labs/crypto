Latest: [2026-11-16 continuation](continuation_20261116/REPORT.md) adds
actual small P-256 CAS qualification and exact linear preprocessing.
The original report below is the preserved2026-11-14 snapshot.

See [REPORT.md](REPORT.md) for the implemented construction, exact scope,
unsigned observations and open m2..7 baseline/2x/regularity requirements.
See [PROTOCOL.md](PROTOCOL.md) before any benchmark and
[HANDOFF.md](HANDOFF.md) for the execution state. No timed experiment or
Magma run has occurred. Do not treat input degree as regularity.

Native dependencies: C++20, GMP, OpenSSL, pkg-config, Bash and timeout.
`run_checks.sh FRESH_DIR` tests the standalone core;
`run_adapter_checks.sh FRESH_DIR` tests/export-replays the Magma adapter.
Core export: `aux_base build 4 OUT`; byte replay: `aux_base check 4 OUT`.
`aux_base base DEPTH OUT` builds construction-only fixtures through depth18;
dense system materialization is explicitly limited to depth8.

The point dump uses `ecbench.factor_base_dump/v1-wide`, registered P-256
ICV1 and canonical FB1/point codecs. Certificate/schema extensions are
separate files. Generated JSON declares Fp solution semantics. Magma
programs are generated by native code, use the actual 256-bit prime and
remain unqualified until executed and checked against complete references.
