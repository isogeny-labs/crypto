# Signed norm-branch coefficient census

**Protocol:** `EXP-NORM-BRANCH-CENSUS-20261113-v1`
**Frozen question:** does the exact coefficient tensor of the public signed
norm-branch determinant have a growing, source-bound flattening-rank defect
large enough to justify a SAT/proof-size experiment?
**Standing:** exact-computation experiment only; no timing, attack, security,
novelty, or universal-hardness claim. All scientific interpretation is
`[pcc:unverified]`.

## Prior evidence and mechanism

For `d=k+1` distinct support abscissae, put

```
u = floor(d/2)+1,  v = floor((d-1)/2),  u+v=d,
M(epsilon) = [ U | D(epsilon) W ].
```

The determinant is supported on Laplace subsets of size `v`. After fixing the
target sign, it becomes a Boolean-character polynomial on the `k` variable
branches supported on the two adjacent levels `v` and `v-1`. Within a fixed
left/right cardinality block, nonzero row and column scales reduce its rank to

```
K[A,B] = product_{i in A, j in B} (x_j-x_i)^2.
```

The universal distinct-node full-rank conjecture is already false: the frozen
`d=5` example in `../NORM_BRANCH_COUNTEREXAMPLE.md` has an all-nonzero `2 x 2`
rank-one block over `Q` and every prime above seven. Borchardt's identity also
explains the extreme square block: after scaling it is inverse-square Cauchy,
whose determinant is the ordinary Cauchy determinant times the permanent of
the ordinary Cauchy matrix. Distinct nodes make the first factor nonzero, not
the permanent. These facts motivate a census; they do not imply useful growing
compression.

## Canonical typed input and exact rewrites

The native crate owns one typed `BranchInstance` IR containing the prime,
curve, prime-order generator, labelled support points, fixed target, degree
window, and a balanced variable partition. Every tested representation is
generated from that IR:

1. direct signed group sums;
2. the evaluation matrix `M(epsilon)`;
3. Laplace coefficients from independent Vandermonde minors;
4. the fixed-cardinality product kernel `K`;
5. the Boolean coefficient flattening.

No arm imports a separately generated instance. Exact equality/model-set checks
bind these representations before ranks are interpreted. The contraction-order
search enumerates every balanced split up to `k=10`; at `k=12,14` it uses the
same eight deterministic balanced splits in every arm (contiguous,
interleaved, and six domain-separated SplitMix64 shuffles). Complement-duplicate
splits are canonicalized.

## Frozen family

- Prime fields: `p in {8191, 131071}` (both prime and `3 mod 4`).
- For each prime, deterministically scan nonsingular short-Weierstrass curves
  from curve seed `0x4e42433100000000 xor p` until `#E(F_p)` is prime. Point
  counting is exact. The first affine point in lexicographic `x,y` order is a
  generator because the group order is prime.
- Support seeds:
  `0x4e42435300000001`, `...0002`, `...0003`, `...0004`.
  Draw nonzero scalar labels, reject target/support zero, duplicate fibres and
  target fibres, and use prefixes of one maximum-size draw.
- Ladder: `k in {6,8,10,12,14}` variable points plus one fixed target.
- Discovery sizes: `k<=10`. Held-out sizes: `k=12,14`; their instances and
  partitions are generated by the frozen seeds but are not used to alter the
  code, thresholds, or arm definitions.
- Fixed target sign: `-1`, so a singular matrix represents signed support
  points summing to the target.

## Arms and controls

For every natural instance and split:

- `natural`: exact curve-derived coefficients;
- `random_coefficients`: independent nonzero coefficients on precisely the
  same two-level support (the actual support-matched null);
- `random_ordinates`: same abscissae and independently randomized nonzero
  ordinate multipliers; fixed-cardinality block ranks must agree exactly with
  `natural` (an invariance control, not a null);
- `second_vandermonde`: distinct arithmetic-progression abscissae with the same
  dimensions (family/general-position control, not a null);
- `separable`: a rank-one synthetic matrix, proving that the rank detector can
  report compression.

The old `d=5` counterexample is replayed over `Q` by checked integer arithmetic
and modulo both frozen primes. The documented signed block is also matched to
the native canonical-Laplace block by explicit invertible row/column signs. A
mutation battery flips one cross factor,
duplicates one abscissa, changes target inclusion, changes block cardinality,
flips the fixed target sign, flips an ordinate, and changes a curve
coefficient. Guard violations fail closed; semantic mutations must change the
expected model set or certificate.

## Semantic gate

On the fixed curve `y^2=x^3+2x+2` over `F_17`, target `(0,6)`, and support
`(3,1),(5,1),(6,3),(10,11),(13,7)`, exhaust all `2^5` branch assignments and
require identical ordered model sets from:

1. direct signed group sums;
2. zeroes of the Laplace/Fourier determinant polynomial;
3. singularity of the direct evaluation matrix.

For every model, recover a nonzero kernel vector, split it into bounded `A,B`,
and require the complete polynomial norm, target-branch, and group-sum checks.
The least model and total count are retained. The same group/Fourier equality is
checked on every scaling cell; direct matrix determinants are additionally
checked on every assignment through `k=8` and on frozen sampled assignments at
larger `k`.

## Measurements

For every cell/split record:

- global flattening dimensions, rank, normalized rank, nonzero support edges,
  and a certified pivot minor;
- every fixed-cardinality block dimension and rank from both the full Laplace
  coefficient matrix and `K`;
- inverse-square Cauchy extreme-block rank and permanent;
- natural model count and least model;
- exact field additions, multiplications, inversions, and comparisons performed
  by coefficient generation and rank elimination;
- allocated matrix bytes and an integer-coefficient bit-growth upper bound;
- cap, failure, and censoring state.

Full rank modulo `p` is also an exact certificate of full rank for the canonical
integer lift over `Q`, because the same pivot determinant is a nonzero integer
modulo `p`. Any modularly defective held-out block requires either fraction-free
integer replay or an explicit integer null vector before a `Q`-rank statement.

No wall time is a scientific endpoint. Host time and RSS are provenance only.

## Frozen decision rule

All correctness, mutation, independent-checker, and positive controls must pass.

- **ADVANCE to SAT/proof-size B2** only if, for both held-out sizes and every
  prime/seed pair, the minimum natural global rank over the frozen split search
  (breaking rank ties by the numerically smallest left mask) is at most one half
  of the random-coefficient-null rank on that same split, and the paired
  `log2(rank)` slope from `k=12` to `k=14` is lower than the null slope by at
  least `0.125` per added Boolean variable. At least one corresponding growing
  fixed-cardinality defect must be reproduced by the product-kernel checker:
  target inclusion is unchanged, exactly one of the left/right cardinalities
  grows by one, available block rank does not shrink, and rank deficiency does
  not decrease.
- **KILL the registered linear-message compression on this family** if every
  held-out natural global flattening has the available full rank, equals its
  matched null rank, and every admissible held-out fixed-cardinality block has
  full rectangular rank while the counterexample and separable controls still
  report their known defects.
- **INCONCLUSIVE** otherwise, including any cap, checker disagreement, field-
  specific defect without integer replay, mixed effect, or threshold miss.

`KILL` is representation- and family-scoped. It does not prove nonlinear
branch selection hard, and it does not disprove all tensor, SAT, or index-
calculus algorithms. SAT tuning is inadmissible unless `ADVANCE` fires.
