Its documented one-block elimination order is a competing engineering option; it is not evidence that adding product variables improves solving. The inspected current README documents bounded native prime characteristics, so it does not establish a directNIST-prime baseline interface. Do not transfer current documentation claims to the pinned0.11.0binary without checking that version's source.
