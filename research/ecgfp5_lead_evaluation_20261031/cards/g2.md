## A. Odd-characteristic GHS covers. Verdict: CLOSE
Obstruction: no curve in either K-isogeny class has full rational 2-torsion, and every other (2,...,2) cover has genus >= 25 (EcGFp5) or >= 33 (EcMasFp5).

**Measured (program, exact):**

- EcGFp5: HackMD constants reproduce from Pornin's (2, 263z). chi(263z) = chi(4-4b) = -1; f has exactly one root in K, so |E[2](K)| = 2. The 2-isogenous E' (kernel (0,0)) also has exactly one. j not in F_p.
- EcMasFp5: f irreducible over K, j not in F_p.
- Canonical x-coordinate cover, all 31 subsets tested for "prod f^(sigma^i) square in K(x)": none. EcGFp5: m = 5, |B| = 12, g = 65. EcMasFp5: m = 5, |B| = 16, g = 97. Random Moebius change of x: m = 5, |B| = 20, g = 129.
- Best covers built: g = 33, m = 5, for both (EcMasFp5: Hessian plus cube root in K gives an F_p-rational cubic; EcGFp5: irreducible quadratic mapped to x^2-7 with M(0) = 0).
- Toy validation: F_p-coefficient cubic gives m = 1, g = 1; prod_{i<4}(x - w^i z) gives m = 4, g = 5, the literature class (d,n) = (5,4); the same with a non-square constant gives m = 5, g = 9; (x^2-t)(x^2-sigma t) gives m = 4, g = 25.

**Derived (not source-verified):**
- g = 1 + 2^(m-2)(|B|-4) (Riemann-Hurwitz, Kummer cover, inertia of order 2).
- The relation space is a C5-submodule of F_2^5, so m is in {1, 4, 5}. m = 1 iff j is in F_p (excluded).
- m = 4 forces four K-rational branch points, hence E[2] in E(K) and 4 | #E(K): the g = 5 class, density about q^-3 = 2^-192 (Chao ECC2007 slide 21: Theta(q^2) curves).
- Here #E(K) = 2n or n, and isogenous curves share it, so no isogeny walk (including via (0,0)) reaches that class. Gorla-Massierer lines 1751-52 give the same advice.
- Enumerating all (T, M) patterns, minimum g is 25 for EcGFp5 (not built) and 33 for EcMasFp5 (built). m >= 4 means non-hyperelliptic.

## B. Oracle-assisted static DH. Verdict: REVISE
Classification: protocol-level only, not an ECDLP weakness; no deployment found gives the oracle.

**Arithmetic** (JV lines 740-775, 785):
- Queries: |F|/2 = p/2 = 2^63.0 oracle calls (one variable-base [d]X by the victim each). JV's own example is 2^25 queries at about 2^26.
- Storage of the [d]P_i: 2^63 x 40 B = 3.7e20 B (2^68.3 B).
- Per target: 4-point decomposition succeeds with probability 1/(24p), so 24p = 2^68.6 trials of ([r]X plus a 5-equation, 4-variable solve). JV writes 4! p c~(5,p).
- C_pdp4 is unmeasured; assuming 2^16 to 2^30 F_p multiplications gives 2^85 to 2^99 offline.
- So the lead's reading holds, except the decomposition is about 24p randomized trials per target, not one.
- 2^63 queries is 293 years at 10^9/s, so the queries bind, not the offline work.
- Granger (ECC 2010 slides; ePrint PDF 403): R1 is O(q) queries with polylog time per target, via the 5-point m = 5 system that C1 could not measure. R2 is q^(1-1/(n+1)) = 2^53.3 queries asymptotically, with unmeasured constants at n = 5 (slides' n = 4 alpha = 0.873 suggests 2^55 to 2^61).
- Model caveat (derived): JV Def. 3 closes the oracle before the challenge. A persistent oracle gives [d]X from the single query [r]X, so the real exposure is the generic Brown-Gallant/Cheon attacks, which depend on the factorisation of n-1 (not computed).

**Deployments** (WebFetch/WebSearch, summaries not verbatim):
- Signatures only: Lighter (closed signer), POD2, goldilocks-crypto (no ECDH or encryption API). Pornin's repository has neither; plonky2_ecgfp5 is gadgets.
- Miden: a ZK Hack Lisbon ElGamal prototype (decryption not described); miden-crypto's default signature list excludes ecgfp5.
- EcMasFp5: only pil2-proofman PR #202 (merged 2025-03-11, no description); purpose unverified, the HackMD cites the SP1 memory argument.
- Schnorr (s = k + e d) reveals no [d]X for attacker-chosen X.

**Next step:** desk screen for a persistent [d]X service (ECDH/ECIES/decrypt) on ecgfp5; 0 compute. Do not measure C_pdp4 yet. Kill criterion: measure it only if such a service exists with no per-key query cap below 2^50.
