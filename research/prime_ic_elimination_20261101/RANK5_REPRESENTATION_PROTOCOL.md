# Frozen rank-5 representation-size screen

Frozen: 2026-11-01, before adding the statistics command or generating any row

Status: exact syntactic preflight; no solver timing or subgroup claim

## Question

At fixed `m=3`, depth 3 and the same shared-coefficient construction, do a
Solinas modulus or a special-`j` short-Weierstrass equation change the growth
of the deterministic Boolean representation, rather than merely its constants?

This preflight is deliberately narrower than the registered solver factorial.
It can reject a representation-size explanation.  It cannot decide solver
work, relation yield, subgroup effects, chart behavior outside the selected
affine chart, or the rank-5 lead as a whole.

## Frozen fixtures

All moduli are prime, below `2^31`, congruent to 1 modulo 8, and grouped by
bit length.  The Solinas values are the existing P-224-shape fixtures.  The
generic values are generated by SHA-256 of `prime-ic-generic-N`, forcing the
top bit and residue 1 modulo 8, then taking the first prime in steps of 8.

| bits | Solinas | generic |
| ---: | ---: | ---: |
| 20 | 1032193 | 991961 |
| 24 | 16760833 | 9117497 |
| 26 | 67104769 | 51442009 |
| 28 | 268369921 | 252089969 |

For every modulus, use these exact curve/target triples:

| class | `a` | `b` | affine target |
| --- | ---: | ---: | --- |
| `j0` | 0 | 1 | `(0,1)` |
| `j1728` | 3 | 0 | `(1,2)` |
| `generic` | 2 | 1 | `(1,2)` |

Every cell uses arity 3, remainder depth 3 and terminal `c=1`.  These triples
are nonsingular over every listed prime and the targets lie on their curves.

## Exact metrics and controls

For all 24 cells record canonical IR SHA-256, field bit width, semantic field
variables, equations, polynomial terms, Boolean variables, AND gates, XOR
gates, assertions, ordinary-CNF clauses/bytes and CNF-XOR ordinary clauses,
XOR rows and bytes.  Counts come from the same circuit object used by the
already-tested exporters; emitted DIMACS headers must agree.

Controls:

- the locked Rust 1.78 suite must pass before rows;
- repeated construction of every cell must give identical hashes and counts;
- the F17 known assignment and mutation tests remain green;
- malformed modulus, singular curve and off-curve target remain rejected.

## Frozen reading

For each representation metric, fit `log2(metric)` directly against modulus
bit length over the four sizes.  Report all raw counts and pairwise ratios.

- **advance as a representation lead** only if one special class has a slope
  at least `0.05` lower than its matched generic-curve class for both CNF and
  CNF-XOR Boolean-variable/constraint totals, with the sign repeated under
  both modulus families;
- **reject at representation-size scope** if every slope difference is below
  `0.05` in magnitude or changes sign between modulus families;
- otherwise report **inconclusive**.

No multiple-testing p-value is used because this is an exact deterministic
factorial and the decision is a fixed effect-size gate.  Passing the advance
gate would only nominate the full matched subgroup/cofactor solver factorial;
failing it does not rule out arithmetic speed, propagation or automorphisms.
