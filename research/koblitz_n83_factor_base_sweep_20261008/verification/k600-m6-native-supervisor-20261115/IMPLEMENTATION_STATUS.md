# Exact K600 m6 native zero-trial admission component — 2026-11-15

**Status: implemented and unit-tested; not executed in Linux or admitted for search.** `examples/n83_k600_m6_native_preflight.rs` supplies two Rust commands: `prepare` checks a clean source checkout, the exact S3-bound K600 adoption manifest/replay/storage/import, store index and remote, public fixtures, a Linux arm64 ELF worker, and an immutable Docker image ID; it writes a write-once JSON lock to be committed. `run` requires that exact lock in Git at HEAD, rechecks source/input/binary/image hashes, performs a fresh native S3 GET into an empty cache, snapshots the worker source, specifies a pinned one-CPU/4-GiB/zero-swap/no-network/read-only container, enforces an outer wall cap and cleanup check, distinguishes a worker cap from a successful preflight, and writes a terminal receipt with source and input hashes. The writable Docker mount contains only `worker-output/`; source snapshot, store index, and freshly fetched S3 cache are mounted separately as read-only inputs and are rehashed afterward. It invokes `primary-store-v3-orbit-chain-cold` with K600, m6, zero trials and the frozen 125,000-variable, 350,000-domain-clause, one-model and 10,000-conflict caps. It does not run either positive or natural arm.
