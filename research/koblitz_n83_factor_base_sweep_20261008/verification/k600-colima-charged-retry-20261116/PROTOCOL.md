The prior plan allowed 1,200 seconds and observed a cap at 1,214.178 seconds including termination and receipt checks. [CHARGED_BUILD_PLAN_RETRY.json](CHARGED_BUILD_PLAN_RETRY.json) changes that cap to 2,400 seconds and moves the byte-identical stage script to this committed full checkout. The solver and runtime-image caps stay 900 and 300 seconds. The outer Docker cap rises from 2,700 to 4,200 seconds to cover all three stages and receipt/cleanup overhead. The output is new and may not reuse the incomplete first-attempt Cargo target.

The source path is the already mounted full checkout at `/Volumes/SSD990-2/tmp/n83-colima-inputs/n83-full-validation-20261116`. The original host's 80 GiB SSD admission reserve is amended to **40 GiB** because the currently available SSD space is about 56 GiB; the previous build's incomplete output occupied 1.3 GiB. This is a resource admission change, not evidence that the new build fits. Record disk before and after and stop on any storage error. Boot and VM-root floors stay 20 and 10 GiB. Do not delete frozen output, raw logs, or an active task's cache to satisfy the floor.

## Admission, execution and stop conditions

First run [admit.sh](admit.sh) from the exact clean committed source. Its no-work, no-network container must verify the Git source and committed plan blob without stderr, all script and archive hashes, the bootstrap producer ELF/hash, pinned image, architecture, cgroup, socket, disk floors, absent new output and absent source-labelled runtime image. It has a 120-second outer cap and writes its own log, receipt and source commit. A failed admission stops before the build.

Only after that pass, run [build.sh](build.sh) from the same clean commit. It invokes the unchanged native producer and retained three-stage plan into `charged-20261116-attempt-2`; its outer receipt records child, inspect, image-inspect and cleanup exits and source cleanliness. Success requires a complete `build.json`, every stage PASS, source-labelled image inspection, exact binary and solver receipts, no OOM, clean source, and no residual container. A cap, nonzero exit, missing receipt, source/input drift, storage error, OOM or failed cleanup is a STOP. Retain the stopped state and raw logs rather than relaunching into the same directory.

The build duration is setup charged to cold one-target IC cost, including the earlier bootstrap and toolchain provisioning. This new attempt can exceed the prior controller's 3,600-second total allowance; a separate versioned controller/budget amendment and frozen worker input/host gates are required before any K600 solver arm. This build cannot establish relation yield, useful rank, target descent, matched rho or a minimum total-runtime factor base.
