This local L0 pilot compares the native SAT result to CryptoMiniSat on the **same exported constraints**, using the public planted 4+2 witnesses in [the frozen fixture](../hosted-m6-witness-ladder-20261017/fixture.json). The fixture SHA-256 is `76b78ec1a68807d130fc11e54e4220b5cde619d677316e313dc247869f727a9d`. The sequential K600 base and Gray/hash residual pools are the three already-verified objects in the requested S3 factor-base prefix. Their signed-Frobenius domains, first-pair order, zero intermediate-identity mask, target x, and stage pins are the same as [hosted run 39062976388](../hosted-m6-witness-run-39062976388/RESULT.md).

The export uses the repository's `to_dimacs_xor` on the original CNF clauses and native XOR rows **before** calling the native solver. The new output file is created exclusively; its BLAKE3, SHA-256, byte count, variable count, CNF clause count and XOR-row count are recorded. The first local arm is Gray, then hash if the first export and model checks pass. In each arm the fixed-pin stages are `all_x`, `summand_x`, and `open`; their outer wall caps are 600, 900, and 1,800 seconds. A separate solver process gets one CPU thread and a fresh input for each stage. The exact binary is `/opt/homebrew/bin/cryptominisat5`, version 5.14.7, SHA-256 `a3f85c3709b5e2a040bf82a4a604d1c7b9f10219bbf180a9e0f72319a2e892ac`. The local host has no enforced 4-GiB container cap, so L0 walls and memory are exploratory and cannot establish a hosted speedup.

The initial committed-source Gray `all_x` run at 5,000 conflicts emitted `s INDETERMINATE` after 0.22 seconds. Its raw artifact and `PRODUCER_FAILURE` receipt are retained: the runner had accepted `UNKNOWN` but omitted CryptoMiniSat's observed spelling. The corrected runner treats either spelling as a **censored solver limit**. This amendment declares a finite follow-up ladder *before* further calls: retry the native-matched base conflict cap, then multiply it by 20 and 200 only while the stage remains censored. The base caps are 5,000, 10,000 and 20,000 for `all_x`, `summand_x` and `open`, respectively. Stop escalating a stage after an independently verified SAT model; do not call a cap an UNSAT result or compare native and external conflict units as equal work.

The first parser retry exposed a second producer error: CryptoMiniSat returned exit code **15** for `s INDETERMINATE`, while the runner expected zero. That artifact is also retained. A direct invocation of the pinned binary on the same exported instance reproduced `(15, "s INDETERMINATE")`; the runner now requires that observed pair.

The corrected Gray `all_x` calls at 5,000, 100,000 and 1,000,000 external conflicts all remained indeterminate on byte-identical exported constraints. Before interpreting this as external search behavior, a native SAT call on the same fixed witness must export its **complete** assignment. An independent checker will test every original CNF clause and XOR row in the 11.6-MB DIMACS file, not just the eleven decoded x blocks. A mismatch is an export or convention failure and invalidates a solver comparison. The raw native assignment stays in local research scratch; only hashes, checked counts and disposition enter the PR.

Every SAT assignment must have a single SAT status, all declared variables assigned consistently, and satisfy every exported CNF clause and XOR row. The first eleven 83-bit x blocks are then checked against the target and fixed units; the five S3 nodes are recomputed over the original F₂⁸³. Summand x coordinates must lift through the archived full point sets, with signs and Frobenius phases, to six subgroup points whose sum is the target before counting a partial relation. `UNKNOWN` at either cap is censored. An UNSAT verdict for a planted stage is a producer failure because the frozen full-point witness proves satisfiability.

Export, solver, parsing, field checks, group lift, and cleanup are charged separately. A local positive control justifies a later pinned-host matched-target natural-search comparison; it does not measure ordinary relation yield, useful rank, linear algebra, individual-log extraction or total index-calculus runtime. `selected_best_total_runtime` remains null.
