# Runtime/scaling protocol draft — not frozen; do not launch

Question: do the four changes lower complete cold verified one-target cost
against matched APS controls? Failures, timeouts and unverified solves remain
in the population and never count as wins. Toy scaling does not establish an
exponent or behavior on P-192/P-224. No test duration is experimental evidence.

Comparisons to freeze:

1. Exhaustive versus first-informative, same exact roots, encoding, labels,
   base size, input and seed.
2. Legacy versus exact roots, both exhaustive: bind actual equations by digest,
   independently check complete root sets equal.
3. Unordered cubic versus line divisor, same full labeled base, root/stopping
   policy, both global sign orientations deduplicated.
4. Orbit line with/without saturation, identical certified bases/labels. Freeze
   beta/lambda per subgroup; independently relabeled orbits are refusal controls.
   Charge the saturation variable and construction rather than assuming a win.

Use eight or more independent targets per curve, five or more measured rounds
plus a warmup, interleaved paired seeds, identical A/A arm, positive and stated
null/rejection controls. Include strongest applicable rho and fastest available
same-input external solver; name missing licensed tools. No multi-target
throughput substitutes for one-target cost.

Review/freeze four sizes inside p<=65521, exact curves, generators, orders,
orbit parameters, base sizes and seeds before data. An 8–16-bit ladder describes
only that bounded range. Replay fixtures remain development controls, not
held-out data. Larger parameters need separate support/review.

Retain solving degree, matrix/root/F4 diagnostics, complete cold/five-phase
online intervals, separate final serialization/audit overhead and included
instrumentation overhead. Require L2 and A/A admission. Preserve censoring and
failures; do not rank successful-only means as time to solution. Recompute
all totals independently. Missing operation counts leave complete S/bitop
ratios unknown; common 0/0.1/1 GAE bands require counts on every arm. Report
per-size paired ratios/uncertainty, not a pooled exponent or extrapolation.

Remaining launch prerequisites:

1. Reviewed ladder/full-output oracle, claim-appropriate complete accounting
   and independent metric validation.
2. Native experiment.export/v1 including pre-transcript failures and
   planned/attempted/completed/excluded flow counts. The canonical schema and
   skill are in crypto-autoresearcher; its existing exporter is Python, and no
   native exporter was found in the checked ecbench/sibling Rust paths. Keep
   that port/integration open under the repository's native-language rule.
   APS's cooperative-deadline counts are not eligible for deterministic native
   count replay; a static audit and rho replay do not close APS replay admission.
3. Reviewed schema-valid protocol, fixed analysis, seeds, sample-size/power
   rationale, runtime pilot/budget, stop rules and control expectations;
   freeze/commit before affected data. This draft is not that freeze.
4. Explicit approval for previously rejected source/worktree S3 checkpoint
   egress. Automatic approval review rejected it; generic measurement requests
   do not approve it. Do not retry/reroute/shrink it to evade denial. Full shared
   logs/index, detailed build logs and host metadata also remain unapproved.
5. Successful mandatory checkpoint and maintained EKS admission with tested
   source-built image, L2/A-A/replay/S3 checks and required CRIU/EBS recovery.
   Interrupted timing epochs are invalid. No local benchmark substitutes for
   missing prerequisites or approved egress.

No protocol freeze, funding/submission request, resource provisioning or
schedule is created here. Existing complete-cost backlog/problem remain open.
