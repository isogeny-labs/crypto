# pf_yield: exact m=2 decomposition census on small prime-field curves

Command (from this directory): `cargo run --release` (no dependencies; Rust only; runtime about 1.7 s single-threaded).
RNG: xorshift64* with fixed seed 0x9E3779B97F4A7C15 (printed at start; the base-sampling streams are derived from the seed, p, a, b and B). Outputs: `results/pf_yield.json`, `results/pf_yield.csv`, `results/table.md`.

## Conventions
- Curves y^2 = x^3 + a x + b over F_p, a and b drawn from the seed, prime group order r (r != p), 3 curves per p, p in {2003, 5003, 10007, 20011, 40009, 80021} (primality checked in code). #E counted by enumerating x (affine points plus infinity). The curves are the same as in the first version of this census.
- Three factor bases per (p, curve, target size), flagged `base`:
  - `small_x`: all affine points with x(P) <= X (both y values), closed under negation; B = |F| is the prefix closest to sqrt(r/2), sqrt(r), sqrt(2r).
  - `random`: B distinct points drawn uniformly at random from the affine points of E(F_p), not closed under negation (same B as the `small_x` row).
  - `random_negclosed`: points drawn uniformly at random, each added together with its negative, until B points are present (B is the same or one larger when the last pair overshoots; the actual B is in the table).
- mu = B^2/r.
- N(R) = number of ordered pairs (P1, P2) in F x F with P1 + P2 = R, for every one of the r points R (infinity included). Both (P1,P2) and (P2,P1) count. Sum of N(R) = B^2 (asserted); N(infinity) = B for the negation-closed bases (asserted).
- U(R) = number of unordered pairs {P1, P2} (P1 = P2 allowed, taken as index i <= j in a fixed ordering of F) with P1 + P2 = R. Sum of U(R) = B(B+1)/2 (asserted). Mean U = B(B+1)/(2r).
- "decomposable fraction" = fraction of R with N(R) >= 1 (equivalently U(R) >= 1). The "outside" statistic uses only affine R not in F.
- JSON holds, per row, the histograms of N and U with the matching Poisson probabilities (Poisson(mu) for N, Poisson(mean U) for U). Self-tests asserted in code: r*P = infinity and associativity on random points.
