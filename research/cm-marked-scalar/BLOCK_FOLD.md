# Folding adjacent columns into retained point actions

2026-11-08, continuation of PR3674. This is a new implementation; the frozen cache_core.hpp, cold worker/protocol and admission refusal remain unchanged. No new timing attempt is authorized by this file.

Let the existing signed expansions give coefficients v_i=ell*q_i+r_i, so the original scalar is the signed sum of v_i*2^i. A block of h adjacent columns has integer coefficient u=sum(v_i*2^i) relative to its lowest column. When u is zero or an already retained signed bank label, replace that block by h doubles of the preceding accumulator followed by [u]P. At the leading block no accumulator exists, so a retained [u]P can seed it directly. The invariant is exactly A_new=2^h*A_old+[u]P, including zero blocks and negative labels. This never identifies a curve collision with a scalar action.

The bank is the identical counted prefix/odd table used by cache_core.hpp. No extra point precomputation is added. A forward dynamic program considers both the original single-column actions and all admissible blocks of at most16 columns. It minimizes (main D+A,main negations,main D,number of steps), in that order, with deterministic first-encountered ties. Because every original column remains feasible, its selected main D+A cannot exceed that original schedule. This is an exact property of the finite program; it does not claim globally optimal addition chains or improved runtime. Integer planning, its allocations and table normalization belong inside a future full cold boundary.

The extension test uses signed integer coefficients only. If the largest retained positive label is M, each column is at most M+1 in absolute value. For |u|>M+1, the next extension satisfies |2u+v|>=2|u|-(M+1)>M+1, so no longer block can return to a bank label. This bounds the scanner without overflowing its signed64-bit accumulator. Widths2..7, supported radices<=32, scalar lengths<=2048 and maximum span16 are explicit finite implementation limits. Identity, zero quotient and an outer sign remain covered.

Independent qualification must reconstruct the emitted integer polynomial and operation counts with GMP without calling the producer's recoder/planner. It must verify actual point output against independent scalar multiplication, bank labels, the original fallback bound and planted multi-column/leading/zero/sign cases. Qualification is untimed software checking; any comparative census must first publish/freeze its own protocol and inputs. The same block policy applies to binary-radix controls.
