# Fixed-label residual correction

2026-11-08, T-1888, PR #3674. P-192 primary; P-224/P-256/P-384/P-521 retained. This proposal preserves the original marked mu and the complete point-output contract. It does not change the orbit generator or substitute an easier scalar.

Let s=center(mu) modulo n, and let m be the radix. Choose the centered Euclidean remainder r of s modulo m. For an integer offset v, define c=r+m*v and k=(s-c)/m. Then m*k+c=s as an exact integer identity, and for every rational subgroup point P,

    [mu]P = [k]Q + [c]P,    Q=[m]P.

For the relation arm m=ell, Q is the already checked closed loop sigma eta phi(P)=[ell]P. Its fused evaluator computes [ell]P by the same width-2 public multiplication used previously. The qualification also evaluates the full explicit maps and endpoint isomorphism. Both realizations give the same points. This is an executable rational-subgroup recipe, not a newly expanded global noninteger quotient.

The new evaluator interleaves width-w signed digits of k with width-2 signed digits of c, so both terms share the main doubling loop. It charges the entire radix prefix, both point tables, Q-table normalization and every actual group double/add/negation API call. It factors the sign of k into one final negation; the corresponding sign change of c is retained. Identity input has its actual zero-work count. Point conversion, allocation, scalar preparation and backend field work remain additional runtime costs, not hidden in a D+A proxy.

The frozen finite design will use offsets -64..64 and widths 2..7. Fair controls use the identical split/evaluator for radices 1,2,4,8,16,32, including the zero-cost radix-1 copy. A separate direct reference repeats every centered-scalar translation -256..256 and width 2..7 in the new instrument. The primary comparison requires relation D+A to be strictly smaller than both the best binary control and the best direct reference, separately on each curve. Weights 2,3,4 for D+weight*A are sensitivities only. Counts and table/negation vectors are retained for every row; no runtime claim follows from a count result.

This changes the old forced-zero residual, not mu. A small integer remainder lets k be an ordinary quotient rather than forcing modular division by ell. Any gain must pay for applying [c]P.
