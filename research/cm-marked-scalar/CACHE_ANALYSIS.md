# Native cold-panel analysis and independent points

The native analyzer accepts only the frozen CM-CACHE-COLD-V2 design. It verifies nine distinct input hashes, its own executable/source, complete 3,500/7,000-row matrices, exact effective configurations, independent expected outputs and the sum of the five exclusive phases. It rejects out-of-range indices before narrowing, overflowing phase sums, unknown counters represented as zero, invalid isolation receipts, changed environment/host bindings and aggregate function clocks exceeding the enclosing process wall time.

Calibration selects a reported reference configuration per curve. The decisive held-out test uses the fastest of all eleven reference medians separately at every point. The deterministic cache-default candidate must exceed both 1.01 and the largest bidirectional paired reference A/A ratio at every held-out point. A fast installed plan does not replace that primary result. Phase means are reported separately from median total times: medians of different phases need not add to a median total.
