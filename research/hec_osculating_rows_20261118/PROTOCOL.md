# One-point startup relations

For each nonbranch small place P, compute the reduced representative (u,v) of nP. If u splits completely, nP equals the signed sum of rational places with multiplicities read from u. Insert the resulting homogeneous row if nonempty and currently admissible. Skip failed attempts, charging every multiplication, split test and insertion. Unlike direct horizontal fibres these relations can share large places. Use generic Jacobian multiplication for the first order and one-place addition for the second. No cross-target reuse.

Arm 0 uses the original normalized solver. Arm 1 uses the previous deferred graph solver with the registered schedule. Arm 2 adds n=g+1 at each small place. Arm 3 adds both n=g+1 and n=g+2 in place order. All four arms use the same fixtures, public inputs, seeds, and 512-anchor cap as the preceding graph study. Audit split decompositions against group multiplication and the graph against the reference linear solver. Compare all counted and timed outcomes to the audited replay and check each scalar on the original target. Record 12 rotating-order complete wall observations and one field counter capture per cell/arm. Report coverage, startup rows, anchor effects, and per-genus ranges of median speedup over arms 0 and 1. Require tenfold over arm 0 across the full panel for the performance goal. Freeze in Git before one 600 CPU-second run. Results apply to this implementation and schedule.
