# Higher-arity principal-relation rank screen

Motivation: previous rational-family screen discarded split residuals containing more than2off-anchor rational places. For genus3/4, that discard can remove most of the generated relations when the anchor set is small. Retaining3/4LProws is ordinary larger-matrix elimination, not a claimed new algorithm or new asymptotic result. Need test retained rank, not gross acceptance.

Sources reviewed before approach choice: existing RATIONAL-RESULTS.md, RATIONAL-RANK-PROTOCOL.md, RATIONAL-RANK-VERIFIED.jsonl, orbit.rs, rational.rs and LINEAR-COLD-RESULTS.md. Original doubleLP draft primary sections2/3: https://cacr.uwaterloo.ca/techreports/2004/corr2004-29.pdf . Avanzi/Theriault2010 publisher abstract only: https://www.aimsciences.org/article/doi/10.3934/amc.2010.4.189 . Filtering/overdetermined selection is prior art; no inference from their timing numbers. The existing polynomial interpolation and exact norm/group checks are reused. The new screen changes admission/retained algebra, not polynomial generation.

Fixed6curve/anchor cells: deterministic pick_instance for(g,p)=(2,1009),(3,503),(4,127), H in{g+6,2g+8}. Preserve unavailable cells; do not substitute. Verify ell^2>(ceil(sqrt(p))+1)^(2g) as before. Canonical firstHplaces. Only d0family,M=g+1; all integer sign classes with firstsignpositive, fresh Newton interpolation. Same tuple seed2026111503 xor(g<<40) xor(H<<16), distinct sorted tuples by rejection. Fixed budget min(C(H,M),1024)tuples, classcap32768; no early rank stopping. This differs explicitly from historical early-stop rows: compare policies on the same complete generated stream here, not historical totals. Include all generation/unused outputs as counts; no elapsed time comparison.

Policies:maxoff2..g (g2single2LPcontrol). Build primitive signed principal rows from fully split residuals, combine repeated place coefficients before off-count. Canonical normalized modular dedup globally, then subset by offcount. Every unique admitted row (anypolicy) passes full unprojected Jacobian zero check. No known scalar is used. Report exact offarity histogram and duplicate/rejection counts.

For each policy perform incremental ordinary Gaussian elimination with LPcolumns ordered before anchors. LPpivotcount is rank(R_off), retained-pivotcount is rank(R)-rank(R_off). Retain dependent rows; no graph2LP assumption beyond policy2. Track first visited signclass attaining retainedrankH-1, final ranks and status, admissions, elimination mulmods and maximum normalized pivot row nonzeros. Independent end-of-stream dense rank calculations in the original column ordering must agree separately for full/offrank, and retain bounds rank<=FB-1 and anchorrank<=H-1. Independent routine shares field primitives but not incremental basis/order. Elimination counts omit generation/groupchecks/setup, so cannot establish complete cost or speed ratios. Admission yield alone cannot establish a gain.

Local singleprocess memory<256MiB, soft60s admission budget perinvocation, no cloud spending. Native runner uses fixed180s overall timeout only to retain terminal status; if60s budget reached inside main, stop before nextcell and report notstarted/censored cells explicitly (do not replace). Implement no clock reads inside scientific loops except cell boundary; no performance data emitted. Before once-only gate: hash source/lock/field/poly/jac/oracle/tablefactor/binary/protocol; commit/checkpoint/gate. Fail on any group/rank mismatch. Preserve raw failures, no posthoc cell selection.

If3/4LPadmissions fail to create retained rank earlier, or elimination grows substantially without a generation-count advantage, do not promote this into a timing campaign.
