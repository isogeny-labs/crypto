# Nine branch-support classes for a hyperelliptic genus-seven target

Status: derived necessary condition, using [Borodin–May (2025), Section 2, Lemmas 2.1–2.2](https://arxiv.org/pdf/2508.16886) and the [Diem](https://www.esaga.uni-due.de/f/ulrich.goertz/iem-archiv/dissertation_diem.pdf) trace setting. This is a new application in this GHS audit, not a claim that the underlying parity method or any vulnerable curve family is new. The argument is not formalized in Lean or signed by PCC. [pcc:unverified]

Let `E/F_128` be any ordinary elliptic curve with odd trace t, and suppose a genus-seven **hyperelliptic** curve `Y/F_2` has `J_Y` isogenous to `Res_(F_128/F_2) E`. Then `Y` is ordinary, so its 2-rank is seven. Borodin–May give `#W=2-rank+1=8` for the geometric Weierstrass points W of a characteristic-two hyperelliptic curve, and `#Y(F_(2^m)) ≡ #W(F_(2^m)) (mod 2)`.

The required L-polynomial `1-tT^7+128T^14` gives `#Y(F_2)=3`, which is odd, and `#Y(F_128)=129-7t`, which is even because t is odd. Therefore W has an odd number of rational points, and an odd number of Frobenius orbits of length seven. Since W has only eight geometric points, its orbit decomposition is **exactly one orbit of length one plus one orbit of length seven**. No other branch-orbit pattern is possible for this hyperelliptic target.

Up to `PGL_2(F_2)` change of the hyperelliptic x-coordinate, there are exactly **nine** possible supports of this form. Send the unique rational branch point to infinity. The remaining orbit is a root set of one of `(2^7-2)/7=18` monic irreducible degree-seven polynomials over F2. The stabilizer of infinity has order two, generated by `x↦x+1`. It acts freely on the 18 orbits: if translation preserved a seven-orbit, it would agree there with a Frobenius power; squaring that action would force the power to be identity, and then translation would fix a root, impossible. Thus the 18 orbits pair into nine coordinate classes.

This bounds the **branch supports**, not the number of hyperelliptic curves, whose Artin–Schreier right-hand sides can vary. It does not address nonhyperelliptic genus-seven Jacobians, nor does it produce a correspondence from the source curve. The published classical genus-seven GHS slice is a positive control for the possibility of this branch type. The follow-on [complete F2 model census](HYPERELLIPTIC_CLASSIFICATION.md) now resolves the six nonclassical-only source trace classes within these nine supports.

## General even-q support count

The same parity argument works for every `q=2^s` and ordinary `E/F_(q^7)`: the sparse L-polynomial gives odd `#Y(F_q)=q+1` and even `#Y(F_(q^7))=q^7+1-7t` because ordinary trace `t` is odd. Hence any genus-seven hyperelliptic target has branch support `1+7`. This is a necessary condition for a target in the Weil-restriction isogeny class, not a sufficient condition for transfer.

Let `S(q)=1+q+q²+q³+q⁴+q⁵`. The number of such branch supports up to `PGL₂(F_q)` is exactly

`B(q) = S(q)/7` if `7 ∤ (q−1)`, and `B(q) = (S(q)+36)/7` if `7 | (q−1)`.

Proof: move the unique rational point to infinity. There are `(q⁷−q)/7` irreducible monic septics, and the residual affine group `AGL₁(F_q)` has order `q(q−1)`. If an affine transformation fixes a septic, it permutes its seven roots as a power of Frobenius, so its seventh power fixes at least two roots and is the identity. A nonidentity stabilizer must therefore have order seven. Such an affine transformation exists only if its slope has order seven in `F_q×`, which requires `7 | (q−1)`. Thus the action is free in the first case, and Burnside gives `B(q)=(q⁷−q)/(7q(q−1))=S(q)/7`.

In the second case, there are `6q` affine transformations of order seven: six slopes of order seven, with q translations each. For one such transformation `f(x)=ax+b`, shift to its fixed point `c=b/(1−a)`. A degree-seven orbit is fixed exactly when one of its roots `z` obeys `z^(q^j)=f(z)` for some `j=1,...,6`. After the shift, `w=z−c` obeys `w^(q^j)=aw`. Since `a⁷=1`, this equation has q solutions in `F_(q⁷)` by the norm-one form of Hilbert 90, of which one is zero. The six nonzero solution sets for different j are disjoint; their elements have degree seven. Thus f fixes `6(q−1)/7` septics. Burnside adds `6q·6(q−1)/7` fixed-septic incidences to the identity count, yielding `(S(q)+36)/7` support orbits. In particular `B(2)=9`, `B(4)=195`, and `B(8)=5355`.

This extension uses the published parity lemmas plus a direct affine-orbit count. It has not been independently formalized in Lean or signed by PCC. [pcc:unverified]
