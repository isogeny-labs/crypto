For K=GF(2^n), B nonzero, S3(a,b,c)=(ab+ac+bc)^2+abc+B.
As a polynomial in c it is A c^2+L c+C with A=(a+b)^2,L=ab,C=(ab)^2+B.
If A=0 and L=0, then a=b=0 and C=B!=0: there are no roots. If A=0,L!=0 there is exactly one linear root C/L. If A!=0,L=0, Frobenius is bijective and the unique distinct root is sqrt(C/A). Otherwise c=(L/A)u converts the equation to u^2+u=AC/L^2. This F2-linear map has kernel {0,1}, rank n-1 for every finite binary field including even n. Its restriction to vectors with constant coordinate zero is injective, hence echelon elimination on basis bits1..n-1 gives either no solution or one representative; adding1 gives every root.

For a given ordered five-tuple, exhaustive branching through these exact root sets lists every finite u,v,w satisfying the first three original equations, then checks the last equation. Induction on the three edges proves soundness and completeness; at most8 paths survive per order. Enumerating all distinct permutations of a supplied multiset covers every ordered source tuple with that multiset, including zero and repeated sources. Canonical set union removes duplicates. The output contract is all finite original-chain roots conditional on the supplied source multisets, not global search over all h/k charts. A supported norm can produce zero finite-chain solutions for an order; no artificial projective infinity is introduced. Failure/cap/late serialization is unresolved, never an empty complete set.

Work: AS map preprocessing O(n^3) bit operations in a simple echelon representation and O(n^2) bits storage. Cached unordered pairs bound field inversions; each uncached regular pair uses at most three inversions here. For five sources, at most120 orders and8 paths/order, with total emitted tuples<=960 per bag. The implementation is exact field-generic for binary degrees supported by its field backend; no curve A occurs in S3 for this binary model. B=0 is explicitly rejected.
