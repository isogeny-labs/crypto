# ROSENHAIN-SETUP-20261022 run record

The [frozen addendum protocol](../../ROSENHAIN_PROTOCOL.md) checked 21
independently factored Scholten quintics. Every model had 10 square-scale
normalizations among 20 ordered root pairs, and each selected map passed
an exact six-coefficient identity. The [raw model rows](../../results/rosenhain-models.jsonl),
[native validation](../../results/rosenhain-summary.json), and
[full report](../../ROSENHAIN_GATE.md) contain the checks and limits.

The [graph](rosenhain-setup.svg), [PNG](rosenhain-setup.png), and
[PDF](ROSENHAIN_GATE.pdf) display the recorded model counts. Their source is
[plot_rosenhain.py](plot_rosenhain.py). This was an algebraic setup gate with
no wall-time comparison. Theta constants, fast Kummer arithmetic, signed
walk recurrence, and candidate/rho cost cells are unmeasured.
