# Vary the small factor base at fixed scan width

The pencil scans the registered abscissae and retains its previous hit threshold, signed places, target/source streams, step place, and 512-anchor cap. A separate prefix determines which places enter incremental Gaussian elimination and which enter the affine forest. Narrowing the prefix reduces dense dimension and can reject rows with more than two unresolved large roots. Widening it can admit more rows and increase elimination cost.

Use the same eleven curves and four public input pairs per curve as the deferred solver. Let M be the previous prefix length. Arm 0 original normalized solver. Arm 1 deferred solver with prefix M. Arm 2 uses ceil(M/2). Arm 3 uses min(2M,catalogue size). Arm 4 uses the shortest prefix containing the original step place. All prefixes include that place. No arm chooses its cutoff from target results. Compare gates and scalar outputs to the unchanged linear solver under audit. Retain discrepancies and cap exhaustion. Ten cyclically rotated complete wall measurements per arm/input, one separate counter capture and one audited run. Report per-genus coverage, ratios of fixture medians for jointly solved arms and accepted/rejected rows and joins. Arm 0 has placeholder zeros for unavailable forest statistics. The tenfold performance gate requires all 44 successes and tenfold relative to arm 0 throughout for a single fixed policy. Freeze in remote Git and verify the binary before one run with a 600 CPU-second limit.
