# Exact ECCp-131 equal-column screen benchmark

Frozen before the first trial on 2026-10-23. Question: on the same published ECCp-131 curve, what are the measured screen-stage wall, process wall, and EC-addition-call costs of the certified tower's 115-column base relative to the first 115 liftable small abscissae? This is an L0 stage diagnostic, not a full IC cost or speedup claim.

* Input: the existing immutable `runs/replay.json` tower certificate, exact curve source in `src/ecc/curve.rs`, published target in `src/bin/ic/params.rs`, and `research/eccp131_structured_ic_20261022/screen.py` at the current PR head. `B=115` for every arm. Tower columns are the certificate's lifted `x` values in recorded order; control columns are `small_base(115)`.
* Workload per process: seed 131, eight planted controls, 256 setup points `aG`, 256 target points `aG+Q_pub`, complete signed pair table and three-point lookup. Record candidate-scalar digest, input/source digests, base digest, distinct pair points, planted count, natural rows, ranks, base-preparation wall, screen wall, EC-addition calls and process wall/RSS.
* Order: repetition 0 `tower, small_a, small_b`; repetition 1 `small_a, tower, small_b`; repetition 2 `small_a, small_b, tower`. `small_a` and `small_b` form the A/A control. One process per cell, 30 s wall and 2048 MiB sampled RSS watchdog, no replacement trial after a failure.
* Correctness: independently check the published points on curve and killed by subgroup order; require all eight planted identities to decompose, compare setup/target candidate scalar digests across arms and repetitions, and retain all raw JSON and failed outputs. Rank and natural-row counts are reported even if zero.
* Timing boundary: process wall includes interpreter startup and base preparation, screen wall excludes process startup and base preparation, and prior 301-curve auxiliary search is separately charged as setup. No paired rho run or end-to-end `S` is available in this benchmark. A/A spread describes local noise; three repetitions are not a population confidence interval.
