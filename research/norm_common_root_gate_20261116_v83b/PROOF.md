# Common-root rationality gate for linear sections, both characteristics
Let K be a finite field, E nonsingular. In odd characteristic use y^2=F(x)=x^3+Ax+B and N=a^2-Fb^2. In characteristic2 use y^2+xy=F(x)=x^3+Ax^2+B and N=a^2+xab+Fb^2. Assume b is a nonzero polynomial of degree<=1 and N is the actual certified section norm, not an arbitrary polynomial supplied without a,b.

For r in K with N(r)=0 and b(r)!=0, y=a(r)/b(r) (or its negative in odd characteristic) lies in K and satisfies the curve equation. Thus any ground x-coordinate with nonrational lifts must satisfy a(r)=b(r)=0. A nonzero constant b permits none. A nonconstant linear b has exactly one root r=-b0/b1; evaluate a(r) and, only if zero, test this single curve fiber by Euler criterion in odd characteristic or the absolute Artin-Schreier trace in characteristic2. At binary r0, y^2=B always has a K-root; odd F(r)0 is rational two-torsion. No such exceptional case may be dropped.

If this common r has nonrational lifts, N has multiplicity exactly2 there: factor g=X-r from both a,b, so N=g^2N0. The residual b/g is a nonzero constant. If N0(r)=0, the preceding quotient formula would construct a K-point above r, contradiction. This proves the complete set of nonrational ground-coordinate roots is empty or the single double root r, without full norm factorization or quotient spectral trace. Other K-roots and all multiplicities remain available for the source solver; the gate does not enumerate those roots.

For a norm divided by a certified K-rational target factor X-z, removing that rational coordinate does not change the anti-coordinate set. Apply only after verifying exact norm/target identities and the original-family rationality theorem; this is not permission to discard ghost branches for arbitrary original polynomial systems. b identically0 is explicitly unresolved and requires a separate factor or target/domain certificate. Arbitrary H without section coefficients is unsupported.

For large odd primes the exceptional scalar Euler exponent costs O(log q) field multiplications. Binary testing uses one scalar trace of rhs/r^2, O(n) scalar squarings plus inversion. Generic root support/search still dominates unless this removes paid spectral work or prunes whole cells. This is an elementary norm argument with scope established by proof, not a primary-literature novelty clearance. C57 already established related norm coverage/ghost structure; this experiment tests the common-root gate explicitly across characteristics.
