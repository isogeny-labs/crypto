# Derived results: fall degrees of prime-field PKM systems

Everything here is **derived** (proved) unless it is marked *measured*.
Conventions are those of `PREREGISTRATION.md` §2, which follow the ledger §0.
`R = F_p[y, u]/T` is the tower quotient, `f` is a reduced (normal-form)
generator, and `V_{F,c}` is the HKY closure.

## D1. The tower quotient is a function algebra, and every ideal over it is radical

Under grevlex, `T` is a Gröbner basis with leading monomials `y_j²` (note
Lemma 1). So `dim_{F_p} F_p[y]/T = 2^{mt}`, which is the number of `F_p`-points
of the grid `V^m`. Evaluation at the grid is surjective, and the dimensions
match, so it is an isomorphism `F_p[y]/T ≅ F_p^{V^m}`. A product of fields has
only radical ideals. With free unknowns `u`,
`R ≅ (F_p^{V^m})[u] = Π_{x ∈ V^m} F_p[u]`.

**Consequence.** An `m = 2` system (no `u`) is inconsistent iff the reduced
`S₃`, `f`, has no zero on `V²`, iff `f` is a unit of `R`.

## D2. Kummer: `R` is a group algebra graded by popcount

On a Kummer tower, `y_0 = x/g`, `y_{j+1} = y_j²`, `y_{t−1}² = 1`. Writing
`z = y_0` gives `y_j = z^{2^j}`, so `F_p[y]/T = F_p[z]/(z^K − 1)` with
`K = 2^t`. The normal-form monomial `Π_{j∈S} y_j` is `z^k` with
`k = Σ_{j∈S} 2^j`, and its degree is `popcount(k)`. Multiplication is
`z^a·z^b = z^{(a+b) mod K}`. Since `popcount((a+b) mod K) ≤ popcount(a) + popcount(b)`,
rewriting never raises degree. Carries are exactly the degree falls the tower
produces.

*Measured check:* on every Kummer `m = 2` draw, the inverse transform of `f` on
`μ_K²` has support in `{0,1,2}²`, and `f` has no zero on the grid
(`derived/ns_degree.md`). That independently certifies the drawn random targets
as inconsistent.

## D3. Theorem (first fall degree, Kummer `m = 2`). `ffd = 4` for every `t ≥ 2`

**Hypotheses:** a Kummer tower with `t ≥ 2` and `g ≠ 0`, the system
inconsistent, and `3x_R² + a ≠ 0`.

**Setup.** With `x_i = g·y_{i,0}` and `x_i² = g²·y_{i,1}`, the normal form of
`S₃(x_1, x_2, x_R)` is `f = f_2 + f_{≤1}`. Its degree-2 part is the bilinear form

```
f_2 = (y_11, y_10) · M · (y_21, y_20)ᵀ,
M = [[ g⁴,          −2x_R g³        ],
     [ −2x_R g³,    −2(x_R² + a) g² ]],
det M = −2 g⁶ (3x_R² + a).
```

The associated graded ring of `R`, by degree, is `gr R = F_p[y]/(y_{i,j}²)`.
This holds because `T` is a Gröbner basis for a degree-compatible order, so the
top forms of `T` are generated by the `y²`.

**(a) No fall at 3.** `V_{F,2} = ⟨f⟩`. `V_{F,3}` is spanned by `f` and the `y·f`.
An element `αf + ℓ·f`, with `ℓ = Σ β_y y`, has degree `≤ 2` only if
`ℓ·f_2 = 0` in `gr_3`.
- Outer variables (levels `≥ 2`) give monomials disjoint from everything else,
  so their `β_y` vanish.
- For the inner variables, the coefficients of `y10y11y21` and `y10y11y20` in
  `ℓ·f_2` are `(β10, β11)·M`, and those of `y11y20y21` and `y10y20y21` are
  `(β20, β21)·M`. With `det M ≠ 0` all `β` vanish.

So `V_{F,3} ∩ R_{≤2} = ⟨f⟩ = V_{F,2}`.

**(b) A fall at 4.** Let `q = y10·y11`.
- `y11·f` has degree 3: its top form `y11·f_2` is non-zero, because
  `x_R = a = 0` is excluded. So `q·f = y10·(y11·f) ∈ V_{F,4}`.
- Every monomial of `f_2` contains `y10` or `y11`, so `q·f_2 = 0` in `gr R`,
  and `deg(q·f) ≤ 3`.
- If `q·f ∈ V_{F,3} = ⟨f⟩ + ⟨y·f⟩`, then `(q − α − ℓ)·f = 0`. Since `f` is a
  unit (D1), that forces `q = α + ℓ`. But `q` is a normal-form monomial of degree
  2, and so is independent of `1` and the variables.

So `V_{F,4} ∩ R_{≤3} ≠ V_{F,3}`, and `ffd = 4`. ∎

The first fall degree is a constant, independent of the factor-base size
`2^t`. *Measured:* `ffd = 4` on every Kummer `m = 2` draw, `t = 2 … 10`,
planted draws included.

## D4. Theorem (the no-fall certificate, Kummer `m = 2`). `d_F ≤ 2 + popdeg(f⁻¹) ≤ 2t + 2`

`f` is a unit, so `1 = h·f` has the unique solution `h = f⁻¹`. For a monomial
`u = z1^{k1} z2^{k2}`, `u·f` is reached from `f` by multiplying with
`popcount(k1) + popcount(k2)` variables. Each intermediate product has degree
at most `2 + (number of variables so far)`. So `u·f ∈ V_{F,c}` once
`popcount(u) ≤ c − 2`, which gives `1 = Σ h_u·(u·f) ∈ V_{F, 2 + popdeg(h)}`.
Every certificate that never uses a fall is this one, because `h` is unique.

*Measured* (`derived/ns_degree.md`): `popdeg(f⁻¹) = 2t`, the maximum, on every
draw. The no-fall degree is therefore `2t + 2`, linear in `t`, while
`d_F = 4 … 6`. Falls lower the refutation degree from `2t + 2` to the measured
`d_F`. They are the entire mechanism, as in the binary case.

## D5. Theorem (naive control). `d_F ≥ 2^t = |V|`

The naive system is `{S₃(x_1, x_2, x_R), x_1^K − g^K, x_2^K − g^K}` in
`F_p[x_1, x_2]` with `K = 2^t`. For `c < K`, `F ∩ R_{≤c} = {S₃}` (or `∅`), so
`V_{F,c} ⊆ (S₃)`. `S₃` is non-constant and has zeros over `F̄_p`, so
`1 ∉ (S₃)`. Hence `d_F ≥ K`.

Encoding the same factor-base set as one univariate membership costs a degree
exponential in `t`. The tower presentation brings the degree down to 4–6 at
`t ≤ 10`. Since `V` is the same set, this is a statement about presentations
of the *same* ideal: `d_F` is not an invariant of the ideal. Proposition 1 of
`RESEARCH_INDEX_CALCULUS_FACTOR_BASE.md` is about the ideal invariants
(Hilbert function, regularity), which `d_F` is not.

## D6. Lemma (specialisation bound). `d_F(F) ≥ d_F(φ_x F)` for every grid point `x`

Fix `x ∈ V^m`. Let `φ_x: R → F_p[u]` evaluate the tower variables at `x` (D1).
It is a ring map, and `deg φ_x(g) ≤ deg g`.

**Induction on the closure.**
- `φ_x(F ∩ R_{≤c}) ⊆ φ_x F ∩ F_p[u]_{≤c}`.
- If `g ∈ V_{F,c}` with `deg g < c`, then `φ_x(y·g) = φ_x(y)·φ_x(g)` with
  `φ_x(y)` a constant, and `φ_x(u_k·g) = u_k·φ_x(g)` with
  `deg φ_x(g) < c`.

So `φ_x(V_{F,c}) ⊆ V_{φ_x F, c}`, and `1 ∈ V_{F,c}` implies
`1 ∈ V_{φ_x F, c}`. `φ_x F` is the `S₃` chain with constant summands in the
`m − 2` partial-sum unknowns. The bound holds for every tower family and every
`t`.

*Measured* (`derived/spec_chain_synthetic.md`, one base at `P1`, 3 grid points
per `m`): `d_F(φF) = 2, 4, 4, 5, 5, 5, 5, 5` for `m = 3 … 10`.
- The bound is valid but levels off at 5, below the measured `d_F` at
  `m = 3, 4` (5 and 6).
- So it does **not** explain the growth of `d_F` in `m`, and it gives no
  growing lower bound.
- On every measured chain row, the closure's `d_F` is at least the bound
  (`derived/spec_chain.md`). This check is an engine cross-check.

## D8. Theorem (one summand is easy). `d_F(q) = 2` for every `t`

**Statement.** Let `q(z) = S₃(g·z, x_2, x_R)` on one Kummer tower of height
`t ≥ 2`, with `x_2 ≠ x_R` and no root on `μ_K`. In tower variables `q` is
*linear*: `q = α + β·y_0 + γ·y_1` with `γ = g²(x_2 − x_R)² ≠ 0`. Then
`1 ∈ V_{q,2}` and `1 ∉ V_{q,1}`, so `d_F = 2` for every `t`.

**Proof.** `F_p[z]/(q)` has dimension 2. Write `z^{2^j} ≡ a_j + b_j z (mod q)`
and `L_j = y_j − a_j − b_j·y_0`. Then `L_0 = 0` and `L_1 = q/γ`. Suppose
`L_j ∈ V_{q,2}`.
- `y_0·L_j = y_0 y_j − a_j y_0 − b_j y_1` has degree 2 and lies in `V_{q,2}`.
  It writes `y_0 y_j` as a linear form.
- `y_j·L_j = y_{j+1} − a_j y_j − b_j·y_0 y_j` lies in `V_{q,2}`.
- Substituting `y_0 y_j` from the first, `y_j` from `L_j`, and `y_1` from `q`
  leaves `y_{j+1} − a_{j+1} − b_{j+1} y_0`, which is `L_{j+1}`.

At the top, `y_{t−1}·L_{t−1}` uses `y_{t−1}² = 1` and leaves
`M = c_0 + c_1 y_0`, the remainder of `z^K − 1` modulo `q`. It is coprime to `q`
because `q` has no root on `μ_K`. Then `q`, `M` and `y_0·M` are three
independent linear forms in `⟨1, y_0, y_1⟩`; if `c_1 = 0`, `M` is a non-zero
constant directly. Either way `1 ∈ V_{q,2}`. The quotient `F_p[z]/(q)` is
finite, so a constant-size state `(a_j, b_j)` carries the tower in degree 2. ∎

*Measured* (`derived/spec_1d_ladder.md`): `d_F(q) = 2` on all 4 draws at every
`t = 2 … 24` (`ffd = 2`), and `d_F(q_j) ≤ d_F(f)` on every Kummer `m = 2` row
(`derived/spec_1d_rows.md`).

**What D8 says about `m = 2`.** The one-summand specialisation bound of D6
is 2, so it cannot show growth. The growth of `d_F` at `m = 2` is
two-dimensional. `f(z_1, z_2) = 0` is a curve of bidegree `(2, 2)`, genus 1,
and `F_p[z_1, z_2]/(f)` is not finite. Running D8's recursion over `F_p[z_2]`
needs coefficients `a_j(z_2)` and `b_j(z_2)`, functions on the `z_2`-grid,
and their degree grows with `j`. A lower bound on `d_F` at `m = 2` therefore
has to see the curve. No specialisation to finitely many points can give one.

## D7. Recorded relations (literature, restated)

- **`d_F ≤ D`** (Huang–Kosters–Yeo; Caminata–Gorla, for degree-compatible
  orders). This is gate G2.
- The repository note's §3 "does not port" claim fails for tower bases
  (D1–D2). It still holds for unstructured bases, where D5 is the
  obstruction.

## What is not derived

- **No lower bound on `d_F` that grows with `t` or `m`.** Its growth is
  *measured* only.
  - A proof would need a degree-`c` pseudo-solution: a linear functional on
    `R_{≤c}` that kills `V_{F,c}` and not `1`.
  - D2 suggests where to look. A low-popcount monomial times a variable wraps
    past `z^K = 1` only in the top `c` levels, so a pseudo-solution need only
    respect the tower near its top.
  - This is open.
- No theorem for isogeny towers. Their reduced `S₃` has degree 4, and
  *measured* `ffd = 5` = degree + 1.
