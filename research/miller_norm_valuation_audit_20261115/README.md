## Construction and mathematical scope

[NormDegree](lean/NormDegree.lean) uses Mathlib’s actual coordinate ring and `Algebra.norm`. The official rank-two basis gives `degree(norm(p+qY)) = max(2*degree(p), 2*degree(q)+3)`. A new proof derives its ultrametric triangle bound. Multiplicativity follows from norm and polynomial-degree multiplication; norm nonvanishing proves zero support. Mapping bottom to zero and a finite weight `n` to `exp(n)` constructs an actual `Valuation`. The official degree formula and its proof are credited to Mathlib. [pcc:unverified]

[FieldValuation](lean/FieldValuation.lean) extends this valuation to Mathlib’s actual `FunctionField`, its fraction field. The actual coordinate functions have values `exp(2)` and `exp(3)`. Nonzero actual constants have value one. [MillerFunctions](lean/MillerFunctions.lean) proves the actual function-field curve relation, values `exp(2)` for vertical lines and `exp(3)` for nonvertical lines, and value `exp(-1)` for `X/Y`. This uses the multiplicative convention of Mathlib’s `RatFunc.inftyValuation`, which grows at poles. It does not identify the constructed valuation with a canonical projective valuation. [pcc:unverified]

[Normalization](lean/Normalization.lean) derives `v(X^3/Y^2 - 1) < 1` from the actual Weierstrass equation. Lower-weight terms then give `v(t^3*line - 1) < 1` and `v(t^2*vertical - 1) < 1`. [ResidueNormalization](lean/ResidueNormalization.lean) uses the actual valuation subring and its actual residue map: both normalized elements reduce to one. These are actual function-field and residue-field statements, rather than an uninterpreted power-series normalization predicate. [pcc:unverified]

[DiscreteValuation](lean/DiscreteValuation.lean) proves full valuation surjectivity using powers of `t`. Its derived nontrivial cyclic value group supplies the official actual DVR instance. Lean proves `Valuation.IsUniformizer` for `t`, and that the actual maximal ideal is generated by its integral lift. No valuation, DVR, coordinate weights or normalization result is supplied as a hypothesis. [pcc:unverified]

The negative control proves that `1/X`, whose value is `exp(-2)`, is not a uniformizer. Replacing `t` with `1/X` in the line normalization makes `v((1/X)^3*line - 1) = 1`, so the required strict inequality fails. This disproves that substitution; the correctly qualified source normalization survives. [pcc:unverified]
