# Frozen kernel-guided N31 repair

Use the archived 15,856-column training union and two frozen 16,399-row, 18,352-column S3 streams `fresh_1` and `fresh_15`. Verify their SHA-256 digests, the training receipt digest, and the producer source digest before measurement. Form the base projection A and omitted-column matrix B. Compute a basis K for the left kernel of A using M4RI PLUQ on A transpose. Row-reduce K transpose times B; its pivot columns identify omitted columns whose addition restores the full-width rank. This uses the full row stream, but never computes a full-width pivot profile or eliminates the full-width matrix.

The target-conditioned computation has a 120-second process timeout. The 2-GiB memory gate uses observed process peak RSS because this macOS host rejects the attempted `RLIMIT_AS` setting; see [AMENDMENT.md](AMENDMENT.md). Retain base rank, kernel dimension, quotient rank, selected original-column indices, and separate load, kernel, multiplication, and quotient-echelon times. Independently project the selected columns and verify rank with the archived PLUQ ranker. Treat all local times as exploratory stage diagnostics. A solver gain requires charged elimination, solution extraction, and point verification on frozen ordinary queries.
