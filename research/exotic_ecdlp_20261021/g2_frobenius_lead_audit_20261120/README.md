# N31 Frobenius lead resolves to target-conditioned elimination

The archived N31 S₃ system has an exact Frobenius transport between conjugate targets, but the fixed-target degree-four Macaulay matrix lacks the proposed direct self-symmetry. The two archived parameters each have a 31-element Frobenius orbit. Squaring the leaves and target transports all 31 Boolean coordinate equations exactly; holding the leaves fixed produces a different equation stream. This rules out a simple same-target permutation block split from that action.

The earlier primary-component basis was tested on the full 16,399-row construction at the same archived parameter. Both bases have rank **15,841**. The code basis has **2,107,769** row nonzeros and the component basis **2,110,510**. The representation change therefore did not reduce this frozen matrix's incidence. This is a structural result, not a timing comparison.

The surviving engineering lead is target-conditioned elimination. A frozen 15,856-column information set preserved full rank for **14 of 16** fresh parameters. The other two retained rank **15,835** instead of **15,841**; their full-width echelon profiles each expose 11 pivots outside the trained set. The next experiment in [PROTOCOL.md](PROTOCOL.md) repairs these projections adaptively and charges the rank check, added columns, elimination, reconstruction, and point checks. A gain requires the complete charged single-target PDP path on frozen inputs and resources.

The [audit](audit.py) checks SHA-256 identities and these exact fields in five source receipts. Its [PASS result](audit-result.json) is a replay of archived records, not a new solver measurement. The first two audit executions stopped on receipt schema mismatches (`primary` versus `component`, then integer versus list for the information set); the final source resolves both and passed.
