# Sparse reduced-core kernel correctness gate

Replace only the dense nullspace step after LP elimination in the registered F127 quartic point-relation collector with sparse scalar Lanczos on AᵀDA. Adapted from repository N4v2/la2.rs, a known algorithm; engineering, not novelty. Candidate consumes runtime INPUT-QF.txt, fresh point list and relations; no prior point logs. First run candidate, then independent old dense reference. Require all129logs projectively equal with a common nonzero scale, all original relation residuals zero, and same point list. Dense reference is verifier only.

Matrix-free reduced-core application stores sparse rows, row preconditioner and O(n) vectors. Return only nonzero vectors whose residual on original A is zero; AᵀDA alone is insufficient over a finite field. At most32deterministic random-diagonal/vector attempts, cap n+5iterations each; retain every breakdown. No dense candidate fallback. Zero results and corruption of a coefficient with nonzero corresponding vector coordinate must reject.

Additional positive controls: dimensions47,128,512; four seeds0..3 each; planted x_i=i+1, rows (i+2)e_i−(i+1)e_(i+1), rank n−1 exactly because each leading coefficient is nonzero. Require returned vector proportional to planted vector and independent corruption/zero rejection. Twelve cases, no outcome-dependent selection. These sparse banded controls do not establish realistic large-core timing or distribution.

Freeze all source, locked dependencies, quartic and binaryhashes in Git, S3 checkpoint and gate before first execution. Run once into run/ stdout/stderr/exit; stop first failure, retain, no silent rerun without amendment. No timing, larger-field, exponent or tenfold claim. The earlier collector still constructs full rows densely before LP reduction and keeps m=48; this gate removes only reduced-core densification, not all scalability limits or fullcold integration.

Cost rationale: Diem's plane-quartic DLP theorem gives expected soft-O(q), versus hyperelliptic genus3 double-large-prime soft-O(q^(4/3)). Applicability and setup/transfer costs must be proved and charged. Source: https://jtnb.centre-mersenne.org/articles/10.5802/jtnb.815/ ; GTTD https://eprint.iacr.org/2004/153.pdf . Existing N4v2 results concern a different family and are not transferred speedup evidence. Genus2/4, novel improvement and 10x remain open.
