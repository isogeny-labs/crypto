# Anchor-only collisions with source/target columns in the LP core

For a valid reduced full-degree Mumford divisor D=(u,v), set h_t=v+t u. Two distinct signed anchor points Pi away from u=0 with equal (yi-v(xi))/u(xi)=t force two known factors of the norm. Then

    Q_t=(f-h_t²)/(u*(x-x1)*(x-x2))

is monic degreeg-1, since f has degree2g+1 while h_t² has degree<=2g. Exact norm divisibility follows from u|f-v² and the anchor interpolation conditions. F=y-h_t has no polynomial vertical common factor. Its zeros give D+P1+P2+E=0 in degree-zero Jacobian notation. Repeated nonbranch support is retained through divisibility by u; reduced branch support has multiplicity at most1, and its local y-uniformizer gives the same identity. This is standard divisor arithmetic, not a new theorem.

Evaluate u/v/inverses only on H anchor abscissae and bucket both signs: at most2Hsheets, instead of the full rational catalogue. Scan/catalogue setup, inversions, polynomial formation and division, root finding, graph and LA all remain costs. For genus2 Q is linear; genus3 quadratic; genus4 cubic. This is a degree reduction conditioned on an anchor collision, not a uniform-distribution or guaranteed-yield statement. Do not infer factorial or tenfold runtime gains from degree alone. Different t values may still yield dependent rows; one pair per t avoids counting the same split fibre repeatedly.

The source and target divisor classes are represented by core variables s,t with s=1 and t=k, alongside anchor logs. A source relation places +s on its norm row; a direct split decomposition has -s. Target rows use analogous coefficients on t. Up to two unresolved catalogue endpoints are eliminated by the existing affine weighted forest. Crucially its potentials include BOTH source/target variables, so a target partial can survive until principal rows resolve its endpoints. Pure core equations feed incremental echelon; a determined k is checked in the original group and by a separate sparse scalar solver. This joins source/target descent and relation collection rather than requiring a completed anchor-only descent before collection.

An odd-prime cyclic projection supplies catalogue logs when ell²>#J and source has orderell. The correctness gate also exhibits h coprime ell killing all catalogue points after multiplication by ell, checks raw relations in the original group and pure rows using [h]P,[h]source,[h]target. Branch-place2torsion is zero under this projection; it is retained in original-group raw checks. The certificate is extra gate work, not a free production oracle. Final verification [k]source=target remains mandatory.

The finite candidate is bounded: one input pencil, direct split input rows where available, then at most1024unique principal tuples/4096draws. A missing input row, source connection, rank or useful principal relation can fail. Prefix anchors differ from Compact's target-seeded selection. This is a structural sampling/integration candidate with established mathematics, not yet a cost advantage or breakthrough. A complete timed claim would include setup, failed rows, tails and all verification on identical inputs.
