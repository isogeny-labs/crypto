# Exact quotient dimension and a sharp monomial cutoff for the JV example

Lean proves that the actual homogeneous coordinate algebra of the first
printed Joux–Vitse toy system has dimension eight over F101. It constructs
the basis (1,x,y,h,xh,yh,h²,h³). It also proves h³ is outside the actual
source ideal, so the earlier all-high-monomial cutoff of four is sharp.
The proof uses explicit polynomial identities and actual linear maps,
with no assumed Gröbner basis or native Hilbert output. [pcc:unverified]
