# Deferred affine expansion in the relation solver

Test whether postponing expansion of affine expressions reduces work on forest links that never enter a constraint. Compare four fixed arms on the eleven curves in INSTANCES.tsv, four planted input pairs per curve and a budget of 512 anchors. Use the source, target and walk seeds in main.rs. Reuse each pair and walk seed across all arms.

Arm 0 runs the original normalized pencil solver. Arm 1 uses the previous carried solver for genus three and the double-width linear-residual sieve for genera two and four. Arms 2 and 3 keep arm 1's schedule and use the new expression graph and incremental elimination. Arm 2 materializes every installed link immediately. Arm 3 materializes it on first use by a constraint and caches the result. Compare arms 2 and 3 to isolate deferral. Compare arm 3 to arms 0 and 1 for full-solver effects.

Audit the graph solver against the existing linear solver at each admission. Require equal outcome, anchor count and accepted row count across arms 1–3. Check each returned scalar by curve multiplication and against the planted scalar. Require one counted run and twelve rotated-order wall observations to reproduce each audited outcome. Include eligibility and preparation in the wall measurement. Report medians, per-genus ranges, failures, expanded links and total base-field plus subgroup REDC counts. Evaluate the 10× goal across the entire fixture panel against the original baseline. Push source, input hashes and protocol to Git before running. Verify the remote commit and hashes first, then run once with a 600 CPU-second cap.
