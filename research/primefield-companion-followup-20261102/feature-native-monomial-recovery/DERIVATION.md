# Adaptive recovery with the combined character monomial

The monomial source is now bound to the frozen adaptive consumer and quartic recovery program. An initial window retains its geometry tail, the last two monomial pairs and the middle x-coordinates for all selected multiplier lanes. Each nonanchor extension forms the product of coordinate differences raised to the fixed monomial exponents, then applies one homogeneous recurrence. This is the product law derived in feature-native-monomial-transport/DERIVATION.md; its conditional seed-law and prime-field domain are unchanged. [pcc:unverified]

## State invariant

After count rows, previous represents W at row count-1, older represents W at count-2 when count>=2, middle_x contains the selected multiplier x-coordinates at count-1, and the geometry tail is positioned for row count. The extension advances geometry once. Anchors are selected before a recurrence; a nonanchor with count<2 initializes directly. Otherwise the recurrence uses previous, older and middle_x. The transition shifts previous into older, stores the new pair and its x-coordinates, increments count and decrements the finite extra budget. [pcc:unverified]

At length1 the older vector is intentionally empty: the next nonanchor uses the direct branch before indexing it. O, P and 2P anchors prevent a zero predecessor from entering the recurrence across infinity. The inherited monomial -P anchor uses exponent parity. skip_sign performs this entire state transition and omits only the geometry residual/character evaluation. A skipped first extension can therefore still need direct phase/value initialization. Initial length plus extra budget is checked for overflow and against the configured window cap. [pcc:unverified]

The source consumes the resulting monomial directly with the unchanged geometry-only residual. Quartic program construction/evaluation are generated byte-for-byte from the preserved batch-reciprocal adapter, with only the source interface and initial-work fields adapted. Runtime input is a public point. Test scalar labels construct fixtures and verify returned values; they are not source inputs. No target scalar table is introduced.
