# Removing terminal power and reciprocal work

For binary exponentiation, after consuming the last bit the base square is never read. Shift the exponent first, and square only when the remaining exponent is nonzero. For n>0 the exact multiplication-call count becomes bit_length(n)-1+popcount(n), one fewer than the predecessor. For n=0 the helper still returns1 with zero multiplication calls. The exponent-r-minus-two event is unchanged. The existing modulus/domain contracts remain; this variant does not extend the helper to modulus0.

For batch inversion let v_0,...,v_(N-1) be nonzero canonical field elements and P_i=product_(j<i)v_j, P_0=1. The caller constructs P and verifies the canonical inverse of P_N. At descending index i the accumulator is P_(i+1)^(-1): multiplying it by P_i produces v_i^(-1), and multiplying it by v_i leaves P_i^(-1) for the next index. At i=0 the accumulator already is v_0^(-1). Multiplying it by P_0=1 and subsequently updating it to1 are both unnecessary.

The new private helper processes i=N-1 down to1, then assigns the accumulator directly to output0. It requires canonical inputs/inverse and the caller-established prefix relation; it checks prefix length and leading1, but does not redundantly reconstruct the prefix or verify its inverse. All four integrated callers retain their previous nonzero/product-inverse checks. Empty input with prefix[1] is accepted without arithmetic. Singleton input directly receives its canonical inverse. The reversal count is2*max(N-1,0) scalar multiplications, rather than2N for nonempty N. No forward-prefix work is removed.

Integration covers Modes::compile, CoeffStream::take_desc, SharedCoeffStream::take_desc and ProgressionValues::evaluate_normalized. In the compiled constructor, the existing denominator vector becomes the inverse output in place, replacing a separate zero-filled output allocation; it is no longer read as denominators after that point. Fused/neighbor-specific counted helpers and source-field arithmetic are deliberately separate implementations and are not claimed to have this new tail.

Combining the terminal-square change with each integrated nonempty Fermat batch saves three scalar multiplication calls by source derivation: one square and two tail multiplications. This is an event-count identity for the stated paths, not a measured runtime claim. The previous shared-step/factorial setup also benefits from one fewer square. Historical derivations in predecessor directories describe their own immutable helpers and are not rewritten.

Qualification uses an independent fixed64-step left-to-right exponent oracle, including exponent0, values through129, 2^63, 2^63-1 and u64::MAX. It checks exact counts and values for canonical bases in four small prime fields. Batch checks include lengths0,1,2,3,7,16, repeated nonzero factors and independent reciprocal identities. The inherited progression, public recovery and coefficient checks run without capture. Producer checks remain unsigned until independently reviewed. [pcc:unverified]
