# Bounded negative phase split

Optional recover_split_negative_image adds a trace_trials budget (0..64) to
the preceding public recovery adapter. Eligible negative even-n initializers
use two degree-n/2 factors per quartic orientation when a checked eighth-root
trace is found. Exhausted search retains the prior unsplit route.

From this directory run python3 generate.py, then compile:

```
rustc --edition=2021 -O -C overflow-checks=yes --emit=link,dep-info driver.rs -o /tmp/negative-split-check
/tmp/negative-split-check
/tmp/negative-split-check --inherited
```

These are deterministic software checks. DERIVATION.md states domains, costs
and the duplicate-orientation invariant. Scalar enumeration is fixture-only;
the runtime source is point-based. No default policy or original-cohort change.
