# Classification before any launch

The planned native invocation checks a fixed, completely enumerated finite
permutation object and fixed actual-curve polynomial/local identities. The
planned Lean invocation checks a stated quantified arithmetic dependency.
These are correctness/proof checks, not an experiment, sampled benchmark,
search for cryptographic instances, an original owner workload, or an
ECDLP performance claim. Under AGENTS.md checkpoint rule "A command that
is not an experiment run may opt out with CHECKPOINT_SKIP=<reason>", a
specific CHECKPOINT_SKIP will state this classification. GitHub stores
complete source/input/protocol checkpoints before first strict execution.
No S3 experiment-gate pass is asserted. An actual later experiment or
benchmark must satisfy its S3/EKS gates; this classification cannot waive
those gates or the pending original whole artifact custody requirement.
