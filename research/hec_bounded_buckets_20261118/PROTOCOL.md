# Bounded storage for signed hits of a pencil slope

At a full-degree anchor, each scanned abscissa with u(x) nonzero and slope t corresponds to one root of the degree g+1 residual norm quotient. At a fixed x the two signs give different slopes unless y=0, which the scan inserts only once. Thus each slope has at most g+1 hits and at most five on this panel.

Arm 0 original normalized solver. Arm 1 current lifted solver with per-slope vectors and a ready bitset. Arm 2 records hits in fixed five-point arrays per slope and sorts the qualifying slopes. Arm 3 counts hits first, allocates five-point arrays only for qualifying slopes, and recovers their points in a second scan of already computed slopes. Compare complete ascending slope order and ordered point lists with the original bitset implementation in audit mode, including slopes that never produce admitted relations. Preserve the same relation assembly, admissions, group checks and fixed baseline width. Require identical scalar, admissions, anchors, cutoff and joins across arms 1–3. The scan cache and all storage are per invocation. All workloads, controls, rotation and 512-anchor cap match the lifted study. One counted run and twelve rotating full-call times per arm per target. Report verified coverage, ratios of medians and unchanged or differing REDCs. Tenfold requires the same policy across all 44 inputs against arm 0. Git freeze and binary checksum precede a single run capped at 600 CPU seconds.
