their committed Git blobs. The two frozen comparisons report 342 ablation

checker recomputed 766 individual timing ratios and 32 input-cluster

\medskip\noindent\textbf{Code check.} On the final source,
\texttt{cargo test --release --lib} passed 4,474 tests with zero failures
and 119 ignored. A pre-fix parallel run exposed cross-thread contamination
of an opt-in profiling counter; the switch is now local to its requesting
thread, with a cross-thread control. Solver arithmetic and archived timing
records are unchanged.

\medskip\noindent\textbf{Boundary.} This historical page distinguishes a
local specialization gain from the unproved full-DLP improvement. The graph
and all rendered exports remain unchanged because their measured source and
conclusion did not change. Interactive JavaScript behavior could not be run
here because Node was unavailable. This audit does not validate all historical
experiments, prove their implementations in Lean, or establish current public
dashboard deployment. The full evidence and commands are in
