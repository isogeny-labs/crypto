# Remaining transfer acceptance checks

The constructed cusp class is an actual nonzero order-11 class in the mixed
carrier. Its projection onto the desired CM sign factor is not established.
A nonzero image of this class is a useful sufficient positive control for a
candidate map. A zero image does not prove that the candidate map is zero on
the whole intended factor: it requires identifying the actual source subgroup
or testing another bound class. Do not turn this control into a universal
nonexistence criterion.

The F2 modular-factor transfer still needs actual function-field identities,
coefficient/descent compatibility, a binding to the intended Koblitz subgroup,
and the required kernel/recovery certificate. R22's integral abstract maps
and d=1 certificate must be bound to those geometric maps. An arbitrary
nonzero source Jacobian class is not that binding.

Likewise, base E49 closed-divisor cancellation at degree460 does not identify
the colored C5 deck offset. The completed ordinary image data is an input to
full source/kernel lifting and the reverse divisor evaluator. It is not a
substitute for arbitrary collector-class evaluation or an IC-rank claim.
