# Next independent ordinary collectors and the larger-support padding gap

This is a prospective lead, not a point count or a completed experiment.
The ordinary degree-83 orbit now gives a nonzero source order-11 class after
cofactor 61. The next useful test is an independent collector input, rather
than another representative of that same ten-point deck orbit.

First verify the actual diamond action on the saved class R=61E by computing
the shifted signed divisor and comparing T(R) with [6]R. The shared residual
character is a consistency check, not a CM-sign selection mechanism. The two
sign factors remain congruent at 11 and require an actual integral map/kernel
test even if this equality passes.

A bounded new collector search can start over F128. Use a verified native
field, enumerate the elliptic base parameters, and solve the complete source
conditions in the descent coordinates. For this diamond twist, the physical
coordinates are lambda=lambda_d+(1+c)T and nu=nu_d+bT with T²+T+1=0.
Over odd degree seven, solving only the untwisted original equations directly
in F128 would test a different curve. Require all five physical source
residuals, eight unit witnesses, all seven coefficient conjugates, least
closed-point degree seven, and the actual diamond/Frobenius orbit binding.
The existence or abundance of such points has not been measured here.

A certified ordinary degree-seven point R7 would serve two purposes. It gives
collector classes outside the current forward-derived degree-83 orbit, and
it fills the larger degree-460 padding gap: 460+9·5+7=512. There must be an
actual point and complete local data before using this arithmetic identity.

For comparisons using the existing degree-128 base, one can investigate
D_i=P_i+3R7+20Q, whose degree is 7+21+100=128. Repeated supports must be merged
first: if P_i=R7, the condition is multiplicity four, not separate partial
conditions. Construct the complete coupled vanishing spaces and verify every
valuation, source identity, inverse, descent condition and rank before feeding
them to the class engine. Then apply E, compute the cofactor, check the full
annihilator and test independence from the saved ordinary order-11 class by
exact class equality over all eleven scalar multiples.

Do not assume the new class has the old order 671 or least cofactor 61. The
known complementary order 3721 supplies a candidate only under the retained
mixed-carrier/twist bridge; every new input still needs its own annihilator
and 11-primary checks. Two independent rational order-11 classes would inform
the finite CM-sum structure, while their intended sign-factor images would
remain separate obligations.

R38 provides the larger algebra but not the complete degree-512 RR spaces.
These collector and padding proposals do not remove the outstanding proper
factor map, quotient saturation, polarized embedding, theta, node187 or full
ordinary degree-367/460 evaluation requirements.
