# R44 source-algebra certificates

Every native run retains its complete Singular input, source revision,
input/runner hashes, original caps, timestamps and exit plus strict output.
An exit0/late marker is rejected if any line begins with Singular's question
mark error. Both20minute timeouts are retained; they are not math negatives.

POINT44_RESULT rows give the actual base degree, twist, kernel/source/physical
relative dimensions5/10/20, orientation trace, Frobenius^d diamond step and
source tuple period. The following labels print full kernel, orientation
quadratic and b,c,lambda,nu. The coefficient field is beta with the original
retained irreducible modulus. Variables(T,Z,X) have lexicographic order:
Xis the cyclic11generator abscissa in its degree5kernel field; Zthe orientation;
Tthe physical auxiliary AS constant. Source descent setsT=0; original physical
coordinates shift lambda by twist*(1+c)*T and nu by twist*b*T, withT²+T+1=0.

All kernel monic/separable/Rabin, normalization, exact Tate11order, original
five equations/eight units at all ten deck iterates, and corruptednu checks
are required. Formula method source run additionally copies and hashes every
accepted algorithm-control receipt in dependency-receipts/. Stage receipts
are partial-check evidence only; full acceptance still requires terminal pass.

The final Frobenius map uses a proved normalized quadratic recurrence and
kernel image xf=X^(2^d); its five compositions are checked against sign on
all four coordinates. The source period uses actual b,c field generation
with all prime-divisor witnesses, plus AS irreducibility. Dimensions are not
substituted for a coordinate-field generation proof.

TRACE44_RESULT records the independently computed orientation/Tate/seven
trace bits and prints full polynomials C,delta,c2. FILTER44_RESULT compares
scalartrace and actual quadratic Frobenius with all retained83/284split flags.
Control outputs retain direct-versus-modular values, matrix inverses against
old Groebner inverses, old-versus-certified periods and direct coordinate
Frobenius comparisons. None of these alone is a target Picard image.
