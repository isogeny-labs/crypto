# R46 input/output encoding
Same coordinates, physical quadratic coefficient descent and canonical point-row format as R45/FORMAT.md. ROOT46.rs uses increasing-degree polynomial coefficients in the actual binary residue field. Every polynomial division reconstructs dividend from quotient/remainder. GCD monic normalization uses verified field inverse. gcd(common,lambda^q-lambda) is split via all field-basis trace polynomials; final linear factors reconstruct that monic polynomial and each root re-evaluates in the original common polynomial. Polynomial certificates are checked in-process, not separately exported. The complete output point lists are independently compared byte-for-byte with the R45exhaustive scan. No timings or native-code correctness formalization.
