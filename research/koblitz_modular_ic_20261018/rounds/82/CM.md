# R82: global fraction verifier interrupted before data

The frozen source-fraction program loaded its committed input and
checked eight donor hashes. Its native step then entered `std(norid)`
for the full 22-variable/400-relation candidate ring. R50 had already
recorded this as an expensive verifier. The analyst sent SIGTERM after
roughly five minutes to avoid repeating that known bottleneck. The
Singular wrapper wrote exit 0 and an empty native log; the strict
terminal-marker gate correctly rejected the attempt. No one of the 19
fraction identities was checked, so this run supplies no affirmative
or negative algebra claim.

The raw attempt and its checkpoint are retained. The next frozen
version must avoid the global standard basis. A zero reduction against
the saved generating relations is a valid positive ideal-membership
certificate; a nonzero remainder without a standard basis is not a
nonmembership certificate. The negative control should instead use
the selected source-field denominator check, or another independently
certified quotient.
