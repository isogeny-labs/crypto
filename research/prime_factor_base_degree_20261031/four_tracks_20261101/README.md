# Four complete presentations of one factor base

Two label encodings lower the canonical homogeneous degree of the existing
F17 two-summand system while keeping the same signed point set. XOR recoding
uses seven variables and gives degree6; bounded-weight one-hot encoding uses
nine variables and gives degree5. The linear-label control has degree7 and
the same-base dense control degree9. These are exact first-vanishing degrees
of the ideals generated by the actual canonical highest forms, not observed
affine F4 degrees or timings. Final verification receipts are linked below.

The other two requested directions have concrete outcomes: complete symmetric
chord reconstruction with all pivot cases, and an exact 3x3 unit-pivot
membership pencil. Its expanded canonical top ideal has a free ordinate
direction; Schur elimination returns the XOR equation.

Curve: `icv1-fp5-tm1-a77cc6af`, F17, `y²=x³+2x+2`.
Factor base: **FB1h29cc024e755c**, eight columns, sixteen signed points.
Original [issuer metadata and FB1 dump](../pencil_search_20261101/fixture/)
are reused without changing curve registration or identity conventions.
The inherited order19/cofactor1 metadata is not newly proved here.

## 1. Invertible XOR recoding

Write the original offset as `2u+10v`, with Boolean u,v. Replace the first bit
by `u XOR v=u+v−2uv`. The transform is a Boolean involution and gives

`2(u XOR v)+10v = 2u+12v−4uv`.

The exact offset image stays `{0,2,10,12}`. Consequently the graph
`4x²+9x+9+t`, all lifts, and all signed base points stay unchanged.
The actual recoded equations are the secant equations

`m²−x−z−r=0`,
`xz−r²−rm²−2−2ms=0`,
`e(4x²+9x+9+2u+12v−4uv)−m(x−r)+s=0`,
`f(4z²+9z+9+2w+12t−4wt)−m(z−r)+s=0`,

and four Boolean equations. For nonzero signs, canonical row normalization gives

`I=⟨m²,xz,x²−a mx−uv,z²−b mz−wt,u²,v²,w²,t²⟩`,

where `a=(4e)⁻¹`, `b=(4f)⁻¹`. Every degree6 monomial is in I. For a matching
lower witness, the coefficient functional supported on
`x m u v w`, `x²u v w`, `x³m w`, `x⁴w`, with weights `1,a,1,2a`, annihilates I
and takes value1 on `x³m w`. Thus degree5 survives. The proof covers every
nonzero a,b over a field, including the full seven-variable ideal.

[Recoding.lean](Recoding.lean), [RecodedTop.lean](RecodedTop.lean),
[RecodedLower.lean](RecodedLower.lean), [RecodedCanonical.lean](RecodedCanonical.lean)
link Boolean semantics, upper identities, lower witness and actual highest forms.

## 2. Bounded-weight labels

Use three bits per slot with `u_i²−u_i=0` and every pair product `u_i u_j=0`.
The exact allowed words are `000,100,010,001`; weights2,10,12 recover the same
four offsets. Include all six selector variables and all six support products.

In the highest ideal, selector squares and same-slot products vanish. Therefore
at most one selector from each slot survives. The secant core kills all core
monomials of degree3, giving the degree5 upper bound. The map retaining one bit
per slot and setting the other four to zero maps this ideal into the old
five-variable core-plus-two-bit ideal. The degree4 witness `m x u_0 v_0`
maps to its known nonzero top witness when characteristic is not2. This proves
exact degree5, not just an upper estimate or a lower-degree subsystem.

[SupportOneHot.lean](SupportOneHot.lean) includes classification, offset image,
upper/lower proof and the actual added generators' canonical bridge.
[FourTrackFixture.lean](FourTrackFixture.lean) instantiates both degree results
for all nonzero signs of the concrete F17 fixture.

## 3. Complete symmetric chord coordinates

Let `σ=m²−r`, `π=r²+rm²+A+2ms`, `D=σ²−4π`, and reconstruct
`x=(σ+d)/2`, `z=(σ−d)/2`. The chord incidence equations become two linear
equations in d, together with `d²=D`. [SymmetricChord.lean](SymmetricChord.lean)
proves equivalence with the original full scalar system in characteristic≠2,
for arbitrary signs and graph coefficients.

For `d²=D`, `a d+b=0`, `c d+h=0`, the complete elimination charts are:

1. `a≠0`: `b²=a²D` and `a h−c b=0`, recovering `d=−b/a`.
2. `a=0,c≠0`: `h²=c²D` and `c b−a h=0`, recovering `d=−h/c`.
3. `a=c=0`: `b=h=0` and a square root of D **in the base field** exists.

No chart is discarded or replaced by algebraic-closure solvability. The native
six-variable export retains d explicitly. A smaller saturated chart alone is
not a complete degree or search-cost result. Canonical degree for this arm and
complete branch-summed solver work remain to be checked.

## 4. Unit-pivot determinantal membership

The affine pencil

```text
[y−b x−c−l0     x    l1]
[      a x     1     0]
[       l2     0     1]
```

has determinant `y−(a x²+b x+c+l0+l1*l2)`.
Its kernel has the complete normalization `[1,−a x,−l2]`, with no chart loss
because the bottom-right block is the identity. Substituting
`l0=2u+12v`, `l1=−4u`, `l2=v` gives the XOR graph exactly.
[Determinantal.lean](Determinantal.lean) proves all these identities.

Expanding both memberships and keeping ordinates yields13 variables. The actual
quadratic leading forms lose both ordinate variables, while the four linear
kernel rows also omit them. Evaluation sending yP to1 and every other variable
to0 annihilates the entire top ideal, but sends every power of yP to1.
[DeterminantalTop.lean](DeterminantalTop.lean) proves this obstruction for the
actual nonzero quadratic forms plus arbitrary affine lower terms, covering the
exported system. Thus the expanded canonical quotient has no finite vanishing
degree. The affine system may still have finitely many roots; these are
separate statements. Eliminating the four kernel witnesses and two ordinates
returns track1, whose degree is6. The expansion is not an independent degree win.
