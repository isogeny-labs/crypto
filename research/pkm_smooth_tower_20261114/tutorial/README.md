# Tutorial: index calculus on prime-field curves with smooth maps

[TUTORIAL.pdf](TUTORIAL.pdf) (source [TUTORIAL.typ](TUTORIAL.typ)): a worked,
hand-checkable introduction to Petit–Kosters–Messeng (PKC 2016, slides 12–17)
and the `pkm-smooth-tower` tool. Examples over F_31 and F_101 come from the
recorded tool outputs in [data/](data/); the tree figure is drawn by
[figures/make_tutorial_figures.py](figures/make_tutorial_figures.py).
Teaching material, no performance claim [pcc:unverified].
