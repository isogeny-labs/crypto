## Pruning contract

Original generators are immutable. Candidates are `Row` values carrying original-generator membership proofs. Each deletion is tested against the surviving candidate set, so individually redundant deletions cannot be combined unsafely. Complete, independently replayed closed-space equality is required at every declared cap before accepting a deletion. Equal dimensions suffice because the trial's source roster is structurally a subset of the baseline roster.

Rejections stop at the first label or degree obstruction. `Trial.spaces` is the checked cap prefix; later omitted caps were not computed and convey no degree information. A report status of `complete` means the declared candidate roster was processed, not that every rejected trial evaluated every cap. Censored ranks never justify removal, and a trial-budget exit retains every candidate not safely removed.

Optional `LabelSystem` rows must correspond exactly to candidate rows. The scalar prime is separate from the coordinate prime. Pruning preserves the full augmented `[R|a|b]` row space, including potential target-log information; preserving R alone is insufficient. Curve/subgroup validity remains a caller obligation. No group-row metadata exists for the six polynomial fixtures, so their label audits are explicitly inapplicable. Abstract scalar37 tests never set `curve_scalar_verified=true`.
