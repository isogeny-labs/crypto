# Integration checker preparation — not frozen, no trials

The existing fused kernel panel is the numerical owner. Its terminal checks
must be reconciled before integration execution. This directory contains the complete runner and analyzer source, but lacks a
frozen protocol and input/source locks. The runner also requires all upstream

`audit.py` runs the actual production FusedSchur adapter for each source query,
checks its result independently against dense A using integer NumPy arithmetic
with an explicit N(r-1)^2<2^63 bound, and verifies every fixed kernel counter
against separate formulas. It retains per-query input/output hashes, count
deltas and native event offsets. Native multiplication bit descriptors are
recomputed from event records; non-product bit volumes are preserved and
summed. Their standalone independent correctness belongs to the frozen kernel
panel, not to an alleged second integration proof.

`check_ledger` checks forward/transpose schedules, sums complete nested source
ledgers, adds the separately specified Schur/lift operations and requires exact
meter equality. Unexpected nonzero counters fail; explicit zero keys remain.

`lift_checks.py` adds to each valid-leading-block context three residual
fixtures: zero, ones and seeded b,z,v. Every singular S adds a public normalized
left-null fixture. This decision is deterministic from reference RREF, not a
filter that excludes nonsingular S. Each fixture checks all three transport
identities, source results and nested ledgers; altered leading coordinates,
reduced RHS and source-call counts must fail. Normalized tests also reject
zero witnesses and a doubled-RHS pairing. The imported certificate checker
uses separate unbounded-integer residual sums.

Combined lift schedule per fixture: two forward source calls, one transpose
source call; two forward leading solves and one transpose leading solve;
additional m+2n field subtractions. Reference oracle work:3n^2 dense terms and
3n reductions. Leading obstruction schedules remain separate: RHS fails before
source application; primal fails after one forward query and n RHS subtractions;
dual fails after one transpose query before head negation.
