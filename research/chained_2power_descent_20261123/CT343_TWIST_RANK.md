## Derived result

For p>5, C_d: y^2=d product_(j=1..6)(x-j), d nonzero, has the same rational Weierstrass pairing kernel K generated by W6-W1 and W2-W5 for the bielliptic product pushforward. Its third nonzero class is W3-W4. This uses the CT340 geometric kernel premise; twisting transports the degree-two covers and kernel (the twist involution acts trivially on 2-torsion). It does not identify the twist group or its DLP with the untwisted group.

With z=1/(x-1), eta=y*z^3, c=-120d, X=c*z, Y=c^2*eta, the monic odd-degree polynomial has roots X_i=c/i, i=1..5. For T_i=W_(i+1)-W1 the five descent coordinates are X_i-X_j for i!=j and the product of the four differences X_i-X_k for i=j (local leading coefficient at a branch point, modulo squares). Multiplying coordinates computes the character of a sum. For d=1 the squareclass matrix on K1, K2 is respectively (6,1,1,6,1), (2,-2,-2,2,1); K3 is their product modulo squares. These follow directly from the integer roots (-120,-60,-40,-30,-24). Scaling each root by d multiplies off-diagonal differences by d and diagonal derivatives by d^4. Thus with bits a=chi(6), b=chi(2), cbit=chi(-2), t=chi(d), the two rows over F2 are

    (a+t, t, t, a+t, 0)
    (b+t, cbit, cbit, b+t, 0)

where chi is 0 for square and 1 for nonsquare. All columns are copies of the first two or zero. The determinant is (a+t)cbit+t(b+t). Rank two is equivalent to injectivity on K. By quadratic reciprocity, all three bits depend only on p mod 24, so the following is an all-prime classification for this fixed family, not a statistical extrapolation.

Rank 2: four distinguishable kernel points. Rank 1: two distinguishable signatures. Rank 0: all kernel points share a signature. In general, for A=J(F_p), the full split odd-model descent character map has kernel 2A (standard Kummer connecting injection A/2A -> H^1(F_p,A[2]) and split-Weierstrass evaluation). Thus dim(K intersect 2A)=2-rank, conditional on the geometric kernel premise and standard descent identification. No system of quadratic characters can separate this intersection. For p congruent to 11,19,23 neither twist choice has full rank. A twist that has higher rank is not a remedy for a DLP on the original source group. At F103 and Prime31, p=7 mod24, both original and nonsquare twist have rank 2; the original kernel signatures at the first two coordinates are 00,10,01,11 and the twist signatures are 00,01,11,10. The Prime31 assertion is only a kernel-character calculation, not a full divisor or solver execution.

```python
#!/usr/bin/env python3
"""CT343 fixed-family character rank: public algebraic checks only, no timing."""
import json, math, sys

def need(ok, msg):
    if not ok: raise ValueError(msg)

def bit(x,p):
    y=pow(x%p,(p-1)//2,p)
    need(y in (1,p-1),'zero squareclass')
    return int(y==p-1)

def direct(p,d):
    # X=c*z, c=-120*d, roots X_i=c/i; monic odd model.
    roots=[(-120*d*pow(i,-1,p))%p for i in range(1,6)]
    need(len(set(roots))==5,'distinct roots')
    mat=[[bit((r-s) if i!=j else math.prod(r-t for k,t in enumerate(roots) if k!=i),p)
          for j,s in enumerate(roots)] for i,r in enumerate(roots)]
    k1=mat[4]; k2=[a^b for a,b in zip(mat[0],mat[3])]; k3=[a^b for a,b in zip(mat[1],mat[2])]
    need([a^b for a,b in zip(k1,k2)]==k3,'kernel sum')
    return k1,k2

def formula(p,t):
    a=bit(6,p); b=bit(2,p); c=bit(-2,p)
    if '--bad-twist' in sys.argv:t=0
    return [a^t,t,t,a^t,0],[b^t,c,c,b^t,0]

def rank(rows):
    a,b=rows
    return (len({tuple([0]*len(a)),tuple(a),tuple(b),tuple(x^y for x,y in zip(a,b))})-1).bit_length()

def isprime(p):
    return p>1 and all(p%d for d in range(2,math.isqrt(p)+1))

primes=[p for p in range(7,501) if isprime(p)]+[2147483647]
classes={};examples={};counts={"original":[0,0,0],"twist":[0,0,0]}
for p in primes:
    d=next(i for i in range(2,p) if bit(i,p))
    rr=[]
    for t,factor,label in ((0,1,'original'),(1,d,'twist')):
        observed=direct(p,factor);predicted=formula(p,t)
        need(observed==predicted,f'formula mismatch {p} {t}')
        r=rank(observed);rr.append(r);counts[label][r]+=1
        a,b,c=(bit(x,p) for x in (6,2,-2))
        det=(a^t)*c ^ (t*(b^t))
        need((r==2)==bool(det),'determinant mismatch')
        if p in (103,2147483647):examples.setdefault(str(p),{})[label]={'rank':r,'rows':observed,'d':factor}
    k=str(p%24)
    need(k not in classes or classes[k]==rr,'residue dependence')
    classes[k]=rr
need(len(classes)==8,'missing residue class')
print(json.dumps({'schema':'ct343-twist-rank/v1','primes':len(primes),'checks':2*len(primes),'rank_by_residue_mod24':classes,'counts':counts,'examples':examples},sort_keys=True,separators=(',',':')))
```
