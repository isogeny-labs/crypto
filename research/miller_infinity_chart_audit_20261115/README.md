# Actual infinity chart localization and normalized orders

Lean proves that the actual chart-function image algebra generated by `t=X/Y` and `z=1/Y`, localized at its actual origin, is isomorphic to the norm-degree valuation ring. The isomorphism preserves the actual function-field inclusion. The official normalized maximal-ideal adic valuation of this localization equals the norm-degree valuation on every field element, giving line and vertical pole orders −3 and −2. This proves the specified chart-localization/order bridge; the full finite-point principal divisor and pairing remain open. [pcc:unverified]

## What is proved

[ChartAlgebra](lean/ChartAlgebra.lean) constructs the actual coefficient embedding into the existing valuation ring and the image algebra generated by the actual fractions `X/Y` and `1/Y`. It derives a finite-type Noetherian domain and proves the exact Y-chart relation
`z*(1 + a1*t + a3*z - a2*t² - a4*t*z - a6*z²) = t³`. Every actual chart-function residue comes from a coefficient. [pcc:unverified]

[OriginEvaluation](lean/OriginEvaluation.lean) derives an actual surjective ring homomorphism to K. It fixes coefficients, sends `t,z` to zero, is uniquely determined by those values, and has kernel exactly `(t,z)`. Evaluation and the origin ideal are proved properties of the actual image algebra. [pcc:unverified]

[ChartLocalization](lean/ChartLocalization.lean) localizes at that actual maximal ideal. The source bracket evaluates to one, so it becomes a unit. The curve relation then places `z` in the ideal generated by `t`; the actual localized maximal ideal is `(t)`. Lean proves `t` nonzero and derives the actual DVR structure through the Noetherian local-domain theorem. No DVR or local-unit premise is supplied. [pcc:unverified]

[LocalComparison](lean/LocalComparison.lean) constructs the explicit localization map into the norm-DVR and proves it injective. [ChartFractionField](lean/ChartFractionField.lean) proves that the chart algebra and origin localization both have the full actual elliptic `FunctionField` as fraction field: `t,z` recover `X,Y`, then actual coordinate-ring basis expressions and actual fractions. [DVRIdentification](lean/DVRIdentification.lean) uses actual DVR factorization and the valuation bound to prove the map surjective. Its explicit `RingEquiv` commutes with the actual function-field inclusion. No inverse or fraction-field equality is assumed. [pcc:unverified]

[ChartAdicValuation](lean/ChartAdicValuation.lean) uses Mathlib’s official normalized adic valuation of the local DVR’s height-one maximal ideal. Its parameter has value `exp(-1)` and its units have value one. Actual unit-times-parameter integer-power decomposition proves equality with the norm-degree valuation everywhere. The resulting negative-log pole orders are exactly −3 for nonvertical lines and −2 for vertical lines. [LocalOriginEvaluation](lean/LocalOriginEvaluation.lean) gives an explicit isomorphism from the actual local residue field to K and proves its exact residue/evaluation formula. [pcc:unverified]

Correct `t³*line` and `t²*vertical` normalization is retained. Replacing `t` by `1/X` makes the normalized-line difference have valuation one, violating the required strict inequality. This is an actual control against changing the parameter; the qualified source formula survives. [pcc:unverified]
