# Independent mathematical review

For odd prime p and a nonsquare d, K=Fp(theta) with theta²=d is a quadratic field. Frobenius fixes Fp and sends theta to the other root -theta. Thus x=(t+t^p)/2 and y=(t-t^p)/(2theta) belong to Fp and uniquely satisfy t=x+theta*y. A source pair in the declared domain Fp by Fp exists exactly when u=x²+theta*y², and then that single ordered pair is the entire root set. Zero or equal coordinates need no exceptional branch. A proper source subset requires explicit membership checks. Characteristic two cannot use division by two, and no actual elliptic-curve chart has yet been proved to have this invertible source-linear output.

The source domain is essential: this is not the unconstrained two-variable polynomial root problem over all K. An independent oracle may enumerate all p squared ordered Fp pairs once and index their outputs; it must compare every q squared target rather than favorable supported targets. Field encodings are coordinate labels, not integer ring operations. Generic candidate exponentiation and independent closed-form pair arithmetic are separate implementations suitable for this small correctness experiment.

The stated GF9 target (1+theta,0) has no source under outputs (x,y,x²,y²), since its first two coordinates force x=y=1. Each of four coordinate functionals and four adjacent sums nevertheless has a separate source witness. This proves independent functional feasibility need not give a common source. The joint projection (x,x²) rejects (1,0). The counterexample concerns the separately declared prime-subfield domain, not the older domain containing theta.

The implementation may cache all q inverse t values for an all-target comparison; if so measured storage is O(q) plus O(q²) output records, even though the uncached structural criterion can be evaluated per target without such a cache. Known Frobenius identities and linear coordinate inversion are classical. Completeness for this special family does not establish novelty, global curve coverage, hard-instance qualification or a generalized speedup.
