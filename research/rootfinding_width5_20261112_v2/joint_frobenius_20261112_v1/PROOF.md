# Exact structured Frobenius inverse and its measured batch contract

This fresh variant changes the prior extension diagnostic's domain and map explicitly. Sources are ordered (x,y) in the prime subfield Fp, and outputs are t=x+theta*y and u=x²+theta*y² in K=Fp(theta), theta²=d a declared nonsquare. This is not a curve chart, an original-system solver, or a novelty claim.

For odd p and nonsquare d, theta^p=-theta. Hence the unique possible source at a specified t is x=(t+t^p)/2, y=(t-t^p)/(2theta). Both lie in Fp, reconstruct t, and uniqueness follows from the linearly independent basis (1,theta). The target has exactly one ordered source if its u equals x²+theta*y²; otherwise its root set is empty. Sources with x=y or either coordinate zero are retained. There is no multiplicity suppression: the first map is a bijection, so each target's source set is intrinsically empty or a singleton. Characteristic two is excluded; division by2 is not admitted there.

Candidate source coordinates must encode prime-subfield elements (imaginary coordinate zero); equality of coordinate labels alone is not treated as a general ring embedding.
