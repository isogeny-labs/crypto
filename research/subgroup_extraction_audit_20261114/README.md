# Prime-subgroup extraction needs the correct modulus

Lean refutes the unqualified algebraic implication that a nonzero coefficient modulo the ambient group order suffices to extract a logarithm. It proves corrected recovery modulo the actual prime subgroup order, gives an unbounded prime-order cofactor family, and checks an actual 30-point elliptic curve with an order-five point.
