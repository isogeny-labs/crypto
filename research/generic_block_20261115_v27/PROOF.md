# Prepared signed generic-field fiber reconstruction

The backend implements the constant-image/domain-complement proof using ordinary field addition, subtraction, multiplication and inversion. It uses explicit subtraction in Gaussian elimination and lifting: E v=b-M U z for a particular residual solution, and E v=-M U z for residual kernel directions. These signs cannot be copied from the XOR implementation unchanged. With Q spanning the annihilator of image(E), Q M U z=Q b is equivalent to a nonempty lift fiber. The complement decomposition and homogeneous kernel give every original affine solution, with independent basis checks.

The solver is field-generic for a backend with canonical0/1 and exact add/sub/mul/inv. The supplied prepared arithmetic supports odd prime fields and quadratic extensions Fp[t]/(t^2-nu), with nu a verified nonsquare. Primality of p is a precondition, not proved by this class. Other extension degrees are not implemented by this arithmetic class. Binary packed arithmetic remains separate. Empty, zero-rank and inconsistent systems have explicit affine semantics.
