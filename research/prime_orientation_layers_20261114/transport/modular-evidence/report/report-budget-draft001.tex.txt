\textbf{Exact invariant.} For Packed object$s$, define
\[
 \mathrm{Budget}(B,s):\quad 0<s.d\le2^B,\qquad
 |n|\le2^B\text{ for every integer literal }n\text{ in }s.e.
\]
This bounds the denominator and expression literals. It is not a bound on
all dense polynomial coefficients, nor a cost of building the object.
Rational atoms use the existing actual reduced numerator/denominator Bits
predicate. Arithmetic add/multiply budgets are$B+C$; negation preserves$B$.
Cross-denominator literals inserted by addition are bounded from actual child
denominators. Powers/products use$Bk$ or sums of budgets; geometric clearing
also uses$Bk$, with$k=0$ and empty products handled explicitly
[pcc:unverified].

\textbf{Actual instantiation.} Preserve the actual signed grid, retained
node and bounded-port hypotheses. Let
\[
 H=2^{a+1}(2a+1),\qquad
 S=(a+1)+2H+i+\sum_{j<u}(2j+i+1)m_j,
\]
\[
 A=3a+2,\quad F_j=2j+3a+3,\quad P=2^{a+1}A,
 \quad C=\sum_{j<u}F_jm_j.
\]
Actual affine root charts have budget$A$, factor charts have budget$F_j$,
and the puncture product has budget$P$. This charges the entire grid upper
bound, not a favorable small source set. Actual normalizer and diagonal
budgets are$H$ and$S$, derived from scalar Bits and their exact finite-product
identities [pcc:unverified].

Actual row and denominator expressions have budgets
\[

Thus the actual Packed approximation has budget

The derivation uses actual grid, mask, slopes, normalizer, diagonal and row
constructors. No favorable representation, literal height or denominator
witness is supplied. The bound is deliberately conservative; no optimal
height or improved runtime is asserted [pcc:unverified].

\begin{center}{\Large Static encoding volume and work precision}\end{center}
Collect explicit integer leaves into a static literal list. Its length equals
\texttt{castLeaves}, the previously proved number of explicit literal-cast
events. For sign/magnitude encoding, define
\[
 \mathrm{width}(n)=\mathrm{Nat.size}(|n|)+1.
\]
If$|n|\le2^B$, the exact Nat.size lemmas give$\mathrm{width}(n)\le B+2$,
including zero and negative integers. Therefore
\[
 \sum_{n\in\mathrm{literals}(e)}\mathrm{width}(n)
 \le\mathrm{castLeaves}(e)(B+2)
 \le\mathrm{nodes}(e)(B+2).
\]
For the actual approximation, the prior actual node bound$N_*$ and newly
derived$B_A$ give static input volume at most$N_*(B_A+2)$. This bounds an
encoding, not the cost of constructing, reading or reducing those integers.
The current event tag records cast kind without payload; a payload-sensitive
or weighted operational correspondence remains a next obligation
[pcc:unverified].

For actual right label$(r,b)$, form$B_R=b+B_A(r,y,k)$. The actual scalar-only
right denominator is positive and satisfies
\[
 0<d\le2^{B_R},\qquad E=v_2(d)\le B_R,

Here$p$ is auxiliary binary precision, not the elliptic-curve field prime.
