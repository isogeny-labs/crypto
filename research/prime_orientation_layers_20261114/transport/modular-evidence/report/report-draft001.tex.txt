\textbf{Exact signed scalar reduction.} For an actual integral rational$q$
and constructed representation$n=dq$, with$n\in\mathbb Z$ and$d>0$, set
\[
 E=v_2(d),\qquad d=2^E o,\qquad o\text{ odd}.
\]
Integrality derives$2^E\mid n$. Reduce the numerator first modulo$2^{p+E}$,
divide its unsigned integer residue by$2^E$, then invert only the odd part:
\[
 \operatorname{reduce}_p(q)=
 \left(\frac{n\bmod 2^{p+E}}{2^E}\right)o^{-1}
 \quad\text{in }\mathbb Z/2^p\mathbb Z.
\]
Division is integer division before entry into the final residue ring.
There is no inverse of2 in characteristic$2^p$. Negative/zero numerators and
$p=0$ remain covered. The unsigned representative is linked to signed integer
reduction by the pinned Mathlib \texttt{ZMod.val\_intCast} theorem
[pcc:unverified].

\begin{center}{\Large Derived actual denominator and work precision}\end{center}
Use actual signed grid$[-2^a,2^a)$, nonzero retained node$t$ with$v_2(t)=i$,

multiplicity or favorable local jet is added to the domain. Let
\[
 H_a=2^{a+1}(2a+1),\qquad
 S=a+1+2H_a+i+\sum_{j<u}(2j+i+1)m_j.
\]
These are the earlier actual normalizer and diagonal rational-size budgets.
The bound$\operatorname{Bits}(B,q)$ controls both reduced numerator and
positive denominator by$2^B$; inversion preserves that bound
[pcc:unverified].

Let$r(x)=x\bmod2^u$ and$M(x,y)$ be the actual mask. Define exactly
\[
 F(x,y)=\sum_{j\in M(x,y)}(j+a+1)m_j,
\]
\[
 B_N(x,y)=(3a+2)+S+H_a+F(r(x),y),
\]
\[
 B_D(x,y)=(3a+2)+(u+2a+1)
       +\sum_{j\in M(x,y)}(u+j+a+1)m_j.
\]
Every actual affine root chart contributes denominator1: its coefficients
are integers. The factor-chart numerator also contributes denominator1;
only its actual inverse displacement denominator is charged. Finite products
combine these with actual normalizer, diagonal and chart-slope denominators.
This derives the row numerator bound$2^{B_N}$ and geometric bound$2^{kB_D}$,
without a supplied small-height witness [pcc:unverified].

For actual label$(r,b)$ and creation index$k=\max(0,p-w)$, the constructed
right denominator satisfies
\[
 d_{r,b,y}\le2^{B_R},\qquad B_R=b+B_N(r,y)+kB_D(r,y).

Coefficient extraction and trimming retain that denominator; the noncrossing
zero branch uses denominator1. Hence
\[
 E=v_2(d_{r,b,y})\le B_R,\qquad p+E\le p+B_R.

Every mask term and multiplicity remains charged. These are explicit upper
bounds on a constructed denominator, not an optimal precision claim or a
runtime bound. They may substantially overestimate the reduced denominator

\begin{center}{\Large Coefficient boxes and the actual expression bridge}\end{center}
An arithmetic expression uses integer literals, inner/outer variables,
addition, negation and multiplication. Construct actual expressions from
the representation constructors, sorted finite products, repeated powers
and the cleared geometric recurrence. The actual denominator expression is
constructed too; it is not a supplied witness [pcc:unverified].

An$h\times z$ box stores coefficients$[H^bZ^n]$ with$b<h,n<z$.
Zero extension and antidiagonal convolution give exactly the same retained
coefficients as full polynomial arithmetic. Evaluation over
$\mathbb Z/2^q\mathbb Z$ agrees with casting the integer polynomial result.
One convolution uses
\[
 \sum_{b<h}\sum_{n<z}(b+1)(n+1)\le(hz)^2
\]
scalar products, and each individual box has$hz$ slots. This is neither a
complete ring-operation count nor an overall memory bound: recursive
intermediates can occupy multiple boxes [pcc:unverified].

For a requested coefficient, the actual approximation expression is evaluated
in a box$(b+1)\times(n+1)$ at$q=p+E$. The actual inverse-power numerator,
trim-zero and noncrossing branches then feed finite extraction. The theorem
\texttt{OrientationNumeratorCode.boundedRightEntry\_correct} equates this
formula with the canonical actual absolute-right coefficient at creation
precision. There is no reevaluation of immutable creation data at a larger
precision [pcc:unverified].
