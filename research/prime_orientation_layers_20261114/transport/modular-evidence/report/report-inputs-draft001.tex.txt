\textbf{Actual recursion.} On an LSB-first Boolean list, recurse on its tail,
then call the existing addition primitive twice:
\[
 v'=v+v,\qquad v''=v'+\begin{cases}1&b=\mathrm{true},\\0&b=\mathrm{false}.\end{cases}
\]
Append the two actual addition events and record the bit read. The empty list
returns zero. The signed routine folds the magnitude bits, then invokes one
negation for a negative constructor. It returns the ring cast of the original
integer, including zero and negative values. Exact source results are
\[
 \#\mathrm{reads}=\mathrm{Nat.size}(|n|),\qquad
 \#\mathrm{additions}=2\,\mathrm{Nat.size}(|n|),\qquad
 \#\mathrm{negations}\le1.
\]
For $|n|\le2^B$, these imply reads$\le B+1$ and additions$\le2(B+1)$.
Read order is the reverse of the supplied LSB-first list, matching the recursive
value computation. Primary sources are the pinned Mathlib Nat Bits, BinaryRec
and Size implementations and their exact bit-length identities. Standard binary
evaluation is reused without a novelty claim [pcc:unverified].
