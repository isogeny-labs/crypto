# Dedicated witness capture v2 receipt contract

2026-10-30. Minimal additive receipt change to preserved v1, same base9bfe5bcae18fb3007730bf5bae8cea098138647d. Outside-worktree source only, no activation or budget/deadline change.

Both emitter and bound bridge return Result<WitnessReceipt,WitnessError>. Receipt is fixed Copy data: commit WitnessCommit(NewCommit/AlreadyCommitted), payload_sha256 [u8;32], payload_bytes u64, sequence Option<u64>, provenance WitnessProvenance(Dedicated/LegacyAdopted). Standard path/role/encoding are fixed by this API. Dedicated acknowledgement and later retries carry the original Some(sequence); adopted legacy identity carries None and LegacyAdopted. Central replay resolves the latter through the verified committed event prefix, not the current head. No event digest is promised: verified event lookup supplies that binding independently.

Construct the receipt only from emitter-owned validated identity, after new durable acknowledgement or successful existing-payload integrity verification. Errors including IndeterminateIo return no receipt, never synthesize historical acknowledgement from a possibly installed head. Sticky failure and global event debits unchanged. A caller retains an earlier successful receipt across later failure; that persistent caller state receives its own fixed admission.

Requested helper layout adds size_of<WitnessReceipt> to WitnessScratchLayout, covering the returned fixed data alongside existing identity. No payload allocations, buffers, clones, hashes or I/O operations are added. Existing fixed helper control tariff covers selecting and copying these bounded fields; no tariff is lowered. Existing exact/one-less requested_bytes controls follow the actual layout. Add explicit new/dedicated-retry/legacy-adoption receipt controls, unrelated later event preserves original sequence, and indeterminate failure yields no receipt/global acknowledgement even if restore observes a durable event. Existing tests retain all prior assertions through receipt.commit.
