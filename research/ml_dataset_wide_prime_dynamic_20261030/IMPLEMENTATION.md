Caller setup is excluded; production callers must subtract the bound once from original cumulative limits. Every-arity useful controls use the remaining work/bytes after the fixed131072/4096 setup reservation. There is no PrimeField implementation or square-root placeholder in this module.

All1..28 active dimensions are admitted. Mono28 stores28u16 coordinates, enforces a zero unused tail, uses explicit grevlex over active coordinates, checked products/quotients and no packed/tower operations. Inputs are strictly canonical, degree<=32, total<=8192terms, <=256polynomials; canonical chain maximum677fits. Native pair cap<=12 is distinct from input/processed row degrees.

The real F4 loop uses product criterion only, stable ordinary pairs, deterministic lowest-degree selection, actual two-sided S-polynomials, symbolic closure by stored-leading-term divisibility scans, bounded columns, reducer-first matrix echelon and subsequent exact polynomial normal reduction. Initial generators undergo deterministic polynomial normal reduction rather than allocating an initial matrix; the Initial boundary admits the input row count and indicates native preprocessing entry, not successful matrix execution. Matrix counters and the required useful-control pivot update distinguish these phases. This is an explicit ordinary F4 preprocessing choice; no changed ideal or substitute group enumerator.

No basis IDs are removed/reused. New basis storage precedes pair generation, so every retained pending pair has valid IDs even if insertion is interrupted. `pairs_pending` counts stored pairs, not ungenerated candidates after a failed insertion. Such a stop always has native_statistics_complete=false; it is not a resumable checkpoint. Selected pairs remain stored/in-flight until the whole batch and insertions finish. UnitDerived may stop with pairs pending because an actual monic constant is already retained; Complete requires none. DegreeLimit never means complete. Failed terminal callback/deadline overrides success. Stored basis on a partial result is useful retained producer evidence, not an independent derivation proof.

Every native dynamic allocation uses checked Layout and try_reserve_exact under cumulative byte admission. Vec growth reserves the full new capacity conservatively. Inputs/observer memory are outside native ownership. Returned basis storage is moved, not cloned; its coefficient-conversion work is reserved when each basis is retained, including after later stops. Working matrix uses a single reused dense u64 accumulator and sparse pivots with eager field operations, no lazy-capacity/parallel allocation assumptions. Frontier membership scans and all coordinate scans are charged; queue selection reserves96*(V+1)*(P+1) for its bounded passes. Row accounting includes initial admitted generator count; peak column/pair counts and completed steps are reported for exact-boundary controls. All counters are modeled reservations, not hardware instructions or RSS.

Deadline is min(original absolute deadline,entry+5s), cooperative before allocations, callbacks, rows, reducer searches and bounded inner chunks. In-place sort is a finite bounded noninterruptible chunk under external supervision. No duration reset between batches. Callback failure unwinds immediately without further callbacks. Metadata/error/events are fixed-size, no String errors. Empty/zero ideal and genuine constant unit have explicit semantics.
