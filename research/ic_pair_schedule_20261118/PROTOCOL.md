## Hypothesis and frozen arms
H1 (engineering): at B=16 and 25% of all unordered pairs, a simple O(B^2) *distance-round-robin topology schedule* reduces the median **cold, single-target counted EC group additions** by at least 10% versus the R2 seeded random-prefix schedule, across 24 paired seeds, with >=22/24 independently verifiable complete DLP solves per arm. It must not regress by more than 5% at B=32 and 50% of pairs (secondary 24 paired seeds). H1 is falsified if any of these conditions fail. Do not redefine thresholds after run.

Use a *single public synthetic known-answer toy curve*: E over F_1009, y^2=x^3+4x+10, group order r=1069 prime, base G=(0,162). Freeze n=16, 24 seeds: seed0=0x1c2026111850, and n=32, 24 seeds seed0=0x1c2026111840. Factor-base scalars are drawn exactly as in R2, random.sample(range(1,r),B), seed `seed`; target k and Q=kG use same RNG, start scalar generated from seed^0x72d1. All 24 B32 seeds and first 8 B16 overlap with R2 controls. No tuning on held-out outcomes.

The baseline table order is all i<=j shuffled with random.Random(seed ^ 0x65f3), and take exactly ceil(f*M) pair entries. The candidate order is: permute vertex labels with Random(seed ^ 0x9bb2), sweep circular chord offsets d=1..floor(B/2), shuffle the unique unordered edges at each offset using Random(seed ^ 0x9bb2 ^ (d*65537)), append all diagonals last (in label-permutation order), take the same prefix length ceil(f*M). There is no access to any factor-base point/scalar when picking candidate edges. This is O(B^2) scheduling. Both pair tables compute each pair with one affine EC group add (including duplicates of point sums), select the first relation witness for each output point, and use the same sequential scalar walk, parity-union rank rule, exact graph linear solve, and descending target search as R2.

Each seed has a random-prefix baseline arm, a repeat A/A baseline (counted scientific metrics must match), a candidate arm, a full random table control, and a matched seeded 4-partition rho. Count affine group additions for constructing factor base, table, collection and target descent, and separately count field modular operations in graph LA.
