For a partition with fixed prefix length k and retained exact model x, child j for every k<=j<n fixes x[0..j] then flips bit j. Every other assignment in the parent has exactly one first differing free bit j. Thus the children are disjoint and cover the parent minus exactly x. Fully fixed models correctly generate zero children. Construction checks witness prefix consistency and retains the witness search. The independent coverage audit reconstructs original equations plus each prefix, rechecks each native search/BQI proof, checks child count/order and exact complement prefixes, and requires parent indices to precede children with reciprocal unique membership. These checks rule out missing branches, repeated/disconnected children, and fabricated source prefixes within the declared bounded conditional scope.

Only CandidateRetained states expose a callback. with_candidate_owner checks the same session owner and original deadline before invocation, lends that exact exclusive owner together with the immutable retained candidate and original deadline, then performs a final same-owner/deadline admission check. Its output is stored in CandidateCall.value before final admission. A failed final admission therefore returns the owned output, marks the session Unknown with sticky failure, and prevents exclusion/next. The control uses an owned model vector and explicitly checks it survives refusal. The consumer must immediately retain the returned value, including the error case; Session itself does not store arbitrary callback output. Callback costs belong to the original parent ledger and intentionally are not counted in Attempt.charge. Both documentation and the test explicitly account for this difference.

Exclusions remain caller-supplied u64 records, not checked cryptographic exhaustion certificates. Neither callback return nor exclude(record) authenticates a signed-domain verdict. The final enum deliberately says RemainingBooleanModelsExhaustedUnderRecordedExclusions. Production integration must retain and bind each exact model, actual checked map, signed domain/target, classified ExhaustedForModel progress and successful callback admission to the corresponding partition record before exclusion. Generic rejection, cap, owner error or deadline must not exclude. Duplicate record IDs are not rejected here; a future evidence binding layer must prevent ambiguous record lookup. No unconditional no-lift, pattern UNSAT, authentic map provenance or full original-owner worker integration is established by this component.

The published controls meaningfully cover all eight unconstrained three-bit models without duplicates, several independent truth-table ideals, source/split/parent/exclusion mutations, delayed exclusion, partition limits, variables above 128, owner-refusal sweeps retaining splitting state, and callback owner identity/deadline/postcheck custody. Failure leaves diagnostic partial state; this is not a restartable allocation checkpoint. No frozen packet was edited, no cloud action or scientific generation occurred.
