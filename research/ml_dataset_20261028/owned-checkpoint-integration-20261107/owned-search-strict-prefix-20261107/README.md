# Strict schema-directed retained wire prefix admission

The proposal adds a child module to the unchanged native decoder, reusing Reader, Meter, Spec, Value and original limits. It checks type/shape incrementally before accepting EOF. Truncated bytes never pass merely because the complete decoder returned Truncated.

`strict_prefix::admit(raw, limits, deadline, owner) -> Audit` returns an immutable audit retaining raw bytes, consumed offset, parser node count and accepted charges. State is IncompleteIdentityUnavailable before the first three complete root fields, IncompleteIdentityAvailable after complete schema/snapshot_index/identity and only if the entire observed suffix is valid, or CompleteWire for a fully consumed valid encoding. binding_prefix() returns only those first three complete fields, never an unfinished Value or complete search snapshot. It returns None on every error, including malformed later suffixes. Original source authentication and historical report/capture joins remain caller responsibilities.

Observed magic/tag/type, exact field order/count/key prefixes, schema literal, fixed byte/hash lengths, lowercase acknowledgement hashes, UInt32 bounds, bool values, and final encoding_complete=true are checked as soon as bytes suffice. Partial little-endian numbers are checked using their revealed lower bound; fixed numbers also compare each observed byte. UTF-8 must be extendable within the declared text length: invalid continuation/overlong prefixes and an incomplete four-byte code point in a declared two-byte string reject. Generic Any diagnostics remain bounded valid wire values; generic object keys must be unique. Those generic diagnostics do not acquire an unstated semantic schema.

One shared owner and absolute deadline govern parsing. Refused resources are never reinterpreted as valid prefixes, and the final EOF transition performs owner/deadline admission. Prefix validity concerns observed bytes; it does not guarantee enough remaining supply to materialize a future suffix. Partial text/bytes are length-capped but copied/allocated only when complete. Known containers reserve their bounded capacity before descent. All input ownership must already have been admitted by the caller.
