# Independent bounded wire inspector

This Python implementation independently reads the producer's `OWNSEARCH\x01` tagged binary stream. It inspects explicitly ordered chunk files without joining the entire stream in memory. The tagged format has null, bool, little-endian u64, UTF-8 text, bytes, list and map values. A fixed root field order binds the declared `owned-search-retained-evidence/v1` schema, snapshot index and four original source hashes. The final `encoding_complete=true` sentinel certifies complete encoding only; the inspector never interprets it as solver completion.

The inspector rejects truncation at every byte boundary, trailing bytes, invalid tags/booleans/UTF-8, duplicate map keys, wrong root/identity field order, wrong schema, malformed hashes, false completion sentinels and admitted byte/value/depth/string/map bounds. Raw byte bodies are consumed in blocks of at most64KiB; nested payloads are not materialized. The CLI accepts at most4096 explicit input chunks and opens them lazily, one at a time. The streaming SHA256 covers the exact concatenated bytes inspected.

Usage: `python3 inspect_wire.py CHUNK0 CHUNK1 ... --max-bytes 134217728 --max-values 2000000 --max-depth 64`. Chunk order is caller-provided. Limits are finite and refusal is not proof that an artifact is mathematically invalid.

This is structural wire inspection, not authenticated capture-chain verification, source reconstruction, mathematical replay, private-data clearance or a proof of last/first fall degree. It checks fixed root/identity shape; it does not validate every nested algorithm-specific field. The output labels producer_status as producer data and sets mathematical_replay=false and capture_chain_verified=false. Missing versus empty structures remain distinct on the wire. Semantic replay must separately reconstruct/authenticate the original map, equations, proofs and signed arithmetic and verify the existing emitter-owned event chain.

Eleven independent synthetic format/adversarial tests pass. They include byte-by-byte chunking, rejection of every truncated prefix, exact byte caps and malformed declared lengths. These tests use an independent small test encoder, not a substitute original solver. Cross-decoding the actual Rust producer fixture passed: a92745-byte stream and361 ordered chunks of at most257bytes yielded identical inspections and SHA256. CROSSCHECK.json binds that result; the Rust fixture uses real retained structures with synthetic source identity. No scientific rows or cloud jobs are produced.
