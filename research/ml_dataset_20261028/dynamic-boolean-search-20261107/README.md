# Search V2: continue after local native closure caps

Immutable V1 is preserved. Native scheduler and sparse donor bytes are unchanged. search.rs records an explicit NativeDisposition per node: Complete, LocalCap or Stopped. A retained native Err(Cap) can seed subsequent search only when the parent bridge recorded no failure and the same parent owner/deadline passes another admission check. Parent/global admission failures, native deadline/owner/allocation/malformed/overflow failures remain terminal. No resource pool or absolute deadline is reset.

Only native.basis committed rows can seed unit inference or constant-one branch refutation. Uncommitted batch/staged rows are diagnostics and never authorize either. Every returned model still undergoes exact original and node equation evaluation. Failed models still cause actual two-child splitting. A fully assigned invalid candidate without a committed native refutation remains Unknown/Cap after capped closure; it is not mislabeled UNSAT. Native complete=false and Err(Cap) remain visible even if independent original evaluation later yields a witness.

Controls add a one-batch cap with retained unit producing a verified model; a degree2 cap on1+x0*x1 followed by real branch continuation; one-batch cap with committed constant-one refutation; parent-stop sweep under capped-native execution; and the intentionally too-small degree1 profile on1+x0+x1 that remains Unknown because child refutation rows were not committed. Earlier assumptions that the latter fixture should solve failed in tests-r1.log (15pass2fail); its actual limitation is now an explicit negative control. Corrected continuation controls use the same finite native limits for each node under the unchanged cumulative parent budget, never larger test-only resource allowances.

The original search suite, proof-origin checks, both-child execution,130-variable witness, all-check refusal sweep and global work/deadline checks are rerun. test.receipt.json records exact tested source/binary hashes and unchanged readback; tests-verified.log is final evidence. No independent BQI certification, signed curve lift, ECDLP completion, CLI admission, large-n experiment or scientific generation is claimed.

Retention means partial diagnostics, not every scratch buffer or a restartable checkpoint. An unfinished copied_poly, empty_node, forced-value vector or transactional scheduler arithmetic scratch can be dropped on refusal while accepted work/allocation charges remain. Committed nodes/equations/origins, native attempts, queue/child links and completed candidate vectors remain available; no checkpoint restoration has been verified.
