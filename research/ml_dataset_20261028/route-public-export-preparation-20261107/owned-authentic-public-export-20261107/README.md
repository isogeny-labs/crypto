Existing old fixture cells lacking these fields cannot be rewritten or reused by this acceptance path. Native stdout/stderr are actual process streams redirected directly into mandatory cell stdout.log/stderr.log before dispatch; preparation logs stay outside the cell. ## Acceptance checks

The real public invocation must return success and write a terminal receipt with historical mode, exactly one nonfailed historical scope slot and exactly one restricted projection. It must produce exactly one prefix record, one restricted target and one index record. The test recomputes target and record hashes using the separate historical domains, checks index/feature statuses and exact label joins, checks the historical aggregate without the legacy aggregate, requires unavailable feature/scalar/witness fields remain null, and reapplies exact complete/partial-tail qualification to the actual exported record. A notification, a partial export directory or a producer claim cannot satisfy these checks.

Public dispatch result and any receipt-read error are preserved; a missing or failed real receipt is not manufactured into success. The public policy is available only after direct success and a full remaining60s public allowance. A failure can preserve an incomplete export, but no public-acceptance.json success receipt is written until all checks pass.
