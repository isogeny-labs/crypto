# Historical checkpoint route: independent source review

No blocking source defect found in the frozen central, solvers wrapper, caller and export changes identified by SOURCE_BINDINGS.json. This assessment is source review with inspection of saved focused-test receipts. It is not a full assembled crate typecheck or completed authentic-cell historical export. No production changes, compilation, cloud jobs or Conductor actions were performed by this reviewer.

The route preserves these admission boundaries:

- Central historical entry requires the supported explicit checkpoint policy. Original inputs and raw manifest/config/outcome are admitted before deriving expected channel disposition. The narrow supervisor envelope rejects normal producer reports and unknown extensions; observed reason is labeled unverified. Canonical outcome hash is correctly distinguished from raw manifest hash.
- Full capture replay verifies map/payload/event custody and contiguous snapshot/chunk publication. Every complete snapshot receives wire and shared source/map/receipt binding checks. Only final full-decoder Truncated can enter strict-prefix admission; unavailable identity and all shape/resource refusals produce no candidate. The failed full decoder remains retained, and the extra prefix raw buffer is prepaid.
- All decoding, prefix parsing, binding comparisons, selection, descent, semantic certificates, revalidation and projection use the retained Frame budget and original deadline. Binding comparisons have a postcheck. One selector result chooses one complete snapshot, and audit_snapshot is invoked once. A selected complete snapshot's descent or proof failure returns immediately; no older-row retry exists. This no-mathematical-fallback finding is source control-flow evidence, not an end-to-end test result.
- The authentic map moves into retained descent custody; authenticated_map accesses it there for subsequent revalidation/projection. Retained failed states, all raw chunks and tail remain available. Allowed head stops are explicitly enumerated finite limits or none; StorageFailure is rejected.
- Historical projection has a separate schema/verdict and names selected checkpoint receipt separately from terminal capture head. Tail descriptors include individual artifact lengths/hashes and receipts. No-tail means none_observed. It emits original auxiliary Boolean descent and committed-row scope, restricted visibility, null public features/degrees and false producer completion/report-join/scalar/exhaustion claims.
- Revalidation checks raw original/context/manifest/head bytes and every chunk including tail, plus descriptor fingerprints and final head equality. Failure makes central success invalid. Projection is one-shot and any projection error poisons the verdict. The caller keeps failed slots sticky and reuses the retained owner for successful revalidation; it never replaces an incomplete owner with new funds.
- Caller policy modes and verdict acceptance are disjoint. Generation is refused for historical mode at invoke and helper dispatch boundaries. Solvers dispatches the historical central entry explicitly. Caller projection checks the matching schema/status. Export separates historical target/record identifier domains, feature/index statuses and aggregate counts, rejecting unsupported legacy records in historical mode while retaining restricted/null-feature output. Existing terminal v1 behavior and report join remain distinct.
