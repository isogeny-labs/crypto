# Original-owned Boolean candidate to signed relation proposal

Concrete external, uncompiled source extending the owning search/worker transport proposal. The authentic retained CheckedMap and Math are now wired to the existing checked-model verifier under the original cumulative ledger, addition allowance and absolute deadline. No shared/frozen source or scientific dataset is modified.

## Exact donor contracts

The signed-lift wrapper is copied byte-for-byte from dynamic-boolean-signed-lift-adapter-20261107/adapter.rs. Its underlying checked_model.original.rs is byte-identical to the staged source's cryptanalysis/checked_binary_sat_model.rs. Gate variable index w-1 equals the verifier's model index; there is no guessed coordinate/sign conversion. The verifier checks actual allowed signed points, original binary field/curve, chain prefixes, identity flags and exact signed target. It returns generic semantic rejection for several causes, not a certified no-lift classification.

The staged OriginalOwner's Math retains both signed domain and signed_target, including Option::None for identity. This is a required source dependency; the older main owner's Math lacking signed_target cannot compile this increment unchanged. No raw domain, target or map is accepted from the external caller.

## Implemented connection

OwnedAttempt now owns checked_model::Progress, one-shot lift state and raw lift outcome before verifier entry. After checked expansion, Search V2, structural/BQI audit and successful MatrixComplete transition, a Boolean Witness invokes lift_candidate. The candidate comes from that same retained search; its map comes from OwnedExpansion.source(); domain/target come from the same moved Math. The code checks successful audit and exact-model admission before consuming the candidate.

LiftAdmission forwards work/bytes/checks to Budget::reserve_checking/check and each group addition to Budget::reserve_addition. begin_extraction(true) is required, matching the actual matrix path. The unchanged original absolute deadline is also forwarded to the donor wrapper. No refreshed phase timeout, budget, sink or execution token is created.

The result preserves VerifiedSignedRelation, RejectedUnclassified, Stopped or Deadline. Deadline/stopped admission failures preserve original sticky stops and owned progress. A rejected candidate remains unclassified and does not refute any search pattern. Success remains in Extraction so future same-owner capture/publication can still be charged; finish_extraction is not called prematurely. If a post-lift owner check fails, the public accessor does not expose a successful outcome, while raw outcome/progress remain owned for diagnostics.

The existing worker transport still retains OwnedAttempt and emits report-unavailable after parent adoption. It does not fabricate a published, full-solve or scalar-recovery outcome. A verified signed relation is one model/pattern's PDP relation, not complete requested dataset production or all-pattern exhaustion.

## Remaining continuation/publication work

Search V2 stops at its first Boolean witness. This proposal preserves that witness, unresolved nodes and lift progress but does not resume Boolean search after rejection. Generic RejectedUnclassified is not safe grounds to exclude every signed solution for that model or to declare PDP unsatisfiable. The root is preparing a separate classified donor outcome that distinguishes completed sign-choice exhaustion from malformed inputs; this packet intentionally does not depend on that unfinished change. Upgrade the donor/wrapper only after its independent review, then implement exact model continuation under the existing owner without rerunning OriginalOwner admission.

Prepaid capture of model/lift progress and immutable terminal acknowledgement, central original-source/model/lift replay, complete exceptional identity-pattern coverage and actual versioned CLI dispatch/export remain required. Retained Progress is diagnostic, not a coherent restart checkpoint: the donor may have a pending path point ahead of the last completed sum when stopped. No native-operation/instruction witness or broad privacy proof is claimed.
