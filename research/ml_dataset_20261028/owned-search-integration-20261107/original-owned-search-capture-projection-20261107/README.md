# Borrowed native owning-attempt capture projection

This component supplies an immutable projection of the authentic owning Boolean-search attempt. It preserves original admitted public/factor/launch/binding hashes, map bytes and existing map acknowledgment, original signed domain and target, raw failed expansion, normalization cursors and equations, continuation partitions (including nested native search/proofs), retained lift records, conditional coverage, and fresh exclusion replay audit. Construction only accepts `&OwnedAttempt`; no arbitrary source map, equations, domain, target, verdict or identity is accepted.

`capture_projection::View::of` is constant-space. Paged access and `page_retained` return borrowed slices, including nested retained data, without cloning or scanning them. The explicit per-page limit counts elements, not nested bytes, actual work or serialized bytes. Zero limits and invalid cursors fail, end cursors produce a terminal empty page, and `usize::MAX` limits do not overflow. A raw continuation/audit accessor distinguishes absence from an empty retained vector. Raw failed audits remain available even when a status gate refuses them.

Status precedence is owner failure/sticky stop, accepted signed relation, successfully replayed retained model exclusions, conditional Boolean coverage, then incomplete. The source-integrated owner defines these gates; a successful retained sub-audit cannot mask a later owner refusal. Replayed exclusions are scoped to this exact owner attempt. No global pattern-negative, complete ECDLP, last-fall degree or persisted-delivery claim is emitted.

## Actual capture contract inspected

The bound `src/ml_dataset/capture.rs` defines `AttemptBinding`, `CommittedEventPosition`, and `CaptureEmitter::payload_borrowed`. The latter accepts a complete `&[u8]`, validates a short flat path/role/encoding, computes artifact digest/length and maintains its existing custody protocol; witness publication must use its dedicated route. This projection does not invent a wire schema, convert owner identities into a replacement `AttemptBinding`, call the writer, acknowledge publication, serialize to an unbounded Vec, or expose mutable owner data. Its `map_ack` is the existing map acknowledgment, never an acknowledgment of these projections.

The precise next integration is bounded admitted serialization of each selected retained artifact into complete byte slices, followed by existing bound capture publication and retained failure/receipt handling. Current capture has no generic streaming-object API. Encoders must account for nested vectors/proofs and serialized bytes separately; a page limit alone is not an encoding bound. Actual writer/replay round-trip and all owner/CLI activation remain unfinished.

## Sources and integration

Read the actual capture API, owned expansion API, owning continuation adapter, independently replayed exclusion adapter, and continuation/verifier records before choosing this interface. `SOURCE_BINDINGS.json` pins those sources. This is software interface/custody work, with no new mathematical method or external novelty claim. `registration.patch` adds a child module to the exclusion-integrated owner; child placement permits read-only access to private fields without making them public. Copy both new modules next to the owner before assembly. Root coordinates any policy-entry patch against the same owner. Proposed/base adapter files are included solely for exact patch review.

Seven tests compile and execute actual `borrowed_page.rs`, covering borrowed non-Clone/address identity, nested allocation identity, no gap/repeat paging, huge limit arithmetic, invalid/zero cursors and empty/end termination. `tests.log` and `TEST_RECEIPT.json` preserve results. They do not compile `capture_projection.rs`, the production owner, capture writer, or CLI. No full Cargo build, scientific run, Conductor action, cloud operation or additional SAT rebuild occurred.
