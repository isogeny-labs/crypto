# Pre-token original artifact registry checkpoint (patch only)

Problem: verify_and_store_worker_originals writes verified originals and returns their token while roles live only in the worker's in-memory registry. A killed worker may never write worker-artifacts.json, so collect_cell_artifacts demotes public.json and factor-base.json to unregistered partial artifacts. Central original admission consequently rejects an otherwise durable checkpoint prefix.

The patch adds an immutable worker-originals.json containing exactly the actual public/witness/factor storage receipts, after verification and before returning the original-worker token. Failed checkpoint publication propagates before producer authority. This is a separate path; final worker-artifacts.json publication remains unchanged. Its descriptor joins the in-memory registry and is reserved against backend publication.

Collector fallback reads at most8193bytes, requires a regular bounded file, strict schema and exactly3fixed ordered descriptors, verifies exact path/role/encoding/SHA-256/length against durable originals, and promotes only those validated receipts. With a final registry present, all3originals and the checkpoint descriptor must join exactly; missing entries, duplicate paths or metadata conflicts reject. No original descriptor is reconstructed by filename after interruption. Without the checkpoint, legacy collection behavior remains unchanged.

Eight meaningful tests are included in the patch: collector recovery without a terminal registry; exact final coexistence; legacy absence; malformed/extra/duplicate/wrong-role/encoding/count checkpoint; original hash mutation and size cap; final missing/duplicate/role/missing-checkpoint conflicts; reserved path plus storage refusal; and actual verify_and_store_worker_originals publication failure returning no token. These tests have NOT been compiled or executed under the current source freeze.

Files: implementation.patch, proposed3source files, the2existing source bases, preparation script and source bindings. The patch is reviewed source only, not activated. No native/CLI compile or runtime, cloud operation, candidate edit or Conductor action was performed. Before launch, this shared production fix must be applied/validated and the genuine worker/supervisor interrupted-prefix test must use that shared code, not a fixture-only role workaround.
