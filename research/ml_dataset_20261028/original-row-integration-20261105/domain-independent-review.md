# Independent domain-encoding design review

Accepted for implementation, with the integration obligations below. This reviews the mathematical construction and executable Python model; it does not certify Rust implementation, native cost, producer success or dataset completion. No production source edits, Rust builds or native runs were performed.

Verified all frozen prototype manifest hashes. Independently replayed its Python selftest with exact recorded result: 282 codebooks, 10,264 coordinate/selector assignments, 78,720 individual gate-output corruptions. Added exhaustive enumeration of every auxiliary assignment for three small non-affine examples (512 complete assignments), using direct polynomial evaluation rather than the prototype's topological assignment helper. Each original code has exactly one satisfying complete extension; other original coordinates have none. CHECKS.json and check.py retain this evidence.

The affine argument is correct under the explicit sorted, distinct, in-range input contract. Elimination computes a reduced basis of all original differences. Containment follows by construction, and equality of distinct cardinality with 2^rank establishes equality with the affine hull. The nonpivot equations solve each nonpivot coordinate from pivot coordinates with the required translated constant. Singleton, full-space and empty cases are accounted for. Cardinality alone without uniqueness, or unchecked overflow, would be unsound; these must remain checked-source invariants and checked arithmetic in Rust. The Python public encode validates them, but its internal affine_rows assumes them.

The selector argument is sound and complete in the Boolean quotient. Topologically ordered fresh gate equations uniquely force each equality indicator; disjointness of indicators makes the valid-index sum equivalent to a valid selector. Distinct codebook entries give a unique selector for each coordinate. Conjoining untouched chain constraints is sound because gate/selector variables are fresh. The tested gate faults are not enumeration of all joint corruptions, but the topological uniqueness proof covers that distinction; the added 512-assignment independent check directly exercises joint assignments on small examples.

Actual retained-map counts independently reproduced from map hash ff7b21092922b90471ea3a68bc0a608dfce3a83f2dc7ce0323f61cad33ef44fe: 115 original variables; 46 XOR and 46 unit generators; rank-one codebook; 22 affine rows, 43 monomials and 31 variable slots per factor; 158 total generators. For every original domain clause all variable identities are distinct. Expanding its positive-literal complements gives exactly 76,281 raw-domain terms and 1,107,234 variable slots. Existing per-monomial allocation tariff alone yields at least 64*76,281 + 4*1,107,234 = 9,310,920 bytes before polynomial headers/intermediates, already above the local 8,000,000 cap. This is a tariff lower bound, not measured resident memory. Verified every diagnostic receipt file digest and its retained output; did not rerun the native diagnostic. Its accepting owner isolates local limits and cannot establish original-owner success.

Integration obligations: the prototype uses zero-based local variables while retained maps/BQI use positive global IDs. Rust must translate via actual CheckedMap block IDs, never by assuming a local offset, and allocate auxiliary IDs strictly after the complete original map dimension. Bind exact coordinate-block count (first m factor blocks only), ordering of untouched generators, route, pivot convention, selector bit order, gate allocation order, dimensions and complete ordered emitted generators. Empty-codebook emission multiplicity must be canonical. Use private constructor output retaining the actual checked map; parsed metadata/digests alone are not authority. A separate replay constructor must rebuild from independently authenticated original inputs and compare all ordered generators, not merely a polynomial set or its ideal.

The design correctly distinguishes equality of affine domain ideals in the original Boolean ring from selector elimination/contraction in an extended ring. Neither preserves degree filtration or the old unit-multiple span. Keep distinct schema/role/adapter/export encoding identity and distinct experiment arm. An old-encoding row replay must reject new-encoding artifacts. A row identity supplies no exact first/last-fall label.
