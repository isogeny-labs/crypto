# Authentic owner checkpoint callsite

The proposed owner adds Caps.checkpoint: Option<policy::CheckpointCadence> and retains Option<scheduler::CheckpointControl> inside OwnedAttempt. Root owns the policy definition and selection: the legacy ConservativeAffineEnvelopeV1 produces None; the explicit ConservativeAffineEnvelopeCheckpointV1 produces every_batches=1,max_snapshots=16 without raising any original resource cap.

Control is constructed once for continuation, after explicit admission. It remains retained even if a pre-session allocation/expansion guard fails. For the live session it is moved into a local Option captured across every next/exclude iteration; the same control is reinstalled into OwnedAttempt immediately after the session returns, before terminal failure handling. It is never recreated per partition or node.

The owning hook calls EncodingSource::checkpoint_native using authentic borrowed overlay references, live charges, retained lift records, the same MatrixAdmission original Budget, publication, sink and capture limits. It preserves the exact publication Stop in a local slot before returning the required unit error. After next_with_checkpoint returns, the native/search kernel has installed failed child attempts; precise Publication(stop) takes precedence over the generic continuation callback failure. Postcheck failures without an explicit publication error remain continuation failures, with the original budget first stop retained.

No cadence means the existing Session::next path and existing between-exclusion publication behavior remain unchanged. The explicit checkpoint policy supplements those existing source/exclusion snapshots. max_snapshots counts within-search hook attempts, not all source/exclusion/final snapshots. The same original capture resource limits bound the combined publication stream.

Control counters and checkpoint reasons remain retained in memory but are not added to the frozen snapshot wire schema. Current row identity/descent replay does not infer causal completeness or replay scheduling from those counters; snapshots retain actual native/parent states and charges. A future causal checkpoint-schedule verifier would need a versioned wire extension for cadence, attempts and exact control stop, bound to the explicit request. This patch makes no such causal claim.

Publication and MatrixAdmission use explicit structural seams. The new tests preserve exact Trace publication stop with nested retained native state and verify legacy None never calls publication. Complete owner/sink/encoder integration is not typechecked here. No full Cargo build, production policy activation, scientific generation, cloud operation or published source change occurred.
