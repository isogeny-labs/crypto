# Scoped matrix evidence replay CLI

This self-contained Python CLI composes the bounded wire/capture reader, exact equation-lineage checker and independent GF(2) Boolean quotient row verifier. It replays committed native basis identities relative to captured normalized equations plus branch/prefix constraints. It does not use producer success flags as proof.

Commands:

- `python3 replay_capture.py capture /sealed/cell/live --binding CAPTURE_BINDING_SHA --sources trusted-sources.json`
- `python3 replay_capture.py wire /path/snapshot.bin --variables 2`

The capture command verifies the complete committed prefix, payload bytes, map acknowledgement, owner binding and externally supplied source hashes before any row replay. The diagnostic wire command does not authenticate capture/source identity. Its optional variable count is explicit and must equal any retained expansion count; the synthetic Rust fixture requires it because no expansion is present. The capture command offers no variable override.

Default replay limits are5,000,000 work units shared by lineage and row checks,2,000,000 modeled allocation units for row replay, and4096rows across all snapshots. Capture decoding has separate finite byte/event/value/depth limits and a shared selected-state retention allowance. These are software admission counters, not retired hardware instructions or measured RSS. Neither limits nor rejected input create a mathematical verdict.

Only nodes whose equation ancestry passes are used. Global lineage mismatch or cap refusal prevents rows from that snapshot entering replay. Partial builders are explicitly skipped; their completed sibling equations can be checked without declaring the tree complete. Current/staged/scratch native rows are not verdict inputs because they may be mid-mutation. Per-row results distinguish verified identity, mismatch, malformed input and inconclusive cap refusal. Zero checked rows never yields verified_selected_rows. Exit0 means selected row identities verified; exit2 means the scoped verification was not established. Parse/custody refusals also fail the command.

All reports keep original descent authentication, signed lifts, complete search and complete Groebner basis claims false, with first/last fall degree and degree of regularity null. A verified row can become a scoped training label after the caller supplies the appropriate source/custody/privacy gates; it is not a solved ECDLP instance or an exact-degree certificate.
