# Independent retained Boolean row replay

`polynomial_replay.py` checks an actual polynomial identity over the Boolean quotient ring GF(2)[x_0,...,x_(n-1)]/(x_i^2+x_i), independently of Rust proof code. Each wire proof pair `[generator, multiplier]` means multiplier times that exact supplied node generator, and all contributions are XORed. Polynomial terms must use the scheduler's strict degree-then-lex order; proof terms use strict `(generator, lexicographic multiplier)` order. Monomials must be increasing, squarefree variable arrays. Generator order and zero generators remain significant. Invalid noncanonical inputs are rejected, not normalized silently.

`verify_row(variables, generators, row, limits=Limits())` returns `verified`, `mismatch`, `invalid`, or `inconclusive`. Caps are inconclusive. Its equality is relative to supplied node equations; source authentication, original map descent, signed lift, complete Groebner basis, degree of regularity and fall degree are not inferred. The caller must separately verify capture custody and equation lineage. Apply it to retained committed native basis rows. A partially constructed current/staged row can have inconsistent intermediate proof data, so a mismatch there alone is not evidence of a producer proof bug.

`verify_field_row(variables, generators, basis_row, variable, row, limits=Limits())` checks both row identities and the actual scheduler Field(i,v) operation: x_v times the basis row in the Boolean quotient. The basis must be nonzero and v must divide its leading monomial, as in task generation. There is no additional generator index for a field equation. It does not verify scheduler queue completeness or a pre-quotient degree bound.

Limits bound variables, generators, polynomial terms, proof terms, degree, cumulative work and cumulative allocation units. Allocation units count literal and tuple slots conservatively, including constants; they are not measured Python heap bytes. Hard maximum envelopes prevent an unbounded caller limit. An API input is already materialized; untrusted wire decoding must use the sibling bounded semantic reader. The fixture replay command accepts only the exact fixed hash/size fixture, so it is not a general unbounded JSON input path.
