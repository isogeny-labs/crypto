# Original-owner matrix phase adapter proposal

This proposal adds concrete Rust code for a private child of `sat_original_owner`, with the byte-identical dynamic Boolean scheduler V3. It is external, unregistered and **uncompiled**; no native acceptance, original-owner fixture, CLI delivery or scientific result is claimed. The earlier sparse unit-window matrix donor remains a distinct finite-span operation rather than being renamed F4.

The API is `OriginalOwner::matrix_phase(&mut self, Caps) -> Attempt`. It accepts no caller-supplied map, generic owner, deadline or budget. Only the existing private owner, constructed by `OriginalOwner::admit` from `VerifiedWorkerOriginal`, may enter. It requires `build_map` and successful `persist_map` acknowledgement, consumes the existing one-shot Boolean-attempt guard, and splits immutable borrowing of the exact CheckedMap from mutable borrowing of the same original Budget. Failure returns the phase custody object rather than a detached error.

The exact checked equation expansion is retained in `Attempt`. The ordered source generator list is copied under original ledger reservations; individual monomials are preserved and polynomial terms are reordered by degree then lexicographic vector order, because the expansion and scheduler use different term orders. Zero generators and generator indices remain intact. Buffers are stored in the attempt before fallible growth; source-copy/sort cursors and partially reordered source remain on refusal. No resumable checkpoint claim is made.

Construction begins through `Budget::begin_native(false)` and expansion plus order conversion remain under the original construction deadline. Only complete expansion/conversion calls finish_native. Matrix admission uses begin_native(true), the same cumulative work/memory ledger, and the unchanged original absolute deadline. Kernel work/byte ceilings are clamped to returned phase limits. All phase and adapter charges use the existing reserve_checking path, which debits the shared pool; these are logical reservation units, not PMU instruction counts. Scheduler result, partial matrix, proof combinations, queue and row operations remain retained. Every failure preserves the first original stop. No original deadline or scientific budget is renewed.
