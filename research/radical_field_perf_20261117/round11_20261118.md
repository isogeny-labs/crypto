# Root-finding CPU optimization follow-up (2026-11-18)

Scope: `src/cryptanalysis/prime_radical_root.rs` (public polynomial coefficients, prime fields <= 2^61-1).

## Retained changes

1. **Canonical 32-bit Fp products:** multiply two canonical residues with a native 64-bit product and remainder when p <= 2^32-1; use existing Mersenne and wide-remainder paths otherwise. Noncanonical inputs deliberately retain the wide path.
2. **Specialized quadratic-extension square:** `(a+bi)^2 = (a^2+n b^2,2ab)`. Add `Ring::sqr` (defaulting to `mul(x,x)`) and override it in `Fq2`. Reuse it in binary exponentiation, AMM membership cubings, digit-correction cubings, and Sylow inverse-power cubings.
3. **Monic cubic shift reuse:** `h=c2/3; P=c1-c2*h; Q=2*h^3-c1*h+c0`. Five base-field multiplications instead of seven for coefficient depression.
4. **Regression rollback:** The preceding PR's Cardano discriminant rewrite `(Q/2)^2-(-P/3)^3` **was reverted** after actual Rust CI showed slower execution, even though C++ mirrors suggested otherwise. This is a critical reminder not to accept C++ approximations as compiler-level proof.

## Local measurements

AMD EPYC 9V74 on Linux, GCC/Clang -O2, CPU 0 pinned, 8,192 operands for Fp/cubic and 2,048 for Fq2, 13 alternating before/after pairs, median per-operation wall-clock (ns). The harness also uses `perf_event_open(PERF_TYPE_SOFTWARE, PERF_COUNT_SW_TASK_CLOCK)`. Hardware cycle/instruction counters return EACCES, and `perf` command is not installed. **These are standalone C++ arithmetic reproductions, not compiled Rust.** Fq2 benchmark uses n=2 and a representative 44-bit exponent.

The GCC Mersenne multiplication control was 2.228 -> 2.215 ns (1.006x), and Clang 2.262 -> 2.356 ns (0.960x); no claim of a universal win. Dedicated square and exponent benchmarks cover many more primes and n values in the local archive.

## Correctness and rejected optimization

Local C++ exhaustive-equivalence comparisons over all 8,192 Fp operands per field and 2,048 Fq2 operands per p,n combination passed for tested fields and representative powers. UBSan completed cleanly on both benchmark harnesses. New ignored Rust microbenchmarks and randomized equivalence tests exercise the **actual production module** in the isolated GitHub Actions job, which must pass before merge. The full main-crate `cargo test` job is independently blocked by duplicate test symbol `the_trace_coset_base_on_an_a1_curve_is_affine_and_in_two_e` (E0428).

An additional quartic-depression rewrite reducing scalar multiplies by modular doubling was rejected: GCC -O2 regressed to **0.826x** at p=1,000,000,009 and **0.711x** at p=2^61-1, despite Clang sometimes improving. Do not merge it.

The Cardano discriminant reuse in the preceding PR measured actual Rust **10.120 -> 16.638 ns** for p=1,000,000,009 (0.608x), **8.674 -> 12.713 ns** for p=2^61-1 (0.682x), and similarly regressed on small primes, so it is deliberately reverted in this revision.
