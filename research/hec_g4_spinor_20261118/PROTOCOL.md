Laga and Thorne identify the source Kummer origin with the pure spinor of the plane spanned by 1, x, x², x³ in the degree-nine branch algebra. Its vectors annihilate the spinor. In the branch idempotent basis the coefficient-of-x⁸ form is diagonal with entries 1/f′(r). The Pauli matrix for each branch class has square (-1)^(shift dot character). Its commutator with each distinct branch matrix is -1 by the Weil pairing. Multiplication by the specified square root therefore realizes the Clifford generators up to a global quadratic-form convention. That common factor leaves the annihilator unchanged. The eight independent branch classes generate the full matrix algebra. Each radical sign represents an isometry of the diagonal form. The even Clifford action identifies the projective branch translations.
