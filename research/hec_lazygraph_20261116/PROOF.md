# Deferred signed LP elimination: algebra and limits

Let K be a field. Input relation matrix M=[L A] has E rows, n large-prime columns L, and d retained columns A. Each row of L has at most two nonzero entries (repeated vertex contributions are combined algebraically). The retained columns can include a target coefficient and constant; regard both as formal variables for elimination.

Maintain y_v=c_v y_root+E_v(x) with nonzero c_v for nonzero roots; root0 has y_0=0. Substituting a new equation gives p y_r+q y_s+R(x)=0. Distinct roots: one nonzero root coefficient is a legal pivot; attach that root. Equal nonzero roots: delta=p+q. If delta!=0, pivot that root against dummy0 (anchor). If delta=0 emit R. If root is0 emit R regardless delta. Thus every accepted pivot eliminates exactly one independent LP column, and every other input emits an LP-free equation, possibly zero or dependent. The pivot count equals rank(L), not the rank of [L A]. A relation being emitted does not imply it increases retained rank.

Inductively, invertible row operations and invertible LP variable substitutions reduce M to [P B;0 R], where P has independent rows and full row rank equal to rank(L). A row-space element with zero LP part cannot use a nonzero linear combination of P's rows, because those rows are independent. Therefore rowspace(R) is exactly {s : (0,s) in rowspace(M)} and rank(R)=rank(M)-rank(L). This is an exact algebra statement, not an asymptotic heuristic. No random graph hypothesis enters it. Duplicate vertices, signs and nonunit coefficients remain legal provided incoming coefficients are normalized in K; a zero net LP coefficient can yield an immediate retained equation.

## Deferred representation

Replace every expression E_v by a node ID in an acyclic arithmetic circuit. Leaves are incoming sparse A rows. Every expression operation creates a node z=ca*z_a+cb*z_b; creation order is topological. The same field operations and root decisions as eager elimination imply exactly the same emitted rows under expansion. Parent compression combines IDs; it does not expand retained coordinates. Coefficients and topology still require ordinary scalar field operations/inversions.

If N is circuit size, S total leaf entries and h emitted roots, evaluate all leaves and nodes once to compute Rx in O(N+S+h+d) field/storage operations, without constructing R. For R^T y, seed each output adjoint by its weight and traverse nodes in reverse order, sending ca/ cb times each adjoint to its children; scatter leaf adjoints to retained columns. Linearity proves this is exactly the transpose. Multiple references, equal children and repeated roots ADD their contributions. Allocation/zeroing costs are included. A simple implementation evaluates dead nodes too; pruning is not assumed.

Structural union-find yields O(E alpha(n)) find work under weighted union/path compression, with the dummy component always retained and non-dummy attachments by size; anchoring increases dummy size. Each visited find creates O(1) nodes and each edge O(1) further nodes; hence O(E alpha(n)+n) structural storage/work plus input sparse coefficients. This bound concerns deferred representation construction, not expanded rows or the eventual Krylov iteration count. Input catalogue and relation-search costs are unchanged. Forward/transpose application is linear in the actual stored circuit, even if it retains dead nodes. Black-box linear solving requires a suitable rectangular/singular-system strategy; forming R^T R can lose rank over a finite field and is NOT automatically valid.

This combines established signed LP graph elimination and linear-circuit/black-box matrix evaluation. No originality or tenfold complete-solve gain follows from the representation. If unchanged work T0 occupies fraction f of a complete run, even deleting the entire affected part gives total ratio<=1/f; tenfold requires f<=0.1. The original cold-cost and compiled-map cohort bounds are not transferred to a new LP workload.
