# Complete signed extraction from the FASS quotient

Tracking: [crypto PR #4976](https://github.com/isogeny-labs/crypto/pull/4976).
This continuation consumes the [quotient-query component](../quotient_query/THEORY.md)
and leaves its frozen evidence unchanged. The arguments below are written
derivations, with unverified repository PCC standing; no Lean theorem or
signed execution verdict is claimed. [pcc:unverified]

## 1. The output is a set of signed triples

Let p>3 be prime, let E/Fp be the nonsingular curve y²=x³+Ax+B, and let
V be the distinct roots of a monic split selector L. The concrete selector
is L(z)=z^d−1, with d dividing p−1. Choose an actual subgroup H of E(Fp),
possibly the full group, and define the finite, sign-closed factor base

$$
\mathcal B=\{P\in H\setminus\{O\}:x(P)\in V\}.
\tag{1}
$$

The identity is excluded from the base. Repeated summands are allowed.
The target Q is a specified rational point, including the permitted target
Q=O. The complete-output contract is the set

$$
\mathcal T_Q=\{(P_1,P_2,P_3)\in\mathcal B^3:
P_1+P_2+P_3=Q\}.
\tag{2}
$$

These are **ordered** triples of actual points, not just x-coordinates or
existential sign assignments. The same point used twice remains two slots.
All admissible witnesses survive until this set has been obtained. A caller
may subsequently quotient by slot permutations or by equality of relation
rows, but those operations have separate keys and provenance.

An input policy which requires Q in H may reject Q outside H. If such targets
are admitted instead, the mathematical answer is empty because H is a
subgroup. The interface must state which behavior it implements.
The native continuation admits an otherwise valid target outside an explicit
subgroup and obtains its complete empty answer through the extraction checks.

### Actual subgroup membership

The full-group policy imposes no extra subgroup predicate. A small-field
explicit cyclic policy takes an on-curve generator R and the complete
inventory O,R,2R,...,(r−1)R. Starting from O, repeated group addition must
produce those exact distinct entries, return to O at r, and never return
earlier. This establishes that the inventory is exactly the cyclic group
generated by R, of order r. Membership is then exact lookup.

Checking [r]P=O by itself only establishes membership in E(Fp)[r]. It does
not in general establish membership in a specified cyclic group generated
by R. A scalable cyclic policy needs the relevant additional facts, for
example a certified group order hr with r prime, gcd(h,r)=1, and R of
exact order r. This continuation uses explicit cyclic inventories only for
small-field controls; it does not infer an unproved cyclic subgroup for the
existing Prime31 fixture. [pcc:unverified]

## 2. An affine chart and an identity chart

Write W=x(B), choose any coordinate cover W contained in U contained in V,
and put F(x)=product_{a in U}(x−a). The native variants use U=W for the
actual-base restriction and U=V for the full-selector superset. The selector
in the eliminated coordinate remains L: the point membership checks below
restrict every recovered summand to the actual base. This can introduce
coordinate candidates which fail extraction, but it cannot omit a valid
triple from (2).
Write F_B(t)=product_{a in W}(t−a) for the actual base-coordinate polynomial.

For a finite target Q=(X,Y), define

$$
\begin{aligned}
R_X(t)&=\prod_{z\in V}S_3(t,z,X),\\
G_X(t)&=\gcd(R_X(t),t^p-t),\\
N(x,t)&=\prod_{z\in V}S_3(x,z,t),\\
Z_Q&=\{(a,t)\in\mathbb F_p^2:F(a)=G_X(t)=N(a,t)=0\}.
\end{aligned}
\tag{3}
$$

The gcd is monic. Products retain degree drops; division by a possibly
vanishing quadratic leading coefficient is not allowed. N may be evaluated
as the retained division-free selector norm modulo F and G_X.

For the identity target Q=O, the right condition becomes x(P_3)=t, because
the finite prefix P_1+P_2 must equal −P_3. Thus t belongs to W. The native
implementation uses this actual support for the right modulus under both
left-selector policies:

$$
G_O(t)=F_B(t),\qquad
Z_O=\{(a,t):F(a)=F_B(t)=N(a,t)=0\}.
\tag{4}
$$

This is a separate target chart. Substituting a fictitious x-coordinate for
O into S3 would change the problem.

The existing query certificate decomposes the finite grid into triangular
components. The signed consumer must check the input binding and every
certificate identity before trusting any support, including an empty
verdict. It must recover every root of each positive component. Supplied
root inventories are acceptable only when their product equals the bound
monic split polynomial and their entries are canonical and distinct.

## 3. Recovering every witness and sign

For each (a,t) in the complete affine support, recover all distinct roots
of

$$
C_{a,t}(z)=\gcd(L(z),S_3(a,z,t)).
\tag{5}
$$

For finite Q, also recover the complete right bucket

$$
W_{t,Q}=\{w\in V:S_3(t,w,X)=0\}.
\tag{6}
$$

An implementation may retain these right buckets when constructing G_X.
Their completeness must come from that construction or an independent
check, not from a single successful witness. For Q=O the right bucket is
the singleton {t}; support construction has already required t in W.

For every root z of (5), consider every distinct rational point P_1 in B
with x(P_1)=a and every distinct rational point P_2 in B with x(P_2)=z.
Compute R=P_1+P_2. Retain this branch only when R is finite and x(R)=t.
Then compute the uniquely determined third point

$$
P_3=Q-R.
\tag{7}
$$

Require P_3 in B and, for finite Q, x(P_3) in the complete right bucket.
Replay P_1+P_2+P_3=Q in the original curve group before retaining the
ordered point triple. For Q=O, (7) is P_3=−R.

This sign join needs no arbitrary choice of an ordinate for the intermediate
coordinate t. The actual sum R fixes its sign. In particular, choosing one
left root, choosing one right root, or joining two independently chosen
canonical signs is not a complete-output implementation.

Each y=0 point has one rational lift, not two copies labelled + and −.
An ordinary point with nonzero y has the two distinct lifts (x,y) and
(x,−y). A coordinate with nonsquare curve value has no rational lifts and
produces no signed triple.

### The prefix identity branch

If P_1+P_2=O, the coordinate t does not exist. For finite Q this branch is
exactly

$$
\mathcal T_Q^{\infty}=
\begin{cases}
\{(P,-P,Q):P\in\mathcal B\},&Q\in\mathcal B,\\
\varnothing,&Q\notin\mathcal B.
\end{cases}
\tag{8}
$$

If Q=O this branch is empty: it would require P_3=O, which the base excludes.
Equation (8) includes P=−P when P is a nonidentity two-torsion point.
The affine and prefix-identity branches are disjoint by their actual prefix
sum, even when other slots of a triple cancel.

## 4. Soundness and completeness

**Proposition 1.** Under the hypotheses and complete-support/witness
contracts above, the union of affine extraction and (8) equals T_Q exactly.
[pcc:unverified]

*Soundness.* Every retained point belongs to B, and direct group replay
checks (2). Every triple in (8) has that sum by the group inverse law.

*Completeness.* Take any ordered triple in T_Q and set R=P_1+P_2. If R=O,
then P_3=Q and the triple appears in (8); when Q=O this case cannot occur.
Suppose R is finite, with coordinates a=x(P_1), z=x(P_2), t=x(R).
The classical three-point summation identity gives S3(a,z,t)=0, so
F(a)=N(a,t)=0 and z occurs among the roots of (5). If Q is finite,
R+P_3−Q=O gives S3(t,x(P_3),X)=0, hence t is a root of G_X and x(P_3)
is in (6). If Q=O, then P_3=−R, so t belongs to W and therefore is a root
of F_B; (4) applies.
Thus the complete affine support contains (a,t), and the complete rational
lifts include the original P_1 and P_2. Equation (7) recovers exactly the
original P_3, which passes all checks. No tuple from T_Q is omitted.

This proof only needs the direction from an actual group relation to an S3
zero. It never assumes that every algebraic coordinate zero already has the
required rational lifts or compatible signs. Those properties are checked
after elimination.

**Corollary 1 (complete EMPTY contract).** A successful extraction which
exhausts every affine support component, every witness/sign branch, and the
applicable identity branch may return EMPTY if its final ordered set is
empty. Any resource cap, missing input, failed certificate, incomplete root
inventory or unhandled chart prevents that verdict. A finite empty affine
grid alone only discharges the affine part of this statement.
[pcc:unverified]

The finite-field qualifier checks specific calls. It is not a formal proof
that the implementation realizes every hypothesis in this universal result.

## 5. Degree drops and the amount of extraction

Write f(u)=u³+Au+B. Considering S3(a,z,t) as a polynomial in z gives leading
coefficient (a−t)². If a=t, its linear coefficient is −4f(a).
If in addition f(a)=0, its constant value is

$$
S_3(a,z,a)=(3a^2+A)^2=f'(a)^2\ne0.
\tag{9}
$$

The last inequality follows from nonsingularity: f and f' have no common
root. Therefore S3(a,z,t) is never the zero polynomial, and its gcd with
the split squarefree selector has at most two distinct roots. The same
argument handles the right witness polynomial, including a two-torsion
target. A vanished quadratic coefficient is handled by its actual linear
or constant polynomial, not by division by zero. [pcc:unverified]

There are at most two left witness coordinates, at most two lifts of each
of a and z, and one P_3 for each surviving pair of actual points. A direct
upper bound is consequently

$$
|\mathcal T_Q|\le
8|Z_Q|+|\mathcal B|\,\mathbf 1_{Q\in\mathcal B}
\quad(Q\ne O),\qquad
|\mathcal T_O|\le8|Z_O|.
\tag{10}
$$

This deliberately loose bound counts retained triples, not all work spent
recovering roots, checking rejected branches or constructing the quotient.
The right bucket adds a membership condition; it does not create another
independent factor of two after P_3 has been fixed by (7).

## 6. Cancellation is a property of signed triples

A triple is cancellation-containing when P_i=−P_j for some distinct slots
i,j. Two equal nonidentity two-torsion points satisfy this condition. For
such a triple, the remaining point equals Q. A triple with no such pair is
called **noncancelling** here; this word does not assert linear independence,
rank gain, a new relation, or ECDLP progress beyond exact extraction.

For selector targets X in V, the coordinate mask

$$
a=X\quad\hbox{or}\quad S_3(a,X,t)=0
\tag{11}
$$

can arise from cancellation. It is not a safe rejection rule: a single
masked cell can carry both cancelling and noncancelling signed triples.

### A small exact control

On E/F97: y²=x³+x, let P=(1,14). Since 14²=2 modulo 97, P is on E.
The tangent slope is 4/28=14 modulo 97, so 2P=(0,0). Hence P has order
four and 3P=−P=(1,83). With L=x−1, the base is {P,−P} and target Q=−P.
The affine cell (a,t)=(1,0) lies on a=X, yet carries both

$$
(P,P,P)\in\mathcal T_Q
\quad\hbox{and}\quad
(-P,-P,P)\in\mathcal T_Q.
\tag{12}
$$

The first is noncancelling and the second has an inverse pair. The example
also exercises repeated summands and a finite two-torsion prefix. It is an
exceptional correctness control, not the ordinary Prime31 workload.

A prime cyclic variant uses y²=x³+2x+3 over F97 and P=(3,6):
2P=(80,10), 3P=(80,87), 4P=(3,91), 5P=O. With d=96, the exact order-five
subgroup policy gives B={±P,±2P}. For Q=3P, the cell (3,80) has left
witnesses z=3 and z=80, respectively supporting (P,P,P) and (−P,Q,P).
Keeping only one left witness can therefore discard an entire class of
signed relations. These arithmetic identities are written fixture
derivations; their native checks are recorded separately. [pcc:unverified]

### An exact cancellation baseline

Let N=|B| and assume the finite target Q belongs to B. For each of the three
slot pairs, there are exactly N ordered triples in T_Q whose points in that
pair are inverses: choose the first point in the pair and the other is
fixed, while the remaining point is Q. Each pairwise intersection of these
three sets contains one tuple. The triple intersection contains (Q,Q,Q)
exactly when Q=−Q. Inclusion-exclusion therefore gives

$$
|\mathcal T_Q^{\rm cancel}|=
3N-3+\mathbf 1_{Q=-Q}.
\tag{14}
$$

Exactly N of these triples are in the prefix-identity chart (8). Their
finite-prefix count is 2N−3+1[Q=−Q]. If Q is not in B, there is no
cancellation-containing triple; in particular this is true for Q=O because
O is excluded from B. This counts actual signed inverse pairs and remains
valid in the presence of repeated summands and other two-torsion points.
[pcc:unverified]

For the inherited d=63 Prime31 selector, the previously recorded actual
base has 68 signed points and the finite target with X=1 has nonzero
ordinate. Equation (14) predicts 201 cancellation-containing triples:
68 with identity prefix and 133 with finite prefix. It does not predict
the number of additional noncancelling triples. In particular, the old
133-cell coordinate count cannot alone exclude additional witnesses in
those cells. This is an analytical baseline stated before the new native
qualification, not a native outcome. [pcc:unverified]

### Separate canonicalizations

For each coordinate a in W choose R_a=(a,min(y,−y)), with canonical field
representatives. Encode a finite base point by its coordinate index and
sign relative to R_a; a two-torsion point has the single sign +1. For an
ordered triple let

$$
c_a=\sum_{i:x(P_i)=a}\operatorname{sign}(P_i),
\qquad \sum_{a\in W}c_aR_a=Q.
\tag{13}
$$

Keep three distinct objects: the ordered point triple; its sorted multiset
of point IDs, which forgets only slot permutations; and the integer vector
c, which also combines repeated and opposite points. Each retained class
keeps its originating witness/triple indices.

If Q itself is a base point, subtract its signed unit column to obtain a
homogeneous integer row. For Q=O, c is already homogeneous. Otherwise keep
Q as a separate symbol with coefficient −1. A fixed public target label
(for example Q=aP+bQ_original) is not discarded when two rows coincide.

Do not reduce two-torsion coefficients modulo two or general coefficients
modulo an alleged subgroup order without recording that additional quotient.
The integer vector is an exact presentation of the signed sum. A
cancellation-containing triple can leave coefficient 2 on a two-torsion
column, so an integer zero-row test is not equivalent to the point-pair
cancellation test. Conversely, no inverse pair does not imply a useful
independent row. A prime-order index-calculus matrix and its rank require a
separately bound subgroup and target-label contract.

## 7. Cost boundary and the work still to price

The component boundary begins with the public curve, selector, target and
subgroup policy and ends with a complete signed triple set and its replayed
row representation. For a cold component comparison, all of the following
belong inside the interval:

| Phase | Charged work and retained information |
| --- | --- |
| Input validation | Canonical field inputs, curve discriminant, target equation, selector degree and divisibility, exact subgroup inventory when used |
| Actual base construction | Selector-root generation, square-root/lift work, subgroup membership, both signs and canonical point IDs |
| Right message | Every selector specialization, degree-drop handling, scalar polynomial arithmetic, radical rational part or an equivalent complete root construction, all witness collision buckets |
| Quotient construction | F and G, retained norm evaluation and reductions, explicit tensor state |
| Query certificate | All dynamic gcd blocks, splits, recomputation, inversions, divisions, Bezout/cofactor output and certificate checking |
| Positive-support extraction | Every root isolation, inventory/product check, fibre specialization and candidate membership test, including rejected candidates |
| Signed join and identity cases | Every recovered left/right witness, all point lifts, all group additions/subtractions, membership tests and replay; the Q=O and prefix-identity branches |
| Output and rows | Exact deduplication, permutation and coefficient keys, backpointers, hashing/serialization and output storage |

Diagnostic counts from different phases are not interchangeable operation
units. A count of group additions excludes the field work needed for each
addition unless separately expanded; a count of polynomial products hides
their degree-dependent costs. Similarly, a maximum output vector length is
not peak process memory. A complete field-operation ledger, allocation and
root-finding costs, and a matched external implementation remain additional
work before a performance comparison.

The component does not yet perform relation collection for many target
labels, independent-row selection, sparse linear algebra, descent or scalar
recovery. Those phases and failed target attempts belong to a full ECDLP
cost boundary. Their costs are not set to zero by this extractor. The
qualification is a bounded development correctness check with no timing or
speed ranking; canonical performance dashboards are unchanged.
