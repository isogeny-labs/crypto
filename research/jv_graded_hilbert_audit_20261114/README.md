homogenized coordinate equations. The new proof first shows I homogeneous
for Mathlib's standard grading. It restricts the actual quotient map P→P/I
to Mathlib's degree-d homogeneous submodule P_d and proves that the kernel
is exactly I∩P_d. The **canonical degree piece** is defined as P_d modulo
that actual kernel. The first isomorphism theorem identifies it with the
actual quotient image. This construction does not start by defining the
desired dimensions or by assuming a grading of a chosen normal-form list.
