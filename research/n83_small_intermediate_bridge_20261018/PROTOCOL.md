# Native N83 K1107 versus K2304 factor-base bridge

This comparison puts the two independently replayed cold leaders from the
small and intermediate root11 factor-base panels on the same 32 new public
N83 points. The current IC source uses two target workers with cooperative
cancellation. The one-target online wall interval is the primary selector;
the binary's fresh-process internal total and the full child-process wall
are separate cold selectors. The paired rho arm solves each identical point.

The exact curve is `EC1N83Ckb1a1haacb69ee9f37`: degree 83 over GF(2),
irreducible polynomial terms `[0,2,4,7,83]`, Koblitz coefficient `a=1`,
prime subgroup order `8569786107849059`, cofactor `1128547018`, and
generator coordinates `6614244651398184860292015`,
`8868260410029249391539529`. The factor base scans polynomial x values
from one, projects rational lifts to the subgroup, and takes the first K
distinct signed-Frobenius orbits. K1107 has 183,762 usable points and 1,107
folded columns; K2304 has 382,464 usable points and 2,304 folded columns.
The [candidate manifests](.) retain the previously replayed ordered base
digests, base hashes, source and exact environment flags. The native
[manifest generator](../../examples/n83_bridge_fixture.rs) derives their
current-source IC1 IDs and seals them before timing.

The [public targets](targets.jsonl) and [answer sidecar](answers.jsonl)
are generated by the native fixture command from
`BLAKE3("n83-native-small-intermediate-bridge32-20261018-v1" || u32_le(i))`;
the scalar is one plus the full 256-bit digest interpreted little endian
modulo `r-1`. The independent scalar sidecar stays outside both producers.
The native [workload manifest](workloads.json) hashes a canonical one-target
record for every public point and records its 12-hex workload ID. A measured
IC row uses `<candidate-id>W<workload-id>R1` as its run ID.
The [exclusion audit](exclusion.json) records overlap with prior N83 target
files and the separate 32-point finalist fixture. The
[protocol record](protocol.json) pins the fixture, candidate manifests,
native sources, IC/rho sources, calibration target, rho configuration,
workflow, and resource limits by SHA-256.

Use four distinct overlapping Tier 1 cloud allocations, one per eight-point
stratum. Rotate K order by point index. Alternate IC/rho order within each
candidate-point pair. Run three independent fixed-point rho calibrations
before and three after each pair, and compare their medians; relative spread
must be at most 10%. The complete panel has 64 IC and 64 same-point rho
solves and 384 calibrations. Each IC starts a fresh process with empty
factor-base, index, and log caches. The flags freeze root11 dynamic load75,
two target workers, cancellation enabled, and indexed5 ID30 disabled.
The rho seed is `2026111400 + 2*point_index + fixed_candidate_index`.

Cap each IC child at 900 seconds, each rho or calibration child at 120
seconds, each producer stratum at 270 minutes, each cloud job at 330
minutes, and each child at 15.25 GiB peak RSS. The native runner records
executed binaries, source hash, commands, event order, child-process wall,
peak RSS, cgroup memory and CPU receipts, exposed CPU affinity, topology,
pressure, and steal time. The native replay checks each ordered base-dump
SHA-256, base hash, four-point group relation, target scalar, same-point rho
scalar, five exclusive online phases, source policy, resource cap, and
calibration. Admit each producer event only when cgroup CPU throttling, OOM,
OOM-kill, and host CPU steal counters do not increase during it. The aggregate
must confirm that visible CPU affinity and cgroup CPU/memory limits match the
frozen host envelope at both boundaries of every event, then bind four
provider jobs to four distinct
overlapping runner IDs and independently replay the archived bytes.

For each metric, compare K2304 against K1107 with 32 paired differences.
Use log(K2304/K1107) for online time and direct millisecond differences
for both cold measures. A candidate is selected only when at least 23
non-tied points favor it, its exact two-sided sign p is at most 0.05, and
the paired mean favors it. Report descriptive paired 95% intervals,
individual point costs, rho/IC ratios, verified rank and relations, and
resource conditions. Failed or missing pairs, resource events, noise,
incomplete replay, and absent provider bindings retain their recorded
status and leave the relevant selected ID null. The full child-process
wall includes launch and input loading; the separate independent audit is
recorded after that interval.
