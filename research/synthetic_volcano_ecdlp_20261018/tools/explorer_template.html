Read the assumptions before the trends

The nominal subgroup order is the largest prime below 2^(bits−2), matched across families. It is not certified to be the order of any subgroup on a constructed curve. The deep component has strata 1 / 4 / 12 / 36 / 108. Horizontal degree labels 11, 23, 29 use illustrative cyclic shifts, not computed isogeny maps.

Index calculus uses a signed factor base of size B ≈ r^(1/3). The assumed decomposition probability is 1−exp(−B^m/(m!·r)). IC2 scans the base; IC3 first builds a pair table. Preprocessing generates factor-base logarithms, followed by an individual target descent. Full matrix rank is assumed. These are two declared cost models, not a survey of every IC algorithm.

The positive control multiplies oracle scan cost by 0.55^level; the negative control uses 1.7^level. The null has no imposed level multiplier. The Koblitz-origin surface alone gets an assumed Frobenius discount. Its descendants use ordinary binary costs. No actual depth-4 Koblitz instance at extension degree 30, 40 or 50 is claimed.

There are more floor candidates than surface candidates. Selecting a minimum can favor the floor under an exchangeable null. The balanced profiler therefore tests one prespecified vertex per stratum. Ten-target means and ranges are descriptive model outputs. Any apparent size law follows from the selected equations.
