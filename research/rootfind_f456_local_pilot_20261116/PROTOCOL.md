## Question, prior work and source

Can the source-bound complete cold `rootfind-negfold-batch` m=3 call finish faster than each matrix F4, matrix F5, inherited F4 and F6-IC on the first two public targets of the registered Koblitz E0 n13 panel? The proposed mechanism is the already implemented folded binary pair table and batched relation scan; this study introduces no mathematical attack or new algorithm. The current production source is `src/cryptanalysis/ic_boundary.rs`, `src/bin/ecbench/pdp3_koblitz.rs`, and `src/cryptanalysis/ecbench/`. The source-bound L0 component record `research/rootfind_pair_index_timing_20261116/RESULTS.json` is narrower and supplies no complete-call result. The earlier F4/F5/F6 cross-family records and the program paper's Gröbner section establish the four baselines, but do not decide this exact current-source K13 paired comparison. [pcc:unverified]

## Fixed input and execution

`SPEC-K13-L0.json` is copied from the frozen combined K13 spec with only these deliberate changes: first two targets instead of eight, eight arms rather than ten (omit the m=2 arms), one warmup and one measured round instead of one and six, `L0` instead of `L2`, and a 300-second per-execution cap. There are 8 × 2 × 2 = 32 planned process executions. The arms are strong signed-Frobenius rho, matrix F4, matrix F5, inherited F4, F6-IC, scalar rootfinding m=3, batch rootfinding m=3, and a duplicate batch m=3 A/A. The only directional comparison is batch m=3 against each four Gröbner arms on the same two target IDs; scalar m=3 and rho are context. [pcc:unverified]

## Measures and interpretation

Primary descriptive measure: `time.process_wall_ns`, from fresh process start through a verified `[d]G=Q` answer. Retain each attempt, full phase timings and RSS; record timeouts/failures rather than dropping them. Compare only identical workload hashes, target points, source binary, round and host; require all arms on a target to verify and the parent auditor's `ecbench verify --replay-all` to reproduce every record. Audit `ecbench work` for native pricing, and `compare`/`band` where supported. A/A must be shown alongside directional ratios. Report measured values and spread; two targets and one measured round cannot support a robust interval or population inference. No quantitative performance advantage or ECDLP attack-cost claim is promoted from this pilot. [pcc:unverified]

This pilot is useful if it confirms valid same-target calls and identifies which complete-call phase and Gröbner arm set the nearest local wall boundary. A wrong answer invalidates that arm and triggers source investigation; a timeout is censored; a missing admission gate leaves the study unrun. Even if all two local pairs favor rootfinding, the separately frozen 560-execution L2 panel, its A/A interval rule, second-host replay and claim record remain required for the target comparison.
