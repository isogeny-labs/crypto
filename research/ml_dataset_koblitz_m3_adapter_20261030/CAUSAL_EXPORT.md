Source baseline: 99d97d849e35793e2f88406836deb9754204676b; exact source SHA256 values are in koblitz-export-draft/source-bindings.json. Patch: koblitz-export-causal.patch, SHA256 9499d5f0246d1d52c91dea4dd45d3e6658dc98e3ed6c2cf645d7bac1cd1cedc7.

The exporter now has a native Koblitz branch after verified original static-input projection. A shared predicate is extracted verbatim from central verification: reserved root/payload names and roles identify native sources even when adapter_id/strategy is removed. The predicate selects replay; it does not confer authenticity. Existing prime replay and legacy static projection remain unchanged.

The projector validates the original config/public/factor-base binding (including recipe and sampling seed), central semantic replay, capture context, the entire committed stream, watermark stability and descriptor hashes, then checks all retained signed additions before any feature callback. Policy is projected from that authenticated config through the same explicit allowlist used by static exports. No later file reread supplies policy. Explicit legacy remains an explicit recipe field; absent legacy remains absent. Candidate limit/basis changes therefore change feature identity even for equal point sets. Seeds, construction status/counters and logs are excluded.

Public prefix rows contain static math/recipe, the scheduled action and pre-addition state. Post-addition sum, target match, capture sequences, source descriptors and replay summary stay restricted. There is no new native equation, construction or matrix feature channel. Summary preserves those not_implemented statuses. Existing external sort, hash identity and field-size split machinery is reused. Native restricted record IDs have a distinct namespace. Failure aborts before installing output files; replay rejects a forged later addition before any callback.
