# Reuse the worker's verified-original stage

Live read of mod.rs worker shows curve generation, curves::verify(public, private_witness), and curves::verify_factor_base(public, factor_base) all complete before public.json and factor-base.json are stored and before the solver is invoked. These stages already have distinct telemetry records and share the process supervisor's absolute deadline. This supports a worker-produced immutable token for verified public originals rather than repeating full factor-base replay in original_math.

Token construction must occur only after those actual checks and successful original-file storage, and bind the exact public/factor-base digests, original configuration and AttemptBinding. It must carry only public inputs; the known-answer private witness must not enter solver calculations. Solver dispatch may receive a borrowed token, not a boolean in outcome JSON. Legacy unsupervised calls do not acquire it. Central historical replay still verifies mathematical content independently rather than trusting the live token.

This does not retroactively put curve generation/replay into the adapter's modeled work ledger. Their observed process/telemetry costs remain separate and unproved instruction counts stay null. The original absolute supervisor deadline is never reset. Bounded parsing, Group::read/domain decoding, copying the curve/signed points, token metadata and retained original bytes inside the adapter still need an explicit pre-admission with input byte/shape caps. The token avoids duplicate expensive checks; it does not permit unbounded decoding or a caller-forged curve.

Next implementation should reconcile T887's shared worker scope and T936's shared types ownership, keep the new token in an internal solver/worker module, and test wrong original digest/config/attempt, changed files, missing verification stage, late deadline and retained original setup failures. Existing non-Koblitz profiles keep their current path. No profile activation or scientific run is authorized by this note alone.
