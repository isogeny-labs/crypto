\noindent\textbf{Verification.} The generated assessment is byte-exact under \texttt{build\_cover\_transfer\_assessments.mjs --check}. The independent \texttt{verify\_assessment.mjs} reconstructs exact model, map, cover, field, and Jacobian joins and replays the cover equations over declared fields. It also SHA-binds this report and its figures. The release library suite passed 4,494 tests with 119 ignored in a serial run; the standalone cover binary passed 13/13, including the 2,771-model constructor test.

\noindent\textbf{Boundary.} The 186 binary maps have bounded typed point-class operations. The 2,585 odd-characteristic maps have cover geometry but no compatible balanced two-infinity Jacobian transfer implementation. There is no end-to-end speed, discrete-log, or full-Jacobian transfer claim. The earlier published executable covered a smaller bundled catalog and is not a replay of all 2,771 current inputs. The conditional Lean group lemma does not import this catalog.
