Over an odd extension field K of characteristic p, each quadratic parameter map M(t)=a+bt+ct² lies in the prime subfield exactly when M(t)^p-M(t)=0. This polynomial has degree at most2p. The GCD across declared maps imposes every constraint. Intersect with t^|K|-t using modular exponentiation and GCD, without materializing a |K|-degree polynomial. The resulting monic polynomial has exactly the admissible K parameters as roots, is squarefree, and has degree at most2p. If all constraints vanish identically, return the whole-field symbol instead of an empty set. Extraction of every parameter for large K is a separate output stage; the experiment enumerates only GF9/GF25 independently as an oracle. This is coefficient admission, not full quintic support or odd curve solving. For a prime field the constraint is identically true and does not enforce interval support.
