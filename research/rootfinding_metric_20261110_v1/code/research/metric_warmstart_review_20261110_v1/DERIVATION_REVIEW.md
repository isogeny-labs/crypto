# Basis-transport and output-contract derivation

For the seven integer coordinates lambda0,...,lambda4,gamma,delta, define the five congruences lambda_i - gamma*a_i - delta*b_i = 0 mod p. Their map to (Z/pZ)^5 is surjective via lambda0..lambda4, so its kernel has determinant/index p^5. Each row of a retained candidate basis must lie in this kernel. Seven independent integer rows with absolute determinant p^5 then generate precisely the same lattice. Candidate membership alone does not prove basis equality.

For a positive integer diagonal metric D, exact LLL row swaps and integer row additions give B_red = U B D with unimodular U, including if reduction ends at a step cap. Dividing each coordinate by its old metric weight must be exact and yields B' = U B. Multiplying B' by a new positive metric yields a valid starting basis of the same lattice in that new norm. Old certificates/ranges/masks cannot be reused: every new vector is checked against the current coefficients and fresh signed bounds. Increasing and decreasing metrics require the same proof. Replacing a zero coordinate width by one is a search metric convention, not a claim about its semantic interval.

Cache validity is bound to the exact lattice/public context, not merely bit length or p. Positive cases must remain separate cold starts under the fixed protocol. A cache mismatch or invalid full-basis check forces a cold start. Warm failure and its cold fallback are both charged; the first comparison requires exact mask equality, including positive mask 11101111 and retained u=3. All arms must retain identical declared rows and full candidate pools or return incomplete.

The same geometric enclosure proof applies after transport: a modular lattice vector defines J in pZ, and a tested u is excluded only if the exact signed quadratic range plus T/U envelopes contains no p-multiple. A full block closes only if all its u values are excluded. Repeated/zero sources remain contained. An unknown h or incomplete survivor search never becomes a root-set count or a global closure statement.

The test is an amortized conditional certificate-discovery component on fixed five-prime data, not a new global all-roots solver or matched genuine F4/F5/F6 comparison. Cold-vs-warm timing is meaningful only at common complete-output scope, including parse/setup, basis verification, charged fallback, all candidates, independent replay and serialized final output. Six complete arms over three paired repetitions require 176400 candidate/u checks; the whole-run cap must be at least this and is declared 180000. Old 30000-per-arm bounds cannot silently become the whole comparison cap. A late/partial report must invalidate comparisons and completion flags while retaining raw lower bounds.
