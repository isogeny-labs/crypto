# Crater reanalysis and repetition design

The [report](REPORT.md) and [PDF](REPORT.pdf) answer the crater-comparison,
sample-size and key-size questions using existing frozen observations.
The fully enumerated 98% bootstrap interval is [0.97323, 1.05706], so the
corrected crater verdict remains inconclusive. No new scientific solver
measurements were made.

[Native C++ source](design.cpp), [complete derived output](design.json),
[input hashes](INPUTS.sha256) and [rendering source](render.py) make the
calculation reviewable. Proposed repetition counts are conditional planning
scenarios, not executed campaigns or guaranteed power. The current subgroups
are 25–32 bits; larger-size coverage remains an
[open problem](../../problems/conductor-gap-crater-sampling-and-size.md).
