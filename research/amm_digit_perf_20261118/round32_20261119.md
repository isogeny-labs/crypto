# Round 32: independent root-verifier Euclidean inversion

Date: 2026-11-19 UTC (Nov 18 US Pacific). PR #4706.

## Implementation

Optimized `src/cryptanalysis/prime_root_trace.rs` without changing the
certificate protocol, event order, root-finding producer, or input validation.

The verifier previously computed Fermat inverses `a^(p-2) mod p` each time
it divided by a nonmonic polynomial or normalized a GCD. New `vinv(a, p)`
uses signed-coefficient extended Euclid, replacing modular exponentiation
with the Euclidean quotient/remainder sequence. The implementation is
limited to public coefficients of odd primes `p <= 2^61-1`. Its
nonconstant timing **must not** be used with secret scalars.

Four production inverse call sites changed:
1. constant-divisor polynomial division;
2. nonmonic linear synthetic division;
3. general nonmonic polynomial division; and
4. polynomial monic/GCD normalization.

The old `vpow` is kept as an independent frozen reference for regression
testing. The producer's field-operation accounting is untouched.

## Scope and follow-up

The optimization is validated for selected verifier operations; it does
not establish faster complete root extraction, which uses separate
instrumented producer field operations. It is also not an end-to-end
index-calculus relation-generation or GPU result. Keep PR #4706 draft
until full-library validation and representative whole-solver / verifier
throughput runs complete.
