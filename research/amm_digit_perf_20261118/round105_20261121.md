# Round105: Mersenne addition chain for quartic root-verification

**Scope:** verifier-only optimization in `src/cryptanalysis/prime_root_trace.rs`, PR #4880, source commit `27f66fd6e7d14d194e0e97cc1576da9e446f678d`. Frozen Round104 baseline: `ba3b4de3936d78adfcd2a47eb0d518e4fe38ac32`.

For p=2^61-1, the Frobenius and split-test exponents are 2^61-1 and 2^60-1. The previous binary powering path performs 60/61 quotient-ring multiplications. The new verifier-only addition chain exploits `(2^a-1)·2^b + (2^b-1) = 2^(a+b)-1`, building 2,4,8,16,32-bit runs of ones and then concatenating 16+8+4(+1) bits. It uses **8/9 multiplications rather than 60/61** while keeping 59/60 squarings. Gated to the two exact exponents; all other exponents and primes retain the existing binary path. No changes to the producer's event trace, cost counters, or certificate format.
