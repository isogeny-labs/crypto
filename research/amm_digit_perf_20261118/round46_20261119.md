# Round 46 (2026-11-19): squarefree quadratic split by two scalar characters

## Code retained

In `src/cryptanalysis/prime_root_bounded.rs`, avoid generic polynomial modular Euler powering and polynomial GCD when splitting a **monic, squarefree quadratic** over a prime with `p % 4 == 3`. This specializes the split loop *after* the linear-part computation, so round-45 quadratic Frobenius remains intact.

For `h(x)=x²+b x+c` and `D=b²-4c`, compute `sqrt(D) = D^((p+1)/4)`, and verify its square equals `D`. Obtain the two distinct roots `r0,r1=(-b±sqrt(D))/2`. The old split factor is `gcd(h,(x+delta)^((p-1)/2)-1)`. By quadratic CRT and Euler's criterion, it contains precisely roots `r` for which `(r+delta)^((p-1)/2)==1`. Use two scalar character evaluations to construct `1`, `h` or `x-r` exactly, including when `r+delta==0`. All nonapplicable cases fall back to the old polynomial exponentiation and GCD.

The **producer** uses right-to-left scalar powering. The **independent certificate replay** uses left-to-right powering, separately checks that both reconstructed roots satisfy `h`, and reconstructs the expected factor. Existing split event, quotient verification, RNG, deadlines, and resource limits are preserved. The optimization changes the accounted number of charged field operations, which is intentional; it does not claim cost-equivalence at the old budget boundary. This is not a constant-time implementation.
