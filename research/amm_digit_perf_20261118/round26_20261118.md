# Rootfinding verifier optimization round 26 (2026-11-18)

Scope: `src/cryptanalysis/prime_root_trace.rs`, independent polynomial-root certificate verification.

## Production changes

1. Monic constant-polynomial division: return a canonical copy of the dividend and an empty remainder.
2. Monic linear division: use a reverse Horner/synthetic-division recurrence with one accumulator, avoiding the intermediate remainder vector and per-iteration trimming.
3. Nonmonic division: discard the top coefficient after choosing the quotient coefficient, since it cancels exactly, instead of multiplying and subtracting its leading term.
4. Sparse polynomial multiplication: skip zero coefficients in either input rather than performing modular multiply-accumulates by zero.

These paths operate only on public verifier inputs and are variable-time.

## Perf access and outstanding work

The `perf` executable was absent in the local container. Direct Linux `perf_event_open` software task-clock attempts returned `EACCES` (errno 13), so hardware-cycle and instruction measurements were not available. Local timings above use CPU-affined `steady_clock`, not `perf` hardware counters. The Rust measurements use elapsed wall-clock `Instant`.

Full-library compilation/validation is not established by the isolated job. Aggregate polynomial-root throughput, index-calculus relation throughput, and GPU throughput have not yet been measured. The pull request remains draft pending full validation.
