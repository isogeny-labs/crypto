# Root-finding optimization Round83 (2026-11-21)

**Status: experimental, [draft PR #4873](https://github.com/isogeny-labs/crypto/pull/4873), do not merge.** Baseline is Round82 commit `359e1140f5315feac52e116bd5ea96ab49b22389`. Source-exact benchmark script: [round83_full_ab.py](round83_full_ab.py).

## Candidates and final experimental code

1. Complete-root certificate factor reconstruction: reuse one preallocated vector and update coefficients backwards when multiplying by each `(X-r)`. For `r=0`, perform a coefficient shift. **Enabled only for the maximum supported degree (eight)**; retain the former short-product path below eight, since broader dispatch caused regressions in previous A/B tests.
2. Reuse the existing verifier symmetric-square kernel for modular-power replay: **rejected** after two exact Rust A/B attempts showed broad solver regressions, especially degree eight. The replay keeps its original multiplication.
3. Replace GCD replay state clones with moves: **rejected** after local GCC/Clang analogues regressed.
4. Eliminate redundant per-field event-capacity checks in the trace engine: after `field()` checks the room and work budgets, it calls a new already-prechecked emitter; all other event kinds retain the original capacity check. The reporting, sink-failure charging and event schema are unchanged. This remains **experimental** until broader validation.

## Local profiling and correctness

CPU-pinned GCC/Clang reproductions each passed 2,304 exact constructed root-product and polynomial-square comparisons; UBSan passed. Across 13 paired trials, the isolated degree-eight root-product median was **3.09x (GCC)** and **2.57x (Clang)** faster at p=1,000,000,007; at p=2^61-1 it was **2.92x (GCC)** and **2.84x (Clang)**. A trace-event budget-check analogue showed 1.108x GCC and ~0.998x Clang, insufficient for an integration claim.

Linux `perf` executable was absent. Direct `perf_event_open` probes of task-clock and cycles returned **EACCES** (kernel `perf_event_paranoid=2`), so there are **no hardware-counter results**. These C++ microbenchmarks are not source-exact production Rust.

## Acceptance gate

- Do **not merge** while full solve+verify regressions exist, or while Round82's parent PRs remain drafts.
- Ablate the event-budget shortcut independently from the degree-eight product to isolate the regressions; require two or more repetitions showing a stable end-to-end gain across field sizes.
- Run broader repository tests, historical certificate tampering/sink failure tests, and representative index-calculus **relations/second** measurements before any merge.

The independent verifier still validates root ordering, canonical values, factor products and Frobenius/GCD certificates. No relation-generation throughput improvement was measured.
