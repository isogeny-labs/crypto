# Round 18: s=1 membership, sparse roots, stack normalization (2026-11-18)

Production PR: https://github.com/isogeny-labs/crypto/pull/4706. Compiled production Rust CI: https://github.com/isogeny-labs/crypto/actions/runs/44337121900

## Source changes

- AMM when `v3(|K*|)=1`: `x=a^e3` and test `x^3==a`, skipping the independent `a^t` membership power for canonical public field elements.
- Monic `y^2+by`: return `{0,-b}` without discriminant/sqrt; general `ay^2+by`: return `{0,-b/a}` without sqrt.
- Quartic with zero constant: factor `x`, solve cubic cofactor, add zero; avoid Ferrari resolvent.
- `RadicalRootCtx::roots`: stack `[u64;5]` coefficient normalization replaces per-call allocation for degree ≤4, preserving arbitrary modular-zero padding.
