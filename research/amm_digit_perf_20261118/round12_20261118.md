# Rootfinder arithmetic optimization round 12 (2026-11-18)

PR #4706: `src/cryptanalysis/prime_radical_root.rs`, public-input CPU operations only.

## Changes

1. **General quadratic early reject.** Compute discriminant `b² - 4ac` before inverting the leading coefficient. If there is no square root, return immediately without an inverse. For monic quadratics, reuse `quad_monic` directly.
2. **Monic quadratic Vieta finish.** The second root is `-b - root0`. Replaces a modular multiply by inv2 with a subtraction.
3. **Monic cubic shortcut.** Already-monic cubics avoid a spurious inverse and three coefficient multiplications.
4. **Experimental adaptive 4-bit power window** in `rpow`, with `Fp::powm` sharing that implementation, for dense public exponents; shorter/sparser exponents preserve binary powering. Do not assume this is a general win; negative controls below require actual-Rust decisions.

### Negative exponentiation controls

Do **not** extrapolate the synthetic dense exponent gains to arbitrary AMM exponents.
For actual `e3`-shaped Fp2 exponents at `p=2^61-1`, GCC `1,899.676 → 2,423.056 ns` (**0.784x regression**) while Clang `1,729.846 → 1,487.247 ns` (**1.163x improvement**). The C++ outcome is compiler-dependent. Rust benchmarks on the production file and actual exponent distribution are a blocker before enabling this broadly.

### Correctness and integration

C++ mirrors validated identical quadratic roots on 2,048 intentionally split and 2,048 irreducible random quadratics per prime (4 primes) and binary/window equivalence on 2,048 random field values × 8 exponents × 4 primes, for both Fp and Fp2.
The actual Rust module now includes frozen-reference equality tests for powers, discriminants, quadratic roots, noncanonical coefficients and dedicated paired benchmark functions.
The isolated GitHub Actions workflow imports the production Rust module directly. Run status must be checked separately; no unverified CI success claim here.
Full-library CI can independently fail on duplicated test definitions in `ic_framework/plugins.rs`, outside this diff.
