# Round 22: Nonresidue setup and trace-field arithmetic (2026-11-18)

Production source modifications:

- `prime_radical_root.rs`: use quadratic reciprocity for the *first* quadratic nonresidue (2 via p mod 8, 3 via p mod 12, 5 via p mod 5), falling back to Euler scans from 7. Skipping 4 and 6 is valid when 2 and 3 are quadratic residues. The nonresidue and Fp2 representation are identical to the frozen search.
- `prime_root_trace.rs`: use one-correction modular add/sub for canonical field inputs, native u64 multiplication for p<=2^32-1, and Mersenne folding for p=2^61-1. Unhandled and noncanonical cases use the original u128 remainder. Trace events and work accounting are unchanged.
- Added production-Rust equivalence tests and ignored paired microbenchmarks. Workflow explicitly runs the new nonresidue test and Rust microbenchmark.
