## Code changes

1. Normalize nonmonic moduli once in the independent certificate verifier modular exponentiation. Scaling a polynomial modulus by a nonzero field unit preserves every Euclidean remainder. This saves extended-Euclid inversions across repeated power steps.
2. Add vpower_reduce with owned residue inputs, avoiding zero-quotient allocations and redundant clones when polynomial degree is below the modulus degree.
3. Keep the normalized modulus in PowerState for independently replaying PowerBegin/PowerStep, while checking original certificate values unchanged.

Added Rust tests: round95_nonmonic_power_reduction_matches_legacy_reference (1,536 deterministic power equivalence cases) and round95_verify_nonmonic_root_certificates. Source-exact Rust A/B uses research/amm_digit_perf_20261118/round95_nonmonic_ab.py, baseline commit 11c7c28e9314525a9fc310ef6ce73eca2dbff0e5.
