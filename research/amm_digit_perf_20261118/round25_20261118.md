# Root-finding verifier optimization round 25 (2026-11-18)

Scope: `src/cryptanalysis/prime_root_trace.rs`, independent public-input root-certificate verifier.

## Production code changes

1. **Synthetic division of monic polynomials.** For leading coefficient one, the leading term cancels exactly. Remove the redundant multiply-by-one, subtraction, and modular inverse; pop the canceled coefficient. Preserve the old nonmonic loop unchanged.
2. **Symmetric polynomial squaring.** Compute each off-diagonal product only once, double it modulo p, and retain the ordinary fused product for short inputs with 32-bit prime moduli (actual Rust showed their crossover was not favorable).
3. **Modular polynomial powering.** Use symmetric square in repeated squaring rather than generic polynomial multiplication.
