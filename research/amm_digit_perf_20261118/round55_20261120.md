# Round 55: small polynomial squares (2026-11-20 UTC)

## Production changes

File: `src/cryptanalysis/prime_root_bounded.rs`, PR [#4706](https://github.com/isogeny-labs/crypto/pull/4706).

- Producer constant square: one field multiplication, no redundant addition into zero.
- Producer monic linear square: `(x+c)^2=x^2+2cx+c^2`, one field multiplication and one modular doubling; includes `x^2`.
- Producer dense symmetric square: extend established optimized kernel from length >=5 to length >=2, retaining sparse fallback for exact zeros.
- Independent verifier: corresponding constant, monic linear and dense length-2..4 optimizations in `Replay::square_diagonals`; no producer arithmetic reused.

The monic-linear case reduces charged field arithmetic from 7 to 2 per producer or verifier invocation. Output coefficients remain canonical, and no budget or deadline check is skipped for arithmetic actually performed.

## perf limitation

Local `perf` binary is not installed. Direct `perf_event_open` attempts for software `task-clock` and hardware `cycles` and `instructions` all returned `EACCES` (errno 13); `perf_event_paranoid=2`. Consequently, local measurements are CPU-pinned clock-based A/B timings, **not perf PMU data**. Exact source-compiled Rust timings are from the isolated CI runner. No index-calculus relations/sec measurement has been made.
