# Round 121 — Fp2 sparse multiplication and 32-bit Jacobi narrowing
2026-11-22 · Draft PR #4909 · **do not merge yet**

## Production changes

- `src/cryptanalysis/prime_radical_root.rs`: In `Fq2::mul`, when the **left** imaginary coefficient is zero, compute `(a,0)(c,d)=(ac,ad)` directly, saving one base-field multiplication relative to the generic Karatsuba path. The dense arithmetic body is unchanged, but its new entry branch has a measurable cost.
- `RadicalRootCtx::sqrt_discriminant`: for canonical discriminants of every eligible 32-bit modulus, run the Jacobi remainder loop using `u32` rather than `u64`. The special `p=2^32-5` addition chain is preserved.
- Added two native Rust unit tests, the [Round121 A/B harness](../amm_digit_perf_20261118/round121_sparse_fq2_ab.py), and the [Round121 workflow](../../.github/workflows/radical-root-round121.yml).

## Local Linux performance counters

AMD EPYC 9V74 · GCC and Clang C++ algorithmic reproductions with `-O3 -march=native` · CPU pinned · 15 alternating A/B trials, twice. Linux `perf_event_open` software task-clock measurements succeeded. The `perf` CLI and hardware PMU cycles/instructions were unavailable. GCC ASan/UBSan passed, and 300,000 randomized Fp2 comparisons per compiler run matched.

Isolated left-sparse Fp2 multiply: **GCC 1.83–2.19x**, **Clang 1.76–2.09x**, depending on field and run. Dense controls ranged approximately 0.93–1.08x. These C++ timings are screening results, **not Rust numbers**.

The 32-bit Jacobi narrowing gave mixed local complete-quadratic results (near parity to roughly +6% in favorable runs). Independent randomized Euler/sqrt tests passed, but production Rust old/new discriminant timing was not established.

## Alternative candidates screened

- Both-operand sparse checks: rejected; local dense regression up to roughly 9%.
- Cold/out-of-line sparse handler: rejected; lower sparse speedup and no reliable dense recovery.
- Check 61-bit modulus before sparse branch: rejected in C++ screening; compiler-dependent dense regression.
- Adaptive 64→32-bit Jacobi loop: rejected, with GCC 0.89x regression in one uniform-quadratic control.

## Acceptance decision

**Keep draft and unmerged.** Replicate source-exact Rust timings, characterize actual operand sparsity in AMM cubic/quartic root solving, remove or constrain the dense penalty, and run full repository CI. ECC2K binary-field index-calculus relation throughput has **not** been measured and is not claimed to improve.
