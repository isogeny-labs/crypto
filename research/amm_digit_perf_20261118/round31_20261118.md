# Round 31: bounded prime-field root extraction (November 18, 2026 Pacific)

PR: https://github.com/isogeny-labs/crypto/pull/4706
Source: src/cryptanalysis/prime_root_bounded.rs

## Seven optimized code paths

1. Gate.scalar: avoid two consecutive Instant::now() calls per successful field operation. The charge() path already checks the deadline; on FieldLimit, we explicitly check the deadline first to preserve Deadline precedence. No resource charges were removed.
2. Producer.add / Producer.sub: native 64-bit conditional reduction for canonical coefficients, replacing u128 remainder.
3. Producer.mul: Mersenne end-around carry for p=2^61-1, native 64-bit product for p<=2^32-1 and unchanged general u128 fallback.
4. Replay.plus / Replay.minus: native conditional reduction.
5. Replay.times: separately implemented Mersenne/small-field product reduction, preserving the independent checker and the general u128 fallback.

All shortcuts operate on canonical *public* field data; they are variable-time, not constant-time.

Before that change, canonical arithmetic shortcuts alone showed only ~1-2% positive native-Rust results on addition and neutral/slightly negative multiplication under the costed gate. Do not attribute the entire 1.7x to Mersenne arithmetic.

## Exact validation

The isolated Rust job passed **165,888 exact equivalence comparisons** vs frozen original and wide u128 references at nine primes. The full rootfinder before/after tests over p=17, 487, 1,000,000,007, 2^61-1 and two degree classes matched every emitted event, roots, resource counters and stop reason. Separate independent streaming replay checks passed. The latest isolated script additionally tests deadline priority and no charges on failed scalar-budget calls.

- Producer add p=1e9+7: 2.800 -> 0.948 ns (**2.95x**).

- Producer mul p=2^61-1: 3.238 -> 1.318 ns (**2.46x**).

Clang independently measured 3.91x, 5.02x, 2.00x and 2.58x for those arithmetic-only cases. Linux perf executable was unavailable; both software task-clock and hardware CPU-cycle perf_event_open probes returned EACCES (errno 13). Thus local data comes from pinned wall-clock medians, **not actual perf counters**.

The automation run ZIP contains benchmark source, raw GCC and Clang CSVs, sanitizer log and exact perf diagnostics.

## Scope and limitations

Complete real bounded root extraction has now been timed in actual production Rust for degrees 1 and 2. Larger degree 3-8 workloads, the full library build, GPU root extraction and index-calculus relation-generation throughput remain unmeasured. PR #4706 should remain draft until full-library checks and richer workload coverage are resolved.
