# Round 35: deflate known +/-1 roots before Cardano/Ferrari (2026-11-19)

## Production changes

Module: `src/cryptanalysis/prime_radical_root.rs`.

1. **Monic cubic:** test whether +/-1 is a root using canonical coefficient sums in a native u64 (no modular multiplication or division). If so, synthetic-divide by `x-1` or `x+1` and solve one monic quadratic, bypassing Cardano, AMM, and extension-field arithmetic.
2. **Monic quartic:** use the same inexpensive root tests, synthetic-divide to a monic cubic, and avoid Ferrari's resolvent or the generic Frobenius factorization fallback.
3. **Mersenne Fp exponentiation:** skip the final, unused squaring in the binary `Fp::powm` loop for `p=2^61-1`.

The shortcuts accept canonical public coefficients only. The base-field limit `p<=2^61-1` makes the raw coefficient sums overflow-free. Results remain sorted and deduplicated; the `frobenius_fallback` indicator reflects whether a fallback was actually used. No constant-time or secret-scalar claims.

### Correctness

The isolated job passed `round35_small_linear_factors_match_bruteforce`: 1,344 cubic/quartic root sets across seven primes, both signs, and 48 varying cofactors per sign/prime; it also checks the direct cubic API. `round35_mersenne_power_skip_terminal_square_matches_previous` passed 4,096 exact power comparisons, including exponents 0, 1, fixed and random values. The ignored native Rust benchmark separately passed exact before/after digest assertions for its chosen inputs.

The general exhaustive quartic test is **not runnable inside the isolated test crate** because that crate intentionally stubs the generic Frobenius fallback; an initial CI job failed for this harness limitation, not for a new arithmetic mismatch. The isolated workflow was corrected to run the relevant specialized tests. Full-library validation is tracked separately and may be blocked by unrelated repository issues.
