# Round 33: bounded root-finder polynomial squaring and monic division

Date: 2026-11-19 (UTC). PR: https://github.com/isogeny-labs/crypto/pull/4706

## Production changes

File: `src/cryptanalysis/prime_root_bounded.rs` (commit `1c772d5381ee6e87e186f330e1dd60789a344992`).

1. **Producer symmetric squaring**: repeated polynomial powering now computes the diagonal once and each off-diagonal product once, doubling cross terms. Exact zero coefficients are skipped. This replaces a generic polynomial multiply for squaring.
2. **Producer monic/sparse division**: monic divisors require no reciprocal or leading-coefficient multiply; the cancelling leading coefficient is zeroed directly, and zero-valued lower divisor terms are skipped. General nonmonic divisors retain a reciprocal and the same quotient/remainder.
3. **Independent replay symmetric squaring**: verification still uses an output-diagonal traversal, but computes each mirrored pair once in modular exponentiation. The replay is implemented independently of the producer.

These are *public-input, variable-time* optimizations; not constant-time crypto primitives. Producer/replay resource-work counters can decrease in proportion to skipped operations, while high-level certificate events remain identical.

## Local profiling attempt and C++ independent screening

The local environment had **no `perf` executable**, and both `perf_event_open` software task-clock and hardware cycles returned `EACCES` (errno 13). `/proc/sys/kernel/perf_event_paranoid` was 2 on a read-only procfs. Consequently no hardware PMU, cycle, instruction or `perf stat` measurements are available.

Local CPU-pinned GCC `-O3 -march=native` C++ arithmetic reproductions provided **wall-clock-only** independent screening, 13 alternating paired trials, medians, and 6,912 exact reference comparisons across three primes and three polynomial distributions; UBSan build also completed without errors. ## Scope, regression controls and next work

The measured end-to-end gains are specific to `solve_bounded` with constructed roots and public primes. This does **not** establish improvements for complete radical-root Cardano/Ferrari extraction, ECC point decomposition, index-calculus relation throughput, GPU kernels, or cryptographic constant-time operation.

The dedicated isolated Rust workflow passed. Full-library and other repository-wide jobs remain separate gates; the PR should remain draft until all required checks pass. Next useful measurement: profile the hot degree-8 split/gcd workload using actual hardware PMU counters on a host with appropriate permissions, and separately measure verifier end-to-end replay cost.
