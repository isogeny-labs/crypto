# Round 53: bounded polynomial root inverses and constant division

**Date:** 2026-11-20 UTC. **PR:** [#4706](https://github.com/isogeny-labs/crypto/pull/4706). **Dedicated native Rust job:** [round-53 CI](https://github.com/isogeny-labs/crypto/actions/runs/44662073809/job/136042549210) (passed; `rustc 1.100.0 -O`, Ubuntu 24.04).

## Three production changes

1. `Producer::inverse`: replace Fermat exponentiation by an explicitly bounded extended Euclidean algorithm, using signed `i128` Bezout coefficients and charging every quotient step. No secret-key or constant-time claims.
2. `Replay::reciprocal`: implement independent binary almost-inverse by shifts and modular coefficient subtraction. Replay remains independent of producer quotient Euclid and still verifies root identities/event stream.
3. `Producer::division`: exact nonzero-constant division shortcut. Constant 1 returns the polynomial; other constants use one inverse and a coefficient pass, with aggregated copy work and per-field checks.
