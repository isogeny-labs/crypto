# Round 122 — 2026-11-22: AMM cofactor cache and candidate audit

**Result: retain one targeted optimization; revert two candidates after full-root regressions.** Draft PR [#4909](https://github.com/isogeny-labs/crypto/pull/4909) remains unmerged.

## Retained production change

In `src/cryptanalysis/prime_radical_root.rs`, `Cube<R>::new` already computes `t = |K*| / 3^s`. The hot `Cube::root_inner` recomputed a dynamic 128-bit quotient and `t % 3 == 1` on each eligible AMM cube-root query. Cache the 3-coprime cofactor and its 3-class per field. This is algebraically exact, variable-time, **public inputs only**. Update the hand-built test context and add order/root checks.

[Source-exact native Rust A/B, two successful executions](https://github.com/isogeny-labs/crypto/actions/runs/45084007306), Rust 1.100.0 optimized, CPU-pinned, 13 alternating trials, median ns/op, 2,304 comparison cases per execution, matching checksums:

## Local Linux screening and perf restriction

AMD EPYC 9V74, GCC 14.2 and Clang 17, CPU 0 pinned, 32,768 representative group-order inputs, two independently repeated C++ runs. Isolated cofactor division/mod-3 replacement was 1.73–2.61x faster depending on compiler and optimization scope. GCC ASan/UBSan and equivalence comparisons passed. **Do not conflate with production Rust timings.**

The `perf` executable is absent, and `perf_event_open(PERF_COUNT_SW_TASK_CLOCK)` returned `EACCES` (errno 13); hardware counters were also unavailable. Therefore local results are **steady-clock wall-time measurements, not successful perf counter data**.

## Rejected variants

- **Manual nonmonic quadratic ordering.** C++ isolated two-element sort improved 1.30–1.33x, but [native source-exact Rust complete-quadratic tests](https://github.com/isogeny-labs/crypto/actions/runs/45084248185) passed 6,009 equivalence comparisons and showed regressions: p=97 uniform 56.714→63.039 ns (0.900x); p=65,521 uniform 125.471→133.904 ns (0.937x); p=1e9+7 known-root 243.001→253.371 ns (0.959x). **Reverted**.
- **Skip the initial AMM correction multiply by the identity.** Algebraically sound, but [two native source-exact Rust A/B executions](https://github.com/isogeny-labs/crypto/actions/runs/45084373609) showed p=65,521 complete cubic 488.119→506.310 ns (0.964x), and p=2^61−1 Fp2 cube-root 1693.210→1801.313 ns (0.940x) in replication. **Reverted**.
- **Mersenne exponentiation traversal / canonical bypass.** Local C++ left-to-right or speculative bit multiplication benefited short powers, but regressed heavily for 61-bit dense exponents (as low as 0.56–0.65x). **Not applied to Rust**.

## Acceptance

The retained AMM optimization is source-exact Rust A/B validated, but whole-crate CI, merge readiness, and end-to-end ECC2K relations/sec remain unmeasured. This code is for prime-field radical roots, not the binary-field ECC2K index-calculus relation engine. Keep PR draft and unmerged. Retain historical benchmark scripts for rejected candidates, but remove their automatic workflow triggers.
