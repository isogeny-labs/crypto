# Round 23: root-trace verifier fast modular arithmetic (2026-11-18)

Production changes in `src/cryptanalysis/prime_root_trace.rs`:
- Independent verifier `vmul`: native 64-bit 32-bit-modulus path and Mersenne `2^61-1` two-fold reduction, preserving the generic `u128` fallback for noncanonical inputs.
- `vproduct`: fused multiply-accumulate without `u128` division in those two modulus classes.
- `vdiv`: canonical modular subtraction, avoiding `u128` modulo.
- `verify`: canonical field Add/Sub verification and modulo-free linear-root check.

## Limitations and rejected experiment

Local `perf` binary was absent. `perf_event_open` software task-clock returned **EACCES** (`perf_event_paranoid=2`), so local medians are pinned wall-clock, not PMU cycles or instructions. No claim of end-to-end root extraction, relation-generation or GPU speedups.

A proposed `Fp::powm` final-squaring elimination regressed to **0.830x** on the p=2^61-1 square-root exponent in the local GCC reproduction and was **not committed**.

The isolated Rust CI job passed; full-library validation remains separate. PR remains draft pending whole-solver integration evidence.
