## Implementation

The polynomial ring identity `f(x) mod x^d = sum_{i=0}^{d-1} f_i x^i` permits direct truncation. Also `f(x) = x^d * floor(f/x^d) + (f mod x^d)`, with the quotient just the shifted high-coefficient sequence. Four production paths now specialize monic powers `x^d` for `d >= 2`:

1. `Producer::division`: split the high and low coefficient arrays directly.
2. `Producer::reduce_monic`: truncate high coefficients.
3. `Replay::remainder`: independently truncate the low coefficients, including any nonzero leading scalar on the divisor.
4. `Replay::cancel_monic`: independent truncation with replay-specific work accounting.

For producer division/reduction the metered work counts nonzero high-degree cancellations, consistent with the former trim-driven method. For replay the original fixed descending traversal checked every degree, so the fast path aggregates the same number of COPY_WORK charges. All four preserve deadline/budget checks, no field arithmetic is needed, and all outputs remain canonical Poly17 values.

A new unit test compares against an independent coefficient-split oracle across 4 primes, degrees 2 through 8, multiple input lengths, and 32 randomized polynomials per length. The source-exact paired Rust CI tests both the original and modified source using R56 markers.
