# Round 113: quadratic Karatsuba and unit-inverse shortcuts (2026-11-22)

Target: `src/cryptanalysis/prime_root_trace.rs`. [Draft PR #4880](https://github.com/isogeny-labs/crypto/pull/4880). Frozen baseline `d4598fdb83ba6fa64bcc65ac1faf6ee67bc40b34`; source-exact final code `f43f29d06e1809d1f8517a5259762a996f0e010b`.

## Changes

- Added a 32-bit-prime Karatsuba quotient-ring quadratic multiplier, replacing two cross multiplications with one product and two modular subtractions. The 61-bit Mersenne implementation and power loop retain their original paths after native performance screening.
- Special-cased multiplicative inverses of 1, -1, 2, -2 ahead of extended Euclid. Zero and generic operands are unchanged.
- Added a randomized independent-arithmetic oracle test spanning p=3, 5, 65,521, 1,000,000,007, and 2^61-1; native A/B harness now includes isolated multiplication, inversion, modular power and complete root extraction plus independent certificate verification.

**Rejected:** sliding-window polynomial powering (inconsistent shape-dependent timings), fixed-storage degree-5/6/8 Mersenne quotient ring (Clang/sparse regressions), and 61-bit Karatsuba (regressed locally).

**Decision: keep PR draft/unmerged.** End-to-end regressions, repository-wide validation and actual ECC2K index-calculus relations/sec are still unresolved. Measure these before accepting the change.
