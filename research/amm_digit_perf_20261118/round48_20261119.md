# Round 48: Shared Tonelli–Shanks powers and fixed nonresidue (2026-11-19)

## Production changes

In `src/cryptanalysis/prime_root_bounded.rs`, for squarefree quadratic factor splitting over `Fp` with `p=1_000_000_009`:

1. Producer caches `11^((p-1)/8) mod p = 172_252_358`, instead of recomputing the constant on each split.
2. Producer obtains the two powers `D^q` and `D^((q+1)/2)` via one shared ladder of squares, where `q=(p-1)/8=125_000_001`.
3. Independent certificate replay uses the same mathematically fixed nonresidue power, eliminating its redundant field exponentiation.
4. Replay has its own bit-indexed shared ladder and independent field arithmetic. Both paths verify the reconstructed square root before using it.

The constant is independently checked in a production regression test against a wide `u128` modulo oracle: `c^4 = -1`, `c^8 = 1`. No constant-time claims. Non-eligible primes retain the earlier path. No event schema changes.
