# Root-finding optimization round 74 (2026-11-20)

## Production change

Replaced the runtime division in canonical 32-bit prime multiplication in
src/cryptanalysis/prime_radical_root.rs with a cached 64-bit Barrett
reciprocal. Fp::new computes mu = floor(2^64 / p) only once per field.

For a,b < p <= 2^32 - 1, x = a*b < 2^64.
q = floor(x*mu/2^64) is either floor(x/p) or one less; hence
r = x - q*p satisfies 0 <= r < 2*p. One conditional subtraction of p
gives the exact residue. Product, quotient and correction fit u64/u128.

Noncanonical inputs, primes larger than u32, and the existing 61-bit
Mersenne fast path are preserved. Shared uses include quadratic, cubic
and quartic root extraction, Fp2 multiplication/squaring and AMM powering.

## Explored but rejected

- Applying the Jacobi prefilter to additional quartic sqrt probes:
  at a 50% quadratic-residue mix the 61-bit GCC case was 0.920x,
  and guaranteed-root cases regressed further. Not committed.
- One fold plus two corrections in fused Mersenne multiply-add:
  1.124x GCC but 0.948x Clang. Not committed.
