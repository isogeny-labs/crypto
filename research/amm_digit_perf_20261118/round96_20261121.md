# Round 96: scalar quotient-ring powering for linear moduli

Date: 2026-11-21. Source-exact native Rust comparison against frozen Round95 head commit `2b5100f506001e3947658886731b9b4dbad4738e`. Current candidate remains a **draft**, not approved for merging.

## Optimizations implemented

1. **Linear quotient-ring powering:** In verifier `vpower`, when modulus is `c + dX` with nonzero `d`, reduce an input polynomial by Horner evaluation at `-c/d` and then exponentiate a scalar. This replaces repeated polynomial convolution, division, and heap allocation during modular powering. Supports nonmonic divisors, zero residues, and exponent zero.
2. **Avoid unused final scalar square:** `vpow` shifts exponent before squaring and performs no final square when the exponent has reached zero.
3. **Clone-free certificate header validation:** `verify` matches borrowed fields of the first `RootEvent::Begin` instead of allocating `report.polynomial.clone()`.

The trace producer, report schema, independent verifier, and legacy APIs were not altered. The quotient-ring identity follows from `F_p[X]/(c+dX) ≅ F_p` for `d != 0`.

## Local perf task-clock and arithmetic analogy

A local CPU-pinned C++ algorithmic analogue was built with GCC and Clang on an AMD EPYC 9V74. Each compiler validated 9,000 randomized quotient-ring equivalence cases. GCC UBSan passed. 15 alternating A/B trials over 9 prime/modulus-shape configurations, 24 input fixtures * 80 repetitions each.

- GCC speedups for p=1e9+7: 3.41x nonmonic, 6.25x monic, 3.41x zero constant; for p=2^61-1: 2.07x, 3.71x, 2.07x.
- Clang speedups for p=1e9+7: 2.70x nonmonic, 4.82x monic, 2.87x zero constant; for p=2^61-1: 1.84x, 3.25x, 1.84x.
- `perf_event_open` successfully collected **software task-clock** samples for every local before/after trial; ratios were consistent with wall clock. Hardware cycles and instructions counters returned ENODEV. The `perf` CLI was not installed.
- C++ uses generic `u128` multiplication instead of optimized production Rust small-field and Mersenne arithmetic, so these are **not Rust performance figures**. Local raw trials and reproduction source are included in the conversation artifact for Round96.
