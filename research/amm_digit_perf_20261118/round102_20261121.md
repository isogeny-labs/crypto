## Implementation

In `src/cryptanalysis/prime_root_trace.rs`, specialize degree-three quotient-ring arithmetic over odd prime fields:

1. Fused cubic multiplication reduces x^4 and x^3 directly without generic polynomial products, quotient storage or repeated trim scans.
2. Symmetric cubic squaring evaluates each cross-product once and directly reduces the result.
3. Horner evaluation reduces an arbitrary-length base into three scalar residues, then cubic power uses the scalar-array multiplication and squaring operations.
4. `PowerStep` certificate replay uses these independent fused operations for monic cubic moduli and p >= 2^24. The solver trace, public API and certificate format remain unchanged.

New randomized Rust tests compare against independent polynomial long-division arithmetic across p=7, 65,521, 1e9+7 and 2^61-1, monic and nonmonic moduli, arbitrary-width bases, powers, products and squares.
