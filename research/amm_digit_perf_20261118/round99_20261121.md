## Code changes

- During independent certificate `PowerStep` replay for monic quadratic moduli, fuse residue multiplication with reduction in the two-coefficient quotient ring. This bypasses general convolution and quotient/remainder allocation.
- Likewise, fuse symmetric quadratic squaring with reduction, removing the separate generic product, quotient allocation and trimming.
- Preserve zero/constant/linear residues, canonical trimming, the producer's independent field-operation event trace, and the certificate schema. Other modulus degrees use existing generic arithmetic.
- **Use the fused replay path only for p >= 2^24.** Two source-exact initial Rust executions showed repeatable 4% complete-quartic and 2.4% degree-eight regressions over p=65521, despite favorable isolated C++ microbenchmarks. The guarded production version restores prior small-field arithmetic. Threshold is empirical, not an asymptotic claim.

The production source has a targeted `round99_quadratic_power_step_replay_matches_generic_polynomials` test: 8,192 deterministic randomized cases per prime for each of multiplication and squaring, with p=3, 65,521, 1,000,000,007 and 2^61-1. The independent oracle uses generic `vproduct` plus `vpower_reduce`. Existing certificate tamper/replay tests also run.
