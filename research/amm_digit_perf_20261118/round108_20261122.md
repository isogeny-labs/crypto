# Round108: traced multiplication by 1 and X (2026-11-22)

Draft [PR #4880](https://github.com/isogeny-labs/crypto/pull/4880). Final source commit `d02058b3715bc2532b8710b17920cea7af86af8b`. Frozen Round107 baseline: `b9daacfc955b703dc94a2320ee2091ff4b47607f`.

In `src/cryptanalysis/prime_root_trace.rs`, `Engine::mul` recognizes `1*f`, `f*1`, `X*f` and `f*X` (the X case requires the other operand width >=4). It returns a copy or coefficient shift and still emits the same independently verified `Product` event. The fast path is called only for prime <=65,521 and a short operand; generic dense convolutions and independent certificate verification remain untouched. The new randomized Rust oracle tests cover four fields, five widths, 64 cases, two monomials and both operand orders.

No reliable *complete solver* speedup has been demonstrated.
