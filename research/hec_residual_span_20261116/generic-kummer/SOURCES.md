# Sources and stage boundary

Flynn's primary generic biquadratic expressions: https://people.maths.ox.ac.uk/flynn/genus2/kummer/biquadratic.forms and its README https://people.maths.ox.ac.uk/flynn/genus2/kummer/README . Original coordinates and the projective sum/difference identity were read. SOURCE.sha256 pins the fetched mathematical expression file. The generator parses published mathematical monomials, substitutes f5=1, f0=c and all other f_i=0, and emits integer coefficient tensors. It does not execute Maple or copy the author's program/prose into this repository. Algebraic formulas are attributed to Flynn; no new priority claim.

Stage 1 protocol: freeze/push source hash, generator and binary before one symbolic specialization. Require 16 forms, degree two in each input and both matrix/argument symmetry after exact integer coefficient collection. Retain generated tensors and stdout/stderr/hash. This is symbolic implementation preparation, not a speed result. If a source/parse/algebra gate fails, retain it and do not silently rerun.

Stage 2 will have a separate prospective primitive protocol and binary freeze after projection, fixed-input coefficient compilation, all-chart differential addition and charged signed recovery are implemented. No complete solve or tenfold claim from symbolic specialization. Runtime scientific code is Rust; no Maple, Magma or Python execution. The earlier Kummer screen's field restrictions remain unchanged.

Adjacent retrieved source: mariascrs/NN_isogenies commit bdc57f671cea175b512b95d792256440f977242e. Its functions.m and isoNN.m implement fast theta arithmetic, not the needed generic base-field circuit. Its Maple derivation starts with rational Rosenhain branch data. MIT license inspected; none of that code is ported. This source collision prevented importing the wrong kernel.

Primary projection/recovery: Chung–Costello–Smith section 6.3–6.4, https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/recovery.pdf . For this binomial model the generic projection specializes to (1,-u1,u0,v1²+u1*(u1²-u0)). The identity and degree-one charts require explicit cases, as in Flynn's classical coordinates. Kummer signs are not relation signs.
