# Scalar verification by exhaustive action-component certificates

[pcc:unverified] Self-contained derivation for independent review, not a novel theorem or formally verified proof.

Let C:y²=x5+c be smooth over Fp with p not2,5, p=1mod5, z of order5, sigma(x,y)=(zx,y), and infinity the rational point at infinity. For each geometric affine P=(a,b), div(y-b)=sum_(i=0)^4 sigma^i(P)-5 infinity, with orbit multiplicity retained. For a!=0 the five x roots are distinct. At a=0,b!=0 the zero has multiplicity5; when b=0 smoothness gives simple zeros in local parameter y (x-a has order2), again the same formula. Infinity has pole order5. Thus Phi5(sigma)[P-infinity]=0. Such classes generate the Jacobian over the algebraic closure, so Phi5(sigma)=0 as an endomorphism. This uses principal divisors directly, without computing Frobenius characters.

For the fixed qualified instances, J(Fp) has prime order ell!=5. Nonzero D generates this cyclic group; sigma preserves it since sigma is defined over Fp. Hence sigma acts by a scalar lambda, and Phi5(lambda)=0. When all four distinct roots are supplied and their product polynomial is checked equal to Phi5, the actual action MUST be one of them. Whole-Jacobian prime order is the unchanged external instance premise, not inferred from one point order.

For each candidate root r, fold orbit signs/phases into conditional rows A_r L=b_r in units D. Public source row is L0=1/sm, target is the last coordinate, each primitive row is T+sum sign*r^phase*L_j=-a. The geometric principal relations imply these equations when r is the actual action. For each root a certificate must prove EITHER (i) w^T A_r=0 and w^T b_r=1 (excluded), OR (ii) w^T A_r=e_T and w^T b_r=k (scalar). The actual root cannot be excluded, since D!=0 and normalized 0=1 means 0=D in the group. At that root a scalar proof therefore exists and yields T=kD. If several roots supply scalar proofs all must bind the same claimed k; wrong roots need not be excluded if they prove that same k conditionally. No producer truth label or actual action computation enters this logic.

Security requirements for an independent verifier: check curve/prime-order model binding, D!=0 and source equation, target validity, rational z order5, complete distinct root product equality (not just individually valid roots), every used principal relation and orbit phase, each candidate's linear witness and same claimedk; reject missing/unresolved roots. Check principal multiplicities as in exact polynomial verifier, not mere point membership. Candidate-specific rowgeometry must be derived from same bound packet. These obligations are not all replaced by the current algebra gate.

This is proof by exhaustive finite alternatives, standard conditional linear certificate reasoning. Potential runtime effect: remove character-sum action bootstrap, pay up to four branch witnesses and root generation instead. Subgroup work can rise; no 10x conclusion without allphase costs.
