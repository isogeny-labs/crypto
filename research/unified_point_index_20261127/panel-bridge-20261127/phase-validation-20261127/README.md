The panel now requires the optimized arm's recorder schema, five exclusive online buckets summing to the online wall interval, cold clocks within the full solve process interval, and phase meter steps equal to the receipt's charged steps. A missing or inconsistent metric rejects that performance row while retaining the raw diagnostics. The legacy panel path is unchanged. A solve whose required arm replay cannot start before the deadline is marked incomplete. [pcc:unverified]

The scope permits only the four inherited lint classes documented in the preceding measurement-overlay receipt. Lossless logs and the attempted Conductor check are in `development.tar.xz`, with SHA256SUMS and source hashes. Conductor returned 127 because the CLI was absent. [pcc:unverified]

This validation does not attest the arm's clocks independently, calibrate primitive operations, price process overhead or recover failed-run internal phases. It is development code, with no benchmark, S3 checkpoint, image or native L2 run. [pcc:unverified]
