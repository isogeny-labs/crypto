It checks the live driver Git revision, pinned native crate tree and builder/overlay digests, frozen spec and protocol hashes and schemas, the public seed mapping, every panel file in the input hash list, the optimized policy and the one-thread/original-deadline bounds. It accepts no executable payload from the panel. [pcc:unverified]
