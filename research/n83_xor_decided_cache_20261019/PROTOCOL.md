## Mechanism and correctness boundary

A row may skip the expensive `lowest_unassigned`/`row_residual` work only while assignments have grown without a backjump. Increment an assignment-generation counter on every actual unassignment; invalidate all cached row decisions logically on generation change. Rebuild/reset of the parity matrix must clear cached decisions. Cache only after checking a row's residual; never skip a conflicting row. Preserve the existing pivot invariant, reason clauses, model verification, solver outcome and all default behavior. Handle generation wrap by clearing cache entries. Record the opt-in setting in each new worker receipt and container environment; prior receipts remain tied to their historical source commit.
