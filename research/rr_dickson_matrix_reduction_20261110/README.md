## What changed

The existing [p1tool](../split_prime_ecdlp_20261107/followups/p1_rr_dickson/p1tool/README.md)
adds `--reduce affine` and `--reduce quadratic` to RR emission. Affine mode uses
only equations of total degree at most one. Quadratic mode may use any equation
of the form `a*x+b=0`, provided `a` is a nonzero field constant and `b` contains
no `x`. Neither mode divides by a variable or saturates away a chart. Each
candidate is substituted into every remaining equation and rejected if any
result exceeds the original maximum input degree. Variable/equation scanning
order is deterministic. This is a representation change, not a new algorithm
claim; msolve may already perform equivalent preprocessing internally.

Reconstruction metadata records modulus, original variable names, retained
indices, sparse RHS polynomials, original equations, and SHA-256 digests of
both msolve inputs. Reverse substitution requires no planted coordinates.
Compare original equations and the pinned original input digest when auditing
the map; metadata generated by this producer is not an independent certificate.

The main risk is the same trade seen before: fewer variables may give denser
equations or different F4 behavior. Input degree preservation says nothing by
itself about solving degree. No claim to reduce either width or cost is made.
