# Admission before an executable two-section mapper

This is a preparation list, not an admitted experiment or performance protocol.
Full10xgenus2+ objective and failed complete-cold result remain unchanged.

1. Materialize the8descended homogeneous quotient sections globally. At
extension-valued inputs use the coefficient-Frobenius/character-permutation
formula from kummer13. Raising evaluated values to p powers also moves X;
the base-input field-trace shortcut is invalid. Preserve non-base controls.

2. Represent the source Jacobian on a complete finite atlas, or produce a
certificate that a selected chart contains a valid point. A local degree3
Mumford chart has6coordinates; divisibility u|(f-v^2) gives3equations.
Adding s(X),s(X+D),H(X) gives6equations. A Rabinowitsch variable can saturate
the known denominators. This is a chart-level system, not automatically the
full1296length intersection. Source addition charts and multiplicities matter.

3. Build the intrinsic inverse of Sigma away from0. Existing gradient/Hessian
formulas prove uniqueness on transverse-chord charts only. Need tangent,
nontransverse and chart-boundary handling or a proved chart-avoidance method.
Tian4.2.3 is the established comparator: general Kummer alignment plus lifting.
Do not mislabel the two-section route as the first algebraic mapper.

4. Certify finite zero scheme, degree<=1296, and avoidance of the two kernel
fibers. Extract a closed point without enumerating the extension field.
Retain failure/unsupported cases. Do not replace factorization by a point scan.

5. Decode U,V with one global orientation; compute closed-divisor traces and
actual source/destination subgroup checks. Require e coprimeell, and fail if
not, rather than silently divide. Compare public D1,B,D1+B,2B,-B,0 and a
withheld-scalar control against the frozen cyclic mapper. Challenge scalars
must never enter extraction. Corrupt section/sign/denominator controls needed.

6. Freeze any executable protocol/source/lock/fingerprints and checkpoint
before gates; only after correctness and the full cost case are credible,
admit complete cold comparisons against best existing arm. All construction,
extension algebra, quotient-ring solving, traces, exclusions, relation rank,
LA/descent and verification remain charged. Genus2/4 require separate mechanisms.

No local measurements, command executions of a scientific worker, or new
benchmark records were generated for this preparation. msolve is available
locally but has NOT been invoked; availability is not a solve or cost result.
