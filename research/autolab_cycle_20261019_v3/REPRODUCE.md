# Reproduce the component

Build each native C++ worker with g++ -O3 -std=c++17 -Wall -Wextra -Werror native.cpp -o native in its own source directory. Run pair_cell_obstruction worker with `replay controls`, `replay relaxed`, or `replay fixed`; adaptive_pair_cells takes only `replay`. Use one permitted CPU,4GiB and an external90s process-group deadline. These are correctness/profile replay commands, not qualified benchmark timings. Native guards include output serialization; only the parent supervisor charges final stdout lifetime. Frozen preregistrations and raw supervisor records are in raw/. Coordinator replay additionally needs the original anchored multi-GiB journal, intentionally excluded. Sources compile without external mathematical libraries. The original hard fixture and SAT dependencies are hash-identified in retained prior records but not included in this component publication. No claim that this subset reruns that hard search.
