# Different finite fields need different domain algorithms

The binary guard uses proper F2-subspaces and Frobenius-linear maps. Over odd extensionsK/Fp,the same image-cell theorem applies to p-linearizedL_Uand Fp-subspaces. For cubicq0+q1X+q2X^2,the general second-Vieta identity is
T2=3q0^2+2q0(q1e1+q2(e1^2-2e2))+q1^2e2+q1q2(e1e2-3e3)+q2^2(e2^2-2e1e3).
Expansion proves it in every characteristic withoutdivision,including3. Reducing the integer coefficients modulo2 gives the implemented binary formula. An odd-extension implementation and independent executable oracle are not supplied by this theoretical identity.

In a prime fieldFp,any nonzeroFp-linear span of pairwise products is allFp:one nonzero square already spans its one-dimensional vector space. Thus this subspace-quotient guard is vacuous for prime-field interval domains. A nontrivial properFp-subspace does not exist. NIST-prime work must keep exact interval/implicit-domain predicates and use a different support representation,for example the existing integer coefficient lifts with explicit quotient variables;it cannot inherit binary pruning percentages. A shared exact all-root interface can dispatch different field/domain-specific algorithms. No uniform fiftyfold speed claim follows from a binary optimization.
