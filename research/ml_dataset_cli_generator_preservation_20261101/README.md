The frozen CLI46 attempt at e0a865 retained only the three quadratic domain equations in each prime causal root native report. Two original quartic generators were absent and two pairs were above the degree bound. Independent two-way ideal checking correctly withheld the public prefix and algebraic channels. Original failed evidence is preserved in PR #3165; these fixtures do not replace it.

The opt-in traced visitor now emits an explicit generating_set: raw native rows followed by missing incoming generators. Branch selection and recursive specialization use this same set. The consumer reconstructs the exact native-plus-input contract, then independently checks both ideal containments. Retained inputs establish one direction by construction; the other still requires checked polynomial identities. Native report fields and native work counters remain unchanged. Legacy traces keep their earlier interpretation.

Algebraic training targets remain limited to the raw native row prefix and its matching proof prefix. Appended input constraints cannot receive native-derived labels or nonexistent native row indices. The full certified set is used only where needed for ideal checks and recursion. This changes traced traversal semantics intentionally; it is not a passive instrumentation claim.

The source includes four frozen-input regression fixtures, legacy-unknown checks, actual revised root/first-child traversal, and missing-generator, coefficient, raw-report and child-specialization mutation controls. Existing degree, time, certificate and event limits are unchanged. Additional comparisons/copies/serialization and larger specializations incur real wall/memory work; native field_ops is not a total traversal instruction count.
