# First bounded study: design for review, not a frozen execution protocol

The first implementation scope is the shared collector plus the full-target chord chart. The trace-variable construction stays queued. This design does not claim a run, scalar recovery, theorem, measurement or complete runtime estimate. [pcc:unverified]

## Gates before data

1. Approve checkpoint writes for the exact new branch prefix in LAUNCH_GATES.md. Use the current unmodified official script and a truthful branch/head-bound RESUME. No skip, fake marker, changed destination or broad credential fallback.
2. Read current instructions, atlas and primary sources, check Conductor, resolve source/target model identity and actual odd-subgroup transfer/current source bindings.
3. Implement new versioned native Rust/C++ producer and independent arithmetic auditor; keep old dated sources/records immutable. Implement a pinned Lean project for the actual chord factorization, membership completeness and exceptional branches. A statement record is not a proof.
4. Create and validate the canonical experiment.protocol/v1, exact input/source/analysis/control hashes and budget BEFORE execution; commit/freeze and obtain an actual successful official checkpoint.

## Pilot boundary

Proposed first fixture is the historical F37 E(7,19), d=35 monic twist T(28,33), P=(1,8), U=(32,29), cyclic order19, actual Phi/I=[10]D. Exact current identity/route pins are a launch prerequisite; do not invent registry aliases or infer a general rational main-to-twist map. The complete three-abscissa source-policy frontier and its matched/pullback controls must be declared before data. A favorable prefix cannot establish a strongest-policy result. [pcc:unverified]

For each policy/cap, inspect every frozen public setup-query prefix, then separate one-target workloads. Candidate receives actual unknown Q. Test source-only, twist-only, frozen alternating and dual-model schedules with shared column order. Charge both calls in dual mode and all unsuccessful calls. Report original-source scalar checks separately for every target; no batch-throughput substitution. Retain blocked setup, failures, identity shifts, sign lifts, ties and losses.

## Primary observation and work contract

The finite primary observation is additional useful coefficient rank from the combined admitted rows at a matched total-work prefix. Keep per-query and across-query criteria distinct. Require a common curve field/subgroup field declaration and shared ordered base; deduplicate by original coefficient rows. In the complete-or-unknown special case, inspect whether any per-query union criterion is vacuous before interpretation. [pcc:unverified]

Before a cost claim, define native operation counters and an ecbench or appropriate component reference that prices setup, route selection, transport, polynomial construction, every attempted solve, root extraction, point lifting and row/scalar work. Vector counters with different units are not equal-cost sums. A degree/cap result is not intrinsic regularity or time. The same source solver gets the new chart. No end-to-end or speed statement is planned without its complete matched accounting. [pcc:unverified]

## Required controls

False source/target/route, swapped base columns, a dependent row advertised as new rank, an omitted failed query, an omitted diagonal/tangent branch, an extra or missing root, a forged original-input witness, an uncharged second solve, a false public setup log and a false original scalar must be rejected by the appropriate independent checker. Rehash altered payloads, retain exact files/diagnostics and require no success receipt. Declare a null control only when its event truly does not exist, with the tested condition and intact bytes.

A/A uses identical source/chart and schedule. A synthetic coefficient-space complementarity fixture tests the metric only and must not be presented as an actual curve gain. A planted actual relation tests completeness without counting as an unseen-target yield result. Every old record imported must be pinned and labelled historical rather than fresh execution.

## Budget and outputs

At most two existing LOCAL workers; 600-second cap per build/proof/native command and one focused scientific window <=3600 seconds. No EKS, paid provisioning, AWS/auth probes, arbitrary result assets or credential reuse. Retain resource failures and exact unfinished coverage.

A future completed run must leave native records, all failed sources/attempts/controls, canonical export, hashes and deterministic reconstruction, faithful proof map/axiom audit, source-linked report/diagram/PDF, appropriate signed PCC claims and exact-head CI/review status. This PR changes no numeric benchmark, leaderboard or registry; canonical quantitative graphs stay unchanged because there is no new scientific data. [pcc:unverified]
