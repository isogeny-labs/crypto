## Algorithm and stopping rules

- Construct the same `E/K`, `C/F4`, `J`, map `h`, source `P`, and target `Q` in one public Magma 2.30-1 process. Verify `#E=2·8317`, primality of 8317, `8317P=O`, `h(P)≠0`, `8317h(P)=0`, and `h(Q)=7h(P)` as the fixture gate.
- Use a degree-at-most-two factor base on the genus-eight hyperelliptic target. For successive nonzero multiples `k h(P)`, factor the first Mumford polynomial. Accept a relation only if all factors have degree at most two and the sum of factor divisor classes exactly reconstructs `k h(P)`. Record unsuccessful smoothness and reconstruction attempts; never treat them as relations.
- Store each accepted relation as `sum e_i B_i = k h(P)`. Build the linear system over `F_8317`; accept factor-base logarithms only when the system is consistent and has full column rank. Cap relation attempts at the 8,316 nonzero subgroup elements. Record the number of encountered factor-base classes, accepted relations, rank, and all phase times. An incomplete rank is a censored attack arm. [pcc:unverified]
- Descend the mapped target by trying `h(Q)+j h(P)` for `j=0..8316`. Skip the identity class, which would turn the offset scan into a disguised exhaustive search. Accept only a nonzero degree-at-most-two decomposition using previously solved factor-base classes and exact Jacobian reconstruction. Recover `log_P(Q)=sum e_i log(B_i)-j mod 8317` and verify it on both `E` and `J`. If no such decomposition occurs, report a censored target-descent arm.
- Run an independently coded Pollard rho on the same `P,Q`, with deterministic partition and restarts and an explicit operation count. Verify its recovered scalar on `E`. Rho may use source negation if implemented explicitly; any baseline change must be recorded as an amendment.
