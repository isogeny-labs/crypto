## Mathematical equivalence

Let M be the 645-by-677 signed point-incidence matrix over F_ell, one row per source equation, all small and large point variables retained, and vectors a,b from public query labels (M l = a+b x). For consistent group equations, a target-only certificate exists exactly when there is y with M^T y=0 and b^T y nonzero. Then x=-a^T y/(b^T y), to be verified by [x]G=Q. If there is no such y, target not uniquely identifiable by this linear system; this is not an ECDLP hardness claim. Do not substitute LP-only cancellation for this test.

For any point column incident to exactly one live source row i, its equation in M^T y forces y_i=0. Remove that variable from all equations, and repeat; each removal is a unit pivot of the dual constraint system. Now any point of degree two, with signs s,t in rows i,j, enforces y_j=-st*y_i. The graph on surviving **source rows** with these signed edges is a different orientation from the LP graph on point columns. Each connected component either has consistent sign labels sigma_i relative to its root, giving y_i=sigma_i*z_C, or contains a sign conflict, forcing its entire component to zero because ell is odd. For consistent components, construct T with T[i,C]=sigma_i, zero elsewhere. T has disjoint nonempty column supports and is injective. Substituting y=Tz (zero on peeled rows) satisfies all peeled and degree-two equations; aggregate every remaining point constraint into C=M_remaining^T T by exact signed coefficient addition; retain d=T^T b and e=T^T a. This gives a bijection between ker(C) and ker(M^T), preserving a^T y, b^T y and original row identity. In particular target recovery is equivalent to C z=0, d^T z=1. A dual no-recovery certificate is C^T u=d, checked exactly. Neither a matching nor a full structural rank substitutes for exact modular rank or these certificates.

On this capture all 132 degree-two edges are in trees (no inconsistent component), hence impose 132 independent constraints after 65 singleton pivots. Exact rank decomposition: rank(M)=197+rank(C); rank([M b])=197+rank([C; d^T]). Thus no cancellation-space loss is hidden by the reduction. This is elementary elimination, not a novel graph theorem or an asymptotic improvement claim.
