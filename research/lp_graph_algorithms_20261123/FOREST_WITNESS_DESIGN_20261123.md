# Graph-IC: coefficient-aware forest cancellation witnesses (design and protocol)

Date: 2026-11-23 UTC. Owner PR: [#4988](https://github.com/isogeny-labs/crypto/pull/4988). This document proposes an **exact certificate generator**, not a speedup claim. [pcc:unverified]

## Why another graph stage?
The existing `GainDsu` in `src/cryptanalysis/large_prime_graph.rs` counts exact LP rank for canonical rows with at most two distinct nonzero LP columns. It does not return a linear combination of original rows whose LP coefficients cancel. A count of `R-rank(A_L)` cannot enter the small-factor-base solver without actual coefficient-bearing certificates. The existing `large_prime_filter` and `large_prime_filter_mst` generate complete relations, but their pivot and local MST policies should remain the controls.

## Forest/anchor construction (mathematical contract)
Work over **prime** subgroup-order field `F_ell`, not the coordinate field `F_p`. For each canonical input row `r_i`, maintain a forest of independent two-LP equations (edges) and at most one independent anchoring equation per forest component. An edge `a x_u + b x_v=0` between distinct components is added to the forest unless both components are already anchored; with both anchored it is already in the earlier row span and must be emitted as a dependent witness rather than used as a new tree pivot.

To reduce a new row, push each coefficient along the unique forest path to its component root. Along edge `a x_child+b x_parent=0`, remove coefficient `c` at the child by subtracting `(c/a)` times the edge. Maintain source-row coefficients simultaneously. The remainder is supported only at component roots. If an anchor exists in a root component, use its nonzero root remainder to cancel that coordinate; otherwise it remains a new independent direction. New rows therefore are either independent forest edges, independent component anchors, or dependent rows with **explicit** `w_i=1` and `Σ_j w_j A_L[j,*]=0`.

For a closed balanced cycle, all root remainders cancel. An unbalanced cycle first anchors its component; subsequent cycles become dependencies. A bridge between two **anchored** components is dependent even though it connects previously separate graph components; omitting this case would make `R-rank` too small. Zero LP rows produce unit witnesses. The rule also covers singleton rows. Exact row rank is `#forest edges + #anchors`; left-nullity is `R-rank`. This is the row-space frame-matroid basis representation, not ordinary unweighted cycle rank. Reject noncanonical inputs before altering state; prime modulus is the caller obligation.

Each emitted witness is a sparse vector over *input row positions*, not just an LP cycle ID. The consumer must reconstruct the small-factor-base coefficients, RHS, and original group relation from the source-row combination and independently verify replay before admitting it to linear algebra. No claim of useful factor-base rank follows from LP nullity alone.

## Bounds, control, falsification
The initial bounded reference implementation reconstructs forest paths by a deterministic traversal per input endpoint and per needed anchor. This deliberately has **no asymptotic improvement**: a conservative bound is `O(R(V+E) log(R+2) + L)` conservative ordered-map time with `O(R+V+E+L)` memory for `R` stream rows, `V` LP columns, `E` accepted forest edges and `L` total materialized witness coefficients (not counting temporary maps and field inversions). More precisely, charge actual traversal scans, field inversions, source-term writes and peak allocation. A future dynamic-tree/parent-potential design could reduce traversal but must be measured after materialization and source replay.

Correctness gate: independently recompute every witness over `F_ell`, require its new-row coefficient to be exactly one and its entire LP projection to vanish; cross-check independent row count with dense exact modular rank and existing `GainDsu` across seeded F3/F7/F1000003 random canonical streams. Include balanced cycles, unbalanced cycles, dual-anchored bridges, zero rows, singleton inputs, and malformed input refusal. A passing source-exact harness is not full root-crate qualification.

Performance gate (not yet authorized or executed): **same frozen authentic two-LP collector stream**, fixed curve and subgroup, same resource limits, compare this witness-producing arm to existing pivot and MST, including setup, traversal, inversions, output support, source provenance, duplicate removal, useful rank after projection, replay, peak memory and fallback. If no authentic stream is available, report blocked; synthetic comparisons cannot be promoted as Prime31 results. The reference arm is expected to be slower on some shapes; a null outcome is useful.

## A useful-rank statement (derivation, not a benchmark)

Let `A_L ∈ F_ell^{R×V}` be the canonical at-most-two-LP coefficient block. As rows are streamed, the independent forest/anchor choices give a basis of the *row space* because (i) a cross-component edge with at least one unanchored side contributes one independent root direction; (ii) an unanchored component's first unbalanced cycle or singleton contributes the unique new anchor direction; and (iii) the code treats every remaining root-cancellable row as dependent. By induction, the number of independent choices after any prefix is `rank(A_L[prefix,*])`.

For each dependent row `i`, the code emits a relation `w_i=e_i+Σ_{j<i} c_{ij}e_j` satisfying `w_i^T A_L=0`. The largest nonzero index is `i` with coefficient 1. Hence all such vectors are linearly independent, and their number `R-rank(A_L)` equals the full left-nullspace dimension. They are therefore an **exact basis** of `ker(A_L^T)`. This statement is algebraic and depends on prime `ell`, canonical arity≤2 inputs, and successful inverses; it does not depend on graph-cycle counts alone.

Consequently for the small-column block `A_S`, the span of all factor-base-only outputs is exactly `ker(A_L^T) A_S`, before source/weight caps or duplicate removal. Its dimension can be determined *after materialization* by exact modular rank; neither LP nullity nor structural matching bounds determine it a priori. The same witness basis also transports the RHS `b`, so inconsistency or target-coordinate uniqueness still requires the downstream finite-field system's own checks. The new toy test compares this projected rank with the existing pivot filter on identical canonical streams; a cap/refusal can reduce the admitted span and must be counted rather than silently ignored.

This is a verifiable mathematical correctness property, not an asserted faster forest algorithm. A dynamic-tree improvement is useful only if it reduces total path search plus source-materialization work on actual collector streams.
