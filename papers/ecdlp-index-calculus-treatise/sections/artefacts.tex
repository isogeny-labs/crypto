\chapter{Artefacts}\label{app:artefacts}

Every number in this treatise is copied from a committed artefact, or
derived from one by a script named in the caption, except the
Kummer-tower last fall degrees of \S\ref{sec:fd-pkm}, which are
session-reported (raw data not committed). The treatise ran one
re-verification (\S\ref{sec:fd-binary}) and no new measurement. Artefact
paths are relative to the \texttt{crypto} repository unless prefixed
\texttt{crypto-autoresearcher:} or \texttt{cryptanalysis:}. Each chapter
names its own sources; the lists below give the main directories per
part.

\paragraph{Figures.} The figures of the programme record and the ledger are
copied with their data (\art{figures/data-program.json},
\art{figures/data-ledger.json}); their plotting scripts live in those
papers' directories. The new figures (fall degrees, weak families) are
rendered by \art{figures/make_fig_fall_degrees.py} and
\art{figures/make_fig_weak.py} from \art{figures/data-new.json}. That file
holds recorded values only, each with its source.

\paragraph{Programme counts and cost model.} The tables and figures of the
introduction, Chapters~\ref{ch:model} and~\ref{sec:method}, and
\S\ref{sec:corr-archive} read three data files:
\art{figures/data-fm-glance.json} (counts by month and standing),
\art{figures/data-fm-opcost.json} (per-operation costs) and
\art{figures/data-fm-phases.json} (leaderboard phase shares). Each lists
its sources with the path at \texttt{origin/main} and the git blob or tree
hash, and states its counting rule; \art{figures/extract_fm_data.py}
regenerates them from a \texttt{crypto} checkout with \texttt{git show}
only. \art{figures/make_tab_fm.py} writes the
\texttt{tab-fm-*.tex} tables and computes every derived value (sums,
shares, ratios); \art{figures/make_fig_fm_glance.py},
\art{figures/make_fig_fm_opcost.py} and \art{figures/make_fig_fm_phases.py}
draw the figures. The scripts read only those JSON files.
