## Build and source package

From this directory, with a standard LaTeX distribution:

    make check
    make eprint

LaTeX errors and overfull boxes. The second creates an ignored PDF-plus-source
ZIP. The paper Makefile also locates the bundled paper.mk after standalone
extraction. Inspection and build outcomes are recorded in inspection.json.

was requested and is pending. For an author version, copy ../AUTHORS.example
