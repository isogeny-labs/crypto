\section{Catalogue of the programme's studies}\label{sec:catalogue}

This appendix lists every study directory under \art{research/} on \texttt{main} at the paper's date, every benchmark row under \art{benchmarks/}, every open-problem record under \art{problems/}, and the research notes and \art{docs/ic/} programme documents, 1444 entries in all, grouped by curve family. Campaigns of many directories are collapsed to one row, with every member path listed under it. Each row gives the study's own headline number with its class and status (the study's own class: \\emph{exponent vs own incumbent} is a change of exponent against the index-calculus incumbent, not the paper's \\cls{advance}); a number marked superseded or corrected must be read through the correcting path. Rows were compiled from each study's README and results files and are summaries, not re-measurements; where a study states no number, none is given. Generated tables (leaderboard rows, the registry) are summarised through \art{docs/ic/LEADERBOARD.md} rather than listed file by file. The machine-readable source is \art{papers/ecdlp-index-calculus-program/data/catalogue.tsv}, built by \art{papers/ecdlp-index-calculus-program/tools/catalogue.py}, which also checks that no directory is missing.
