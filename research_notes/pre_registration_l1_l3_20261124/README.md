# Pre-registered designs — L1, L2, L3 (2026-11-24)

**Leads:** L1, L2, L3 in `crypto-autoresearcher/docs/open-leads-20261123.md`.

This file is the **pre-registration**, not a result. Nothing below is evidence
until the frozen run is executed and the decision rule is applied. Freeze this
file at its merge commit; any change after the first target is generated is a
disclosed deviation.

Common conventions:

- All p-values are two-sided unless stated; multiplicity is controlled by Holm
  within each lead's family.
- Every random control must share the structured object's invariances
  (Gate B, G32 §3). The invariance is stated per lead.
- The null is generated before seeing the structured yields; the seed and the
  generator hash are recorded.
- A lead closes as a **recorded negative** if the primary endpoint fails the
  decision rule; a failed run is not silently rerun with new seeds.

## L1 — charter-signal follow-up cell 13/N3/m=4

**Record:** `crypto-autoresearcher/notes/g31-001-replication-20261121/RESULTS.md`.

**Hypothesis.** The pilot cell 13/N3/m=4 has a positive structured-base yield
effect (+2.2 pp, 9/10 signs, sign-test p=0.022) that survives a pre-registered,
negation-matched replication at a larger sample.

**Frozen cell.**

- Curve class: prime-order short Weierstrass curves, distinct j, generated by
  the frozen `g31-001` curve generator (same seed family), 25–30 curves per arm.
- Sizes: the 13-bit and N3 cells from the replication, plus the
  `N = floor(p^{1/4})` arm requested by L1.
- Base: the x-window structured base at `m = 4`.
- Targets: 2000 uniform targets per curve, fresh, shared across arms.
- Null: negation-closed random base of the same B-log size; 100 draws per cell.
- Primary endpoint: mean yield difference (structured − matched null) at
  `m = 4`, per cell, in percentage points.

**Decision rule.** Replicate only if (i) the 95% bootstrap CI for the primary
endpoint excludes 0, (ii) the sign test across curves has Holm-adjusted
`p < 0.05` over the pre-registered cell family, and (iii) the effect is at least
1.0 pp. Otherwise close as a recorded negative; the pilot's p=0.022 is not
re-used as evidence.

**Power/MDE.** With 25 curves and 2000 targets, the replication's observed
per-curve null-sd implies an MDE (80% power, two-sided 5%) of roughly 1.4 pp;
state the exact simulated MDE in the run record before looking at yields.

**Compute budget.** ≤ 20 minutes on one machine. Stop and record if exceeded.

## L2 — characteristic-2 defectivity arm

**Record:** `crypto-autoresearcher/research_goals_20261120_ic_blindspot_batch.md`
G31-001.

**Hypothesis.** The secant-dictionary span test has a characteristic-2 analogue:
subfield-vector-space bases show a measurable defect against a matched null.

**Frozen design.**

- Fields: `F_{2^n}` for `n = 8, 10, 12` (toy), one curve model per field
  (short Weierstrass over `F_{2^n}` with a prime-order subgroup).
- Structured arm: base = an `F_2`-subspace of dimension `d` inside the
  x-coordinate set, constructed by the char-2 analogue of the span test.
- Null: a random `F_2`-subspace of the **same dimension** that is
  Frobenius-stable to the same order. In characteristic 2, `−P = P`, so
  negation closure is vacuous; the exchangeable invariance is Frobenius
  stability / subfield membership, not negation. This is stated explicitly so
  the null is not accidentally weaker.
- Targets: 1000 per cell; `m = 2, 3`; 50 null draws per cell.
- Primary endpoint: defectivity = (observed span dimension − expected random
  span dimension) / expected, with the expected value computed from the same
  null ensemble.

**Decision rule.** Declare a char-2 defect only if the 95% CI excludes 0 in at
least one pre-registered cell after Holm correction and the effect exceeds the
simulated MDE. Otherwise close as a recorded negative: the char-2 analogue is
not established.

**Compute budget.** ≤ 25 minutes. Stop and record if exceeded.

## L3 — bounded-height supply measurement

**Record:** `crypto-autoresearcher/notes/g31-002-char0-barrier-20261121.md` §5.

**Hypothesis (to falsify).** No polylog-height budget reaches toy relation
rates; the required-height lemma's height bound is not beatable by a
Krumm-style enumeration at 20–24 bits.

**Frozen design.**

- Models: 2–3 explicit curve models at 20, 22, 24 bits (short Weierstrass,
  Edwards, Montgomery if available), each with a prime-order subgroup.
- Enumeration: Krumm-style bounded-height enumeration with height bound `H`,
  recording the number of points of height ≤ H, the relation count at `m = 3`,
  and the enumeration work (group operations).
- Budget ladder: `H = 2^h` for `h` in a pre-registered geometric ladder, up to
  the point where the run exceeds 20 minutes; record the last completed rung.
- Primary endpoint: relation rate (relations per target) at the largest
  completed height, versus the rate predicted by the required-height lemma.
- Decision: if **any** rung with polylog work (`work <= polylog(p)`) reaches the
  toy relation-rate threshold, the lemma is falsified and the rung is reported
  as a positive. Otherwise the lead closes as a recorded negative with the
  height/work curve.

**Compute budget.** ≤ 25 minutes total; each rung is independently stoppable.

## Artifacts required for each run

- Frozen config JSON with seed, generator hash, curve list, target list hash.
- Raw per-target counts (not just means).
- The null ensemble (seed + draws) and the analysis script hash.
- A `RESULTS.md` with exact commands, raw numbers, units, and a
  "what this does and does not establish" section.

## What these designs do not establish

They do not assert the pilot effects are real. They do not promote any toy
measurement above toy scope. They do not authorize a cryptographic-size claim
without the G30-003 protocol.
